id: general
name: 其他法律咨询
when: 不属于其他任何一类的法律问题，或者一个问题跨了好几类、一时难以归类。例如房屋租赁、婚姻家事和继承、交通事故、借贷担保、物业邻里、税务相关的法律问题、投资准入等。归类不清时先按本手册的通用方法处理，过程中发现明显属于某一类的，按那一类的方法补充。
examples:
  - 办公室房东要提前收回房子，我们能要什么赔偿
  - 借给朋友 20 万只有微信转账记录，能要回来吗
  - 公司股权在离婚时会被分割吗
  - 员工开公司车出了交通事故，公司要担责吗
  - 外资公司能不能做这个业务
  - 我父亲去世了没留遗嘱，房子怎么继承

## 先弄清的事实
| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 身份和目的 | 您是以公司还是个人身份问的？最想达成什么结果：预防风险、解决纠纷、要钱，还是了解规定？ | 决定站位和建议方向 | 是 |
| 事情经过 | 请按时间顺序说一下发生了什么：什么时候、谁、做了什么、现在到了哪一步？ | 法律分析建立在事实上，时间线决定时效和适用的法律版本 | 是 |
| 所在地 | 事情发生在哪个省市？对方在哪里？ | 地方性法规、管辖法院 | 是 |
| 书面材料 | 有合同、协议、收据、聊天记录、通知、判决等书面材料吗？能贴关键内容吗？ | 有约定先看约定；证据决定能不能主张 | 是 |
| 对方态度和已采取的行动 | 对方怎么说？双方谈过吗？有没有发过函、报过警、起过诉？ | 判断争议焦点和程序阶段 | 否 |
| 期限 | 有没有收到什么文书写了期限？离事情发生过了多久？ | 防止错过答辩、上诉、时效 | 否 |
| 金额 | 涉及多少钱？ | 影响路径选择（协商、小额诉讼、普通诉讼）和成本收益 | 否 |

## 工作步骤

1. **澄清事实，复述确认。** 用一两句话复述理解的事实和用户的目标。关键事实缺失时先问（3–6 个问题），用户希望先给初步意见的，基于明确列出的假设作答。
2. **识别法律关系。** 把事情拆成一个或几个法律关系，每个写清：主体（谁对谁）、类型（合同、侵权、物权、婚姻家庭、继承、劳动、行政、刑事……）、请求或抗辩（谁能向谁主张什么）。一个事实可能同时引出几种关系（例如员工开车撞人：受害人与公司之间的侵权关系、公司与员工之间的追偿关系、保险合同关系、交通行政处罚）。
3. **检查是否属于其他专门任务。** 涉及劳动用工、合同审查、被诉应对、起诉可行性、期限计算、主体调查、公司股权、数据合规、知识产权、行政监管、消费者纠纷、刑事风险的部分，按对应任务的方法处理，避免遗漏专门规则。
4. **按效力层级检索。** 法律 → 司法解释 → 行政法规 → 地方性法规（用户所在地）→ 指导性案例 → 办案指引。
   - 民事问题先从《民法典》对应编入手（总则编、物权编、合同编、人格权编、婚姻家庭编、继承编、侵权责任编），再查对应的司法解释（担保制度、合同编通则、婚姻家庭编、继承编、侵权责任编、物权编、总则编解释等，资料库均有收录）。
   - 用 search_law 检索，关键条文用 read_articles 读原文；用 find_law_by_title 和 law_outline 找到章节后系统阅读，不要只读一条。
   - 有约定的，先审约定是否有效（《民法典》第一百四十三条、第一百五十三条；格式条款第四百九十六条、第四百九十七条），有效的约定优先于任意性规定。
   - 按行为发生时的法律判断（民法典施行前的事实看时间效力规定）。
5. **分析。** 对每个法律关系：
   - 列出构成要件，逐项对照事实，标注"已有证据 / 需补证据 / 存疑"；
   - 列出对方可能的抗辩，客观评估——对方有道理的地方直说；
   - 看程序问题：诉讼时效（一般三年，自知道或应当知道权利受损和义务人之日起算，《民法典》第一百八十八条；中断事由第一百九十五条）、管辖、举证责任；
   - 算账：能主张的金额、成本（诉讼费、律师费、保全担保、时间）、能否执行到位。
6. **给建议。** 给出可选路径（协商、发函、调解、投诉、仲裁、诉讼、报警等），每条写优缺点和适用条件，推荐一个并说明理由；列出下一步具体动作和时间；需要的文书可以起草初稿（按文书起草的方法）。
7. **提示何时找律师。** 下列情况明确建议委托律师：已经进入诉讼仲裁或收到法律文书；涉及刑事风险；金额较大或对生活经营影响重大；事实复杂、证据关键且需要调查取证；涉及境外法律或港澳台；婚姻、继承中涉及较多财产和多方当事人。

## 必查依据
- 通用检索顺序：法律 → 司法解释 → 行政法规 → 地方性法规 → 指导性案例 → 办案指引。资料库不收录部门规章、地方政府规章和规范性文件，用到时说明。
- 常用的通用条文：
  - 民事法律行为效力：《民法典》第一百四十三条、第一百五十三条。
  - 诉讼时效：《民法典》第一百八十八条、第一百九十五条。
  - 违约责任：《民法典》第五百七十七条、第五百八十四条、第五百八十五条；不可抗力第五百九十条；合同解除第五百六十三条至第五百六十五条。
  - 侵权责任：《民法典》第一千一百六十五条。
  - 时间效力：《最高人民法院关于适用〈中华人民共和国民法典〉时间效力的若干规定》第一条、第二条。
- 常见专题的检索词（条号以资料库为准）：
  - 租赁：search_law「租赁合同 解除 出租人」「买卖不破租赁」「转租」。
  - 民间借贷：search_law「民间借贷 利率」「借贷 转账 证明」，限定司法解释，查民间借贷司法解释。
  - 担保：search_law「保证期间」「保证方式」，查《最高人民法院关于适用〈中华人民共和国民法典〉有关担保制度的解释》。
  - 婚姻财产与股权：search_law「夫妻共同财产 股权」，查婚姻家庭编及其解释，并结合公司法的股东资格规定。
  - 继承：search_law「法定继承 顺序」「遗嘱 形式」，查继承编及其解释。
  - 交通事故：search_law「机动车 交通事故 责任」「用人单位 工作人员 执行工作任务 侵权」。
  - 外商投资：search_law「外商投资 准入 负面清单」，查《外商投资法》及实施条例；负面清单本身是规范性文件，资料库可能未收录。
- search_guides「咨询分析」「法律检索路线图」「期限」，借用通用的咨询工作流程和期限计算方法。

## 地区差异
- 先判断问题是否受地方规定影响：房屋租赁（地方房屋租赁条例、登记备案）、物业管理（地方物业管理条例）、交通事故赔偿标准（按受诉法院所在地的统计数据）、户籍和社保相关事项，地区差异明显。用 search_law 按用户所在省检索地方性法规。
- 地方法院的裁判口径和赔偿计算标准（例如人身损害赔偿使用的当地统计数据）资料库没有收录，要明说并告诉用户去哪里查（当地高院公布的标准、统计年鉴）。
- 没有地区差异的问题（大部分合同、继承基本规则），不必硬写地区差异。

## 输出结构
1. **结论先行**：一句话回答 + 把握程度（较确定 / 有争议 / 取决于某个事实）。
2. **事实与假设**：列出基于哪些事实，哪些是假设。
3. **法律关系梳理**：谁对谁、什么关系、能主张什么。
4. **法律依据**：按层级列出，引用可点开的原文。
5. **分析**：要件对照、对方抗辩、时效与程序、金额测算（如有）。
6. **建议与下一步**：可选路径对比 → 推荐路径 → 具体动作和时间。
7. **需要补充的材料**。
8. **何时需要找律师**。

## 容易出错的地方
- 事实不清就下结论，或者把假设当事实。没问到的关键事实要列为假设。
- 只看一个法律关系，漏掉同一事实引出的其他关系（例如只讲侵权不讲保险，只讲民事不讲行政或刑事）。
- 忽略合同约定，直接套法律的默认规则。
- 不看时效、期限和程序，结论"有理"但已经主张不了。
- 只讲对用户有利的一面，回避对方的合理抗辩。
- 凭记忆引用条号，或引用旧法。所有条文都要回资料库核对。
- 把需要律师的复杂问题处理成"按以下步骤自己办就行"。
- 遇到境外、港澳台因素时，直接套用大陆法。应当指出法域问题，说明本回答只分析中国大陆法部分。
