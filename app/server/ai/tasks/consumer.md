## 先弄清的事实
| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 用户身份 | 您是商家还是消费者？ | 决定站位和建议方向 | 是 |
| 商品或服务 | 是什么商品或服务？是食品、药品、化妆品、普通商品，还是服务（培训、美容、健身）？ | 食品药品有专门的十倍赔偿规则；服务类常涉及预付款 | 是 |
| 交易方式 | 线上（哪个平台）还是线下？什么时候买的？价格多少？买了多少件？ | 网购有七日无理由退货；购买数量影响"合理生活消费需要"判断 | 是 |
| 问题是什么 | 对方具体主张什么问题：质量不合格、标签标识问题、宣传不实、隐瞒信息、过期，还是不想要了？ | 区分一般违约、欺诈、不符合食品安全标准，赔偿规则不同 | 是 |
| 对方主张 | 对方要求退款、换货、赔偿多少？依据是哪条？投诉到了哪里（平台、12315、市场监管、法院）？ | 判断主张是否有依据，以及应对渠道 | 是 |
| 证据 | 有订单、聊天记录、商品实物照片、宣传页面截图、检验报告、进货凭证吗？ | 欺诈和不符合标准都要证据；商家抗辩需要进货凭证和合规资料 | 是 |
| 对方购买特征（商家视角） | 对方买了多少？短时间内多次购买吗？同时投诉了很多商家吗？ | 判断是否超出合理生活消费需要、是否恶意索赔 | 否 |
| 商家合规情况 | 商品有合格证明、检验报告吗？进货渠道合法吗？标签哪里有问题？宣传语是谁写的？ | 商家能否抗辩"不影响安全且不误导""非明知" | 否 |

## 工作步骤

1. **定性：这是哪一种纠纷。** 不同类型请求权基础和金额差很多：
   - 一般质量问题、违约：退货、更换、修理、赔偿损失（《消费者权益保护法》第二十四条、第五十二条；《产品质量法》第四十条）。
   - 网购无理由退货：七日内无需理由（《消费者权益保护法》第二十五条）。
   - 经营者欺诈：退一赔三，增加赔偿不足五百元的按五百元（《消费者权益保护法》第五十五条第一款）。
   - 食品不符合食品安全标准：价款十倍或损失三倍，增加赔偿不足一千元的为一千元（《食品安全法》第一百四十八条第二款）。药品是假药劣药的，按《药品管理法》第一百四十四条第三款。
   - 明知缺陷仍提供造成死亡或健康严重损害：所受损失二倍以下的惩罚性赔偿（《消费者权益保护法》第五十五条第二款）。
   - 产品缺陷造成人身或他人财产损害：产品责任（《产品质量法》第四十一条；诉讼时效二年，第四十五条）。
   - 预付款、押金：按约定退还，经营者不得设置不合理条件（《消费者权益保护法实施条例》第二十条、第二十二条）。
2. **三倍赔偿（欺诈）怎么判断。** 欺诈要求经营者故意告知虚假情况或隐瞒真实情况，使消费者陷入错误认识而购买。核对：
   - 是否有虚假或引人误解的宣传、隐瞒重要信息（第八条知情权、第二十条真实信息义务）；
   - 商品服务的标签标识、说明书、宣传材料存在**不影响商品服务质量且不会对消费者造成误导的瑕疵**的，不适用三倍赔偿（《消费者权益保护法实施条例》第四十九条第一款）；
   - 通过夹带、掉包、造假、篡改生产日期、捏造事实等方式骗取赔偿或敲诈勒索的，不适用第五十五条第一款，依治安管理处罚法等处理（同条第二款）。
   - 只是违反广告法用语规定（如使用"最佳"），并不当然等于对消费者构成欺诈；要看是否真的误导了购买决定。但商家要知道，这仍可能招来行政处罚（《广告法》第九条第三项、第五十七条），两件事分开评估。
3. **十倍赔偿（食品）怎么判断。** 核对：
   - 是否属于"不符合食品安全标准"：限量、添加剂、营养成分、与卫生营养相关的标签说明书要求、质量要求等（《最高人民法院关于审理食品药品惩罚性赔偿纠纷案件适用法律若干问题的解释》第五条）。
   - 责任主体：生产者承担十倍不以明知为前提；经营者以"明知"为条件（《食品安全法》第一百四十八条第二款）。经营者有无进货查验、索证索票，是"明知"判断的关键。
   - 标签瑕疵的例外：标签、说明书存在不影响食品安全且不会对消费者造成误导的瑕疵，不适用（第一百四十八条第二款但书）。司法解释第六条至第八条区分了哪些抗辩法院支持、哪些不支持（例如字号字体不规范、错别字但不影响理解等可以抗辩），逐项对照。
   - 知假买假：购买者明知不符合食品安全标准仍购买，法院在**合理生活消费需要范围内**支持（同解释第十二条）；短时间多次购买的，按合理需要的总数支持（第十三条、第十四条）；恶意制造假象相要挟的，驳回并可能移送公安（第十五条、第十六条）。2021 年《最高人民法院关于审理食品药品纠纷案件适用法律若干问题的规定》第三条（不支持以"明知"抗辩）仍在资料库中，与 2024 年解释一并读，按新解释的"合理生活消费需要"口径分析。
4. **七日无理由退货。** 适用于网络、电视、电话、邮购方式销售，自收到商品之日起七日；法定除外商品（定作、鲜活易腐、在线下载或已拆封的音像制品计算机软件等数字化商品、交付的报纸期刊）和根据商品性质并经消费者确认不宜退货的（《消费者权益保护法》第二十五条）。要点：
   - 经营者不得擅自扩大不适用范围，要以显著方式提示（《消费者权益保护法实施条例》第十九条）；
   - 因检查商品必要拆封查验且不影响商品完好的，不能以拆封为由拒绝（《最高人民法院关于审理网络消费纠纷案件适用法律若干问题的规定（一）》第三条）；
   - 商家对除外商品自愿承诺无理由退货的，要遵守承诺（同规定第二条）。
5. **商家应对"职业索赔"的策略。** 客观评估，不要一概认为对方"恶意"：
   - 先核对对方主张是否真的成立（标签是否真有问题、宣传是否确实虚假）。成立的，尽早整改、下架问题商品，再谈赔偿金额。
   - 购买数量明显超出合理生活消费需要的，在诉讼中可以主张只在合理范围内支持。
   - 对方以投诉举报相要挟索要远超法定标准的金额，或有掉包、造假等行为的，保留证据，可以报警（《刑法》第二百七十四条敲诈勒索）。但对方依法投诉、起诉本身不是敲诈。
   - 行政投诉和民事索赔要分开处理：对 12315 或市场监管部门的投诉，按期回复，说明事实和整改情况；和解时注意和解协议写明一次性解决、撤回投诉。
   - 和解金额参考：对方在法院可能拿到的金额（考虑合理消费数量、标签瑕疵抗辩）+ 行政处罚风险 + 应诉成本。
6. **消费者视角的维权路径。** 协商 → 平台投诉 → 消费者协会调解 → 向市场监管部门投诉 → 仲裁或诉讼（《消费者权益保护法》第三十九条）。网购时平台不能提供销售者真实名称、地址、联系方式的，可以向平台要求赔偿（第四十四条）。虚假广告的，广告经营者、发布者也可能承担责任（第四十五条）。小额纠纷可以走小额诉讼程序。
7. **格式条款和店规。** "最终解释权归本店所有""签收即视为质量合格""拆封不退"等条款，可能因排除消费者权利而无效（《消费者权益保护法》第二十六条；《民法典》第四百九十七条；网络消费规定（一）第一条）。

## 地区差异
- 多数省市有消费者权益保护条例或实施办法，对预付卡、押金、退款期限、经营者告知义务有细化规定；用 search_law 按省份检索「消费者权益保护条例」「预付」。
- 各地法院对职业索赔的态度长期不一（有的严格限制，有的按合理消费量支持），2024 年食品药品惩罚性赔偿解释统一了"合理生活消费需要"的规则，但具体数量认定仍有地区差异。资料库没有地方裁判口径时要明说。
- 部分省市对单用途预付卡有专门地方性法规或规章（例如冷静期、资金存管），用户在相关地区的要查。

## 输出结构
1. **结论先行**：对方主张（或我方主张）能否成立、大概能支持多少（给计算：价款 × 倍数，与保底金额比较；数量超出合理需要的说明按什么数量算）。
2. **定性和依据**：属于哪一类纠纷，引用条文。
3. **抗辩或主张要点**：逐项列出，标注证据是否到位。
4. **金额测算表**：

   | 项目 | 计算 | 金额 | 依据 |
   |---|---|---|---|
   | 退还价款 | | | |
   | 惩罚性赔偿 | 价款 × 3 / × 10，或保底 | | |

5. **应对方案**：商家——整改、回复投诉、和解区间、诉讼预判、是否报警；消费者——维权路径、证据清单、投诉信或起诉要点。
6. **文书**：投诉回复函、和解协议、消费者投诉书（按需）。
7. **行政风险提示**（商家）：同一问题可能引发的行政处罚。

## 容易出错的地方
- 把三倍和十倍混用。十倍只适用于食品不符合食品安全标准（及药品法的专门规定），普通商品欺诈是三倍。
- 只要标签有问题就认定十倍成立。要看是否属于不影响食品安全且不误导的瑕疵，逐项对照司法解释第六条至第八条。
- 认为经营者对十倍赔偿负无过错责任。经营者要"明知"，生产者才不问明知。
- 认为"知假买假"一律不支持或一律支持。现行规则是在合理生活消费需要范围内支持。
- 把违反广告法的极限用语直接等同于欺诈。
- 认为拆封就不能退。必要的拆封查验不影响退货。
- 商家视角下把所有索赔者都定性为敲诈。依法投诉起诉不是敲诈，贸然报警或公开指责可能引火上身。
- 忽略行政投诉的回复期限和后续行政处罚风险，只盯民事赔偿。
- 用旧版食品安全法或旧消法司法解释的规则，没有核对 2024 年后的新规定。
