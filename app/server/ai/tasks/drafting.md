---
id: drafting
name: 文书起草
when: 用户要一份能直接发出、签署或公布的文书：催款函、解除或催告通知、异议函、回函、协商协议、股东会或董事会决议、授权委托书、承诺书、规章制度等。只问"能不能告""合同有没有问题"的不归这类；收到对方文书要应对的归被诉应对，起草只是其中一步时以应对为主。
examples:
  - 帮我写一封催款函，对方欠货款 30 万拖了半年
  - 供应商一直不交货，帮我起草解除合同通知
  - 写一份股东会决议，同意股东之间转让股权
  - 员工严重违纪，帮我写解除劳动合同通知书
  - 帮我起草一份公司考勤管理制度
  - 客户发函说我们违约，帮我写个回函
---

## 先弄清的事实
| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 文书用途 | 这份文书发出去（或签了）之后，您希望达到什么效果？要钱、解除合同、留证据，还是内部存档？ | 同样叫"函"，催款、解除、异议的法律效果完全不同，决定写法 | 是 |
| 双方主体 | 我方和对方的全称是什么？对方是公司的话，有统一社会信用代码或注册地址吗？ | 主体写错，函件可能无效或送达不到；起诉时也要用 | 是 |
| 事实经过 | 按时间说一下经过：什么时候签的合同、约定了什么、对方哪一步没做到、您催过几次？ | 函件只能写有证据的事实，时间线决定时效和解除权是否还在 | 是 |
| 依据材料 | 合同、订单、对账单、发票、聊天记录、之前的往来函件，手里有哪些？能贴关键条款吗？ | 要引用合同条款号、金额、期限；没有书面依据的要提醒补证据 | 是 |
| 具体要求 | 您要对方做什么？付多少钱（本金、违约金、利息分别多少）、几天内、付到哪个账户？ | 函件的要求必须具体、可执行，金额要能算清 | 是 |
| 送达方式 | 合同里有没有约定通知地址、邮箱或联系人？对方现在的实际经营地址在哪？ | 意思表示到达才生效，送达方式决定能不能证明对方收到 | 是 |
| 语气和后续打算 | 想保持合作还是准备撕破脸？如果对方不理，您打算起诉、仲裁还是先谈？ | 决定措辞强硬程度，以及要不要写明后续法律措施 | 否 |
| 以谁的名义发 | 以公司名义盖章发，还是委托律师事务所发律师函？ | 律师函只能由律师事务所出具；公司自己发的不能叫律师函 | 否 |
| 内部文书的程序 | （决议、制度类）公司章程怎么规定的？股东或董事几个人、持股多少？制度有没有经过职工代表大会或全体职工讨论？ | 决议、制度的效力取决于程序，不只是文字 | 否 |
| 所在地 | 公司在哪个省市？（劳动类文书问员工工作地） | 规章制度、劳动文书受地方规定影响 | 否 |

## 工作步骤

1. **先判断文书的法律性质，再动笔。** 起草前在心里把文书归入下面一类，归类决定写法：
   - **单方意思表示类**（解除通知、催告通知、撤销通知、抵销通知、异议通知、拒绝履行通知）：到达对方才生效（《民法典》第一百三十七条），内容一经到达就产生法律效果，写错很难撤回。重点是"权利是否真的存在""表达是否明确无歧义"。
   - **主张权利、留痕类**（催款函、对账函、索赔函）：主要作用是向义务人提出履行请求、中断诉讼时效（《民法典》第一百九十五条）、固定对方的确认或沉默。重点是金额算清、能证明送达。
   - **双方协议类**（协商解除协议、和解协议、补充协议、还款承诺书）：要写明权利义务、履行期限、违约后果、争议解决，并防止"一次性了结"条款把我方其他权利也放弃了。
   - **公司内部决议类**（股东会、董事会决议）：效力取决于召集程序和表决比例，文字再漂亮，程序不合法也可被撤销或认定不成立（《公司法》第二十五条至第二十七条）。
   - **内部制度类**（规章制度、员工手册）：对员工有约束力的前提是经过民主程序并公示（《劳动合同法》第四条），起草时要附上程序操作清单。
   - **授权、承诺类**（授权委托书、承诺书、保证书）：重点是授权范围和期限、承诺的条件和责任上限。
2. **确认发这份文书的前提成立。** 不要用户说"帮我写解除通知"就直接写。先核对：
   - 解除合同：有没有约定解除事由，或者符合法定解除情形（《民法典》第五百六十三条）？迟延履行的，是否已经催告且合理期限届满？解除权有没有过期（第五百六十四条：知道解除事由起一年内不行使或经催告后合理期限内不行使即消灭）？解除权不成立时发出解除通知，自己可能反成违约方——这一点必须直说。
   - 催款：债权是否到期？有没有超过三年诉讼时效（第一百八十八条）？已经超过的，催款函仍可发，但要争取对方书面确认或还款承诺，而不是指望函件本身恢复时效。
   - 劳动解除：解除理由是否属于法定情形、证据是否充分（这部分按劳动用工手册判断）；单方解除前须事先通知工会（《劳动合同法》第四十三条）。
   - 股东会决议：事项属于股东会职权吗（《公司法》第五十九条）？会议是否提前十五日通知（第六十四条，章程或全体股东另有约定的除外）？表决比例够不够（第六十六条：一般事项过半数表决权，修改章程、增减资、合并分立解散、变更公司形式须三分之二以上表决权）？
   前提不成立或拿不准时，先告诉用户风险和替代做法（例如先发催告函，期满后再发解除通知），再按用户选择起草。
3. **找依据。** 每份对外文书至少写清一个依据：合同条款（写条款号和原文要点）或法律条文。法律条文只引用与本事最直接的一两条，引用前用 read_articles 核对原文，不要堆砌。
4. **整理事实。** 只写有证据支撑的事实，按时间顺序，日期、金额、单号具体到能核对。避免：
   - 自认对我方不利的事实（例如"虽然我方也晚交了两周"）；
   - 情绪化评价（"恶意拖欠""毫无诚信"可以少用，换成事实描述）；
   - 和后续主张矛盾的表述（例如函里说"合同已解除"，又要求对方"继续履行"）。
5. **写清要求和期限。** 要求要可执行：金额分本金、违约金、利息，写明计算方式和截止日；履行期限写"自收到本函之日起 X 日内"或具体日期；写明收款账户或履行方式；写明逾期后果（"我方将依法提起诉讼/申请仲裁，并主张由此产生的律师费、诉讼费等费用"——律师费能否由对方承担取决于合同约定，没有约定的不要写成"必然由贵方承担"）。
6. **合规检查。** 发出前过一遍：
   - 有没有以曝光、举报、向其客户散布等相威胁，换取超出合法债权的利益？这类表述可能构成敲诈勒索（《刑法》第二百七十四条），必须删除。依法向主管部门投诉、举报本身可以，但不要和索要金额绑定。
   - 有没有对第三方（对方客户、行业群）散布未经证实的负面信息？可能侵害名誉权（《民法典》第一千零二十四条）。
   - 公司自己发的函不能自称"律师函"，也不要冒用律师事务所名义。
   - 涉及员工、客户个人信息的，只写必要信息。
7. **送达与留痕。** 给出送达建议：
   - 首选合同约定的通知地址和方式；合同约定了电子邮箱或指定系统的，数据电文进入该系统时生效（《民法典》第一百三十七条）。
   - 没有约定的，用 EMS 寄到对方注册地址和实际经营地址，面单"内件品名"写明文件名称（例如"解除合同通知书"），保留底单、妥投记录和寄出文件的复印件；同时可通过微信、邮件发送扫描件并截图留存。
   - 重要通知（解除、撤销、劳动解除）建议多渠道同时送达；争议大的可以考虑公证送达。
   - 劳动解除通知要让员工签收；拒签的，按劳动合同约定的送达地址邮寄，并保留证据。
8. **出稿并标注待确认项。** 草稿里用【 】标出需要用户填写或核对的内容（名称、金额、日期、账号），文后列"使用前请核对"清单。

## 必查依据
- 检索顺序：先读用户提供的合同条款 → 法律 → 司法解释 → 行政法规 → 地方性法规（劳动制度类查用户所在地）→ 办案指引。
- 建议检索词：
  - 解除通知：search_law「解除合同 通知 到达」「解除权 行使期限」；read_articles《民法典》第五百六十三条、第五百六十四条、第五百六十五条。
  - 催款：search_law「诉讼时效 中断 履行请求」；read_articles《民法典》第一百八十八条、第一百九十五条；违约金查第五百八十五条，损失赔偿查第五百八十四条。
  - 支付令（对方无争议只是不付钱时可以在函里提示）：《民事诉讼法》第二百二十五条、第二百二十七条。
  - 意思表示生效：《民法典》第一百三十七条。
  - 公司决议：《公司法》第二十五条至第二十七条（无效、可撤销、不成立）、第五十九条（股东会职权）、第六十四条（通知）、第六十六条（表决比例）、第七十三条（董事会表决）。
  - 劳动类：《劳动合同法》第四条（规章制度）、第四十三条（通知工会）、第五十条（解除证明、交接）。解除理由本身按劳动用工手册去查。
  - 格式条款（起草用户协议、标准合同时）：《民法典》第四百九十六条、第四百九十七条。
- search_guides：「律师函起草」「催款」「解除通知」「股东会决议」「规章制度 民主程序」「和解协议」，办案指引里有成型的文书结构可参考。

## 地区差异
- 规章制度的民主程序：各地对"职工代表大会""全体职工讨论"的组织方式、公示方式有地方条例和裁审口径，起草制度时用 search_law 按用户所在省检索「职工代表大会」「规章制度」地方性法规；资料库没有地方裁审口径的，要明说"各地法院对公示方式的认定标准不一，建议保留员工签收记录"。
- 劳动解除通知、经济补偿计算受地方规定影响，按劳动用工手册的地区处理。
- 律师费、保全费能否由败诉方承担，主要看合同约定，各地法院对没有约定时的支持程度不同，不要写成确定结论。
- 其他商事文书基本没有地区差异。

## 输出结构
1. **一句话说明**：这份文书是什么、发出后会产生什么效果、发之前要满足什么前提（前提有问题的放在最前面，标"注意"）。
2. **文书正文**（可直接复制使用）。常见结构：
   - 催款函：标题 → 致（对方全称）→ 事实（合同名称及签订日、我方已履行情况、对方应付金额及到期日、已催告情况）→ 依据（合同条款、法律）→ 要求（金额分项、期限、账户）→ 逾期后果 → 落款（公司全称、盖章、日期、联系人）→ 附件清单。
   - 解除合同通知：标题 → 致 → 合同基本信息 → 解除事由（对应约定或法定解除情形、催告及期满事实）→ 明确表示"自本通知到达之日起解除"或"如于 X 日前仍未履行，合同自该日届满时解除" → 解除后的处理（结算、返还、违约责任主张，明确保留追究违约责任的权利）→ 落款 → 附件。
   - 劳动合同解除通知书：员工信息 → 解除依据（具体事实 + 规章制度条款或法律条款）→ 解除日期 → 工资结算、经济补偿（如有）→ 工作交接和证明出具 → 送达签收栏。
   - 股东会决议：公司名称 → 会议时间、地点、召集人、通知情况 → 出席股东及其表决权比例 → 逐项决议内容及表决结果（同意、反对、弃权的表决权比例）→ 股东签字或盖章 → 日期。
   - 规章制度：总则（目的、依据、适用范围）→ 具体规则 → 违纪情形分级及处理 → 民主程序与公示说明 → 生效日期。
3. **使用前请核对**：列出【 】中的待填项和需要用户确认的事实。
4. **送达与留痕建议**：具体到用什么方式、保存什么凭证。
5. **风险提示**：前提不成立的风险、对方可能的反驳、何时建议让律师审阅或以律所名义发函（金额大、准备起诉、对方已委托律师）。

## 容易出错的地方
- 不核对前提就写。解除权不存在时发出解除通知、债务未到期就催款、决议事项超出股东会职权，文书越"专业"后果越严重。先判断再写。
- 编造事实或合同条款。用户没给的日期、金额、条款号一律用【 】留空，不要补全。
- 把公司发的函写成"律师函"，或者落款写某律师事务所。
- 一份函件里主张相互矛盾的请求（既解除又要求继续履行；既说对方违约又承认我方先违约）。
- 金额前后不一致，或违约金、利息算法不清。违约金过高的，对方可以请求调整（《民法典》第五百八十五条），函里写明计算依据比写一个大数字更有用。
- 期限写成"尽快""近日"，或者没写起算点。
- 威胁性措辞（曝光、举报、影响征信、找对方领导）与索要金额挂钩。
- 劳动解除通知只写"严重违反规章制度"不写具体事实和条款；解除理由写定后，仲裁中通常按通知载明的理由审查，后补理由很难被采纳，所以要一次写全。
- 规章制度只给条文，不提醒民主程序和公示，导致制度对员工没有约束力。
- 股东会决议漏写出席情况和表决比例，或者用"全体股东一致同意"掩盖实际没开会——没开会的决议可能被认定不成立（《公司法》第二十七条），全体股东书面一致同意的要按章程和公司法规定的方式签署。
- 忽略送达：草稿写得再好，对方不认收到就没有效果。每份对外文书都要附送达建议。
