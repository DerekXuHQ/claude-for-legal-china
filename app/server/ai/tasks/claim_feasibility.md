## 先弄清的事实

能不能告是法律问题，值不值得告是经济问题。两方面的事实都要问。

| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 想要什么 | 您最终想要什么结果：拿回钱、对方继续履行、解除合同、赔礼道歉？金额多少？ | 决定请求和路径 | 是 |
| 法律关系 | 你们之间是什么关系？签了什么合同（书面、口头、订单、聊天确认）？ | 找请求权基础 | 是 |
| 债权凭证 | 有合同、订单、送货单签收、对账单、发票、欠条、结算单、聊天记录、付款记录吗？ | 证据链是否完整，尤其是对方确认欠款的证据 | 是 |
| 对方主体 | 对方是公司还是个人？全称、统一社会信用代码或身份证信息？ | 列明被告是起诉条件；查偿债能力 | 是 |
| 时间线 | 应当付款或履行的日期？最后一次催款是什么时候、怎么催的？对方最近一次承认欠款或部分付款是什么时候？ | 诉讼时效 | 是 |
| 对方的抗辩 | 对方为什么不付？有没有提过质量异议、说我方违约？ | 预判争议焦点 | 是 |
| 担保 | 有没有保证人、抵押、质押、保证金？ | 增加回收渠道；保证期间可能已过 | 是 |
| 争议解决条款 | 合同约定了管辖法院或仲裁吗？ | 决定去哪里告 | 视情况（有合同时要问） |
| 对方财产情况 | 知道对方有哪些财产吗（账户、房产、车辆、应收账款、股权）？对方还在正常经营吗？ | 赢了能不能拿到钱 | 是 |
| 我方是否有瑕疵 | 我方有没有没履行完的义务、交付问题、迟延？ | 对方可能反诉或抗辩 | 是 |
| 预算与时间 | 能接受多少成本、多长时间？ | 路径选择 | 否 |

## 工作步骤

### 1. 请求权基础

把用户想要的结果翻译成法律请求，找到依据：

| 想要的 | 请求权基础 | 构成要件 |
|---|---|---|
| 支付货款、服务费、租金 | 合同约定的付款义务；《民法典》第五百七十七条、第五百七十九条（金钱债务的履行请求） | 合同成立有效、我方已履行、付款条件成就、对方未付 |
| 逾期付款损失 | 合同约定的违约金或利息；没约定的，主张逾期付款损失（按 LPR 标准计算，以资料库规定为准） | 逾期事实、计算基数与期间 |
| 赔偿损失 | 第五百八十四条（可得利益，不超过订约时可预见的损失）；合同编通则解释第六十条至第六十三条 | 违约、损失、因果关系、可预见性 |
| 解除合同、返还 | 第五百六十三条、第五百六十六条 | 解除事由、解除通知到达 |
| 借款本息 | 借款合同；民间借贷司法解释 | 借贷合意 + 款项交付；利率不超过 LPR 四倍 |
| 侵权赔偿 | 第一千一百六十五条及特别规定 | 侵权行为、损害、因果关系、过错 |
| 向股东、关联方追 | 《公司法》第二十三条（人格否认）、第五十四条（未届期出资加速到期）、第八十八条（转让未届期股权）；公司法解释（三）第十三条、第十四条（未出资、抽逃出资） | 视具体情况，见第 5 步 |
| 代位追偿 | 《民法典》第五百三十五条（代位权）、第五百三十八条、第五百三十九条（撤销权） | 债务人怠于行使到期债权；无偿或低价处分财产 |

### 2. 诉讼时效

- 一般 3 年，自权利人知道或应当知道权利受损害以及义务人之日起算（《民法典》第一百八十八条）。分期履行的从最后一期履行期限届满起算；未约定履行期限的，按《最高人民法院关于审理民事案件适用诉讼时效制度若干问题的规定》第四条确定。
- 中断事由：权利人提出履行请求、义务人同意履行、提起诉讼或申请仲裁等（第一百九十五条）；义务人分期履行、部分履行、提供担保、请求延期、制定清偿计划的，属于同意履行（时效规定第十四条）。中断后重新计算 3 年。
- 已过时效的：债务人可以拒绝履行；但债务人在催款通知上签字盖章、同意履行的，不得再以时效抗辩（第一百九十二条）。可以尝试取得对方重新确认。
- 保证期间：没约定的为主债务履行期届满之日起 6 个月，期间内没有向保证人主张（连带保证）或起诉债务人（一般保证）的，保证人免责（第六百九十二条、第六百九十三条）。这一点经常被忽略，要单独算。
- 劳动争议仲裁时效 1 年。
- 计算细节转 deadline 的方法，结论放在报告前部。

### 3. 证据链

按要件逐项对应证据：

| 待证事实 | 已有证据 | 证明力 | 补强办法 |
|---|---|---|---|
| 合同关系 | 合同、订单、聊天确认 | | 无书面合同的，用往来记录、付款记录、发票还原 |
| 我方已履行 | 送货单签收、验收单、物流记录、服务记录 | | 签收人是否有权代表对方 |
| 欠款金额 | 对账单、结算单、欠条、对方承认的聊天 | | 发对账函请对方确认 |
| 催款记录 | 函件、快递单、聊天 | | 继续书面催款，保存寄送凭证 |

常见补强：发对账函或催款函（同时中断时效）；聊天记录要能对应到对方身份（实名、头像、与合同联系人一致）；录音要能听清并说明谈话对象；必要时公证或可信时间戳。

### 4. 对方偿债能力

- 让用户本人查官方页面（不在后台自动查）：国家企业信用信息公示系统（存续状态、经营异常、注册资本与实缴、股东）、中国执行信息公开网（被执行人、失信、限高、终本案件）、中国裁判文书网和人民法院公告网（涉诉）。查完把结果贴回来。
- 对方已有大量终本案件、失信、注销或吊销的，回收可能性低，要直说；考虑是否有股东、关联方、保证人可以追。
- 财产保全：起诉前或起诉时申请冻结对方财产（《民事诉讼法》第一百零三条、第一百零四条），需要提供担保（可用保险公司保全保函）。对方有财产但可能转移的，保全是关键。

### 5. 追加责任人

公司没钱时，检查能否追到其他人：
- 股东未届出资期限：公司不能清偿到期债务的，债权人可要求其提前缴纳（《公司法》第五十四条）。
- 股东未实缴、抽逃出资：在未出资本息范围内补充赔偿（公司法解释（三）第十三条、第十四条）。
- 转让未届期股权：受让人承担缴纳义务，转让人补充责任（《公司法》第八十八条）。
- 人格混同、过度支配：股东连带责任（《公司法》第二十三条），证明难度大。
- 一人公司股东不能证明公司财产独立于自己财产的，连带责任（《公司法》第二十三条第三款）。
- 未依法清算即注销：清算义务人的责任（《公司法》第二百三十二条及相关规定）。
- 保证人、抵押物。

### 6. 路径选择

| 路径 | 适用 | 优点 | 缺点 |
|---|---|---|---|
| 协商 + 书面催款 / 律师函 | 所有情形的第一步 | 成本低、中断时效、留证据 | 对方可能借机转移财产 |
| 支付令 | 金钱债务、债权债务关系明确、无对待给付、能送达（《民事诉讼法》第二百二十五条） | 快、费用低 | 对方书面异议即失效，转诉讼 |
| 小额诉讼 | 简单金钱给付、标的额在当地上年度就业人员年平均工资 50% 以下（第一百六十五条） | 一审终审、快 | 无上诉 |
| 普通诉讼 | 多数情形 | 全面审理 | 时间长（一审通常数月，加二审更久） |
| 仲裁 | 有有效仲裁协议 | 一裁终局、保密 | 费用通常高于诉讼 |
| 劳动仲裁 | 劳动争议 | 前置程序、不收费 | 时效 1 年 |
| 申请破产 / 申报债权 | 对方资不抵债 | 公平受偿，可以追究管理人、股东责任 | 回收率通常低 |
| 刑事报案 | 合同诈骗、职务侵占等真正的犯罪线索 | 有威慑力 | 不能把民事纠纷包装成刑事；公安不受理纯经济纠纷 |

管辖：合同纠纷由被告住所地或合同履行地法院管辖（《民事诉讼法》第二十四条）；给付货币的，未约定履行地的以接收货币一方所在地为履行地（民诉法解释第十八条）——往往可以在我方所在地起诉。有协议管辖的从约定（第三十五条）。

### 7. 成本收益

- 诉讼费按标的额累进计算（以《诉讼费用交纳办法》为准，资料库可能没有；不写具体数字时说明按标的额计算）；保全费、保全担保费、律师费（一般由各方自负，合同约定由违约方承担的可以主张）、鉴定费。
- 时间成本、管理成本、客户关系。
- 回收预期：胜诉可能 × 可执行可能 × 金额 - 成本。给出高、中、低三种情形。

### 8. 建议

给出明确建议：立即起诉并保全 / 先发函、限期付款后起诉 / 先补证据 / 不建议起诉（说明原因，例如时效已过、证据不足、对方无财产）。需要时附催款函或律师函草稿：事实（合同、履行、欠款金额）→ 依据 → 要求（限期支付本金及违约金）→ 不付的后果（起诉、保全、主张律师费）→ 联系方式。函件用 EMS 寄送到合同地址，快递单写明「催款函」，保存回执。

## 地区差异

- 小额诉讼标的额上限、诉讼费减免、律师费是否支持、保全担保要求，各地不同。
- 一些地区法院对诉前调解有强制或引导要求，起诉后先转诉前调解。
- 资料库里没有当地法院的执行和保全指引时，明说并建议向立案庭咨询。

## 容易出错的地方

- **只看有没有道理，不看能不能拿到钱**。对方无财产的，判决只是一张纸。
- **漏算保证期间**。保证期间不中断、不中止，比诉讼时效更容易过。
- **证据只有转账记录就认为借贷关系一定成立**。对方可能主张是还款、货款或其他往来，要看能否证明借贷合意。
- **夸大胜诉可能**。对方的合理抗辩（质量问题、我方迟延）要说清楚。
- **建议用刑事报案解决经济纠纷**。只有确有犯罪线索时才提，并说明公安可能不立案。
- **忽视管辖条款**。有仲裁条款的去法院起诉会被驳回。
- **写具体诉讼费、律师费数字**。没有资料库依据的只写计算方式。
- **催款函措辞过激**，出现威胁、恐吓或泄露对方隐私的内容，可能被反诉或引来行政责任。
