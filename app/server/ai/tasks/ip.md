## 先弄清的事实
| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 权利类型和我方角色 | 是商标、专利、版权、软件还是商业秘密？您是想申请或使用、被指控侵权，还是要去维权？ | 三种角色的工作方法完全不同 | 是 |
| 标识或对象本身 | 商标的确切文字（中文、拼音、英文）、有没有图形？专利的话，专利号是多少？作品或技术具体是什么？ | 近似判断、权利范围都要看具体对象 | 是 |
| 商品或服务 | 这个品牌用在什么商品或服务上？实际卖什么、怎么卖（线上、门店）？ | 商标按商品服务类别保护，决定要查哪些类别 | 是 |
| 使用情况 | 什么时候开始用的？在哪些地方用？有销售记录、宣传材料吗？ | 在先使用、有一定影响、三年不使用等判断都依赖使用证据 | 是 |
| 注册或权利状态 | 已经申请或注册了吗？申请号或注册号、类别、状态？对方的注册号或专利号？ | 状态决定权利是否存在、是否稳定 | 否 |
| 对方信息 | 对方是谁？对方发来的函件、投诉通知、起诉状能贴一下吗？ | 判断对方主张的依据、期限和真实意图 | 否 |
| 平台和证据 | 侵权发生在哪个平台、哪个店铺链接？截图、购买记录、公证了吗？ | 维权路径和证据固定 | 否 |
| 时间节点 | 侵权行为是什么时候开始的？您什么时候知道的？ | 诉讼时效、商标法新旧版本适用 | 否 |
| 合同安排（权属问题） | 有没有委托开发、劳动合同、合作协议？关于知识产权归属怎么约定的？ | 权属首先看合同 | 否 |

## 工作步骤

### 0. 先确认用哪一版商标法
《商标法》2026 年全面修订，2027-01-01 起施行，条号整体重排。资料库里两版都有：现行有效的 2019 年修正版，和"尚未生效"的 2026 年修订版。
- 2026-12-31 前发生的注册、异议、无效、撤销、侵权等事项，适用 2019 年版；2027-01-01 起发生的适用新版；跨期行为按行为发生时的法律判断，衔接规则以施行后的配套规定为准。
- 引用商标法时写明版本，例如"《商标法》（2019 年修正）第五十七条"。需要新旧对照时 read_guide「商标法（2026年修订）全文及新旧条号对照」，或用 compare_versions。
- 下文条号均为 2019 年版。

### A. 商标能不能注册、能不能用（清除检索）
1. **固有障碍。** 看标志本身：是否属于禁止使用的标志（第十条，如与国名国旗等相同近似、带有欺骗性容易使公众对质量产地产生误认、有不良影响，以及县级以上行政区划地名），是否缺乏显著性（第十一条：仅为通用名称或直接描述质量、原料、功能），是否属于不以使用为目的的恶意申请（第四条）。
2. **确定要查的类别。** 根据实际商品服务，对应《类似商品和服务区分表》（尼斯分类）的类别和类似群。列出：
   - 核心类别（实际使用的商品服务所在类）；
   - 关联类别（例如奶茶品牌：第 43 类餐饮服务、第 30 类茶饮咖啡、第 32 类饮料，常见还有第 35 类广告销售、第 29 类）；
   - 防御类别（视预算建议）。
   类别对应关系拿不准的，说明"以区分表为准"，不要硬写类似群编号。
3. **给用户一份检索清单。** 商标近似检索系统不能自动查询，告诉用户自己查：
   - 打开国家知识产权局商标局"商标网上查询"（wcjs.sbj.cnipa.gov.cn），选"商标近似查询"。
   - 逐个类别输入检索要素：①完整商标文字；②去掉通用描述词后的显著部分（如"小鹿森林"查"小鹿"）；③同音、近音字；④形近字；⑤拼音；⑥英文翻译或对应外文；⑦有图形的，按图形要素查（可以在系统里查图形要素编码）。
   - 同时用"商标综合查询"按申请人名称查对方或自己的已有商标。
   - 查完把结果（商标、注册号、类别、申请人、状态）截图或复制贴回来。
   - 另外建议在国家企业信用信息公示系统查同名字号，在常用电商平台、应用商店、域名注册商查同名使用情况（企业名称和未注册的在先使用也可能构成障碍，第三十二条）。
4. **分析用户贴回的结果。** 对每个可能冲突的在先商标逐项标注：
   - 商品服务是否相同或类似（从功能、用途、生产部门、销售渠道、消费对象判断，区分表是参考，见《最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释》第十一条、第十二条）；
   - 标志是否近似（音、形、义、整体印象，以相关公众一般注意力为标准，隔离比对，见同解释第九条、第十条）；
   - 在先商标状态：已注册、初审公告中、申请中、已无效或注销；注册满三年的，是否可能因连续三年不使用被撤销（第四十九条第二款）；
   - 在先商标知名度、是否涉及驰名商标跨类保护（第十三条）。
   结论只能是"本次初检发现以下风险"，**绝不能说"无冲突""可以放心注册"**——初检不等于清除法律意见，审查结果和对方异议都无法预测。
5. **申请策略。** 一份申请可以申请多个类别（第二十二条）；同类商品近似商标先申请者优先（第三十一条），所以要尽早申请；有冲突的考虑改标、加显著要素、对在先商标提撤三申请、或谈转让与共存。注册商标有效期十年（第三十九条），到期前十二个月内续展，有六个月宽展期（第四十条）。

### B. 被指控商标侵权
1. **先看对方权利。** 让用户在商标网查对方注册号：是否有效、核定商品是什么、注册多久、权利人是否与发函人一致。注册商标专用权以核准注册的商标和核定使用的商品为限（第五十六条）。
2. **侵权构成。** 对照第五十七条逐项：同一种商品相同商标、同一种或类似商品近似商标且容易混淆、销售侵权商品、伪造标识、反向假冒、帮助侵权等。
3. **抗辩点。**
   - 正当使用：通用名称、直接描述质量功能、地名（第五十九条第一款）；
   - 在先使用：对方申请注册前我方已在同种或类似商品上使用并有一定影响，可在原使用范围内继续使用（第五十九条第三款）；
   - 对方未使用：注册人不能证明此前三年实际使用、也不能证明其他损失的，不承担赔偿（第六十四条第一款）；
   - 合法来源（销售者）：不知道是侵权商品、能证明合法取得并说明提供者的，不承担赔偿（第六十四条第二款）——仍要停止销售；
   - 对方商标效力：违反第四条、第十条、第十一条等的可随时请求宣告无效（第四十四条）；侵犯在先权利、恶意抢注的，自注册之日起五年内可请求宣告无效，恶意注册的驰名商标所有人不受五年限制（第四十五条）；连续三年不使用可申请撤销（第四十九条第二款）。
4. **评估赔偿敞口。** 赔偿按实际损失、侵权获利、许可费倍数确定，恶意侵权情节严重的可以适用惩罚性赔偿（第六十三条）；具体适用看《最高人民法院关于审理侵害知识产权民事纠纷案件适用惩罚性赔偿的解释》（2026 年）。
5. **应对建议。** 对方证据扎实的，尽早停止使用、清理库存、谈和解，避免被认定为恶意；对方权利有瑕疵的，可以同步提出无效或撤销申请作为谈判筹码。回函不要轻易承认侵权，也不要拒不回应。

### C. 我方维权
1. **确认权利基础和证据。** 注册证、核定商品、使用证据；侵权证据用公证购买、可信时间戳、平台订单截图固定。
2. **评估侵权构成**（同 B 第 2 步），并预判对方可能的抗辩。
3. **选择路径。** 平台投诉（快，适合电商）；发警告函（措辞以事实和权利为限，不要以刑事追究相威胁；向对方客户、平台以外的第三方散布侵权指控要慎重，可能构成商业诋毁）；行政投诉，市场监管部门可责令停止、没收、罚款（第六十条）；民事诉讼，可以申请诉前禁令、财产保全（第六十五条）和证据保全（第六十六条）；假冒注册商标情节严重的可能构成犯罪（《刑法》第二百一十三条、第二百一十四条），可以向公安报案。
4. **成本收益。** 说明各路径的时间、费用、能拿到什么（下架、赔偿、刑事追责），推荐组合。

### D. 专利问题
1. **查专利状态。** 让用户在国家知识产权局"专利检索及分析"系统或"中国及多国专利审查信息查询"中输入专利号，查：专利类型（发明、实用新型、外观设计）、授权公告文本、权利要求、法律状态（是否有效、是否缴年费）、申请日。这些系统需要登录，不能自动查，查完把权利要求书和法律状态贴回来。
2. **保护范围。** 发明和实用新型以权利要求为准，说明书和附图用于解释（《专利法》第六十四条）；外观设计以图片或照片为准。侵权判断用"全面覆盖"思路：被诉产品是否包含权利要求的全部技术特征（相同或等同）。逐项列特征对比表。
3. **抗辩。** 现有技术或现有设计抗辩（第六十七条）；先用权、权利用尽等不视为侵权的情形（第七十五条）；合法来源（第七十七条，免赔偿但要停止）；实用新型和外观设计没有实质审查，稳定性存疑，可以要求对方出具专利权评价报告（第六十六条第二款），并考虑提无效宣告。
4. **期限。** 发明二十年、实用新型十年、外观设计十五年，自申请日起算（第四十二条）；侵权诉讼时效三年（第七十四条）。
5. **FTO（上市前排查）**：只能做初步筛查，告诉用户检索关键词、IPC 分类和竞争对手名称，正式 FTO 需要专利代理师或律师。

### E. 著作权和软件
- 作品要有独创性（《著作权法》第三条）；著作权自动产生，登记不是必需，但登记证书是初步证据（第十二条）。
- 权属：署名推定（第十二条）；职务作品一般归作者，单位优先使用，特定情形归单位（第十八条）；委托作品看合同约定，没有约定或约定不明的归受托人（第十九条）。外包开发软件的，先看合同有没有约定归属。
- 合理使用要符合法定情形（第二十四条），"网上找的图片""注明出处"本身不构成合理使用。
- 侵权与赔偿：第五十二条、第五十三条、第五十四条。被索赔图片费时，核对对方是否真有权利（权利链条）、索赔金额是否合理，常见做法是删除、核实权属后协商。
- 软件著作权适用《计算机软件保护条例》；软件侵权的指导性案例可用 search_cases「软件 著作权 实质性相似」查。

### F. 商业秘密
- 构成要件：不为公众所知悉、具有商业价值、权利人采取了相应保密措施（《反不正当竞争法》第十条，2025 年修订后的条号）。没有保密措施（保密协议、权限管理、密级标识）的，很难主张。
- 侵权行为：不正当获取、披露、使用；员工、前员工违反保密义务；第三人明知仍使用（同条）。
- 应对：立即固定证据（离职前的邮件、下载记录、聊天记录）、发函要求停止、考虑竞业限制（按劳动用工手册）、民事诉讼；情节严重的可能构成侵犯商业秘密罪（《刑法》第二百一十九条）。

### G. 未注册标识、包装装潢
擅自使用与他人有一定影响的商品名称、包装、装潢等相同或近似的标识，引人误认的，构成混淆行为（《反不正当竞争法》第七条）。没有注册商标时可以用这条保护。

## 地区差异
- 知识产权案件实行集中管辖：专利、植物新品种、集成电路布图设计、技术秘密、计算机软件等技术类案件由知识产权法院或指定的中级法院管辖，一般商标、著作权案件也有指定管辖。管辖以最高法有关规定为准，告诉用户"起诉法院需核实"。
- 各地法院对法定赔偿额、合理开支（律师费、公证费）的支持幅度不同；资料库没有地方裁判口径时要明说，只能给区间不能给确数。
- 地方性法规有知识产权保护条例（如各省市知识产权保护条例），可用 search_law 按省份检索「知识产权保护条例」，主要涉及行政保护和纠纷调解渠道。

## 输出结构
- **清除检索类**：
  1. 顶部声明：这是初步检索，不是商标清除法律意见，不能据此认定"无冲突"。
  2. 固有障碍判断（显著性、禁用标志）。
  3. 建议检索的类别表：类别 / 对应商品服务 / 优先级（核心、关联、防御）。
  4. 检索清单：要输入的检索词 + 官方查询网址 + 贴回什么。
  5. 用户贴回结果后：冲突标注表（在先商标 / 注册号 / 类别 / 状态 / 商品类似程度 / 标志近似程度 / 风险等级 / 处理建议）。
  6. 申请策略和时间表。
- **被诉侵权类**：结论（侵权风险高 / 中 / 低）→ 对方权利核查结果 → 侵权构成分析 → 可用抗辩 → 反击手段（无效、撤销）→ 赔偿敞口 → 回函要点或草稿 → 期限。
- **维权类**：权利基础 → 侵权分析 → 证据清单和固定方法 → 路径对比表（平台投诉 / 警告函 / 行政 / 民事 / 刑事：时间、成本、效果）→ 建议方案 → 警告函草稿（如需要）。
- **专利类**：权利要求特征对比表（特征 / 被诉产品 / 是否相同或等同）→ 结论 → 抗辩与无效可能 → 下一步（评价报告、委托代理师）。

## 容易出错的地方
- 说"经检索未发现近似商标，可以放心注册"。商标初检永远只能给风险，不能给保证。
- 没有用户贴回的检索结果，就凭印象说"这个名字应该没人注册"。官方系统查不了时要明说，并给出检索清单。
- 只查一个类别、只查完整文字，漏掉显著部分、拼音、谐音和关联类别。
- 混用商标法新旧条号；2027 年以后的行为仍引 2019 年版条号，或反过来。
- 把"商品是否类似"简单等同于"是否同一个尼斯类"。同类不一定类似，跨类也可能类似。
- 告诉销售者"有进货凭证就不用担责"。合法来源只免赔偿，不免停止销售。
- 实用新型、外观设计专利当作稳定权利；没提醒评价报告和无效宣告。
- 专利侵权不看权利要求，拿产品外观或功能比。
- 把"注明出处"当成可以随便用别人作品的理由。
- 维权警告函写得像恐吓，或者向对方客户群发侵权指控，反被诉商业诋毁或不正当维权。
- 商业秘密案件只看"东西被带走了"，不核对权利人有没有采取保密措施。
- 写死法定赔偿上限等数字。修法后数字会变，以资料库现行文本为准。
