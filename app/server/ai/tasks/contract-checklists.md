# 常见合同必备条款与风险清单

用法：先按类型找到对应小节，逐项核对「必备条款」是否有、是否具体；再按我方身份看风险表对应一列。混合合同把相关小节合并使用。所有类型通用的条款：主体全称与统一社会信用代码、签约人授权、定义、通知送达地址（含电子方式，约定适用于诉讼仲裁阶段）、保密、不可抗力、解除、违约责任、争议解决（管辖或仲裁机构明确，不得或裁或诉）、合同份数与生效、附件清单及效力顺序。

## 1. 买卖 / 采购

必备：标的名称规格型号｜数量与计量｜质量标准（国标、行标、样品或技术协议）｜价格（含税与否、税率、币种、运费包装保险）｜交付时间地点方式｜风险转移时点｜检验期限、标准与异议期｜付款节点、发票｜所有权保留（如需要）｜质保期与售后｜知识产权不侵权保证｜违约金与上限。

| 审查点 | 买方关注 | 卖方关注 |
|---|---|---|
| 检验验收 | 检验期要够长；签收送货单不等于质量合格（《民法典》第六百二十三条） | 约定较短的检验期和异议期，逾期视为合格（第六百二十一条） |
| 付款 | 验收合格后付款，留质保金 | 预付款、发货前付清；逾期付款违约金；所有权保留（第六百四十一条） |
| 质量责任 | 不合格可退换、解除并索赔（第六百一十条） | 责任上限；排除间接损失；明确免责情形 |
| 交付与风险 | 交付至指定地点并验收后风险转移 | 交付承运人即转移风险；买方迟延受领的风险 |
| 价格 | 固定价，不随原材料调整 | 调价机制、汇率条款 |

## 2. 服务 / 外包

必备：服务范围与交付物清单｜服务标准或 SLA（指标、计量方式）｜人员配置与更换｜甲方配合义务｜验收方式｜费用构成与支付｜变更流程｜知识产权与数据归属｜保密与数据安全｜分包限制｜服务期、续期与终止交接｜违约与服务费扣减。

| 审查点 | 甲方（采购方）关注 | 乙方（服务方）关注 |
|---|---|---|
| 范围 | 范围写全，「包括但不限于」；超范围要书面变更 | 范围封闭列举，超范围另行计费 |
| 验收 | 以客观指标验收；未达标可扣费、解除 | 约定验收期限，逾期未提异议视为通过 |
| 人员 | 外包人员不得被认定为甲方员工；乙方承担用工责任 | 甲方不得直接管理、指挥外包人员（防止被认定为派遣） |
| 责任 | 违约赔偿覆盖第三方索赔、数据泄露 | 责任上限为已付服务费，排除间接损失 |
| 终止 | 随时解除权、交接与数据返还 | 解除需提前通知并结算已完成部分 |

## 3. 技术开发与软件 / SaaS

必备：需求说明或技术规格｜里程碑与交付物｜验收标准与测试｜源代码与文档交付｜知识产权归属（成果、背景技术、开源组件）｜许可范围（SaaS：用户数、期限、地域、用途）｜服务可用性与故障响应｜数据所有权、存储地、备份、导出与删除｜个人信息处理约定｜安全事件通知｜维护与升级｜费用与续费｜终止后的数据迁移。

| 审查点 | 委托方 / 客户关注 | 开发方 / 服务商关注 |
|---|---|---|
| 成果归属 | 约定成果及专利申请权、著作权归委托方；未约定时专利申请权归开发方（第八百五十九条），委托作品、委托开发软件著作权归受托人 | 保留背景技术和通用模块权利，向客户授予使用许可 |
| 验收 | 验收标准可测；缺陷修复期；验收前不付尾款 | 逾期不验收视为通过；需求变更另计费、顺延 |
| 数据 | 数据归客户；不得用于训练或其他目的；终止后导出和删除 | 聚合匿名数据的使用权；客户对数据来源合法负责 |
| 可用性 | SLA 低于约定按比例退费或抵扣 | 排除计划维护、第三方云故障、客户原因 |
| 侵权 | 开发方保证不侵权并承担第三方索赔 | 排除客户提供材料和修改导致的侵权；赔偿上限 |

## 4. 房屋租赁

必备：房屋位置面积用途｜产权证明与出租权（转租须有原出租人同意）｜规划许可（办公、商铺尤其要查）｜租期（不超过 20 年，第七百零五条）｜租金、递增、支付方式｜押金及退还条件｜免租装修期｜物业费水电及税费承担｜维修责任｜装修改造与退租恢复｜转租分租｜优先承租与优先购买权｜提前退租与违约金｜交还房屋验收。

| 审查点 | 承租方关注 | 出租方关注 |
|---|---|---|
| 房屋合法性 | 未取得规划许可或违法建筑的租赁合同无效（城镇房屋租赁解释第二条）；查产权和抵押、查封 | 承诺房屋权属清晰，用途合法 |
| 出租权 | 二房东须有原出租人书面同意转租，转租期不超过剩余租期（第七百一十七条） | 限制转租，擅自转租可解除 |
| 装修 | 提前解除时装修残值补偿；免租期不因提前退租被追回 | 退租恢复原状或装修无偿归出租方 |
| 提前退租 | 约定可提前解除的条件和较低违约金 | 押金不退并另付违约金；欠租达一定期限可解除 |
| 买卖不破租赁 | 出租人卖房时租赁继续有效（第七百二十五条）；优先购买权（第七百二十六条） | 约定承租人放弃优先购买权 |

## 5. 借款

必备：出借人与借款人｜借款金额与交付方式（转账，避免现金）｜用途｜期限｜利率（年利率明确）｜逾期利率与费用｜还款方式与顺序｜担保（保证、抵押、质押）｜提前还款｜加速到期｜送达与管辖。

| 审查点 | 出借方关注 | 借款方关注 |
|---|---|---|
| 交付证据 | 自然人借款自提供借款时成立（第六百七十九条）；保留转账凭证，收条与转账对应 | 实际到账金额与借款金额一致；预先扣息的按实际出借金额计本金 |
| 利率 | 利率不超过合同成立时一年期 LPR 四倍（民间借贷规定第二十五条），超过部分不受保护 | 逾期利息、违约金及其他费用合计也受四倍 LPR 限制（民间借贷规定第二十八条、第二十九条） |
| 担保 | 保证方式写明连带责任保证；约定保证期间；公司担保有决议 | 担保范围限定；不提供个人无限连带担保 |
| 性质 | 防止被认定为名为借款实为投资或非法集资 | 防止「砍头息」、阴阳借据 |

## 6. 劳动合同

必备（《劳动合同法》第十七条）：单位与劳动者信息｜合同期限｜工作内容和地点｜工作时间与休息休假｜劳动报酬（结构、发放日）｜社会保险｜劳动保护与职业危害防护；可约定试用期、培训服务期、保密与竞业限制、补充保险福利。

| 审查点 | 用人单位关注 | 劳动者关注 |
|---|---|---|
| 试用期 | 期限符合第十九条；录用条件书面明确并签收 | 超期试用可主张赔偿（第八十三条）；工资不低于约定的 80% |
| 岗位与地点 | 约定调岗条件，地点写到城市或区域 | 岗位、地点具体，单方调岗需合理 |
| 工资 | 工资结构清楚，加班费基数约定 | 基本工资不过低，绩效规则书面化 |
| 违约金 | 只有服务期和竞业限制可约定员工违约金（第二十五条） | 其他违约金条款无效 |
| 竞业限制 | 限于接触秘密人员，约定补偿、期限不超过 2 年 | 补偿按月支付；范围与接触的秘密相适应 |

## 7. 保密协议

必备：保密信息定义与排除（已公开、独立开发、合法取得）｜使用目的限制｜知悉范围与转披露条件｜保密措施｜法律强制披露的处理｜期限（含终止后存续）｜资料返还与销毁｜违约责任｜禁止反向工程、招揽人员（如需要）。

| 审查点 | 披露方关注 | 接收方关注 |
|---|---|---|
| 定义 | 范围宽，口头信息也算 | 书面标注「保密」才算，口头须事后书面确认 |
| 期限 | 商业秘密在保密状态存续期间持续保密 | 固定期限（如 2–5 年） |
| 违约责任 | 约定违约金并可另索赔，便于举证 | 违约金合理，有上限；仅限故意或重大过失 |
| 双向 | 单向保护本方 | 要求改为双向对等 |

## 8. 合作 / 合伙

必备：合作模式（是否成立新主体、是否构成合伙）｜各方出资或资源投入及估值｜分工与决策机制｜收入归集与财务管理｜利润分配与亏损承担｜知识产权与客户资源归属｜对外签约和债务承担｜竞业与排他｜退出、转让与清算｜僵局解决。

| 审查点 | 资源方 / 少数方关注 | 主导方 / 出资方关注 |
|---|---|---|
| 性质与责任 | 避免被认定为合伙而对外承担连带责任（第九百七十三条）；明确不构成合伙 | 名为合作实为借贷或雇佣的风险 |
| 财务透明 | 查账权、定期对账、共管账户 | 决策效率，不被小方卡住 |
| 收益 | 保底收益条款的效力风险；分配基数（收入还是利润）写清 | 先回本后分配 |
| 退出 | 退出时投入资源和成果的处置 | 一方违约退出的回购价格与竞业 |

## 9. 股权转让 / 投资

必备：标的公司与股权比例｜价款与支付安排（共管、分期）｜先决条件｜陈述与保证（出资实缴、无代持、无未披露债务和诉讼）｜过渡期安排｜交割与工商变更｜税费承担｜其他股东优先购买权处理｜未实缴出资的承担｜业绩承诺、估值调整与回购（如有）｜投资人特殊权利（优先清算、反稀释、领售、一票否决）｜违约与解除｜竞业与核心人员锁定。

| 审查点 | 受让方 / 投资方关注 | 转让方 / 创始人关注 |
|---|---|---|
| 出资责任 | 转让未届期出资由受让人承担，转让人补充责任（《公司法》第八十八条）；查实缴 | 转让后不再对未缴出资负责的安排 |
| 尽调与保证 | 全面陈述保证、特别赔偿、价款共管或分期 | 保证限于已知事项，设赔偿上限和期限 |
| 程序 | 其他股东优先购买权已放弃（第八十四条），章程限制已排除 | 交割前付清价款，未付款可解除 |
| 对赌 | 与公司对赌的回购须符合减资程序；与股东对赌更易执行 | 业绩指标可实现，回购义务限于标的公司或设上限，个人不承担无限责任 |
| 控制权 | 一票否决、董事席位 | 否决事项范围限定，避免公司僵局 |

## 10. 建设工程施工

必备：工程名称地点范围｜承包方式与资质｜招投标情况｜工期（开工、竣工、顺延条件）｜质量标准与验收｜合同价款与计价方式｜进度款与结算期限｜签证与变更程序｜材料设备供应｜安全文明施工｜保修范围与期限、质保金｜分包限制｜工期与质量违约｜结算审计条款。

| 审查点 | 发包方关注 | 承包方关注 |
|---|---|---|
| 效力 | 承包人资质、必须招标项目是否招标；无资质、借用资质的合同无效（建设工程施工合同解释（一）第一条） | 发包人规划许可等手续（解释（一）第三条） |
| 价款结算 | 以审计结果为准；签证须书面且经授权人签字 | 逾期不答复结算文件视为认可（需约定，解释（一）第二十一条）；工程款利息约定 |
| 优先受偿 | 要求放弃或限制优先受偿权（是否损害建筑工人利益要注意） | 优先受偿权最长 18 个月行使期（解释（一）第四十一条） |
| 转包分包 | 禁止转包和违法分包，否则可解除（第八百零六条） | 分包须经同意；实际施工人风险 |
| 工期 | 逾期竣工违约金 | 工期顺延的签证程序和期限 |

## 11. 委托 / 代理

必备：委托事项与权限范围｜是否可以转委托｜报酬与费用（成功费的条件）｜报告义务｜财物与资料交接｜授权书｜利益冲突｜任意解除及损失赔偿｜期限。

| 审查点 | 委托方关注 | 受托方关注 |
|---|---|---|
| 权限 | 权限列举具体，防止越权表见代理（第一百七十二条） | 授权足以办成事项 |
| 解除 | 委托合同双方可随时解除（第九百三十三条）；约定解除时报酬的结算 | 有偿委托解除的赔偿含可得利益；排除或限制任意解除的约定效力有争议 |
| 报酬 | 按结果付费，费用实报实销需审批 | 已完成工作量的报酬；费用预付 |
| 责任 | 受托方过错赔偿（第九百二十九条） | 责任限于故意重大过失或报酬金额 |

## 12. 加盟 / 经销

必备（加盟）：特许人资质与备案（《商业特许经营管理条例》第七条、第八条）｜信息披露（订约前至少 30 日，第二十一条、第二十二条）｜授权内容（商标、技术、经营模式）｜区域与排他｜加盟费、保证金及退还｜供货与价格｜培训与支持｜冷静期单方解除（第十二条）｜期限续约｜违约与退出。
必备（经销）：授权产品与区域｜是否独家｜最低进货量｜定价与价格管控（不得限定转售价格等垄断协议）｜付款与信用额度｜退换货与库存回购｜商标使用｜窜货处理｜终止后的库存与客户。

| 审查点 | 加盟方 / 经销商关注 | 品牌方 / 供应商关注 |
|---|---|---|
| 资质与披露 | 特许人是否满足「两店一年」等条件、是否备案；披露信息虚假可解除 | 按规定披露并留存签收 |
| 费用 | 加盟费、保证金退还条件；冷静期内解除可退费 | 费用不退的条款要有合理理由 |
| 区域 | 独家区域写清，品牌方不得在区域内直营 | 达不到业绩可取消独家 |
| 供货 | 强制采购的价格公允 | 限定采购范围以保证品质 |
| 退出 | 终止后的库存回购、竞业期限合理 | 终止后去除标识、竞业、客户资料交还 |
