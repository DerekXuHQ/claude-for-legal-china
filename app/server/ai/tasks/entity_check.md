---
id: entity_check
name: 主体调查
when: 用户想了解某家公司、个体户或个人（交易对手、供应商、客户、合作方、投资标的、债务人、新东家）的背景、资信、是否靠谱、有无风险，或要做供应商准入、签约前核查、投资前初步尽调、起诉前查财产线索。
examples:
  - 这家公司靠不靠谱，我们要跟它签 200 万的采购合同
  - 帮我查一下 XX 有限公司什么背景
  - 对方说自己有建筑资质，怎么核实
  - 客户拖款，想看看它还有没有钱
  - 这个统一社会信用代码对不对
  - 投资前想先了解一下标的公司有没有大问题
---

## 先弄清的事实

| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 主体标识 | 对方的全称和统一社会信用代码是什么？（个人：姓名和所在地，身份证号不要发给我） | 精确定位；重名公司很多 | 是 |
| 调查目的 | 为什么要查：签约、供应商准入、追款、投资、招聘？ | 决定查哪些项目、查多深 | 是 |
| 交易内容与金额 | 打算做什么交易？金额多大？谁先付款或先履行？ | 决定风险容忍度和保障措施建议 | 是 |
| 行业与资质要求 | 交易需要对方有什么资质或许可（建筑资质、食品经营、医疗器械、ICP、增值电信、危化品、人力资源服务、劳务派遣……）？ | 资质缺失可能导致合同无效或我方违规 | 视情况 |
| 已有材料 | 对方提供了营业执照、资质证书、财务报表、业绩合同、授权书吗？ | 与官方信息核对是否一致 | 否 |
| 对接人身份 | 和你们谈的人是谁，在对方公司什么职位？有授权书吗？ | 防止冒用公司名义、越权签约 | 视情况（签约时要问） |
| 已知的疑点 | 有没有让你不放心的地方？ | 重点核查 | 否 |

## 工作步骤

### 1. 本地先核对统一社会信用代码

18 位代码的最后一位是校验位，本地可以离线校验（按 GB 32100 规则）。校验不通过的，基本可以判断代码写错或证照有问题。代码第 1 位是登记管理部门代码，第 2 位是机构类别，第 3–8 位是登记机关行政区划码，可以初步看出主体类型和登记地，与对方自称的情况对照。

### 2. 生成核查清单，由用户本人查官方页面

官方系统有反爬、验证码或登录，不在后台自动抓取，也不绕过。做法：按下表生成查询要素（名称、代码、查询入口），用户逐项打开官方页面查，把结果截图或复制回来。

| 查询项 | 官方渠道 | 看什么 |
|---|---|---|
| 登记信息 | 国家企业信用信息公示系统 | 存续状态（存续 / 在业 / 吊销 / 注销 / 迁出）、成立日期、注册资本与**实缴**、股东及出资期限、法定代表人、经营范围、登记机关、分支机构、变更记录 |
| 年报与即时信息 | 同上 | 是否按时年报（每年 1 月 1 日至 6 月 30 日报送上一年度年报，《企业信息公示暂行条例》第八条）、社保缴纳人数、实缴出资公示（《公司法》第四十条） |
| 经营异常、严重违法失信 | 同上 | 被列入的原因（未年报、地址失联、公示信息隐瞒真实情况）和时间 |
| 动产抵押、股权出质 | 同上 | 主要资产和股权是否已设定担保 |
| 行政处罚 | 同上；信用中国；各主管部门网站 | 处罚事由、金额、是否与交易相关（质量、虚假宣传、安全生产） |
| 失信被执行人、被执行人、限制高消费、终本案件 | 中国执行信息公开网 | 有无未履行的生效判决；终本案件多说明已无可执行财产 |
| 涉诉 | 中国裁判文书网、人民法院公告网、中国庭审公开网 | 作为被告的合同纠纷数量和类型、近期是否集中被诉、是否有破产申请 |
| 资质许可 | 对应主管部门的官方查询平台（如住建部门的建筑市场监管平台、市场监管的许可查询、工信部的 ICP/IP 备案管理系统） | 资质等级、有效期、许可范围是否覆盖本次交易 |
| 知识产权 | 中国商标网、国家知识产权局专利检索 | 对方自称的商标、专利是否真实且在其名下、是否有效 |
| 上市公司 | 证券交易所网站、巨潮资讯 | 公告、问询函、监管措施 |
| 个人 | 中国执行信息公开网（失信、限高）；裁判文书网 | 只查与交易相关的公开信息，不收集身份证号、住址等个人敏感信息 |

给用户的查询说明要具体：在哪个网站、输入什么、看哪一栏、截哪张图。

### 3. 分析用户贴回来的结果

逐项打分，形成红 / 黄 / 绿判断：

| 信号 | 红（高风险） | 黄（需关注） | 绿 |
|---|---|---|---|
| 存续状态 | 吊销、注销、清算中 | 迁出、近期变更登记频繁 | 存续 |
| 经营异常 / 严重违法失信 | 在严重违法失信名单 | 在经营异常名录（未年报等） | 无 |
| 执行信息 | 失信、限高、多笔终本 | 有被执行记录但已结 | 无 |
| 涉诉 | 近一年作为被告的欠款、合同纠纷集中出现；有破产申请 | 少量纠纷、与本次交易类型相关 | 无或与经营规模相称 |
| 注册资本与实缴 | 认缴巨额但实缴为零、出资期限异常长（新《公司法》下认缴期限一般不超过 5 年，存量公司有过渡期，见《国务院关于实施〈中华人民共和国公司法〉注册资本登记管理制度的规定》第二条） | 实缴比例低 | 实缴与规模相称 |
| 成立时间与规模 | 新设公司承接大额交易；社保人数为零或极少 | 成立不足一年 | 与交易规模匹配 |
| 股权与人员 | 近期股东、法定代表人突然变更；法定代表人涉及大量失信或被执行企业 | 股东为空壳公司或代持迹象 | 稳定 |
| 资质 | 无资质、资质过期、挂靠迹象 | 资质等级与项目边缘匹配 | 匹配且有效 |
| 一致性 | 对方提供的执照、资质与官方信息不一致 | 地址、联系人与登记不一致 | 一致 |

注意：
- 只根据用户贴回来的结果下结论，**不编造查询结果**；没贴回来的项目标「未查」。
- 关联方：法定代表人、股东控制的其他公司如有大量失信，同样是风险信号。
- 时点：公示信息有滞后，签约前要重新查一次。

### 4. 给出交易建议

按风险等级给出保障措施：
- **绿**：正常签约，常规条款。
- **黄**：降低预付比例、分期付款、货到验收后付款、要求提供银行保函或履约保证金、要求实际控制人或关联公司提供连带责任保证（保证合同写明保证方式和期间）、缩短账期、所有权保留。
- **红**：不建议交易；必须交易的，现款现货、我方后履行、取得足额担保，并经内部审批。

签约环节：核对签约主体与官方信息一致（名称一字不差）、加盖公章或合同专用章、签约人有授权书或为法定代表人（越权代表与表见代理问题见《民法典》第一百七十二条、第五百零四条，合同编通则解释第二十条至第二十二条）、对方为分公司的了解总公司情况。

追款场景：把查到的财产线索（不动产、车辆、股权、对外投资、应收账款、知识产权）整理成清单，供保全和执行使用；股东未实缴或出资期限未到的，提示《公司法》第五十四条的加速到期。

投资场景：本手册只做初筛，深度尽调另需律师、财务团队，建议的尽调清单可以转 corporate 的方法。

## 必查依据

- 《中华人民共和国市场主体登记管理条例》第八条、第九条（登记事项与备案事项）
- 《企业信息公示暂行条例》第六条至第十条、第十八条、第十九条
- 《中华人民共和国公司法》第三十二条、第三十四条（登记事项及未登记不得对抗善意相对人）、第四十条（公示事项）、第四十七条（认缴期限）、第五十四条
- 《国务院关于实施〈中华人民共和国公司法〉注册资本登记管理制度的规定》第二条、第三条
- 行业资质：search_law「资质 + 行业」「许可证 + 行业」，读行政法规和地方性法规
- 担保措施的条款写法：《民法典》第六百八十六条、第六百九十二条；担保制度解释第七条、第八条（公司对外担保决议）

## 地区差异

- 部分地区有本地的企业信用平台或行业资质查询平台，可以提示用户同时查。
- 不同地区的登记机关对地址异常、简易注销的处理节奏不同，影响信息滞后程度。
- 资料库没有地方查询平台信息时，只列全国性渠道。

## 输出结构

```
# 主体风险结论：红 / 黄 / 绿
一句话：主要风险点 + 是否建议交易

# 基本信息核对
| 项目 | 官方信息 | 对方提供 | 是否一致 |

# 风险信号
| 信号 | 情况 | 等级 | 说明 |

# 未查或待补的项目

# 交易建议
付款与履行顺序、担保措施、合同条款要点、内部审批

# 官方查询清单（尚未查的部分，附操作说明）
```

## 容易出错的地方

- **编造或推测查询结果**。没有用户贴回来的数据，只能给清单，不能给结论。
- **只看注册资本，不看实缴和出资期限**。
- **把经营异常名录和失信被执行人混为一谈**。前者多是未年报或地址问题，后者是不履行生效判决，严重程度不同。
- **只查对方公司，不查法定代表人、股东和关联公司**。
- **收集个人敏感信息**。对个人的调查限于与交易相关的公开信息，不要求用户提供他人身份证号，不建议用非法渠道查询（如购买开房、通话、征信记录）。
- **把一次查询结果当成永久结论**。签约和付款前要再查。
- **忽视资质**。需要资质的交易，资质缺失比资信差更致命。
