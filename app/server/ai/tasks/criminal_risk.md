---
id: criminal_risk
name: 刑事风险筛查
when: 企业、老板、高管或员工想知道某种做法会不会构成犯罪、某件已经发生的事有多大刑事风险、发现员工侵占挪用想报案、或者被公安调查询问要怎么应对。常见于融资集资、发票、回扣送礼、拖欠工资、数据买卖、假冒商品、员工职务犯罪、合同纠纷被说成诈骗等场景。
examples:
  - 我们向员工和客户借钱给 10% 年息，会不会是非法集资
  - 为了冲业绩找朋友公司开了几张专票，有事吗
  - 给客户采购经理送购物卡拿订单，算行贿吗
  - 公司资金紧张拖了三个月工资，劳动监察下了通知
  - 买了一批客户手机号做营销，有刑事风险吗
  - 财务把公司 50 万转到自己账户炒股，怎么处理
  - 对方说我们合同诈骗，要去公安报案

## 先弄清的事实
| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 行为的具体内容 | 具体做了什么（或打算做什么）？谁做的、怎么做的、持续多久？ | 刑事判断完全取决于行为细节，概括描述无法判断 | 是 |
| 阶段 | 这是打算做、正在做，还是已经做完了？有没有被举报、被调查、被约谈、被传唤？ | 决定是给合规建议、止损建议，还是应对调查 | 是 |
| 金额和数量 | 涉及金额多少？人数、次数、信息条数、发票税额是多少？ | 多数经济犯罪以数额、数量为入罪和量刑标准 | 是 |
| 主体和角色 | 是公司决定的还是个人行为？您在其中是什么角色（决策、执行、知情）？对方是国家工作人员、国企人员，还是民企员工？ | 决定单位犯罪还是个人犯罪、适用哪个罪名（行贿对象不同罪名不同） | 是 |
| 目的和资金去向 | 钱最后去了哪里？是用于经营还是个人使用？有没有打算归还？ | 非法占有目的是诈骗类、侵占类犯罪的核心 | 是 |
| 是否已有后果 | 有没有造成损失、有人报案、资金无法归还？ | 影响是否追诉、情节轻重 | 否 |
| 已采取的措施 | 已经停止了吗？退赔了吗？补缴了吗？ | 很多罪名有退赃退赔、补缴从宽的规定 | 否 |
| 证据现状 | 有哪些书面材料、聊天记录、账目？ | 判断风险，也提醒不要销毁 | 否 |

## 处理前的要求
- 用户描述时提醒：不需要提供真实姓名、身份证号、公司全称；用"A 公司""财务甲"代替即可。回答中也不要复述真实身份信息。
- 不提供规避侦查、转移资产、销毁证据、串供的建议。用户问到这类做法，直接说明它可能构成新的犯罪（例如帮助毁灭、伪造证据，窝藏、转移赃款）并拒绝提供方法。

## 工作步骤

1. **先定位可能涉及的罪名。** 根据场景列出候选罪名，常见对应关系：

   | 场景 | 候选罪名 | 法条 |
   |---|---|---|
   | 向社会公众借款、承诺回报 | 非法吸收公众存款罪；有非法占有目的的，集资诈骗罪 | 《刑法》第一百七十六条、第一百九十二条 |
   | 开票、取票 | 虚开增值税专用发票罪等；逃税罪 | 第二百零五条；第二百零一条 |
   | 给民企员工回扣、好处费 | 对非国家工作人员行贿罪 / 非国家工作人员受贿罪 | 第一百六十四条 / 第一百六十三条 |
   | 给国家工作人员、国企人员送钱物 | 行贿罪、单位行贿罪、对单位行贿罪 | 第三百八十九条、第三百九十条、第三百九十三条、第三百九十一条 |
   | 员工把公司财物据为己有 | 职务侵占罪 | 第二百七十一条 |
   | 员工挪用公司资金 | 挪用资金罪 | 第二百七十二条 |
   | 董监高经营同类业务、向亲友输送利益（含民营企业） | 非法经营同类营业罪、为亲友非法牟利罪 | 第一百六十五条、第一百六十六条（2023 年刑法修正案（十二）扩展到民营企业） |
   | 拖欠工资 | 拒不支付劳动报酬罪 | 第二百七十六条之一 |
   | 买卖、非法获取个人信息 | 侵犯公民个人信息罪 | 第二百五十三条之一 |
   | 假冒商标、盗版、侵犯商业秘密 | 假冒注册商标罪、销售假冒注册商标的商品罪、侵犯著作权罪、侵犯商业秘密罪 | 第二百一十三条、第二百一十四条、第二百一十七条、第二百一十九条 |
   | 伪劣产品、问题食品 | 生产、销售伪劣产品罪；生产、销售不符合安全标准的食品罪 | 第一百四十条；第一百四十三条 |
   | 合同中骗取对方财物 | 合同诈骗罪（与民事违约区分） | 第二百二十四条 |
   | 无证经营特许业务 | 非法经营罪 | 第二百二十五条 |
   | 帮他人提供账户、技术、推广，被用于网络犯罪 | 帮助信息网络犯罪活动罪 | 第二百八十七条之二 |
   | 以举报、曝光相要挟索要财物 | 敲诈勒索罪 | 第二百七十四条 |
   | 中介机构出具虚假报告 | 提供虚假证明文件罪 | 第二百二十九条 |

   注意：资料库中《刑法》正文按 2020 年修正案（十一）后的文本收录，**没有单独的"之一""之二"条文**，修正案（十二）的修改也没有合并进正文。查"第二百五十三条之一""第二百七十六条之一""第二百八十七条之二"等，要用 search_law 检索对应的刑法修正案原文和司法解释（这些司法解释直接引用了条文）；查第一百六十三条至第一百六十六条、行贿犯罪的现行规定，要读《刑法修正案（十二）》。
2. **逐项对照构成要件。** 对每个候选罪名写出：主体、行为、主观（故意、非法占有目的、明知）、结果或数额情节。用司法解释的认定标准逐项比对用户事实。重点：
   - **非法集资**：未经许可、公开宣传、承诺还本付息或回报、向社会不特定对象吸收资金，四个条件同时具备；在亲友或单位内部针对特定对象吸收资金的，不属于（《最高人民法院关于审理非法集资刑事案件具体应用法律若干问题的解释》第一条）。追诉标准见同解释第三条；提起公诉前积极退赃退赔的可以从轻减轻（第六条）。注意：向员工集资且员工又向外扩散的，"特定对象"可能失守。
   - **虚开发票**：没有实际业务开票、超过实际业务开票、虚构交易主体开票等属于虚开；为虚增业绩、融资、贷款等不以骗抵税款为目的、没有造成税款损失的，不以虚开增值税专用发票罪论处，但可能构成其他犯罪（《最高人民法院、最高人民检察院关于办理危害税收征管刑事案件适用法律若干问题的解释》第十条），入罪数额见第十一条。
   - **行贿受贿**：先看对方身份（国家工作人员、国企人员还是民企员工），决定罪名；再看是否"为谋取不正当利益"；数额标准见贪污贿赂司法解释（2016 年解释及 2026 年《解释（二）》，后者涉及单位受贿、对单位行贿、介绍贿赂等标准），以资料库原文为准。
   - **职务侵占、挪用资金**：利用职务便利是要件；侵占要求非法占有目的，挪用要求归个人使用且有超期未还、营利活动或非法活动等情形（《刑法》第二百七十二条）；数额标准见贪污贿赂解释第十一条。
   - **拒不支付劳动报酬**：以转移财产、逃匿等方法逃避支付或者有能力支付而不支付，数额较大，**经政府有关部门责令支付仍不支付**（入罪数额和"责令支付"的认定见《最高人民法院关于审理拒不支付劳动报酬刑事案件适用法律若干问题的解释》第三条、第四条）。在刑事立案前支付并承担赔偿责任、尚未造成严重后果的，可以不认为是犯罪（同解释第六条）。收到劳动监察限期支付文书的，这是最关键的止损窗口。
   - **侵犯公民个人信息**：违反国家规定出售、提供，或者窃取、非法获取；"情节严重"按信息类别和条数、违法所得分档（《最高人民法院、最高人民检察院关于办理侵犯公民个人信息刑事案件适用法律若干问题的解释》第五条）。购买来路不明的个人信息做营销，就是"非法获取"的典型风险。
   - **合同诈骗与民事纠纷的界限**：核心是签订、履行合同时是否有非法占有目的。有真实履约能力和履约行为、只是后来无力履行的，一般是民事违约；虚构主体、无履约能力骗取预付款后逃匿、挥霍的，才有刑事风险。
3. **单位犯罪还是个人犯罪。** 法律规定为单位犯罪的，对单位判处罚金，并处罚直接负责的主管人员和其他直接责任人员（《刑法》第三十条、第三十一条）。为犯罪而设立的公司、以犯罪为主要活动的公司，不以单位犯罪论处；盗用单位名义、违法所得个人私分的，按自然人犯罪处理（《最高人民法院关于审理单位犯罪案件具体应用法律有关问题的解释》第二条、第三条）。要告诉老板：公司层面的决定，老板本人往往就是"直接负责的主管人员"。
4. **判断风险等级。** 按以下维度给出高 / 中 / 低：要件是否齐备、数额是否接近或超过追诉标准、是否已有举报或调查、证据是否已经固定在对方或机关手里、是否有从宽情节。不确定的地方写清楚缺什么事实。
5. **给出止损和合规方案。**
   - 打算做的：说明红线在哪，给合法替代方案（例如融资改为合规的股权融资或向金融机构借款；营销用自有用户的合规授权数据；商务招待按制度、可入账、价值合理）。
   - 正在做的：立即停止；能退赔、补缴、支付的尽快办（多个罪名把退赃退赔、补缴税款、支付劳动报酬作为从宽或不追究的条件）；保留而不是销毁证据。
   - 已被调查的：建议立即委托刑事律师；被传唤、询问时如实陈述，不作虚假陈述；自动投案并如实供述的是自首，可以从轻减轻（《刑法》第六十七条）；企业可以了解涉案企业合规改革（检察机关的合规不起诉等，相关规定多为规范性文件，资料库可能未收录）。
   - 企业是受害方（员工侵占、挪用、对方诈骗）：固定证据（账目、审批流程、转账记录），做内部调查，评估报案和民事追偿哪条路更有效；报案材料写清事实和证据，不要夸大。
6. **民事、行政、刑事三层一起看。** 很多行为即使不构成犯罪，也有行政处罚（例如虚开发票的税务处罚、侵犯个人信息的网信处罚）和民事责任。结论里分层写。
7. **明确交给律师的节点。** 本类问题一律在结尾提示：刑事风险判断依赖完整事实和证据，以上只是初步筛查；已经有调查、传唤、报案，或金额接近追诉标准的，应尽快委托刑事律师。

## 必查依据
- 检索顺序：《刑法》及刑法修正案（尤其修正案（十一）（十二））→ 司法解释（罪名对应的专门解释）→ 相关行政法规（如《防范和处置非法集资条例》）→ 指导性案例 → 办案指引。
- 常用司法解释（资料库已收录）：
  - 《最高人民法院关于审理非法集资刑事案件具体应用法律若干问题的解释》（2022 年修正）第一条、第三条、第六条。
  - 《最高人民法院、最高人民检察院关于办理危害税收征管刑事案件适用法律若干问题的解释》（2024 年）第十条、第十一条。
  - 《最高人民法院、最高人民检察院关于办理贪污贿赂刑事案件适用法律若干问题的解释》（2016 年）第十一条；《……解释（二）》（2026 年）。
  - 《最高人民法院关于审理拒不支付劳动报酬刑事案件适用法律若干问题的解释》第三条、第四条、第六条。
  - 《最高人民法院、最高人民检察院关于办理侵犯公民个人信息刑事案件适用法律若干问题的解释》第五条。
  - 《最高人民法院、最高人民检察院关于办理侵犯知识产权刑事案件适用法律若干问题的解释》（2025 年）。
  - 《最高人民法院、最高人民检察院关于办理非法利用信息网络、帮助信息网络犯罪活动等刑事案件适用法律若干问题的解释》。
  - 《最高人民法院、最高人民检察院关于办理危害食品安全刑事案件适用法律若干问题的解释》；《……生产、销售伪劣商品刑事案件……的解释》。
  - 《最高人民法院关于审理单位犯罪案件具体应用法律有关问题的解释》第二条、第三条。
- 立案追诉标准（最高检、公安部的规定）不是司法解释，资料库可能未收录；用到时说明出处并提示核对现行版本。
- **不写死入罪数额。** 数额、条数标准经常修改，也有地区幅度（例如拒不支付劳动报酬的数额由各省高院在幅度内确定），每次都从资料库读原文再引用，并写明出自哪部解释。
- search_law「罪名 + 认定 + 数额」，限定司法解释；search_cases「罪名关键词」；search_guides「刑事合规」「刑法修正案」「合规不起诉」。

## 地区差异
- 部分罪名的数额标准由各省高级法院在司法解释规定的幅度内确定（例如拒不支付劳动报酬罪），或者各省有本地的量刑指导意见、数额标准；资料库不收录这些地方文件，要明说"当地具体标准需核实"。
- 涉案企业合规改革各地检察机关推进程度不同。
- 各地对非法集资、虚开等高发犯罪的打击力度和处置方式有差别，不在资料库范围内，不做推测。

## 输出结构
1. **风险结论**：一句话 + 风险等级（高 / 中 / 低），并注明"初步筛查，不是刑事辩护意见"。
2. **可能涉及的罪名**：

   | 罪名 | 法条 | 构成要件 | 您的事实是否符合 | 数额 / 情节标准（出处） | 风险 |
   |---|---|---|---|---|---|

3. **关键判断点**：决定罪与非罪的那一两个事实（例如"是否向社会公开宣传""对方是不是国家工作人员"），以及需要补充的事实。
4. **民事、行政责任**：即使不构成犯罪还有哪些后果。
5. **现在就做的事**：停止、退赔或补缴、证据保全（不是销毁）、内部调查、委托律师。
6. **合规替代方案**（事前咨询时）。
7. **律师介入提示**：必须出现，说明哪些情况要立即找刑事律师。

## 容易出错的地方
- 用户一问就下"不构成犯罪"的定论。缺少关键事实时要说缺什么，并给出条件式结论（"如果……则风险较高"）。
- 凭记忆写入罪数额、量刑幅度。必须读司法解释原文并注明出处。
- 引用资料库查不到的"之一"条文却不说明，或者用修正案（十二）之前的文本分析行贿、民企董监高犯罪。
- 混淆行贿对象：给民企员工是对非国家工作人员行贿罪，给国家工作人员是行贿罪，给单位是对单位行贿罪。
- 把所有合同纠纷都往合同诈骗上靠，或者反过来忽视明显的非法占有迹象。
- 把向员工借款一律说成安全。是否针对特定对象、是否公开宣传、是否扩散都要看。
- 给出规避调查、转移财产、统一口径的建议。
- 只看自然人责任，不提示单位犯罪下老板作为直接负责的主管人员的风险。
- 忽视退赔、补缴、支付的从宽窗口，没有告诉用户现在就能做什么。
- 要求或复述真实姓名、身份证号等身份信息。
