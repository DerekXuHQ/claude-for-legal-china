## 先弄清的事实

合同审查没有「中立」的答案：同一条款，对买方是好条款，对卖方就是坑。先弄清下面这些，再动笔。

| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 合同文本 | 请上传完整合同，包括附件、报价单、技术规格、补充协议 | 附件经常藏着真正的商业条款；缺附件要说明审查范围受限 | 是 |
| 我方是哪一方 | 您是合同里的哪一方（甲方/乙方，买方/卖方，出租方/承租方……）？ | 决定审查立场和修改方向 | 是 |
| 交易背景与目的 | 这笔交易是做什么？您最看重什么（按时拿到货、回款、技术成果归属、退出自由……）？ | 判断哪些条款是「要害」，哪些可以让 | 是 |
| 谁起草的文本 | 是对方的模板还是我方起草？是不是格式合同（平台协议、标准合同）？ | 对方模板要多改；格式条款有特殊规则；对方是大公司标准文本时改动空间小 | 是 |
| 谈判地位 | 我方是强势还是弱势？对方接受修改的可能性？是否已经谈过几轮？ | 决定意见的力度：首选方案还是直接用后备方案 | 是 |
| 金额与期限 | 合同总金额大概多少？履行期多长？ | 决定风险等级和是否值得为某条款坚持 | 是 |
| 是否已签/已履行 | 合同签了吗？履行到哪一步了？ | 未签：改条款；已签：评估风险、补充协议、履约中留证 | 是 |
| 对方主体 | 对方公司全称？是否做过资信核查？ | 主体资格、资质、履约能力；必要时转 entity_check | 视情况（金额较大时要问） |
| 特殊关注点 | 有没有特别担心的问题（之前吃过亏的、领导交代的）？ | 优先审查 | 否 |
| 行业与资质 | 涉及什么行业？需要许可证或资质吗（建筑、食品、医疗、金融、数据、广告……）？ | 资质缺失可能导致合同无效或违法 | 视情况（涉及特许行业时要问） |
| 是否涉外 | 有境外主体、外币结算、境外履行吗？ | 法律适用、争议解决、外汇和出口管制要单独处理 | 视情况（涉外时要问） |
| 内部审批 | 我方签约需要董事会/股东会决议吗？对方签约人有无授权？ | 担保、关联交易、重大资产处置的决议要求 | 视情况（涉及担保、关联交易时要问） |

用户只说「帮我看看」而没说立场时，先问我方身份；实在不回答的，按「双方视角」分别列出主要风险。

## 工作步骤

### 1. 合同画像

读完全文（含附件）后，先写一张画像，后面每一步都对照它：

- 合同类型（按《民法典》典型合同或主要权利义务归类；混合合同写明主要类型和次要类型）。
- 双方主体、我方身份、签约人。
- 交易结构：标的、数量/范围、价款及支付节点、交付/验收、期限。
- 关键风险分配条款位置：违约责任、责任限制、赔偿、解除、知识产权、保密、争议解决。
- 文本来源（我方/对方/第三方模板）与格式条款情况。

### 2. 对照必备条款清单找缺失

读 `contract-checklists.md` 中对应合同类型的必备条款表，逐项核对：有 / 有但不完整 / 缺失。缺失的条款单独列一张表，说明缺失的后果（如「未约定验收期限 → 按《民法典》第六百二十一条，买方怠于通知视为合格」）并给出补充条款文本。

《民法典》第四百七十条列出的一般条款（当事人、标的、数量、质量、价款或报酬、履行期限地点方式、违约责任、争议解决）是底线；没约定的部分适用第五百一十条、第五百一十一条的补充规则，要判断这些默认规则对我方是否有利——对我方有利的，缺失不一定要补。

### 3. 逐条审查：六个维度

每一条款按下面的顺序看，前一层有问题的，后面的不用再细抠。

**① 合法性与效力**
- 主体：是否具备民事行为能力和必要资质；分支机构签约；代理人有无授权；法定代表人越权（《民法典》第五百零四条，《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》第二十条至第二十二条）。
- 整体或部分无效的情形：违反法律、行政法规的效力性强制性规定（第一百五十三条，以及合同编通则解释第十六条至第十八条对「强制性规定」的区分）、违背公序良俗、恶意串通（第一百五十四条）、虚假意思表示（第一百四十六条，阴阳合同；合同编通则解释第十四条）。
- 免责条款无效：造成对方人身损害的、因故意或重大过失造成财产损失的（第五百零六条）。
- 格式条款：提供方应以足以引起注意的方式提示免除或减轻其责任等与对方有重大利害关系的条款，并按要求说明，否则对方可以主张该条款不成为合同内容（第四百九十六条，合同编通则解释第十条）；不合理地免除或减轻其责任、加重对方责任、限制对方主要权利、排除对方主要权利的无效（第四百九十七条）；有两种以上解释的，作不利于提供方的解释（第四百九十八条）。
- 需要审批、登记才生效的合同（第五百零二条第二款）：如特定行业的批准，是否约定了报批义务和未获批准的后果。
- 特殊规则：借款利率上限、建设工程资质与招投标、租赁 20 年上限、劳动合同的违约金限制、特许经营备案与信息披露等，见清单文件。

**② 权利义务是否平衡**
- 双方义务是否对等：付款义务与交付义务、违约责任是否只约束我方。
- 单方权利：对方单方变更、单方解除、单方调价、单方解释权、单方认定违约的条款。
- 责任上限、免责、间接损失排除对谁有利。
- 履行顺序：先付款还是先交货，预付比例，我方的抗辩权是否被排除（同时履行、先履行、不安抗辩：第五百二十五条至第五百二十七条）。

**③ 能否执行**
- 义务是否具体可衡量：交付标准、验收标准、服务水平（SLA）、里程碑是否有客观指标。
- 违约金的计算基数、比例、起算日、上限是否明确；能否被调减（约定的违约金超过损失 30% 的，一般可以认定为过分高于损失，合同编通则解释第六十五条；但恶意违约方请求调减一般不支持）。
- 解除条件、通知方式和期限是否可操作（第五百六十三条、第五百六十五条）。
- 送达条款：地址、电子邮箱、联系人是否写明，是否约定适用于诉讼和仲裁阶段。
- 争议解决：管辖法院是否明确且与争议有实际联系（《民事诉讼法》第三十五条）；仲裁条款是否有请求仲裁的意思表示、仲裁事项和选定的仲裁机构（《中华人民共和国仲裁法》第二十七条）；「或裁或诉」条款通常无效，要改。
- 担保措施：保证方式（未约定或约定不明的按一般保证，第六百八十六条）、保证期间（未约定为主债务履行期届满后 6 个月，第六百九十二条）、公司对外担保有无决议。

**④ 商业风险**
- 付款风险：账期、付款条件（「收到对方款项后支付」「审计后支付」等背靠背条款）、发票先后、逾期付款责任。
- 履约风险：对方无力履约时的退出路径、替代采购费用、保证金或保函。
- 价格风险：调价机制、汇率、原材料价格波动、情势变更（第五百三十三条）。
- 知识产权和数据：成果归属、背景知识产权许可、侵权担保、数据合规。
- 长期合同的锁定：自动续期、排他、最低采购量、竞业。
- 对方的「隐形」权利：在附件、报价单、网站规则中引用的条款（「以对方官网公布的规则为准」）。

**⑤ 表述歧义**
- 同一概念前后用词不一（「验收」「确认」「签收」混用）；定义条款缺失。
- 「及时」「合理期限」「重大违约」「相关费用」等弹性用语，按我方立场决定是要具体化还是保留弹性。
- 数字大小写不一致、币种、含税与否、计算基数不明。
- 条款之间冲突（正文与附件、通用条款与专用条款），有没有约定优先顺序。
- 合同解释规则：以词句的通常含义为基础，结合相关条款、合同性质和目的、习惯和诚信原则（合同编通则解释第一条）。

**⑥ 关系与可操作性**
- 我方实际能否做到（交付周期、对接人、内部审批流程）。
- 条款是否过于严苛以至于破坏合作关系，或对方根本不会接受。
- 通知、对账、验收流程是否与双方实际业务流程匹配。
- 有无留痕机制（周报、对账单、验收单、变更单）。

### 4. 风险分级

| 等级 | 标准 | 处理 |
|---|---|---|
| 高 | 可能导致合同或条款无效、违法受罚；我方承担无上限或与收益明显不对称的责任；核心商业目的可能落空（拿不到货、收不回款、成果不归我方）；争议时几乎无法维权 | 必须修改；改不了要提示是否签约或需要领导决策 |
| 中 | 对我方明显不利但损失可控；约定不明可能引发争议；执行上有障碍 | 争取修改，可以接受后备方案 |
| 低 | 表述不严谨、可优化；对实质权利影响小 | 有机会就改，不必坚持 |

同一份合同的高风险问题一般不应超过五六个，太多说明标准过松，要重新筛选；把真正的要害放在最前面。

### 5. 写修改意见

每个问题写成下面的格式：

- **原文**：引用条款号和原文（准确引用，不改字）。
- **问题**：一两句话说清楚为什么对我方不利或有什么法律问题。
- **风险等级**：高 / 中 / 低。
- **首选修改**：完整的替换文本，可以直接粘贴进合同。
- **后备修改**：对方不接受首选时的折中文本。
- **谈判理由**：给对方听的理由（行业惯例、公平对等、法律规定），不是给我方的分析。
- **依据**：法条（只写核对过的）。

示例：

> **第 8.2 条**　原文：「乙方逾期交货的，每逾期一日，按合同总价的 1% 向甲方支付违约金。」（我方为乙方）
> 问题：日 1%、无上限，逾期一个月即达合同总价的 30%；且以合同总价而非逾期部分为基数。
> 风险：高。
> 首选：「乙方逾期交货的，每逾期一日，按逾期交付部分货款的 0.05% 向甲方支付违约金，违约金总额不超过逾期交付部分货款的 5%。」
> 后备：「……按逾期交付部分货款的 0.1% ……总额不超过逾期交付部分货款的 10%。」
> 谈判理由：违约金应与实际损失相当；以逾期部分为基数是行业通行做法；设上限后双方的风险都可预期。
> 依据：《民法典》第五百八十五条；合同编通则解释第六十五条（约定违约金过分高于损失的可请求调减）。

措辞要求：
- 修改文本用合同语言，主语、时间、金额、条件完整；避免「双方友好协商」这类无法执行的表述。
- 首选方案要合理，不要把对方条款全部反过来——那样对方不会接受，也显得不专业。
- 后备方案是真正能让步的底线，不是首选方案换个说法。

### 6. 缺失条款与整体建议

- 缺失条款表（来自第 2 步），每条附建议文本。
- 如果合同结构有根本问题（例如：名为服务实为劳务派遣、名为买卖实为借贷、名为合作实为借款），在开头单独说明，因为逐条修改救不了。
- 签约与履行建议：签约主体核查、授权与用印、骑缝章、附件签署、履约留痕、关键日期（验收期、质保期、续期通知期）进日历。

### 7. 谈判要点

最后给一页「谈判清单」：
- 必须拿下的（底线）：两三条。
- 争取的：可用来交换的条款。
- 可以让步的：对我方影响小、对方在意的条款。
- 交换策略：例如「接受对方的付款节点，换取违约金上限」。

### 8. 已签合同的审查

用户问的是已签合同时，不写修改文本，改写：
- 各条款对我方的实际风险和应对（什么情况下我方会违约、怎么避免）；
- 我方可以主张的权利和行使期限（解除权、撤销权的除斥期间：第一百五十二条、第五百六十四条）；
- 需要补签的补充协议条款；
- 履约中要保存的证据。

## 地区差异

合同法是全国统一的，地区差异主要在：
- 特定合同的地方规定：房屋租赁（登记备案、群租）、住房租赁（《住房租赁条例》及地方实施规定）、预付式消费、建设工程价款结算、物业服务。用 search_law 按用户所在省市检索。
- 法院对违约金调整、背靠背条款、管辖条款的审查宽严，可以 search_cases 按地区检索；查不到就说没有本地口径。
- 涉外合同：法律适用、仲裁地选择、外汇；只提示需要专门处理，不套用大陆国内规则。

## 容易出错的地方

- **不问立场就审**。不知道我方是哪一方的审查意见基本没用。
- **只挑毛病不给文本**。每个中高风险问题都要有可以直接粘贴的修改文本。
- **修改过度**。把对方条款全部改成对我方极端有利，对方不会接受，等于没改。首选方案要「合理偏向我方」。
- **漏看附件和引用文件**。报价单、技术协议、平台规则里经常有付款、责任和知识产权的实质约定。
- **把违约金「越高越好」**。我方是守约方时，过高的违约金会被调减，反而应该同时约定损失计算方式；我方可能违约时，要设上限。
- **把管辖约定写到与争议没有实际联系的地点**，或者写「或裁或诉」。
- **忽视格式条款规则**。我方提供格式合同时，要提醒对重大利害关系条款加粗提示并留存说明记录；对方提供时，可以据此主张条款不成为合同内容或无效。
- **用错误的法律概念**。「定金」「订金」「保证金」「押金」法律后果不同；「解除」「终止」「撤销」不同；「一般保证」「连带责任保证」不同。
- **把行政规章、地方规定的要求当成合同无效的理由**。合同无效看法律、行政法规的效力性强制性规定和公序良俗；违反规章一般不直接导致无效，但可能涉及公序良俗或行政责任。
- **编造法条或案例**。引用的每一条都要能在资料库核对；不确定就写法规名称不写条号。
- **只看条款不看交易结构**。名实不符的合同（以买卖掩盖借贷、以合作掩盖用工、以咨询费掩盖返利）要先指出性质风险。
- **对已签合同还在写「建议修改为」**。已签的要转向风险应对和补充协议。
