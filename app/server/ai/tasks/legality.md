## 先弄清的事实

「合法吗」的答案几乎都是「看情况」。要把「情况」问出来，问到能落到具体法条构成要件为止。

| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 行为的具体内容 | 具体是谁、做了什么、怎么做的？能举个实际例子吗？ | 法律评价落在具体行为上，概括描述无法判断 | 是 |
| 主体身份 | 做这件事的是公司、个体户还是个人？什么行业？有无相关许可？ | 同一行为对不同主体规则不同（如经营者和消费者、特许行业） | 是 |
| 用户是哪一方 | 您是要做这件事的人，还是受影响的一方？ | 前者要合规方案，后者要维权路径 | 是 |
| 地点 | 在哪个省市发生或实施？ | 地方性法规 | 是 |
| 时间 | 什么时候做的或打算什么时候做？持续多久了？ | 新旧法适用；行政处罚和诉讼时效 | 是 |
| 是否已实施、后果 | 已经做了吗？造成了什么后果（损失金额、人数、投诉、被查）？ | 已实施的要评估责任和补救；后果影响责任层级 | 是 |
| 对方或相关人的态度 | 对方是否同意或知情？有无书面约定？ | 同意、告知、约定常常决定合法与否（如个人信息、监控、扣款） | 视情况 |
| 金额或规模 | 涉及多少钱、多少人、多少条信息？ | 行政处罚幅度和刑事门槛 | 视情况 |
| 证据 | 现在手上有什么证据？ | 维权方：能不能证明；行为方：会不会被证明 | 视情况（维权时要问） |
| 目的 | 这样做想达到什么目的？ | 合规替代方案要保住目的 | 视情况（行为方时要问） |

## 工作步骤

### 1. 把问题改写成法律问题

用户的话往往混合了事实、情绪和推测。先用一两句话复述：「问题是：公司（用人单位）在员工工位安装能拍到电脑屏幕的摄像头，是否侵犯员工的隐私权或个人信息权益，是否需要告知或同意。」复述时把关键事实和缺失事实标出来。

### 2. 识别法律关系与可能的规范

列出这个行为可能触及的领域：民事（合同、侵权、人格权、物权）、行政（市场监管、税务、劳动监察、公安、网信等）、刑事。一个行为常同时触及多个领域，都要列出来再逐个排除。

### 3. 找规范：效力层级从高到低

- 法律 → 司法解释 → 行政法规 → 地方性法规 →（部门规章、规范性文件，资料库可能没有）。
- 先找有没有**禁止性或强制性规定**直接规制这个行为，再找一般条款（诚信、公序良俗、一般侵权条款）。
- 有特别法的用特别法（如个人信息先看《个人信息保护法》，再看《民法典》人格权编）。
- 注意时间：行为发生时的有效版本。近年修订频繁的（公司法、反不正当竞争法、仲裁法、网络安全法、食品安全法等），用 compare_versions 看新旧差异。

### 4. 三层后果分析

对每个可能触及的规范，写清：

| 层级 | 看什么 | 典型后果 |
|---|---|---|
| 民事 | 合同或条款是否有效（《民法典》第一百五十三条、第一百五十四条）；是否构成违约或侵权（第五百七十七条、第一千一百六十五条）；可撤销情形（第一百四十七条至第一百五十一条） | 无效、返还、赔偿、违约金、惩罚性赔偿（消费欺诈、知识产权故意侵权等） |
| 行政 | 哪部法律法规设定了处罚、哪个部门执法、处罚种类和幅度；是否有从轻、减轻、不予处罚情形（《行政处罚法》第三十二条、第三十三条）；处罚时效（第三十六条：一般 2 年未被发现不再处罚） | 警告、罚款、没收违法所得、责令停业、吊销许可、列入经营异常或严重违法失信名单 |
| 刑事 | 是否接近某个罪名的构成要件；有无数额、情节门槛 | 只做风险提示，不下定论；高风险的转 criminal_risk 或律师 |

### 5. 下结论

结论只能是以下之一，并说明条件：
- **合法**：没有找到禁止性规定，且符合必要的程序（告知、同意、许可）。
- **有条件合法**：满足某些条件才合法——把条件列清楚（如「事先告知员工监控范围和目的，不拍摄私密区域，数据限定用途和保存期限」）。
- **违法**：违反了哪条规定，后果是什么。
- **存在争议 / 灰区**：法律没有明确规定或裁判、执法口径不一，说明两种观点和各自依据，给出更稳妥的做法。

不要用「一般来说」「原则上」掩盖不确定，不确定就直接说不确定在哪里。

### 6. 给出下一步

**行为方（我想这样做）**：
- 合规替代方案：怎么做能达到同样目的且合法。
- 已经做了的：如何停止、补救、降低处罚风险（主动消除后果、及时改正、配合调查）。

**受害方（他这样对我）**：
- 能主张什么权利（要求停止、返还、赔偿、违约金），依据是什么。
- 途径选择：协商 → 发函 → 投诉举报（指出具体的主管部门：市场监管 12315、劳动监察、网信、税务 12366、公安等）→ 调解 → 仲裁或诉讼；各途径的成本和效果。
- 证据怎么固定：书面材料、聊天记录、录音、网页公证或可信时间戳、付款凭证、证人。
- 期限：诉讼时效（一般 3 年，《民法典》第一百八十八条）、撤销权、投诉时限。涉及期限计算的转 deadline 的方法。
- 想起诉的，转 claim_feasibility 的分析框架。

## 必查依据

- 先用 search_law 按行为关键词全文检索（如「监控 员工 个人信息」「定金 不退」「押金 返还」），不要先入为主地只查一部法。
- 民事基础：《民法典》总则编（民事法律行为效力）、合同编、人格权编、侵权责任编；合同编通则解释、总则编解释。
- 行政责任：查设定处罚的法律或行政法规条文本身，读「法律责任」一章。
- 刑事：刑法分则相应罪名，配套司法解释；立案追诉标准资料库没有就不要写数额。
- 地方：search_law 按用户省市筛选。
- 有疑义时 search_cases 查指导性案例和类案。

常用条文（已核对）：《民法典》第一百四十三条、第一百四十六条至第一百五十四条、第一百五十七条、第一百八十八条、第五百七十七条、第五百八十五条至第五百八十八条（违约金与定金）、第一千零三十四条、第一千零三十五条、第一千一百六十五条；合同编通则解释第十六条至第十八条（强制性规定与合同效力）；《行政处罚法》第三十二条、第三十三条、第三十六条、第四十四条、第四十五条；《个人信息保护法》第十三条、第十四条、第十七条、第二十八条、第二十九条。

## 地区差异

- 很多行政管理事项有地方性法规（城市管理、房屋租赁、物业、预付卡、生活垃圾、电动车、养犬、网约车等），检索时一定加地区。
- 地方执法清单（首违不罚、轻微免罚）资料库可能没有，提示用户查当地部门公布的清单。
- 没查到地方规定时明说「资料库未检索到××省的专门规定，以全国性规定分析」。

## 容易出错的地方

- **只答「合法」或「违法」，不说条件**。大多数行为合法与否取决于告知、同意、许可、程序。
- **只看一个领域**。民事上有效不等于行政上合规；行政违法不等于合同无效。三层分开说。
- **把违反规章、规范性文件直接说成合同无效**。合同无效看法律、行政法规的效力性强制性规定和公序良俗。
- **把「违法」和「犯罪」混用**。用户问「违法吗」，要区分违法程度；刑事风险要谨慎表述。
- **凭记忆写罚款金额、入罪数额**。以资料库条文为准，查不到就不写数字。
- **忽视用户是受害方还是行为方**，给错方向的建议。
- **给出规避监管或掩盖违法的建议**。可以讲合规替代方案，不教怎么不被发现。
- **用旧法**。行为发生在新法施行前的，要说明适用哪个版本。
