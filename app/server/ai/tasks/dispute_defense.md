## 先弄清的事实

第一件事永远是期限。先问清收到了什么、哪天收到的。

| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 文书种类 | 收到的是什么？起诉状副本、应诉通知书、传票、举证通知书、仲裁申请书、律师函、处罚告知书？请上传全部材料（含信封） | 不同文书对应不同的期限和应对方式；律师函没有法定期限 | 是 |
| 收到日期 | 哪天收到的？怎么收到的（法院邮寄、电子送达、当面、短信）？有没有人代签？ | 答辩期、举证期、听证申请期都从送达之日起算 | 是 |
| 文书载明的期限 | 文书上写的答辩期、举证期限、开庭时间、听证申请期限是什么？ | 法院指定期限优先于一般规定；开庭缺席后果严重 | 是 |
| 受理机构 | 哪个法院、仲裁委或行政机关？ | 管辖是否有异议；仲裁与诉讼规则不同 | 是 |
| 对方的请求与金额 | 对方要求什么？金额多少，怎么算出来的？ | 逐项拆解抗辩 | 是 |
| 事实经过 | 按时间顺序讲一下这件事；对方说的哪些是真的、哪些不是？ | 找争议焦点 | 是 |
| 我方证据 | 有合同、订单、对账单、发票、付款记录、聊天记录、邮件、验收单、录音吗？ | 抗辩靠证据 | 是 |
| 合同中的争议条款 | 合同约定了管辖法院或仲裁吗？ | 管辖异议或仲裁协议抗辩要在答辩期内提出 | 视情况（有合同时要问） |
| 我方对对方的主张 | 对方有没有违约、欠我方钱或造成损失？ | 是否反诉、抵销 | 是 |
| 财产保全 | 账户、财产有没有被冻结、查封？ | 影响经营，需要考虑反担保、置换保全、复议 | 是 |
| 和解意愿 | 愿不愿意和解？能接受的大致范围？ | 和解区间设计 | 否 |

## 工作步骤

### 1. 第一屏：期限清单

把所有期限算出来放在回答最前面，标明起算日、到期日、依据和假设：

| 事项 | 期限 | 依据 |
|---|---|---|
| 民事诉讼答辩 | 收到起诉状副本之日起 15 日（境外被告 30 日） | 《民事诉讼法》第一百二十八条、第二百八十五条 |
| 管辖权异议 | 在提交答辩状期间提出 | 《民事诉讼法》第一百三十条 |
| 举证期限 | 以法院举证通知书为准；逾期举证有不利后果 | 民诉法解释第九十九条、第一百零一条、第一百零二条 |
| 一审判决上诉 | 判决书送达之日起 15 日；裁定 10 日 | 《民事诉讼法》第一百七十一条 |
| 劳动仲裁 | 以仲裁委通知为准；不服非终局裁决的 15 日内起诉；单位对终局裁决 30 日内申请撤销 | 《劳动争议调解仲裁法》第四十八条至第五十条 |
| 商事仲裁 | 以仲裁规则和仲裁委通知为准（答辩、选定仲裁员、反请求期限都有规定） | 所选仲裁机构的仲裁规则 |
| 行政处罚听证 | 告知后 5 日内提出 | 《行政处罚法》第六十四条 |
| 陈述申辩 | 以告知书载明的期限为准 | 《行政处罚法》第四十四条、第四十五条 |
| 行政复议 / 行政诉讼 | 知道行政行为之日起 60 日申请复议；直接起诉 6 个月 | 《行政复议法》第二十条；《行政诉讼法》第四十六条 |

期间计算：开始的当日不计入；最后一日是法定休假日的顺延到休假日后第一日；在途时间不计入，期满前交邮的不算过期（《民事诉讼法》第八十五条）。日期由用户提供的送达日推算，必须写明假设；送达日不确定的，按最早可能的日期提醒。

律师函、催款函没有法定答复期，但要提醒：对方可能随时起诉；回函内容会成为证据，不要在回函里自认不利事实。

### 2. 审对方的请求权基础

对每一项请求，问三个问题：
1. 对方依据什么法律关系和法条主张？（合同违约、侵权、不当得利、劳动法……）
2. 这个法条的构成要件是什么？
3. 对方的证据能证明每个要件吗？

画一张拆解表：

| 对方请求 | 请求权基础 | 构成要件 | 对方证据 | 我方抗辩 | 我方证据 |
|---|---|---|---|---|---|

### 3. 抗辩清单（逐项过一遍）

**程序抗辩**
- 主管与管辖：有仲裁协议而对方起诉的，要在首次开庭前提交仲裁协议，否则视为放弃仲裁协议（《中华人民共和国仲裁法》第三十七条）；协议管辖或法定管辖不对的，答辩期内提管辖异议。管辖异议不要滥用，主要用于对我方明显不便或有策略意义的情形。
- 主体：原告是否适格（是否合同相对方、债权是否转让并通知）；被告是否正确（分公司、个人与公司的混淆、法定代表人个人是否应担责）。
- 重复起诉、已有生效判决或仲裁裁决。

**时效与期间抗辩**
- 诉讼时效（一般 3 年，《民法典》第一百八十八条）是否届满；是否有中断事由（第一百九十五条，对方催款、我方承认、部分履行）。法院不主动适用时效（第一百九十三条），必须由我方提出；劳动争议的仲裁时效抗辩必须在仲裁阶段提出。
- 保证期间（第六百九十二条、第六百九十三条）、撤销权和解除权的存续期间、产品质量异议期（第六百二十一条）。

**实体抗辩**
- 合同不成立、无效、被撤销、未生效。
- 对方先违约：同时履行抗辩、先履行抗辩、不安抗辩（第五百二十五条至第五百二十七条）。
- 已经履行、已付款、已抵销。
- 不可抗力、情势变更（第五百九十条、第五百三十三条）。
- 损失不存在、因果关系不成立、对方未采取措施防止损失扩大（第五百九十一条）、双方均有过错（第五百九十二条）。
- 违约金过高请求调减（合同编通则解释第六十四条、第六十五条：可以通过抗辩或反诉提出；超过损失 30% 一般认定过高）。注意：主张合同无效或不构成违约的同时，可以一并主张违约金过高，法院也会释明（合同编通则解释第六十六条）。
- 金额计算错误：本金、利息起算日、利率上限（民间借贷不超过 LPR 四倍）。

**反诉与抵销**
- 我方对对方有基于同一法律关系或事实的请求的，可以反诉；不同法律关系的另行起诉。
- 法定抵销需要互负到期债务、标的种类相同。

### 4. 证据盘点

列证据清单：证据名称｜证明目的｜来源｜原件在哪｜对方是否认可的可能。缺什么证据、怎么补（向对方或第三方调取、申请法院调查取证、公证、鉴定）。

提醒：
- 微信、邮件等电子证据保留原始载体，不要删除或换手机。
- 对方提交的证据要看真实性、合法性、关联性，逐一准备质证意见。
- 劳动争议中解除、减薪等决定由单位举证（劳动争议解释（一）第四十四条）。

### 5. 风险评估与和解区间

- 评估败诉可能（高 / 中 / 低，各给理由）和最可能的判决金额。
- 诉讼成本：律师费、诉讼费（败诉方负担，按标的额计算）、鉴定费、时间、对经营和声誉的影响、财产被保全的影响。
- 和解区间：下限 = 我方能争取的最好结果；上限 = 最可能判决金额 + 诉讼成本 - 时间价值。说明和解的时机（答辩前、举证后、开庭后、判决前、二审中）。
- 调解协议要写清付款期限和违约后果，必要时申请出具调解书以便执行。

### 6. 应对不同来源的特殊点

- **律师函 / 索赔函**：先判断对方主张有无依据；回函简短、只陈述立场，不承认不利事实，不写情绪；如果对方主张部分成立，可以提出和解。需要的话转 drafting 起草回函。
- **劳动仲裁**：注意仲裁时效抗辩；单位举证责任重；终局裁决的范围；参考 employment 的计算方法核对员工请求金额。
- **消费者索赔（退一赔三、十倍）**：判断是否构成欺诈（《消费者权益保护法》第五十五条）或食品不符合安全标准（《食品安全法》第一百四十八条）；购买者是否以营利为目的大量购买（职业索赔）——各地对知假买假的态度不同，查司法解释和地方口径。
- **知识产权侵权指控**：核对对方权利是否有效、在先使用、合法来源抗辩、是否落入保护范围；参考 ip 任务。
- **行政处罚告知**：程序（告知、陈述申辩、听证）、事实与证据、法律适用、裁量（从轻、减轻、不予处罚情形，《行政处罚法》第三十二条、第三十三条）、处罚时效（第三十六条）。参考 admin_enforcement。

### 7. 起草答辩材料

需要时给出答辩状结构：答辩人信息 → 答辩请求（请求驳回全部或部分诉讼请求）→ 事实与理由（按争议焦点分段：程序问题、事实认定、法律适用、金额计算）→ 证据目录 → 此致。管辖异议申请书单独起草。

## 必查依据

- 程序：《民事诉讼法》第二十四条、第三十五条、第八十五条、第一百零三条、第一百二十八条、第一百三十条、第一百七十一条、第二百八十五条；《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》（举证期限、管辖协议）；《中华人民共和国仲裁法》（2026 年 3 月 1 日起施行的修订本，仲裁协议第二十七条、仲裁协议效力异议第三十一条、法院受理后提交仲裁协议第三十七条、撤销裁决第七十一条、第七十二条）。
- 实体：按对方请求权基础检索，例如 search_law「违约金 过分高于 损失」「诉讼时效 中断」「先履行抗辩」。
- 劳动：《劳动争议调解仲裁法》第二十七条、第四十七条至第五十条；劳动争议解释（一）第四十四条、解释（二）第二十条。
- 行政：《行政处罚法》第三十二条、第三十三条、第三十六条、第四十四条、第四十五条、第六十三条、第六十四条；《行政复议法》第二十条；《行政诉讼法》第四十五条、第四十六条。
- search_cases 查类似争议的裁判观点，尤其是违约金调整、举证责任分配。

## 地区差异

- 消费者职业索赔、违约金调整幅度、劳动争议的裁审口径各地差异较大，用 search_cases 按地区找，找不到就说明。
- 小额诉讼标的额上限按各省上年度就业人员年平均工资确定（《民事诉讼法》第一百六十五条），具体数额以当地公布为准。
- 仲裁机构的规则各不相同，提示用户查所选仲裁委的现行仲裁规则。

## 容易出错的地方

- **不先算期限**。答辩期、管辖异议、听证申请期一过就丧失权利。
- **把收到律师函当成被起诉**，或反过来，把法院文书当成普通催告不理会。
- **漏提时效抗辩**。法院不主动审查时效；劳动仲裁中不提，诉讼阶段再提一般不支持。
- **只做实体抗辩，忽略程序**：仲裁协议、管辖、主体。
- **只主张「不构成违约」，不同时主张违约金过高**。
- **在回函或和解谈判中自认不利事实**。和解谈判中的让步内容要声明不作为证据（实际效果有限，仍要谨慎）。
- **乐观估计胜诉率**。要客观说清对方主张合理的部分。
- **期间计算不写假设**。送达日、节假日必须写明。
