when: 用户提供一份业务方案、营销活动、商业模式、运营规则、宣传文案、内部制度草案或项目计划，问其中有没有违法违规之处、怎么改才合规。重点是「一套做法」而不是「一份合同」；单个行为是否合法、没有方案文本的归 legality。
examples:
  - 我设计了一个会员充值返现活动，帮我看有没有违法的地方
  - 我们想做三级分销，推荐人拿下线的提成，合规吗
  - 这份直播带货的宣传话术有没有问题
  - 抽奖活动规则帮我审一下
  - 我们打算让用户先付钱后排队分红，这个模式行不行
  - 员工持股计划方案有没有法律风险

## 先弄清的事实

方案审查最怕只看文字、不看钱怎么流、人怎么进来。先把业务跑通。

| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 方案全文 | 请提供完整的方案、活动规则、宣传文案、页面截图或流程图 | 审查对象；口头描述容易遗漏关键环节 | 是 |
| 经营主体 | 由哪家公司实施？经营范围和持有的许可证有哪些？ | 许可类业务（金融、支付、医疗、食品、教育、出版、网络信息服务等）无证即违法 | 是 |
| 资金流 | 用户的钱付给谁、什么时候付、钱放在哪、怎么返还或分配？有没有承诺回报？ | 判断预付资金监管、非法集资、传销、变相金融业务的核心 | 是 |
| 参与者与层级 | 谁能参与？推荐人拿多少、按什么计算？有没有多层级？参与需要先交钱或买货吗？ | 传销认定看入门费、层级、按发展人数计酬 | 视情况（涉及分销推广时要问） |
| 目标用户 | 面向消费者还是企业？是否包括未成年人、老年人？ | 消费者保护和特殊群体保护规则 | 是 |
| 地域与渠道 | 在哪些地区做？线上（哪个平台、自建 App 或小程序）还是线下？ | 地方规定（如单用途预付卡）；平台规则；网络经营的额外义务 | 是 |
| 宣传内容 | 对外怎么宣传？有没有收益、功效、排名、「最」字、对比、代言人？ | 广告法、反不正当竞争法的高发区 | 视情况（涉及宣传时要问） |
| 数据处理 | 收集哪些用户信息？做不做画像、推送、共享给合作方？ | 个人信息保护法的告知同意、单独同意 | 视情况（涉及用户数据时要问） |
| 规模与阶段 | 计划多大规模？已经上线了吗？已有多少用户和资金？ | 已上线的要评估存量风险和整改路径；规模影响执法关注度和刑事门槛 | 是 |
| 方案目的 | 想解决什么商业问题（拉新、锁客、融资、激励员工）？ | 改造方案要保住商业目的 | 是 |

## 工作步骤

### 1. 拆环节

把方案拆成一张流程表：**准入 → 宣传 → 用户参与 → 付款/资金 → 履约/兑付 → 分配/激励 → 数据 → 退出/退款 → 售后与争议**。每个环节写清主体、动作、钱、数据。后续审查按环节走，不按方案原文的段落走。

### 2. 先过「红线」：可能构成犯罪或被取缔的模式

逐项判断，有一项命中的放在审查意见最前面：

| 红线 | 识别特征 | 依据（检索核对） |
|---|---|---|
| 非法集资 | 未经许可、向社会公开宣传、承诺还本付息或给付回报、向不特定对象吸收资金（四要素） | 《防范和处置非法集资条例》第二条；《刑法》第一百七十六条（非法吸收公众存款）、第一百九十二条（集资诈骗） |
| 传销 | 交入门费或变相入门费（如必须购买高价商品）取得资格；按发展人员数量或下线业绩计酬；层级 | 《禁止传销条例》第二条、第七条；《刑法》组织、领导传销活动罪（条号以资料库为准） |
| 无证经营金融、支付业务 | 资金池、代收代付、二清、发放贷款、虚拟货币交易 | 相关金融法律法规；《刑法》第二百二十五条（非法经营） |
| 赌博或变相赌博 | 付费参与、结果由偶然决定、可兑换现金或财物（盲盒、抽奖、竞猜要警惕） | 刑法、治安管理处罚相关规定（检索核对） |
| 侵犯个人信息 | 买卖、非法提供用户信息，未经同意共享 | 《个人信息保护法》；《刑法》侵犯公民个人信息罪（条号以资料库为准） |
| 商业贿赂 | 给交易相对方的工作人员或影响交易的人财物、回扣 | 《反不正当竞争法》第八条；《刑法》第一百六十四条 |

命中红线时，结论直接写「不建议实施」，然后给能实现同一商业目的的替代方案；需要时建议转 criminal_risk 或律师。

### 3. 按环节对照监管规则

| 环节 | 常见问题 | 主要规则 |
|---|---|---|
| 准入 | 经营范围不含、缺少许可或备案 | 行业许可规定；《市场主体登记管理条例》 |
| 宣传 | 绝对化用语（第九条）、虚假或引人误解（第四条、第二十八条）、引证数据无出处（第十一条）、医疗保健功效（第十六条至第十八条）、需要事前审查的广告未审查（第四十六条）；虚假商业宣传、刷单炒信（《反不正当竞争法》第九条） | 《广告法》《反不正当竞争法》 |
| 有奖销售 | 奖项信息不明确、谎称有奖或内定、抽奖式最高奖超过法定上限 | 《反不正当竞争法》第十一条（最高奖金额以条文为准） |
| 价格 | 先涨后降、虚构原价、价格欺诈、不明码标价 | 《价格法》第十三条、第十四条 |
| 预付与会员 | 预付卡无书面合同、未明确退款规则、超出规定的预收、关店跑路风险 | 《消费者权益保护法实施条例》第二十二条；《最高人民法院关于审理预付式消费民事纠纷案件适用法律若干问题的解释》；地方单用途预付卡规定 |
| 消费者权利 | 七日无理由退货的排除、霸王条款、格式条款未提示 | 《消费者权益保护法》第二十五条、第二十六条；《民法典》第四百九十六条、第四百九十七条 |
| 电商 | 搭售默认勾选、个性化推荐无关闭选项、虚构交易 | 《电子商务法》第十七条至第十九条 |
| 平台与算法 | 利用数据和算法影响用户选择、强制商家低价 | 《反不正当竞争法》第十三条、第十四条 |
| 付款账期 | 大型企业对中小企业的不合理付款期限 | 《保障中小企业款项支付条例》；《反不正当竞争法》第十五条 |
| 个人信息 | 无合法性基础、未告知、敏感信息无单独同意、向第三方提供未告知接收方 | 《个人信息保护法》第十三条、第十四条、第十七条、第二十三条、第二十八条、第二十九条 |
| 用工与激励 | 推广员是员工还是合作方；以「合伙人」名义规避劳动关系；股权激励的出资与退出 | 转 employment、corporate |
| 税务与发票 | 返利、佣金的发票和个税代扣 | 提示需税务专业人士 |

### 4. 定性每个问题

每个问题给出：
- **违规点**：方案哪一环节、原文哪一句。
- **后果层级**：民事（合同或条款无效、赔偿、消费者惩罚性赔偿——欺诈的退一赔三，《消费者权益保护法》第五十五条）/ 行政（处罚种类和幅度，写到法条，不要估具体金额）/ 刑事（有无入罪风险，金额或人数门槛不凭记忆写）。
- **风险等级**：高（违法明确或可能入罪）/ 中（灰区、执法口径不一、依赖具体执行）/ 低（表述或流程瑕疵）。
- **改法**：具体到改哪句话、加什么流程。

### 5. 设计合规替代方案

只说「不行」没有价值。给出保留商业目的的改法，例如：
- 多级分销 → 只保留一级推荐奖励，奖励按实际消费计算，不收入门费，不以发展人数计酬。
- 充值返现承诺收益 → 改为消费折扣或积分，不承诺现金回报，预收资金规模和退款规则合规。
- 「全网最低」「第一」→ 改为有出处、可证明的具体事实表述。
- 盲盒、抽奖 → 公示概率与奖品价值，不可兑现金，限制未成年人。
- 用户数据共享 → 告知接收方名称和用途，取得同意或单独同意，签数据处理协议。

### 6. 已上线方案的处理

- 先评估存量：已收资金、用户人数、投诉情况、是否被约谈或立案。
- 给出整改顺序：先停高风险环节（停止收款、停止宣传）→ 处理存量（退款、兑付方案）→ 修改规则重新上线。
- 主动整改对行政处罚的意义：主动消除或减轻危害后果的，应当从轻或减轻处罚（《行政处罚法》第三十二条）；违法行为轻微并及时改正、没有造成危害后果的，不予处罚；初次违法且后果轻微并及时改正的，可以不予处罚（第三十三条）。
- 涉嫌刑事的，建议立即找律师，不要在聊天中给出「怎么规避调查」的建议。

## 必查依据

- 先 search_law 按行为关键词检索（「有奖销售」「绝对化用语」「预付」「传销」「非法集资」「个人信息 单独同意」），按法律 → 行政法规 → 司法解释 → 地方性法规的顺序读。
- 行业方案：search_law「行业名 + 许可」「行业名 + 广告」，并查是否有专门的行政法规（如《直销管理条例》《商业特许经营管理条例》《彩票管理条例》）。
- search_cases、search_guides 查执法或裁判口径（如「变相入门费」「消费返利 传销」）。
- 地方：单用途预付卡、网络交易、广告监管的地方性法规，按用户地区筛选。

## 地区差异

- 单用途预付卡、教培和健身预付费、网络直播营销、医美广告、房地产广告等多有地方性法规或地方监管要求，按用户所在地和实施地检索。
- 跨区域的线上活动以最严格地区的要求设计；资料库查不到某地规定时，明说没有查到，建议向当地市场监管部门咨询。
- 执法尺度（如「首违不罚」清单）各地有地方清单，资料库可能没有，提示用户查询当地市场监管部门公布的清单。

## 容易出错的地方

- **只看文字不看资金流**。很多违法模式在文字上包装成「会员」「合伙人」「共享」「消费返利」，要看钱从谁到谁、回报怎么来。
- **漏掉许可问题**。经营行为本身需要许可时，方案再精巧也是无证经营。
- **处罚金额凭记忆写**。只写法条规定的处罚种类和幅度，并以资料库条文为准。
- **刑事门槛凭记忆写**。立案追诉标准经常调整，资料库有就引用，没有就只提示「达到一定数额或人数可能构成犯罪」。
- **把部门规章、地方规定说成法律**。层级要写准；规章资料库可能没有，没有就写名称并标未核实。
- **只说不能做，不给替代方案**。
- **用旧版《反不正当竞争法》的条号**。2025 年修订后条文有调整。
- **对已上线、已有大量资金的方案轻描淡写**。规模越大，越要优先止损并建议律师介入。
