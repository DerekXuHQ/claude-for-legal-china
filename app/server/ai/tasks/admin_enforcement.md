## 先弄清的事实
| 事实 | 怎么问 | 为什么要知道 | 必需 |
|---|---|---|---|
| 收到的文书 | 收到的是什么文书？请贴全文或拍照：检查通知、询问通知、责令改正通知书、查封扣押决定书、行政处罚告知书（事先告知书）、听证告知书，还是处罚决定书？ | 程序阶段决定还能做什么、期限还剩多少 | 是 |
| 送达日期 | 文书是哪天收到的？怎么送达的（当面、邮寄、电子）？ | 陈述申辩、听证、复议、诉讼的期限都从收到或知道之日起算 | 是 |
| 执法机关 | 是哪个部门发的？哪一级（区县、市、省）？ | 决定复议机关、管辖法院，以及适用哪个裁量基准 | 是 |
| 认定的违法事实和依据 | 文书说您违反了哪部法规哪一条？拟处罚的种类和金额是多少？ | 核对事实认定和法律适用是否正确、罚款是否在法定幅度内 | 是 |
| 实际情况 | 实际发生了什么？行为持续多久？涉及金额或违法所得多少？有没有造成后果？ | 判断是否成立、情节轻重、能否不罚或从轻 | 是 |
| 是否初次、是否已改正 | 以前有没有因为同类问题被处罚过？发现后已经改正了吗？ | 首违不罚、轻微不罚、从轻减轻的关键事实 | 是 |
| 执法过程 | 检查时执法人员几个人、有没有出示证件？做了笔录吗，您签了没有？取了哪些证据？ | 程序合法性审查 | 否 |
| 主观情况 | 当时知不知道这样违规？是供应商、员工个人还是公司决策导致的？ | 没有主观过错可以不罚；也影响责任主体 | 否 |
| 影响 | 这次处罚对您最大的影响是什么：罚款金额、停产停业、吊销许可，还是公示影响信用和招投标？ | 决定应对重点（降罚款、避免公示还是保住许可） | 否 |

## 工作步骤

1. **第一屏先给期限。** 根据所处阶段列出时间表，算出到期日（注明起算假设，最后一天是节假日的顺延）：
   - 处罚告知后：陈述、申辩没有统一法定天数，以告知书写明的期限为准（常见 3 日、5 日或 7 日），不提出视为放弃；
   - 听证：当事人要求听证的，应在行政机关告知后**五日内**提出（《行政处罚法》第六十四条）；
   - 处罚决定后：申请行政复议，自知道或应当知道之日起**六十日**内（《行政复议法》第二十条，法律规定更长的除外）；直接起诉，自知道或应当知道之日起**六个月**内（《行政诉讼法》第四十六条）；对复议决定不服起诉，收到复议决定书之日起**十五日**内（《行政诉讼法》第四十五条）；
   - 罚款缴纳：收到处罚决定书之日起十五日内（《行政处罚法》第六十七条），逾期可能加处罚款；确有困难可以申请暂缓或分期（第六十六条）；
   - 查封、扣押：期限一般不超过三十日，可延长不超过三十日（《行政强制法》第二十五条）。
   提醒：复议和诉讼期间处罚一般不停止执行（《行政处罚法》第七十三条；《行政复议法》第四十二条；《行政诉讼法》第五十六条）。
2. **判断复议是不是必须先走。** 有些情形必须先复议才能起诉（复议前置），例如对当场作出的行政处罚决定不服（《行政复议法》第二十三条，其他情形逐项对照该条）。复议前置的，直接起诉会被驳回。
3. **审程序。** 逐项核对，程序违法是撤销处罚的独立理由（《行政诉讼法》第七十条第三项）：
   - 执法人员是否不少于两人、是否出示执法证件（《行政处罚法》第四十二条、第五十五条）；
   - 是否在作出决定前告知拟处罚内容、事实、理由、依据和陈述申辩、听证权利（第四十四条）；未告知或拒绝听取陈述申辩的，不得作出处罚决定（第六十二条）；
   - 属于较大数额罚款、没收较大数额违法所得、降低资质、吊销许可、责令停产停业、责令关闭、限制从业等情形的，是否告知听证权（第六十三条）；
   - 重大案件是否经法制审核（第五十八条）；
   - 先行登记保存证据的，是否在七日内作出处理决定（第五十六条）；
   - 是否在立案后九十日内作出决定（第六十条，另有规定的除外）；
   - 查封扣押是否经批准、当场交付决定书和清单、是否超出涉案范围（《行政强制法》第十八条、第二十三条、第二十四条）。
4. **审事实和法律适用。**
   - 事实是否查清、证据是否充分（第四十条：违法事实不清、证据不足的，不得给予行政处罚）；看清单上的证据和笔录内容。
   - 法律适用：适用违法行为发生时的规定，作出决定时新规定处罚较轻或不认为违法的，适用新规定（第三十七条，"从旧兼从轻"）。用 compare_versions 看行为时和现在的版本。
   - 是否超过追责时效：违法行为二年内未被发现的不再处罚，涉及生命健康安全、金融安全且有危害后果的延长至五年；连续或继续状态从行为终了之日起算（第三十六条）。
   - 同一违法行为不得给予两次以上罚款，违反多个规范的按罚款数额高的处罚（第二十九条）。
   - 罚款金额是否在法定幅度内：read_articles 拿到罚则原文，核对起点和上限、按什么基数（违法所得、货值金额、广告费用）计算。
5. **找不罚、少罚的理由。** 这是大多数企业最关心的。逐项对照：
   - **不予处罚**：违法行为轻微并及时改正，没有造成危害后果的，不予处罚；初次违法且危害后果轻微并及时改正的，可以不予处罚（"首违不罚"）；有证据足以证明没有主观过错的，不予处罚（第三十三条）。
   - **应当从轻或减轻**：主动消除或减轻危害后果、受他人胁迫或诱骗、主动供述行政机关尚未掌握的违法行为、配合查处有立功表现等（第三十二条）。
   - **裁量基准**：行政机关可以制定并公布裁量基准（第三十四条）。很多部门和省份有"轻微违法行为不予处罚清单""首违不罚清单"和罚款裁量基准。用 search_law 按用户所在省检索，资料库没有收录部门或地方规范性文件时要明说，并建议用户在执法机关官网查当地清单。
   - 准备证据：改正的照片和记录、销售额和违法所得的真实计算、首次违法的说明、内部整改制度、供应商的保证文件等。
6. **决定应对策略。**
   - 事实清楚、确实违法：重点放在陈述申辩，争取不罚或从轻，态度配合；
   - 事实或证据有争议、金额大或涉及吊销停产：申请听证，听证中可以质证、申辩（第六十四条）；陈述申辩不会导致加重处罚（第四十五条）；
   - 决定已作出且明显违法或不当：复议（审查合法性和适当性，可以变更）或诉讼（处罚明显不当的法院可以判决变更，第七十七条）。复议机关一般是作出机关的本级政府（《行政复议法》第二十四条），具体管辖逐条核对。
   - 只是检查或询问阶段：配合检查，但可以要求出示证件，对笔录内容逐页核对后再签字，不认可的写明意见；不要销毁或转移证据（先行登记保存期间不得销毁转移，第五十六条），不要阻碍执法。
7. **起草文书。** 陈述申辩书、听证申请书、行政复议申请书。陈述申辩书写法：事实部分逐项回应告知书认定 → 法律适用和裁量 → 不罚或从轻理由及证据 → 请求（不予处罚 / 减轻 / 从轻 / 变更处罚种类）。
8. **后续：公示与信用修复。** 具有一定社会影响的处罚决定依法公开（《行政处罚法》第四十八条）。处罚记录会出现在国家企业信用信息公示系统、信用中国等平台。履行完毕后，按信用修复规定申请修复（修复条件、公示期限由部门规章和规范性文件规定，资料库可能未收录，告诉用户到信用中国网站"信用修复"栏目查询当前规则）。

## 地区差异
- 裁量基准和"轻微违法不罚清单""首违不罚清单"大多由省级或市级部门制定，各地范围不同，是本类问题最大的地区差异。按用户所在省市检索；资料库未收录的明确告诉用户"本地清单需到执法机关官网核实"。
- "较大数额罚款"（触发听证权）的标准由各省或各部门规定，金额不同，不要写死。
- 地方性法规可能在国家规定的幅度内细化罚则，也可能设定地方特有的义务；用 search_law 按省份筛选。
- 各地行政复议机构设置和线上申请渠道不同（多数地方政府司法局有网上复议入口）。

## 容易出错的地方
- 不先给期限，用户错过听证五日、复议六十日。
- 把陈述申辩期限写成某个固定天数。法律没有统一规定，以告知书为准。
- 忘了复议前置，建议用户直接起诉。
- 以为申请复议或起诉后就不用先交罚款、不用停产。一般不停止执行。
- 只说"可以首违不罚"不核对条件。首违不罚要同时满足初次违法、危害后果轻微、及时改正，而且是"可以"不是"应当"。
- 不核对罚则原文，直接接受告知书的金额，或者凭记忆写罚款幅度。
- 忽略"从旧兼从轻"和二年追责时效。
- 建议用户拒绝检查、拒签笔录或转移证据。正确做法是配合但核对、写明异议、保留副本。
- 把可能涉嫌犯罪的行为（例如危害食品安全、虚开发票、非法经营）只按行政处罚处理，没有提示移送公安的风险。此时转刑事风险手册一并分析。
- 写死各地"较大数额罚款"标准、信用修复公示期限。
