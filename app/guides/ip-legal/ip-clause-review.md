本篇用于审查协议中的知识产权条款：权利归属、所有权、许可授予、知识产权保证和赔偿。逐条说明每项条款的作用、与市场惯例或团队标准立场的偏差、风险，以及具体修改建议，形成律师可以直接采用的审查备忘录。

大多数协议中风险最高的是**知识产权归属和权利转让条款**，事后极难补救。劳动合同或顾问协议中的转让缺陷，往往在多年后的并购尽调、融资或诉讼中暴露。应有的转让表述薄弱或缺失的，在备忘录最前面醒目标注，不能淹没在一长串问题里。

## 适用情形

- 劳动合同、顾问协议、工作说明书（SOW）、供应商主协议、许可（许可进/许可出）协议、合作或联合开发协议、和解协议、收购或资产购买协议中的知识产权条款；
- 需要检查权利归属表述或许可范围。

## 需要准备的材料

- 协议全文（以及相关的 SOW、订单、补充协议）；
- 团队的标准立场：各管辖法律下的处理（影响著作人身权不行使承诺是否有效、职务作品规则是否适用、默示许可能否填补空白、许可可以多宽）；偏差由谁、在什么严重程度上审批；哪些管辖被列为需上报或不接受。

## 办理步骤

### 1. 定位

快速通读全文，回答：

| 问题 | 可能的答案 |
|---|---|
| 协议类型 | 劳动合同 / 顾问协议或 SOW / 供应商主协议 / 许可进 / 许可出 / 合作或联合开发 / 和解协议 / 收购或资产购买 / 其他 |
| 本方在知识产权上的立场 | 授予权利或接收权利 / 转让或取得知识产权 / 许可人或被许可人 |
| 相对方 | 名称和成熟度：个人、初创公司、大型企业 |
| 是否为知识产权单独支付对价 | 工资、费用、许可费、预付款、股权、无 |
| 适用法律和争议解决地 | 协议如何约定；团队是否把该管辖列为需上报或不接受 |

立场按每份文件单独判断：审劳动合同时是“接收”方，同一天审对外许可时就是“授予”方。立场不清楚的（双方都贡献也都取得权利的合作协议、涉及知识产权传递的转售协议），先问清楚；双向都有的，分方向分别审查。

### 2. 权利归属缺陷检查（最优先）

劳动合同、顾问协议、SOW、委托创作合同等公司应从相对方取得工作成果知识产权的文件，先查转让表述：

- **现时转让**：“在此转让”“在此不可撤销地转让并同意转让”。只写“同意转让”的，是转让的承诺而不是转让本身，可能还需要另签文件才能完成。
- **范围**：是覆盖工作中创造的全部知识产权，还是只覆盖与公司业务相关的，或只覆盖利用公司资源创造的？预期工作成果范围广而转让范围窄，就是缺陷。
- **著作人身权**：《著作权法》第10条规定了署名权、修改权、保护作品完整权等著作人身权，不可转让，但可以约定作者不行使。协议适用中国法或相对方在中国的，不行使著作人身权的承诺至关重要。
- **进一步协助条款**：相对方同意日后签署完成转让所需的其他文件。
- **在先知识产权的排除**：相对方从转让中排除了什么，清单是具体的还是开放式的？

任何一项缺失或薄弱，在备忘录顶部以 🔴 或 🟠 标注，并给出具体修改建议（见下方模板）。

**人工智能生成内容能否被转让覆盖？** 中国关于人工智能生成内容可版权性的规则仍在发展。北京互联网法院在(2023)京0491民初11279号案中认可了人工智能生成图片在特定条件下的可版权性。承包方在工作成果的实质部分使用了人工智能工具的，这部分的权利状况不确定，而转让条款只能转让已经存在的权利。检查：

- 协议有没有人工智能使用披露义务？
- 有没有关于人工智能在交付物中作用的陈述？
- 有没有区分人工智能辅助部分和人类创作部分的机制？

缺失且可以预见会使用人工智能辅助创作的（咨询、开发、内容创作、设计）：🟠 高。建议增加人工智能使用陈述和披露义务。人工智能生成作品的权利状况是持续变化的领域，须对照最新司法实践核实。〔待核〕

**人工智能辅助下的发明人认定。** 依据《专利法》第16条，发明人有权在专利文件中写明自己是发明人；发明人认定错误不在《专利法实施细则》第69条第2款列举的无效宣告理由之内。工作成果可能包含专利成果的，检查协议有没有人工智能使用陈述、发明人认定程序、创作过程中使用人工智能的披露义务；缺失的，建议增加人工智能使用陈述和发明人认定程序。

### 3. 逐条审查

对每项知识产权相关条款出一个审查块。需要查找的条款：

- **转让 / 委托作品**：协议项下创作成果的知识产权归属；
- **交付物所有权**：与转让条款不同，通常是对工作成果的陈述；
- **改进和衍生作品**：对在先知识产权的改进、衍生作品的归属；
- **背景知识产权与前景知识产权**：是否分别定义在先和新创的知识产权，并在必要范围内许可背景知识产权；
- **许可授予**：范围、独占性、地域、使用领域、可否再许可、期限、终止触发条件、许可费结构；
- **知识产权保证**：不侵犯第三方权利、有权授予、原创；
- **知识产权赔偿**：范围、上限、程序、除外情形（用户修改、组合使用、未经授权使用）；
- **著作人身权不行使承诺**；
- **开源陈述**：交付物中嵌入或不嵌入哪些开源软件；
- **商标使用**：使用相对方标识的授权或限制、品牌指南、许可人的质量控制；
- **保密 / 商业秘密**：商业秘密材料的处理、合理保护措施、返还或销毁、终止后义务。

**严重程度：**

| 等级 | 含义 |
|---|---|
| 🔴 严重 | 不修改不应签署。应有转让的文件存在转让缺陷；本意窄许可写成了宽许可；本意非独占写成了独占。 |
| 🟠 高 | 坚持争取，对方不让步则上报。范围模糊、缺少著作人身权不行使承诺、缺少进一步协助条款、赔偿范围过窄。 |
| 🟡 中 | 第一轮提出，如是最后一个未决事项可以接受。不精确的修饰性表述、存续期短于标准。 |
| 🟢 低 | 标注即可，不耗费谈判筹码。不改变权利分配的文字偏差。 |

条款可以两种方式解读、不清楚措辞是否实现了预期分配的，标注交律师审查，并列出双方各自的有利因素，不替律师做主观判断。权利分配问题一旦签署就难以挽回，在尽调、融资或诉讼中才会暴露；多标注一个模糊条款的代价则很小。

### 4. 跨条款一致性

知识产权条款可能作为一个整体失效。检查：

- **许可授予与许可范围是否匹配？**（“使用”交付物的许可窄于“使用、修改和创作衍生作品”的许可。）
- **保证是否覆盖授予的全部内容？**（许可同时涵盖著作权和商业秘密，而不侵权保证只限于专利，就有空白。）
- **赔偿是否覆盖保证的内容？**（没有赔偿的保证是没有救济的承诺。）
- **终止后许可是否收回？**（还是已付清的许可在终止后继续有效？两种立场都说得通，关键是与意图一致。）
- **本协议与相关 SOW、订单、补充协议的知识产权分配是否一致？** 有冲突的标出。

### 5. 管辖提示

协议涉及以下情形的，标注适用法律，以及团队把该管辖列为标准、需上报还是不接受：

- **著作人身权**：《著作权法》第10条规定署名权、修改权、保护作品完整权等著作人身权，不可转让，但可约定不行使。
- **职务作品**：《著作权法》第18条规定职务作品的著作权归属。一般情况下作者享有著作权；主要利用单位物质技术条件创作并由单位承担责任的工程设计图、产品设计图等，以及特殊职务作品，署名权以外的著作权归单位。
- **默示许可**：中国司法实践对默示许可的认定较为谨慎，一般需要明确约定。
- **专利赔偿的除外情形**：组合使用、修改、用户提供的被控特征除外，是国际通行做法。

### 6. 修改建议的粒度

修改是谈判的产物，不是重写。整条替换传递的信号是“我们抛弃了你的起草”，既有对抗性，又迫使对方重读整条，还丢掉了其中本无问题的部分。精准修改——删一个词、加一个短语、改写一款——传递的是“我们有具体诉求”，对方更容易读懂、接受。

默认采用能达到本方立场的最小改动：

- 能改**词**的不改短语；
- 能改**短语**的不改句子；
- 能改写**款**的不替换句子；
- 能替换**句子**的不替换整条；
- 只有对方文本与本方立场差距过大、逐点修改反而难读时，才替换**整条**，并在发送函中说明：“第【X】条因修改范围较大，直接替换而未逐点标注，可以逐项说明差异。”

拿不准时选更小的改动。

### 7. 形成备忘录

- 备忘录及所审协议可能受保密义务或律师工作成果保护，继承其保密状态：只在保密范围内分发，按保密材料存放，对外交付前去掉内部工作成果标识。
- 引用法条、法规、案例或专著的，注明出处（法律数据库、国家知识产权局官方来源、相对方草案或内部文件等）；凭记忆写出、未经核实的，句末标〔待核〕，优先核查。
- 检索结果不足以支撑某项规则的，如实报告检索到的内容，不用网络搜索或记忆悄悄补齐；是否扩大检索、换数据库、采用较低可信度的来源（须标明并对照官方来源核实），或标为未核实并停止，由律师决定。
- 收尾时由律师决定下一步：起草修改稿、上报、补充事实、等待观察或其他。

## 检查清单

- □ 已按团队标准立场确定管辖提示
- □ 劳动/顾问/SOW/委托创作类文件已先做权利归属缺陷检查
- □ 每个 🔴 和 🟠 问题都有具体替代表述
- □ 已做跨条款一致性检查，不只是逐条审查
- □ 引用已注明出处，未核实的已标〔待核〕
- □ 审批人已具体到人，不是笼统的“上报法务”
- □ 已加内部工作成果标识

## 模板

### 权利归属缺陷提示

```markdown
## ⚠️ 权利归属缺陷

**第【X】条** 转让工作成果中的知识产权，但：【具体问题，例如“写的是‘同意转让’而非‘在此转让’”，或“未约定作者不行使著作人身权，而适用法律为中国法”，或“未列明排除清单，而相对方已有平台类知识产权”】。

**风险：** 这类缺陷往往多年后在并购尽调中暴露。相对方（或其承继者）可能在本方以为已经拥有的工作成果上保留剩余权利。

**建议修改：**
> “【具体替代表述】”

**上报：** 权利归属范围缺陷上报至【审批人】。
```
