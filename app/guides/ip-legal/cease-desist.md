侵权警告函是主张法律权利、要求对方停止某种行为的函件，是知识产权实务中最重要的函件之一。本篇分两部分：**发函**（起草侵权警告函）和**收函**（对收到的警告函分诊，形成选项备忘录）。

发函是走向诉讼的第一步：收件人可以在其选择的管辖地提起确认不侵权之诉，过度或恶意的主张还可能被用来反制发函人。收函则意味着时限开始计算、必须作出决策。两侧都要按下文的关口处理。

## 适用情形

- 按公司维权姿态，对侵权人主张权利、发送警告函。
- 收到他人发来的侵权警告函，需要评估主张、确定应对方案。

**法域。** 知识产权具有地域性，中国注册商标的保护限于中国大陆境内。著作权基于伯尔尼公约具有多边性，但执法和法定赔偿（著作权法第54条）取决于当地法律。本篇以中国大陆法为框架；侵权行为、对方当事人或管辖地在其他法域的，需单独标注，本篇的函件不一定直接适用。

## 需要准备的材料

- 公司维权姿态（激进 / 适度 / 保守）和警告函审批矩阵（审批人、自动升级条件）。
- 公司已有的警告函模板或维权操作手册（如有）。
- 权利证明：注册证、登记证书、专利证书等。
- 侵权证据：截图、购买记录、监测线索、消费者混淆报告等。
- 收函模式下：收到的警告函原件。

## 办理步骤：发函

### 1. 确认所主张的权利

- **商标**：是否注册？在哪里注册（CNIPA / 其他国家）？注册号和类别？如仅为未注册驰名商标，准备首次使用日期、地理范围、知名度证据。
- **著作权**：是否登记？作品名称、登记号、日期？未登记的也可主张；中国著作权登记为自愿登记，登记证书可作为初步证据（《最高人民法院关于审理著作权民事纠纷案件适用法律若干问题的解释》第7条）。
- **专利**：发明、实用新型还是外观设计？专利号、授权日？
- **多种权利**：分别识别。

### 2. 用具体事实描述侵权行为

- **谁**在做：主体名称、个人、平台账号。
- **什么**：被控侵权商标、被控抄袭作品、被控侵权产品，附样品或描述。
- **哪里**：网站 URL、电商平台链接、实体零售、社交媒体。
- **从何时起**：首次观察日期、能记录的最早使用日期。
- **证据**：截图、购买记录、监测服务线索、消费者混淆报告。

不用形容词，只写事实。

### 3. 确认与收件人的关系

| 关系 | 处理 |
|---|---|
| 竞争对手（直接或间接） | 适用标准姿态 |
| 经销商 / 渠道伙伴 | 调整语气，考虑先发温和沟通 |
| 前被许可人 / 前员工 / 前合伙人 | 合同条款可能适用，在函中引用 |
| 陌生人 / 随机侵权人 | 标准处理 |
| 当前客户 / 合作伙伴 | 按审批矩阵自动升级，起草前先报告 |

### 4. 明确诉求

停止侵权使用；报告销量、利润、体量；销毁或召回侵权产品；金钱赔偿；转让域名、移交账户、转让被控标识或作品；删除侵权内容、公开声明；在某日前作出书面合规承诺。

**电商平台并行路径。** 被控行为发生在电商平台（淘宝、天猫、京东、拼多多、抖音电商、快手小店等）的，同时考虑平台知识产权保护投诉。依据《电子商务法》第42-43条，平台收到通知后应采取删除、屏蔽、断开链接等必要措施，并转送通知。平台投诉通常数天内有结果；警告函则给了侵权人在谈判期间清理库存的时间。两条路径不互相排斥，行为以平台为主时建议同时提交。

### 5. 按维权姿态校准

按公司的默认姿态（激进 / 适度 / 保守）确定语气、诉求和后果表述。

### 6. 对方当事人尽职调查（强制，起草前完成）

每封警告函都带有确认不侵权之诉和恶意诉讼的风险，风险大小取决于收件人是谁。起草前先调查并形成简短摘要，交决策人确认仍要发函后再起草：

- 法律主体
- 规模和资源
- 知识产权组合
- 诉讼历史
- 律师情况
- 确认不侵权之诉风险
- 关系风险

### 7. 起草

按中国实务惯例，函件结构见下文「文书结构」。起草规则：

- 写具体事实，不用形容词。
- 不过度主张。
- 法条和判例引用在核实前保持占位。
- 后果表述与维权姿态一致。

### 8. 发函前关口

函件草稿是供律师审核的稿件，不是可以直接发出的函件。发出前逐项确认：

1. 所主张的权利有效：注册权利以注册簿记载为准，不是假设。
2. 主张有合理基础：理性的执业者在这些事实上会提出同样的主张。
3. 诉求相称：要求的救济与行为相匹配。
4. 有权启动争议的人已批准（审批人按公司审批矩阵）。
5. 对方当事人尽职调查（第6步）已完成并经确认。

发函的风险要向审批人讲清：

- 可能触发收件人在对其有利的管辖地提起确认不侵权之诉。
- 过度或恶意的主张可被反制：商业诋毁、不正当竞争、恶意诉讼等。
- 争议一旦启动，不一定能低成本和解。

非律师经办的，发函前须由执业律师审核。

**对外函件不加内部保密抬头。** 发给对方的警告函上不出现「保密——律师工作成果」字样；内部草稿、发函前摘要和分诊备忘录保留该抬头。

## 办理步骤：收函

### 1. 阅读来函，提取要素

发函人、收件人、送达方式和日期、被主张的权利、被指控的行为、引用的法律依据、诉求、威胁、语气。

### 2. 评估对方主张

- **权利有效性**：被主张的注册是否存在且有效？查 CNIPA 商标公告、中国版权保护中心、CNIPA 专利公告，标注看起来休眠或无效的权利。
- **主张是否合理**：商标看混淆可能性（商标法第57条）；著作权看接触 + 实质性相似；专利看全面覆盖原则 + 等同。标出主张最弱的地方。
- **是否过度**：要求是否超出行为的正当范围。
- **时限**：诉讼时效（《民法典》第188条，三年）、权利时间线，标注函件表面的日期问题。
- **管辖**：对方可能在哪里起诉？己方是否有提起确认不侵权之诉的机会？

### 3. 评估己方风险

- 是否确实侵权？如实判断。
- 能否轻松停止？比较合规成本与应战成本。
- 发函人是职业维权人还是真实的权利主张人？

### 4. 列出选项并推荐

| 选项 | 适用 |
|---|---|
| A 快速合规 | 主张有依据，合规成本低，不值得打 |
| B 谈判 | 有中间地带的商业方案（许可、共存、更名时间表） |
| C 坚决回应（驳回） | 对方主张弱、过度或事实错误 |
| D 不回应（但保全证据） | 主张离谱，发函人无起诉能力 |
| E 主动提起确认不侵权之诉 | 面临真实的商业不确定性，对方主张弱 |
| F 申请宣告对方权利无效（商标无效 / 专利无效） | 对方权利本身脆弱 |

推荐一个选项，附两句理由。建议坚决回应的，可转入发函流程起草回函；建议提起确认不侵权之诉或无效宣告的，按公司规定升级至外部律师，不自行起草。

### 5. 期限分诊

- 对方声明的期限：记录，但对己方没有法律约束力。
- 己方内部决策期限。
- 法律期限：诉讼时效、合同约定的补救期。

### 6. 撰写分诊备忘录

内容包括：主张摘要、权利有效性、引用的法律依据、合理性评估、己方风险、选项及推荐、期限、立即行动事项。

## 审查要点

- 不确定是否构成侵权、是否构成近似、主张是否合理、发函是否安全时，不默认安全。标注供律师审核，列出正反因素，写明不确定之处。在假定基础上发出警告函无法撤回；提出疑虑则可以再讨论。
- 收函侧的评级只是供分流的结构化阅读，实质意见由律师作出。
- 发函人引用的法律不在分诊中自行判断有效与否，标注供律师核实。

## 常见风险

- 确认不侵权之诉：有资金的收件人会把警告函当作选择对其有利管辖地的机会。
- 反制主张：商业诋毁、不正当竞争、恶意诉讼。
- 权利基础不实：引用已失效或不存在的注册。
- 诉求不相称导致谈判僵局或被反诉。

## 文书结构

**侵权警告函**

1. 发函人 / 函头及日期
2. 收件人信息
3. 事由：简明，不泄露保密策略
4. 权利说明：商标写注册号、类别、知名度；著作权写作品名称、登记信息；专利写专利号
5. 侵权事实：具体行为描述，附证据
6. 法律依据：商标法第57条 / 第63条、著作权法第52-53条、专利法第11条 / 第65条、反不正当竞争法第6条等
7. 诉求：编号、具体、相称
8. 期限：写明日历日期和确认方式
9. 不遵守的后果：与维权姿态一致（诉讼、行政投诉、平台投诉等）
10. 证据保全要求
11. 权利保留声明
12. 签署栏

**收函分诊备忘录**

主张摘要 → 权利有效性 → 引用的法律依据 → 合理性评估 → 己方风险 → 选项及推荐 → 期限 → 立即行动。

- 《著作权法》第52-53条、第54条
- 《专利法》第11条、第65条
- 《反不正当竞争法》第6条
- 《电子商务法》第42-43条
