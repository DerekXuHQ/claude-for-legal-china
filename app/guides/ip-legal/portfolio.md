商标没按时续展会被注销，专利没交年费会失效，域名到期可能一小时内被抢注。这些都可以避免，前提只有一个：正确的到期日、对应正确的注册号和地域，记在负责人的日程上。本篇说明如何建立和维护知识产权组合的期限台账，报告到期事项，并定期审计。

## 到期日的可靠性

- 台账按建立时公开的规则推算到期日。知识产权局的要求、宽限期、费用标准会调整，**办理前须通过国家知识产权局商标查询系统、中国专利公布公告系统、WIPO 马德里系统查询或相关注册机构核实**。
- 记录了但记错的到期日比没记更糟，它给人虚假的安全感。“近期无到期事项”的结论更要复核。
- 除非与专业知识产权管理系统同步，台账只是工作副本，不能当作正式记录。

## 适用情形

- 中小规模的知识产权组合，或在专业管理系统之上做一层轻量整理；
- 查看未来30/60/90/180天内的续展、年费事项；
- 新增资产、记录缴费、更新状态；
- 定期审计：宽限期、长期待审、撤三风险、权利人不一致、即将到期的专利。

## 各类资产的维持规则

| 资产 | 规则 |
|---|---|
| 中国商标 | 注册商标有效期十年，自核准注册之日起计算（《商标法》第39条）。期满前十二个月内办理续展，宽展期六个月（《商标法》第40条），宽展期内续展需缴纳迟延费。 |
| 中国商标的使用 | 注册商标无正当理由连续三年不使用的，任何单位或个人可以申请撤销（《商标法》第49条，俗称“撤三”）。中国没有定期提交使用声明的制度，而是由他人申请撤三来检验使用情况，因此保留使用证据是防御撤三的关键。 |
| 马德里国际注册商标 | 十年注册期，在 WIPO 续展；个别指定国可能有本地使用或声明要求，按指定国规定另行核实。 |
| 中国发明专利 | 自申请日起二十年（《专利法》第42条）。自被授予专利权的当年开始缴纳年费（《专利法》第43条），每年缴纳；逾期有六个月宽限期（缴滞纳金），宽限期后可办理恢复手续。 |
| 中国实用新型专利 | 自申请日起十年，年费同发明。 |
| 中国外观设计专利 | 自申请日起十五年，年费同上。 |
| 中国著作权 | 无需续展。自然人作品保护期为作者终生加五十年；法人作品为首次发表后五十年（《著作权法》第23条）。 |
| 域名 | 按注册商规定按年或多年续展；通常有约30天宽限期，之后进入约30天、费用较高的赎回期，再被注销。 |

上表以外的地域或资产类型，把维持规则作为自定义规则记录下来（见第3步），状态显示为“代理办理”，向境外代理确认，不自行推算。

## 台账结构

台账头部记录公司名称、生成日期、最近更新日期、最近审计日期、数据来源（知识产权管理系统 / 手工 / 无），并注明“推算的到期日仅供参考，办理前须向国家知识产权局、WIPO 或相关注册机构核实”。

每项资产记录：

| 字段 | 内容 |
|---|---|
| 编号 | 例如 TM-CN-001、PAT-CN-001 |
| 类型 | 商标 / 专利 / 著作权 / 外观设计 / 域名 |
| 地域 | |
| 商标或名称 / 发明名称 | |
| 权利人 | 登记的权利人主体名称 |
| 状态 | 申请中 / 已注册（已授权）/ 已失效 / 已放弃 / 已注销 |
| 申请号、注册号（专利号） | |
| 类别 | 商标的国际分类；专利的分类号 |
| 申请日、注册日、授权日、优先权日、届满日 | 按类型填写 |
| 后续期限 | 近两三个期限：期限类型（续展注册 / 年费）、到期日、宽限期届满日、依据（如“注册日起十年”）、所需行动、状态 |
| 是否在商业使用 | 仅商标，用于撤三监控 |
| 是否由代理办理、代理名称 | |
| 管理系统编号、外部律所、业务负责人 | |
| 专利的权利要求数、是否享受费减 | |
| 备注 | |

期限状态：

- **未到期**：距到期90天以上；
- **即将到期**：90天内到期，未缴；
- **逾期**：已过主到期日，处于宽限期（如有）；
- **宽限期**：明确标出，需缴附加费；
- **已失效**：宽限期已过未办理，权利实际丧失（除非可恢复）；
- **已缴**：本周期已办理。

## 办理步骤

### 1. 建立台账

1. 确定来源：
   - 有知识产权管理系统的，以系统为准导入，台账镜像系统，不另添系统已有的期限；
   - 有电子表格或导出文件的，导入；缺少注册日或授权日的资产，到期日标为“未知”；
   - 都没有的，逐项录入：类型、地域、编号、关键日期、权利人。
2. 按上表规则推算每项资产最近的两三个期限；几十年后的远期续展在报告时按需推算，不预先存储。
3. 汇总：各类资产数量（商标已注册/申请中、专利已授权/申请中、著作权、外观设计、域名）、已推算期限数、需向境外代理确认的数量、缺少关键日期的数量。

### 2. 到期报告

默认看未来90天，可选30/60/90/180天。出报告前重新推算每项资产的期限，不只依赖存储的日期。

```
知识产权组合到期报告 — 【日期】
【公司名称】 — 窗口：未来【N】天

🔴 已失效 / 宽限期内（【N】）
  【编号】 / 【地域】 / 【类型】 / 【商标或名称】
    【所需行动】 — 原到期日【日期】，宽限期至【日期】
    状态：【宽限期 / 已失效】

⏰ 【N】天内到期（【N】）
  【编号】 / 【地域】 / 【类型】 / 【商标或名称】
    【所需行动】 — 到期日【日期】
    依据：【如“注册日起十年”】
    【代理：律所 / 系统编号——如有】

🟡 即将到期（30天以后、【N】天以内）
  【列表】

🌐 代理办理（【N】）
  【编号】 / 【地域】 — 由【当地代理】办理，请直接确认
  【编号】 / 【地域】 — 无当地代理记录，请补充

❓ 未知（【N】）
  【编号】 — 缺少【字段】，无法推算到期日
  依赖本报告前，请向【管理系统 / 国家知识产权局查询系统 / 相关注册机构】确认。

摘要
  跟踪资产总数：【N】
  窗口内到期：【N】
  最近审计：【日期】

基于知识产权组合台账推算。提交或缴费前，请向国家知识产权局 / WIPO / 注册机构核实每个到期日。
```

资产超过约10项的，可以做成看板：按状态（有效 / 宽限期 / 已失效 / 申请中）计数、到期时间线、可按地域、类型、下一行动日期排序的组合表。

### 3. 新增资产

逐项确认：

1. 类型（商标 / 专利 / 著作权 / 外观设计 / 域名）；
2. 地域；
3. 商标或名称 / 发明名称；
4. 权利人（登记权利人，影响撤三答辩和转让）；
5. 关键日期（按类型：申请日、注册日、授权日、优先权日、届满日）；
6. 编号；
7. 类别 / 权利要求数；
8. 是否在管理系统中跟踪及系统编号；
9. 外部律所 / 境外代理（如有）；
10. 业务负责人（对谁重要：产品线、品牌经理）。

录入后推算下一期限。地域规则不在上表中的，问清并记录为自定义规则，以后同地域资产沿用：

1. 有哪些维持事项？（每 N 年续展？每年年费？使用声明？其他？）
2. 期限从什么时候起算——申请日、注册日、授权日、进入国家阶段日、某个周年日？
3. 有没有宽限期？费用如何？
4. 有没有境外代理或当地代理负责？

### 4. 更新

- **记录缴费**：例如“3月4日为 TM-CN-001 缴纳了续展费”，把该期限改为已缴、记录缴费日期，并推算下一期限。
- **与管理系统同步**：核对台账与系统的差异，以系统为准更新台账，并列出台账有而系统没有的内容。
- **状态变更**：例如“TM-CN-004 标记为放弃”，更新状态，清空后续期限，记录放弃日期。

**记为“已缴”前须核实。** 把续展、年费、国际注册费记为“已缴”是有后果的：记错了（日期错、费减资格错），到期日不会因此改变，资产照样可能失效。经办人不是律师的，记录前应向实际办理的律师或境外代理（或通过国家知识产权局查询系统、WIPO 马德里系统、相关注册机构）核实。未核实的暂不记为已缴，带上资产编号、地域、期限类型、管理系统显示的内容、自己认为已办理的内容及时间、信息来源，去问律师。需要寻找执业律师的，可从当地律师协会的推荐服务入手。

刷新状态、出报告、查看到期事项不需要这一步。

### 5. 审计

| 审计项 | 看什么 |
|---|---|
| 期限 | 处于宽限期的（正在产生附加费，立即办理）；已失效但未标为放弃或注销的（确认是否恢复，更新状态）；没有推算出后续期限的（缺数据或规则不明） |
| 长期待审 | 商标申请超过两年仍在审的，查询状态（可能涉及实质审查或驳回复审）；专利申请超过四年仍在审的，查询审查状态 |
| 撤三风险（仅商标） | 依据《商标法》第49条，注册已满三年且使用状态不明的商标，在收到撤三申请之前整理使用证据 |
| 权利归属 | 权利人不是当前存续主体的，可能需要办理转让；同一权利人名称写法不一致的，统一 |
| 到期展望 | 未来24个月内届满的专利——即使没有维持期限，业务方也可能关心：产品规划、后续申请策略、许可窗口 |
| 未监测资产 | 已注册但不在品牌保护监测名单中的商标，交律师决定是否加入 |

```
知识产权组合审计 — 【日期】

期限
  宽限期内：【N】 — 立即办理，避免失效
  已失效（未标放弃）：【N】 — 确认状态
  缺少后续期限推算：【N】 — 补充数据或标为代理办理

长期待审
  商标申请超过2年仍待审：【列表】
  专利申请超过4年仍待审：【列表】

撤三风险（商标）
  使用状态不明的商标：【列表】

权利归属
  权利人主体无法识别：【N】
  权利人名称不一致：【列表】

到期展望（24个月）
  即将届满的专利：【列表】

品牌监测
  已注册但未列入监测名单的商标：【列表】

建议行动
  1. 【最高优先级】
  2. 【其他】
```

## 注意事项

- 台账不提交任何申请或缴费，所有行动由律师或境外代理办理。
- 台账根据录入的日期推算，不向注册机构核实；注册机构的记录才是准据。台账上的“已缴”只表示有人告知已办理，不等于国家知识产权局已受理，受理情况须通过官方查询系统或管理系统确认。
- 是否续展是商业决定（商标是否还在用、专利是否还有价值、域名是否还重要），由业务方和律师决定。
- 数百项以上的组合，台账不能替代专业知识产权管理系统。

## 法律依据

- 《商标法》第39条、第40条、第49条
- 《专利法》第42条、第43条
- 《著作权法》第23条
