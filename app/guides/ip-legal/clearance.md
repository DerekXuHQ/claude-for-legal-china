新商标采用、申请或投入前，做一轮初步检索：先排查固有障碍，再查近似在先商标，逐项标注混淆可能性因素。产出的是标注清单，**不是商标清除法律意见，也绝不得出「商标无冲突」的结论**。

## 适用情形

- 有人提出新商标，问「这个能不能用」。
- 需要做排除性检索。
- 在委托完整专业检索前，先评估混淆可能性因素。

## 每份初检报告顶部必须写明

> **这是一份初步检索，非商标清除法律意见。** 商标清除法律意见需要完整的专业检索（国家知识产权局商标数据库、地方工商登记、域名和社会化媒体检索、外观设计检索等），以及律师对混淆可能性的判断，后者依赖结构化初检无法完全评估的因素。「未发现明显冲突」只意味着本次初检没有发现，不意味着商标无冲突。曾有客户因使用通过了排除检索的商标而被起诉。任何人采用、申请或投资该商标前，须由执业商标律师评估。

这句话不得省略或弱化。低估冲突的后果难以挽回：标识已经印上车身、产品已经上市、申请已经提交，问题都埋在底下。高估冲突则可以在律师审阅时缩小清单。宁可高估。

## 需要准备的材料

一次问清，不拖长：

1. **拟议商标**：确切拼写、风格化处理，文字商标、图形商标还是组合商标。
2. **商品或服务**：实际销售或提供什么，一两句话，用于对应《类似商品和服务区分表》。
3. **类别**：已知的列出；不知道的，根据商品/服务建议可能的类别并与业务确认。
4. **法域**：计划在哪些法域使用、注册或执法（中国大陆 / 香港 / 澳门 / 台湾 / 马德里）。未说明的，按公司的默认注册地。
5. **使用中的呈现方式**：标语、相邻产品名称、装潢或会一同出现的视觉元素。

描述模糊（如「AI 工具」「平台」）的，追问一次客户实际看到的是什么：消费者手机 App、企业级 API、实体产品还是服务。类别取决于此。

## 办理步骤

### 1. 固有障碍筛查

在查任何数据库之前，先查无论有无在先注册都足以否决商标的固有障碍。逐项如实评估，明显的障碍不要淡化。

| 障碍 | 含义 | 何时标注 |
|---|---|---|
| **通用名称**（商标法第11条第1款第1项） | 该词即属于该类商品（如「肥皂」用于肥皂） | 商标直接说出了商品是什么 |
| **描述性**（商标法第11条第1款第2项） | 直接描述特征、功能、质量或原料 | 消费者读到商标无需想象就知道产品的作用 |
| **欺骗性**（商标法第10条第1款第7项） | 对实质特征作误导性表述 | 商标暗示商品不具备的品质，且该品质影响购买决策 |
| **地理名称**（商标法第10条第2款 / 第16条） | 商标主要为地名，且商品来自（或不来自）该地 | 地名 + 通用名；或地名 + 商品，消费者会假定产地 |
| **仅含姓氏**（商标法第11条第1款） | 商标主要表现为姓氏 | 相关消费者读来像某人的姓氏 |
| **虚假关联**（商标法第10条第1款第1-4项；涉及他人姓名等在先权利的，第32条） | 虚假暗示与某人、机构、国家标志有关联 | 商标援引可识别的特定人物或机构 |
| **禁止事项**（商标法第10条） | 国旗、国徽、军旗、勋章等 | 商标包含禁止性元素 |
| **缺乏显著特征**（商标法第9条 + 第11条） | 整体缺乏显著特征，不能区分商品来源 | 相关公众不会把它当作商标识别 |
| **功能性**（商标法第12条，三维标志） | 该特征为使用所必需或影响成本 / 质量 | 立体商标的特征发挥功能作用 |

每个类别写「未发现障碍」或一行具体理由。不出全是「通过」的空表。

### 2. 近似商标检索

目的是**找出可能构成近似的在先商标**，不判断是否构成混淆，那是律师的判断。

- 有商标检索渠道（国家知识产权局商标查询等）的，跨相关类别和法域做初检，每条结果注明来源、检索日期和范围。
- 有法律研究数据库的，检索涉及该商标或近似变体的已有争议，同样注明来源。
- 没有做数据库检索的，在报告中写明下面这段话，然后继续做固有障碍分析和因素分析：

> **未运行数据库检索。** 本次初检未访问国家知识产权局商标数据库、WIPO 全球品牌数据库或任何其他在先权利来源。在作出任何关于可用性的结论前，必须进行完整的专业检索。以下初检仅限于固有障碍分析，以及针对已知商标的结构化混淆因素分析。

不得凭记忆列出「检索结果」。

### 3. 记录每个近似商标

- **商标**：确切文字、风格化
- **来源**：CNIPA 注册号、马德里指定号、域名、社交媒体账号等
- **类别 / 商品服务**：以注册簿记载为准
- **权利人**
- **状态**：已注册 / 审查中 / 失效 / 注销（已失效的不构成障碍，但与知名度和在先权利有关）
- **首次使用日期**（如有）

注册号必须来自实际做过的检索；业务人员提到的商标要注明来源。不编造、不「补全」注册信息。

### 4. 逐项标注混淆可能性因素

依据商标法第57条及《最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释》确立的标准，综合考量：

- **商标近似程度**：形、音、义及整体商业印象，参照《商标审查审理指南》的近似判断标准
- **商品 / 服务类似程度**：参照《类似商品和服务区分表》及相关司法解释
- **在先商标的显著性和知名度**：臆造 / 任意 / 暗示 / 描述 / 通用，以及知名度证据
- **相关公众的注意程度**：一般消费者还是专业采购
- **实际混淆证据**（如有）
- **主观意图**：是否有攀附他人商誉的意图
- **其他相关因素**

每个因素写清两边各有什么、不确定在哪里。

- 绝不写「不构成混淆」。
- 不确定的，写「发现近似商标——采用前需进行混淆评估」。
- 只有实际做过检索，才能写「在已检索的数据库中未发现近似商标」。

### 5. 提出后续步骤

按初检发现分组：

- **发现固有障碍**：重新构思商标，或接受描述性限制、按计划通过使用积累显著性；采用前交律师审核。
- **在已检索数据库中发现近似商标**：采用、申请或营销前必须律师审核，通常下一步是完整专业检索，找出本次初检遗漏的内容。
- **未发现近似商标，但未做数据库检索**：采用前必须完整检索，列出需要查询的数据库。
- **发现近似商标，但在先商标弱、老旧、在不同类别或已失效**：标注供律师审核，初检不作此判断。
- **任何情况下**：由执业商标律师出具完整清除法律意见，深度与商标将承载的投资相匹配。

### 6. 非律师经办时

由非律师经办的，报告须注明：本报告是研究初检，不是法律意见；仅凭本初检采用、申请或投资该商标有法律后果，包括因「通过」检查的商标被诉侵权，须先由执业商标律师评估。同时附一页给律师的简要材料：拟议商标、商品 / 服务及类别、固有障碍（如有）、出现的近似商标（如有）、检索了什么和没检索什么，以及要问律师的三个问题。查找执业律师，可通过当地律师协会或司法局的律师查询系统。完整初检报告与简要材料一起交付。

## 本流程不做的事

- 得出商标无冲突的结论。
- 替代 CNIPA 商标数据库检索、域名和社交媒体检索、境外检索或图形商标检索。
- 提交商标申请（由律师办理）。
- 在初步标注之外评估商标淡化或驰名商标主张。
- 把初检结论提供给客户、对方当事人或媒体。初检是内部研究，加保密抬头的为保密文件。
