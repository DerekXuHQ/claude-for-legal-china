对商标、著作权、专利和商业秘密侵权做初步筛查：按权利类型列出因素，标注每个因素有利于哪一方，**不作侵权或不侵权的结论**。用于判断事项是否值得追究、怎么追究，或评估己方是否可能侵权。

## 适用情形

- 评估他人是否侵犯公司的知识产权（出现山寨产品、抄袭者）。
- 评估公司是否可能侵犯他人权利。
- 决定是否维权、怎样维权。

## 每份筛查报告顶部必须写明

> **这是初步筛查，不是侵权认定，也不是不侵权认定。** 侵权分析高度依赖事实，法律上也很复杂。筛查只识别因素、标出最重要的因素，不作结论。是否构成侵权是法律意见，需要律师结合事实、权利范围、适用的管辖法律和可能的抗辩作出判断。未经律师审查就依据筛查结果行动（发送侵权警告函、拒绝停止、提起诉讼或决定不起诉），是公司最终承担不利诉讼费用、程序制裁、确认不侵权之诉以及（专利案件中）惩罚性赔偿的常见原因。

没识别出的问题难以挽回：警告函没发，商标在市场上沦为通用名称；请求没追，诉讼时效届满；被复制的作品一直挂在网站上。识别过度则可以由律师缩小范围。宁可多识别。

## 需要准备的材料

先确定权利类型：商标 / 著作权 / 专利 / 商业秘密 / 混合或不确定。同一事实可能涉及多项权利，例如竞争对手产品使用了公司标识（商标），产品与公司产品高度近似（可能涉及专利、包装的著作权、商品外观），且由前员工推出（商业秘密）。**涉及多项权利的，每项权利分别筛查，不混在一起分析**：各项权利的因素、管辖规则和救济都不同。

各类型通用的信息：

1. **地位**：公司是潜在权利方（对方抄袭公司），还是潜在被控方（公司被审视）？因素是对称的，但产出不同：权利方筛查导向维权函件，被控方筛查导向风险备忘录。
2. **管辖**：哪个国家 / 地区 / 法院？默认中国大陆，有涉外因素的标注。
3. **时效**：诉讼时效或迟延主张的时钟是否在走？
4. **证据**：截图、URL、包装照片、代码片段、前员工合同等。

信息齐备后再分析因素。

## 办理步骤

### 一、商标

**混淆可能性。** 依据《商标法》第57条和第30-33条，逐一分析并标注倾向：

- **商标近似性**：形、音、义、整体商业印象。
- **商品或服务类似性**：依《类似商品和服务区分表》及相关公众的一般认知。
- **相关公众的注意程度**：一般消费者还是特定行业专业人士。
- **权利商标的显著性和知名度**：臆造 / 任意 / 暗示 / 描述性经使用取得显著性 / 通用。
- **主观意图**：有无抄袭、模仿的故意证据。
- **实际混淆**：调查、误寄邮件、社交媒体上的混淆等。
- **市场重叠程度**：双方商品 / 服务的市场是否交叉。

**驰名商标保护。** 依《商标法》第13条：

- **驰名门槛**：权利商标须在中国为相关公众所熟知，仅在小众领域知名的不够。
- **淡化类型**：弱化（削弱显著性）和丑化（损害声誉）。
- **抗辩**：合理使用、新闻报道、非商业性使用。

权利商标并非明显驰名的，标注淡化主张可能性较低。

**虚假宣传 / 比较广告。** 筛查由竞争对手的比较广告或产品声称引发的：

- 适用《反不正当竞争法》第8条关于虚假宣传的规定和《商标法》相关条款。
- 标注陈述属于字面虚假、暗示虚假还是夸大宣传；夸大宣传不可诉。
- 列明权利方已有或需要的证据。

**产出**：因素表；有利于各方的因素；「非认定」结论行；按公司维权姿态给出路由建议。

### 二、著作权

- **权利归属**：主张方是否为著作权人或享有诉权的独占被许可人？注意职务作品、合作作品、转让和署名推定问题。
- **登记**：《著作权法》第11条规定著作权自作品创作完成时产生，登记不是起诉前提；但国家版权局出具的著作权登记证书是证明权利归属的初步证据。标注登记状况。
- **接触 + 实质性相似**：证明抄袭的两条路径——
  - 接触 + 构成抄袭的相似：被告有接触机会，且作品具有证明抄袭的相似特征；
  - 高度相似：即使无接触证据，相似程度异常到独立创作极不可能。

  实质性相似关注整体观感，以及「接触 + 实质性相似」规则在中国司法实践中的适用。
- **合理使用**：《著作权法》第24条采列举模式，只有落入列举情形才可能构成合理使用。重点看：使用目的和性质（个人学习研究、介绍评论、新闻报道等法定情形）；使用行为的性质和程度；对原作品潜在市场或价值的影响。合理使用高度依赖事实，筛查不作结论。
- **通知-删除规则**：《信息网络传播权保护条例》第14-17条、《电子商务法》第42-43条。被控方为网络服务提供者的，标注是否适用避风港：合格的通知程序、及时删除、无明知或应知、反通知机制。

**产出**：因素标注；合理使用平衡（不作结论）；权利归属、登记、避风港等门槛提示；按维权姿态路由。

### 三、专利

专利筛查与专利 FTO 初检方法相同（同样的权利要求对照表、等同标注、全面覆盖原则），只是对象换成被控产品。

**先分流外观设计专利。** 先查主张专利的专利号。中国专利号以类型代码开头：发明专利（1）、实用新型（2）、外观设计（3）。

- **外观设计专利**（专利法第2条第4款）：标准、保护结构和损害赔偿都不同。不做权利要求对照表，不做等同分析，不逐要素比对。外观设计以图片或照片中的设计为准，把图片当作发明专利的要素清单处理是错误的。
- **实用新型专利**：初步审查授权，未经实质审查，标注权利稳定性问题。
- **发明专利**：经实质审查，权利稳定性相对较强。

**外观设计筛查。**

- **一般消费者整体观察**：依据《专利法》第23条，看一般消费者是否认为被控设计与授权外观设计在整体视觉效果上相同或近似。
- **功能性与装饰性过滤**：外观设计专利只保护装饰性特征，功能性特征不受保护。近似点在于功能决定的特征的，标注该重叠可能不在保护范围内。
- **索要材料**：看不到图片无法做整体观察。须取得：(a) 专利图片（所有视图）；(b) 被控产品可比角度的照片；(c) 已知的现有设计。
- **现有设计状况**：一般消费者观察是比较测试，需要了解现有设计。
- **损害赔偿标注**：依《专利法》第71条，按权利人损失、侵权人获利或许可使用费确定。只标注，不估金额。
- **商品外观交叉标注**：同一装饰性外观的事实，常同时涉及《反不正当竞争法》第6条对包装装潢的保护。标为并行路径，标准不同但证据重叠。

**发明 / 实用新型筛查。**

- 被控产品 / 程序 / 方法的技术详细描述。
- 识别争议专利。
- 每项独立权利要求逐要素对应到被控产品，先分析字面侵权，等同作为标注。
- 间接侵权（教唆、帮助）作为标注。
- **可考虑的无效抗辩**：新颖性（专利法第22条第2款）、创造性（专利法第22条第3款）、说明书公开不充分（专利法第26条第3款）、权利要求不清楚（专利法第26条第4款）、不属于授权主题（专利法第2条、第25条）。列明已知的无效宣告结果、现有技术和审查历史。逐项标注，不作结论。
- **不可执行抗辩**：标注，不作结论。
- **损害赔偿态势**：侵权获利、实际损失、许可费合理倍数（专利法第71条）。

本分析使用中国专利框架。产品在境外制造、销售的，需要相应法域的专利分析；中国框架下发现的问题可以标注，但侵权和有效性认定须由该法域的专业人员审查。

筛查中的对照表是首轮分析，用于找出最强和最弱的对应关系。用于侵权或无效主张的完整对照表（含引证、权利要求解释标注和核实流程）交专业专利律师完成。

### 四、商业秘密

**是否构成商业秘密。** 依《反不正当竞争法》第9条：

- **不为公众所知悉**：不为该信息领域相关人员普遍知悉和容易获得。
- **具有商业价值**：因不为公众所知而具有实际或潜在的商业价值。
- **采取了相应保密措施**：《最高人民法院关于审理侵犯商业秘密民事案件适用法律若干问题的规定》具体列举了合理保密措施的类型。

**保密措施清单。** 列出已有和缺失的措施，合理与否由律师判断：

- 与员工、承包商、相对方签订的保密协议：范围、签署、执行情况。
- 访问控制：技术性（基于角色）、物理性（门禁）、组织性（按需知悉）。
- 文件、代码、数据上的保密标识。
- 离职面谈、离职时返还材料。
- 商业秘密制度和培训。

**侵权行为。** 以不正当手段获取，或违反保密义务披露、使用。第9条列举的不正当手段包括盗窃、贿赂、欺诈、胁迫、电子侵入或其他不正当手段。

- **前员工情形**：新雇主、工作内容重合、离职时间、带走的文件（是否已返还）、访问日志、招聘渠道、职务发明协议。
- **无意披露**：披露者是否负有保密义务？接收方是否知道或应当知道违约？
- **反向工程**：通过合法手段获取的，属于合法抗辩。标注反向工程在事实上是否可行。

**法律适用。** 标注《反不正当竞争法》与合同违约请求权之间的适用关系，不作结论。

**产出**：秘密性、保密措施、侵权行为三组因素，各列有利于双方的因素；按维权姿态路由。

### 五、非律师经办时

由非律师经办的，报告须注明：本报告是研究筛查，不是法律意见；依据筛查发送警告函、决定不停止、提起诉讼或依赖「属于合理使用」都有法律后果，包括无依据主张招致的程序制裁、警告函引发的确认不侵权之诉、专利案件中的惩罚性赔偿以及不正当竞争案件中的不利费用承担；行动前须由律师评估。附一页给律师的概要：争议权利、地位、事实和证据、已识别的因素、已标注的抗辩，以及要问律师的三个问题。可通过当地律师协会的推荐服务查找律师；专利案件须确认律师具有专利代理资格。

### 六、后续衔接

筛查指向维权、且公司维权姿态支持的，可进入侵权警告函起草流程，以本筛查的因素清单作为事实基础，按审批链审批，审批人签署前函件不得发出。著作权托管内容的，可准备删除通知。**不得直接从筛查自动起草函件**，维权与否由审批人决定。

## 本流程不做的事

- 作出侵权或不侵权结论。
- 替代问卷调查证据、损害赔偿专家或权利要求解释。
- 评估筛查管辖范围以外的法域特有抗辩；跨境事实标注需要境外法分析。
- 把合理使用作为法律问题作出决定。
- 起草侵权警告函、删除通知或起诉状（另有流程，受审批链约束）。
- 把筛查结论提供给相对方。
