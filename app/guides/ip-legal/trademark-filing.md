本篇用于中国大陆商标申请，覆盖“类别规划 → 可注册性初筛 → 申请材料准备”三个环节。所有判断都是初步研判，不构成法律意见，不承诺注册结果。新商标的近似商标排除检索另见商标检索指引。

## 适用情形

- 咨询“应该申请哪些类别”“这个商标能不能注册”；
- 需要一份可复用的商标初筛报告，并分级风险、给出下一步建议；
- 商标设计已定，需要准备商品/服务清单和商标说明。

**范围边界：**

- 依据《中华人民共和国商标法》及其实施条例、商标审查审理规则等国内规范。
- 尼斯分类是国际通用标准，类别规划部分可供境外申请参考；可注册性判断和审查标准只针对中国大陆。
- 马德里国际注册、单一国家申请、抢注、驰名商标认定、跨类大规模冲突等复杂情形不在本篇范围，交专业人员处理。

## 需要准备的材料

1. 申请主体名称和主营业务（个人/企业、经营范围）；
2. 商标形态：纯文字 / 纯图形 / 图文组合，以及具体内容；
3. 已知的目标类别或实际使用场景（产品、服务、销售渠道）；
4. 是否已有设计稿，是否已做过近似查询。

信息不足的先补问，不强行评级；缺失项一律标“未提及/待补充”。

## 办理步骤

### 1. 类别规划

1. 确定需求：只做类别规划 / 只做可注册性初筛 / 两者都做。
2. 结合主营业务和使用场景，按尼斯分类确定：
   - **核心类别**：商品或服务直接所属的类别；
   - **关联类别**：上下游、配套、宣传推广等常见延伸保护类别（如第35类广告销售、第9类电子载体、第42类技术服务）。
3. 先覆盖保护范围大的核心商品/服务项目，再补细分项目。
4. 每个建议类别写明理由，便于客户按预算取舍。

**尼斯分类要点**：共45个大类，第1—34类为商品，第35—45类为服务。常用关联类别：

| 类别 | 内容 |
|---|---|
| 第9类 | 科学仪器、计算机软件、可下载电子出版物、APP |
| 第35类 | 广告、商业销售推广、为零售目的的商品展示、特许经营管理（“销售类”防御核心） |
| 第41类 | 教育、培训、文娱、在线出版 |
| 第42类 | 技术开发、软件设计、平台技术服务 |
| 第43类 | 餐饮、住宿 |

尼斯分类逐年更新，具体可选项目和类似群划分会随版本调整。每次都要以官方现行版本（含当年增补）核实项目名称和类似群编号，**不凭记忆编写项目名、类似群号或类别归属**；无法确认的，标“需核对现行尼斯分类版本”。

### 2. 可注册性初筛

依据商标法关于禁用、禁注和显著性的一般规则逐项核查：

- **绝对理由（禁止注册/使用）**：是否含有国家名称、国旗国徽、官方标志；是否带有欺骗性或有不良影响；是否仅有本商品的通用名称、图形、型号；是否仅直接表示质量等特点；是否缺乏显著性。
- **相对理由（在先权利冲突）**：是否与他人在先注册或申请的近似商标在相同或类似商品上冲突；是否可能损害他人在先字号、著作权、外观设计等权利。近似和在先冲突以官方商标库的实际检索为准，初筛不能替代检索。
- **显著性强弱**：臆造词 > 任意词 > 暗示性词 > 描述性词。描述性和通用性表达通常显著性弱，驳回风险高。

### 3. 申请材料准备

客户确认设计方案后准备：

1. **商品/服务清单**：在选定类别下列出规范项目名称，同一类似群归为一组；优先使用尼斯分类规范名称，自创表述容易导致补正或驳回。用表格列出：序号、类别、类似群、项目名称。
2. **商标说明**：见下文。
3. **归档**：申请方案、清单、说明集中归档，文件名含商标名、类别、日期。

## 商标说明的写法

商标说明描述商标的构成要素和含义，一般控制在200字以内：

1. **声明构成**：由文字 / 图形 / 文字加图形等哪些要素组成；
2. **描述文字**：列明文字内容和字体形式（普通印刷体 / 设计字体 / 艺术字）；
3. **解释含义**：说明文字或整体的含义；确无特殊含义的，明确写“无特殊含义”；
4. **图形和组合商标**：先对照图样分析其类型、文字内容、图形元素、字体设计特征、配色和整体风格，再写说明，避免与图样不符。

寓意、配色意图等需要客户确认的，先问再定稿，不替客户编造含义。

## 风险分级

| 等级 | 判定情形 | 建议 |
|---|---|---|
| 高风险 | 触及绝对禁注理由；与在先商标高度近似且类别冲突；显著性明显不足 | 调整或更换商标，提交前进一步核查 |
| 中风险 | 显著性偏弱；存在一定近似可能；类别覆盖不完整 | 优化商标设计或清单，必要时补充检索 |
| 低风险 | 显著性较强；未见明显冲突线索；类别规划合理 | 可以推进，仍建议正式检索确认 |
| 待补充 | 关键信息缺失，无法评估 | 先补齐主体、商标样式、使用场景等信息 |

风险等级是基于现有信息的初步判断，最终以官方商标检索和人工复核为准。

## 报告结构

- 顺序：**结论 → 依据 → 风险 → 下一步行动**；
- 风险等级统一用高 / 中 / 低风险，信息不足的写“待补充（信息不足，暂不评级）”；
- 引用法律依据时写明法律名称和条款指向，并提示按现行有效版本核实；不编造条文号、项目名或案例；
- 缺失信息标“未提及/待补充”，不以推测填充；
- 每份报告附免责声明：“本报告为辅助性初步研判，不构成正式法律意见，不保证商标注册结果。商标可注册性最终取决于官方审查及实际检索结果。涉及在先权利冲突、复杂争议或重大决策时，请在申请前由具备相应资质的专业人员核查确认。”
