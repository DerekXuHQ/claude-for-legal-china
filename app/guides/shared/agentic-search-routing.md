多数法律问题按常规检索处理即可（确认法条、审查单份合同、解释概念）。问题需要多个维度并行检索时，升级为多来源深度检索：分别规划检索路径，交叉验证，最后汇总成结构化研究报告。本篇说明升级的条件、不升级的情形和检索来源。

## 两条路径

```
法律问题
   │
   ▼
先判断复杂度
   │
   ├── 常规检索 ──┬── 依据充分 → 输出
   │              └── 依据不足 → 升级为深度检索 → 输出
   │
   └── 直接深度检索（达到下列 C1 条件，或委托人明确要求）→ 输出
```

## 升级条件

### C1：一开始就走深度检索

问题达到下列任一情形的，跳过常规检索：

1. **多维并行**：问题可拆成 3 个以上独立的法律维度（不同法域、不同信息源类型、不同检索方向）。
2. **跨领域**：同时涉及 2 个以上独立法律领域（如知产 + 劳动、公司 + 税务）。
3. **穷尽意图**：提问本身要求「全面」「穷尽」「所有」「系统性」检索。

快速判断方法：先拆问题，要答清楚需要查几个独立方向？3 个以上即走深度检索；拿不准的，先走常规检索。

示例：

- 「这家公司的所有涉诉风险、行业监管趋势、类案裁判倾向」：主体信用 + 监管合规 + 类案检索，3 个维度。
- 「对赌协议回购条款在浙江法院的裁判倾向及最新监管动态」：法条基础 + 类案 + 监管，3 个维度。
- 「全面梳理股权代持的法律风险」：明确要求全面梳理。

### C2：常规检索不足时升级

常规检索完成后，出现下列任一情形的，升级：

1. 关键依据缺失，且无法合理推断。
2. 成果中有 2 处以上标注了「需验证」「需复核」。
3. 法律检索的来源顺序（见《法律检索的来源顺序与标注》）全部走完，核心问题仍无可靠依据。

升级时，把常规检索已得到的结果摘要带入：哪些来源已经查过、哪些关键词已经试过，避免重复。

### C3：委托人或主办律师明确要求

如「深入查一下」「全面检索」「穷尽检索」「这个需要系统研究一下」。

## 不升级的情形

即使表面符合上述条件，下列情形也不走深度检索：

| 情形 | 原因 |
|---|---|
| 简单法律概念解释 | 单一维度，常规检索足够 |
| 单一条款分析 | 检索范围明确，无需多路并行 |
| 纯事实确认 | 直接查法条即可 |
| 同一问题本轮已做过深度检索 | 不重复检索 |
| 问题本身不是法律问题 | 不启动法律检索 |

## 深度检索的做法

- 各检索方向分别规划：关键词选择、来源切换、交叉验证。
- 遵守来源标注、引用规范和法域识别要求。
- 产出结构化研究报告。

**可用检索来源**（视所在单位已开通的数据库而定）：

- 法规：元典、北大法宝
- 案例：元典、人民法院案例库、聚法案例
- 企业信用：企查查、天眼查、国家企业信用信息公示系统
- 监管动态：政府网站、部委公告
- 联网搜索：作为补充

## 约束

- 深度检索是常规检索的**补充**，不是替代。多数法律问题仍按常规检索处理。
- 深度检索的研究报告仍须经律师审查，所有结论标注依据来源。
- 检索结果标明来源和检索日期，不确定的标「需核实」。
- 深度检索扩大的是检索范围，核心法律推理仍由主办人完成。
