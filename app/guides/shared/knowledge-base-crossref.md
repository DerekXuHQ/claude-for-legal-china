法律检索按固定顺序进行：先看经过整理的体系化知识，再查原始资料的优先源和扩展源，最后才用外部数据库或联网检索。每类来源的权威程度不同，引用时要标明。

## 检索顺序（四步，不跳步）

### 第 1 步：确定检索路线

先明确各类来源的效力分级和检索路径：

- **优先源**：理解与适用系列、类案指南、最高院审判实务、案例库资源、权威问答选登；
- **扩展源**：实务文章、地方审判指引、权威学术著作；
- **警示源**：需核实现行效力的来源；
- 各法律领域的专项检索路径。

### 第 2 步：体系化知识

先查知识库中已经深度整理、综合分析的概念文章，适用于概念性问题（「什么是……」）和体系化知识。

阅读时：

1. 先看文章的成熟度分级（T1-T4），判断结论的可靠程度；
2. 再看文章的「来源权威分布」，判断结论的权威基础；
3. 文章大量依赖效力待核实的来源，或成熟度为 T3/T4 的，必须进入第 3 步交叉验证。

引用概念文章时，注明文章路径和最后更新日期。

不得跳过本步直接查原始资料：概念文章是对原始资料的深度综合，应优先使用。

### 第 3 步：原始资料（优先源 → 扩展源）

体系化知识不足时，按优先级检索原始资料：

```
优先源（理解与适用、类案指南、最高院审判实务、案例库资源、权威问答选登）
  ↓ 不足
扩展源（实务文章 → 权威学术著作 → 地方审判指引）
  ↓ 仍不足
外部补充（法律数据库检索、联网搜索）
```

- 扩展源的结果，注明「可作为实务参考，不构成正式法律依据」。
- 警示源必须附效力提示，不得作为法律结论的唯一依据。

### 第 4 步：外部补充（最后手段）

只有知识库各层都无法回答时，才用元典、北大法宝等法律数据库或联网搜索。

引用具体条号前，按《官方法条核验源》到官方来源核对现行版本；该篇还列出了已知的条号变化。

四步全部走完，核心问题仍无可靠依据，或成果中有 2 处以上「需验证」「需复核」的，考虑升级为多来源深度检索（见《何时启动多源深度检索》）。

## 来源标注速查

| 来源 | 引用时注明 | 说明 |
|---|---|---|
| 知识库概念文章 | 文章路径和更新日期 | — |
| 理解与适用 | 优先源：最高法释义 | 权威性高 |
| 案例库资源 | 优先源：案例库 | 权威性高 |
| 权威问答选登 | 优先源：官方答复 | 权威性高 |
| 法院审判指导 | 需核实现行效力 | 切忌作为唯一依据 |
| 公众号 / 实务文章 | 扩展源：【来源名称】 | 代表作者观点，需结合正式法源核验 |
| 法律数据库检索 | 数据库名称 | 需复核 |
| 联网搜索 | 联网检索，需复核 | 未经二次核验 |
| 凭记忆或未核实的内容 | 〔待核〕 | 未经独立核实 |

## 约束

- 知识库原始资料只读，不修改。
- 仅在问题涉及法律内容时按本顺序检索。
- 引用警示源时必须附效力提示，且不得作为法律结论的唯一依据。
- 成熟度为 T3/T4 的概念文章不对外发布，仅供内部参考。
