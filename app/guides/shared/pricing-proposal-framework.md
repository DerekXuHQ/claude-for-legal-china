编制法律服务报价方案的全流程：从项目分类、客户需求分析、服务范围和团队配置，到报价方式选择、方案撰写和质量审核。

## 适用情形

- 诉讼 / 仲裁代理报价。
- 非诉讼专项法律服务报价（尽调、并购、重组、融资、合规审查等）。
- 常年法律顾问服务报价。

## 需要准备的材料

- 项目背景信息；
- 具体法律需求说明；
- 报价策略方向；
- 客户信息（行业、规模、决策人、历史付费水平等）；
- 当地律师收费管理规定和本所定价政策。

## 办理步骤

```
1 项目启动与分类
2 客户需求结构化分析
3 检索与研究
4 服务策略制定
5 报价方式选择与计算
6 方案撰写
7 质量审核
8 方案输出
```

### 1. 项目启动与分类

判断属于哪一类方案：

| 分类信号 | 方案类型 |
|---|---|
| 起诉、应诉、仲裁、争议、纠纷、诉讼代理、执行 | 诉讼 / 仲裁代理及报价方案 |
| 尽调、并购、重组、融资、合规审查、专项、项目 | 非诉讼专项法律服务报价方案 |
| 常年、顾问、年度、日常法律服务 | 常年法律顾问服务报价方案 |

产出：项目文件夹 + 项目摘要（含分类结论）。

**同步进行利益冲突审查**：对方当事人是否与本所现有客户存在利益冲突；本所是否曾代理过对方或类似案件；是否涉及前客户的保密信息。发现潜在冲突的，立即报告，不再推进。

### 2. 客户需求结构化分析

| 维度 | 分析内容 |
|---|---|
| 客户画像 | 行业、规模、发展阶段、关键决策人 |
| 法律需求 | 核心法律问题、涉及法律领域、复杂度 |
| 痛点与期望 | 客户最关心什么、过往痛点、期望的服务方式 |
| 预算敏感度 | 对价格的敏感程度、决策流程、历史付费水平 |
| 关系深度 | 新客户 / 老客户 / 战略客户、未来业务潜力 |
| 竞争态势 | 是否有竞争对手报价、客户的比较标准 |
| 时间约束 | 方案提交截止日、服务启动时间 |

**复杂度评估：**

| 级别 | 特征 | 对报价的影响 |
|---|---|---|
| 高 | 涉及多个法律领域、金额大、时间紧、事实复杂 | 高费率、充足工时、资深团队 |
| 中 | 单一法律领域但有一定复杂性 | 标准费率、合理工时 |
| 低 | 标准化需求、事实清楚、法律关系简单 | 可考虑固定收费或标准套餐 |

### 3. 检索与研究

1. **同类服务**：同类法律服务产品的服务内容设计、方法、模块划分、服务承诺标准；
2. **法律问题**：项目涉及的核心法律问题、适用法规、主要风险点、典型处理流程；
3. **法律障碍与可行性**：哪些法律难点影响定价，哪些构成承接障碍（如交易路径不确定、监管新规影响、决策依据效力有瑕疵）；
4. **行业价格参考**：同类服务的定价方式和市场价格区间。

### 4. 服务策略制定

**服务范围界定：**

| 类别 | 定义 | 报价处理 |
|---|---|---|
| 核心服务 | 客户明确要求、项目必须包含的服务 | 含在基础报价中 |
| 推荐服务 | 客户未要求、但基于专业判断建议增加的 | 单独列明，注明推荐理由 |
| 可选增值 | 提升服务价值的附加服务 | 单独报价，供客户选择 |
| 排除事项 | 明确不包含的服务 | 在方案中明确列出，避免误解 |

**团队配置：**

| 角色 | 职责 | 适用场景 |
|---|---|---|
| 主办律师 | 项目统筹、核心法律判断、客户沟通 | 所有项目 |
| 协办律师 | 具体法律研究、文书起草、证据整理 | 中高复杂度 |
| 律师助理 | 资料整理、基础检索、行政支持 | 按需 |
| 专业顾问 | 特定领域专家（税务、评估等） | 涉及专业领域时 |

### 5. 报价方式选择与计算

**报价方式对比：**

| 报价方式 | 适用条件 | 优势 | 风险 |
|---|---|---|---|
| **固定收费** | 服务范围明确、工作量可预估 | 客户接受度高、预算可控 | 范围变更需重新议价 |
| **计时收费** | 工作量不确定、复杂度高 | 灵活、公平 | 客户对预算有顾虑 |
| **风险代理** | 诉讼 / 仲裁、有明确经济诉求、胜诉概率较高 | 客户门槛低、利益绑定 | 收入不确定、有合规限制 |
| **固定 + 计时** | 部分工作可预估、部分不确定 | 兼顾确定性 | 结构复杂，需要解释 |
| **固定 + 风险** | 诉讼案件，基础工作 + 结果奖励 | 兼顾保障和激励 | 需合理设定比例 |
| **分阶段收费** | 项目周期长、有明确阶段节点 | 分散风险、现金流好 | 需明确定义各阶段 |

**选择逻辑：**

```
项目类型 → 核心判断 → 报价方式
诉讼 / 仲裁 → 标的额明确 + 胜诉概率评估 → 风险代理 或 固定 + 风险
诉讼 / 仲裁 → 标的额不确定或案情复杂 → 固定 或 固定 + 计时
非诉专项 → 范围明确 → 固定
非诉专项 → 范围不确定 → 分阶段 或 固定 + 计时
常年顾问 → 固定年费 + 超出范围部分计时
```

**费用调整机制。** 服务范围取决于未来不确定因素（交易路径未定、法律政策变化、第三方行为不确定、服务范围可能扩大）的，方案中必须设计费用调整机制：明确触发情形 → 说明增加工作量的原因 → 给出调整幅度区间 → 设计双方确认程序。

**报价合理性自检：**

| 检查项 | 标准 |
|---|---|
| 工时合理性 | 各角色工时预估与工作量是否匹配 |
| 费率合规性 | 是否符合当地收费标准和本所定价政策 |
| 利润率 | 项目利润率是否在可接受范围 |
| 市场竞争力 | 与同类服务市场价格相比是否合理 |
| 内部一致性 | 总价 = 各模块明细之和 |
| 谈判弹性 | 是否预留了谈判空间 |

### 6. 方案撰写

**撰写原则：**

- **面向客户**：方案是给客户看的，不是内部文件；
- **突出价值**：先说能为客户解决什么问题，再说怎么做；
- **专业克制**：不过度承诺，不贬低同行；
- **清晰明确**：服务范围、报价、条件没有歧义。

### 7. 质量审核

| 类别 | 检查项 |
|---|---|
| **完整性** | 是否包含所有必要章节；客户需求是否全部回应 |
| **一致性** | 报价金额是否全文一致；服务范围描述是否前后统一 |
| **准确性** | 法律分析是否正确；引用的法规和案例是否准确 |
| **竞争力** | 差异化是否突出；与竞争对手相比优势在哪 |
| **合规性** | 报价是否符合当地收费管理规定；风险代理比例是否合规 |
| **客户视角** | 客户能否看懂；会不会产生误解 |

### 8. 方案输出

按下文结构定稿交付。

## 文书结构

**诉讼 / 仲裁代理及报价方案**

```
封面 → 案件概况与初步分析 → 代理策略 → 团队配置 →
服务内容与报价 → 服务承诺 → 合作条款 → 附件
```

**非诉讼专项法律服务报价方案**

```
封面 → 项目理解 → 服务内容与范围 → 服务方法 →
团队配置 → 报价方案 → 服务承诺 → 合作条款 → 附件
```

**常年法律顾问服务报价方案**

```
封面 → 服务理念 → 服务内容（基础 + 增值） → 团队配置 →
年度报价 → 服务承诺 → 合作条款 → 附件
```
