从接收法律咨询问题到给出最终解答的全流程，确保每个咨询问题的研究过程可追溯、结论可核验。

## 适用情形

- 接到任何需要研究后答复的法律咨询，从单条法条确认到正式法律意见书。

## 办理步骤

### 1. 先建档（不可跳过）

收到咨询后，先完成以下两项，再开始检索：

1. 建立咨询文件夹及三级目录（input / scratch / output）。
2. 写下问题清单，哪怕只有一句话，后续再补。

理由：没有档案时，检索结果只能散落在聊天记录里，事后补建意味着重复劳动或丢失中间成果。先有容器，再装内容。

**目录结构**（每个咨询问题单独建文件夹）：

```
YYYY-MM-DD【咨询类型】简要描述/
├── input/                    ← 问题记录
│   └── 01-问题清单.md        ← 原始提问及追加问题汇总
├── scratch/                  ← 过程文件
│   ├── 01-问题分析.md        ← 意图拆解、法律关系识别、子问题清单
│   └── 02-研究记录.md        ← 检索过程与关键发现
└── output/                   ← 最终交付物
    └── 01-综合解答.md        ← 最终咨询意见
```

- **命名**：`YYYY-MM-DD【咨询类型】简要描述`。咨询类型包括：咨询、专项咨询、合同审查、诉讼分析、合规审查、法律意见等。
- **原始材料只读**：input 中的原始材料不修改。

### 2. 意图分析与问题拆解

不直接解答，先完成：

1. **问题记录**：把原始提问记入问题清单，追加问题同步更新。
2. **意图分析**：委托人真正想解决什么？表面问题背后的诉求是什么？咨询目标是了解情况、支持决策、解决争议还是推进交易？
3. **法律关系识别**：涉及哪些主体？主体之间是什么法律关系？核心争议是什么？
4. **子问题拆解**：把复杂问题拆成可独立研究的子问题，标注法律领域、关键事实要素、待检索方向，识别子问题之间的逻辑依赖。

### 3. 研究

按《法律检索的来源顺序与标注》分层检索：

1. 知识库中的体系化知识；
2. 原始资料：优先源 → 扩展源；
3. 外部补充：法律数据库或联网检索（最后手段）。

研究过程记入研究记录。

### 4. 综合解答

1. 整合各子问题的研究结果；
2. 识别子问题之间的交叉影响；
3. 形成整体法律判断；
4. 给出行动建议（附决策树）；
5. 标注依据来源和不确定事项。

### 5. 效力审计（必做）

解答完成后自检：

1. **来源覆盖**：所有核心结论是否都有可靠来源支撑；
2. **时效**：引用的法规是否现行有效（查修订、废止、新法替代）；
3. **未覆盖项**：有无应检索而未检索的维度；
4. **待确认项**：哪些结论有赖委托人补充事实才能确定。

## 按问题类型确定深度

| 咨询类型 | 深度 | 研究要求 | 输出形式 |
|---|---|---|---|
| 单条法条确认 | 直接回答 + 附依据 | 快速核实 | 简短回答 |
| 单一法律问题 | 结论 + 依据 + 风险 | 优先源检索 + 效力审计 | 结构化分析 |
| 复杂商业法律问题 | 完整框架 + 决策树 | 全流程研究 + 效力审计 | 完整分析报告 |
| 正式法律意见书 | 完整框架 + 审查备注 + 声明 | 全流程 + 法律意见书起草规则 | 正式法律意见书 |

## 输出要求

- **先结论后分析**：先给可执行的判断，再展开依据，让委托人和业务人员也能看懂。
- **结构化表达**：默认区分事实、判断、依据、风险、建议。
- **写明不确定性**：用「初步判断」「倾向认为」「需结合进一步材料确认」等表述控制边界；没有把握的明确提示，不装作确定。
- **决策树收尾**：正式分析的行动建议部分，每个选项具体到可执行的动作，标明风险等级和前提条件，给出倾向建议，但不替委托人决定。
- **审查备注**：正式交付物文末附审查备注。

## 模板

**行动选项**

> **行动选项：**
> 1. **【选项A】**——描述 | 风险：低 / 中 / 高 | 前提：需要什么
> 2. **【选项B】**——描述 | 风险：低 / 中 / 高 | 前提：需要什么
> → **倾向建议：** 选项【X】，理由：【一句话】

**审查备注（正式交付物）**

> **审查备注**
> - 来源覆盖：法条原文 × 【N】 / 检索 × 【N】 / 未经核实 × 【N】
> - 未覆盖项：未能检索或确认的事项
> - 时效检查：关键法规最新生效 / 修订日期
> - 待确认：需委托人补充事实或作出决定的事项

## 后续服务提示

咨询中发现下列情形的，在「后续服务建议」中提示：

- 可能发展为正式委托事项；
- 存在尚未暴露的深层法律风险；
- 需要专业法律文书（起诉状、律师函、法律意见书等）；
- 涉及多个领域，需要团队协作。
