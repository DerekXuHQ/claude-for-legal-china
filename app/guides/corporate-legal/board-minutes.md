董事会纪要是法律记录，要经得起融资尽调、监管调查和并购数据室的审视。本篇说明如何按公司惯用格式起草董事会或专门委员会会议纪要。替代会议的书面决议另见书面决议起草指引。

## 适用情形

- 即将召开或刚召开的董事会、审计委员会、薪酬与考核委员会、提名委员会、战略委员会等专门委员会会议，或股东会会议；
- 纪要通常在会后起草，也可在会前按议程预先搭好框架。

## 需要准备的材料

- 公司惯用的纪要格式（详细记录式 / 决议式 / 混合式）及一两份既往纪要作为范本：结构、页眉格式、决议措辞都以范本为准。没有范本的，先确定格式再起草，不套用通用格式。
- 董事会组成和各专门委员会名单；
- 公司章程（法定人数、表决规则）；
- 会议通知或通知豁免文件；
- 议程、预读材料、董事会演示文稿、管理层汇报；
- 实际出席名单。

## 办理步骤

### 1. 确定会议及基本信息

查看日程中未来30天内的董事会/委员会会议；没有的，往前看14天（纪要多在会后起草）。确认：

- 会议类型：全体董事会 / 【委员会名称】
- 日期和时间
- 地点或平台（线下地址 / 腾讯会议 / 飞书 / 电话会议）
- 召集和通知：是否已按规定发出通知，或已豁免（豁免通知书常作为附件）

### 2. 确认出席情况

- **出席董事**：以董事会组成名单为起点，核实实际出席和缺席的人员，以及缺席董事是否事先收到通知；
- **出席管理人员**：如财务总监、财务负责人、技术总监等，与董事分别列出；
- **列席人员**：外部律师（姓名、律所）、投资银行、审计师等顾问；仅就特定议题列席的，注明限于该议题；
- **主持人和记录人（秘书）**；
- **法定人数**：查阅公司章程中的法定人数要求；章程未规定的，查适用于该公司类型的公司法规定，并在起草说明中记录来源和具体条款。确认已达到法定人数。

**未达法定人数的，停止起草并标记**，不得产出暗示有效会议的纪要，将问题提交外部律师。补救路径（追认、重新召开会议、书面决议或其他）取决于注册地和所涉行为的性质。

### 3. 收集会议材料

议程和预读材料是议程事项和决议的来源。即使只有粗略议程，也足以搭建纪要结构。从材料中提取：

- 按顺序排列的议程事项；
- 拟议决议（留意“批准”“授权”“追认”“通过”“选举”等用语）；
- 引用的附件（管理层演示文稿、财务报告、法律备忘录、估值报告）；
- 预期的表决事项。

没有材料的，口头确认议程事项，讨论内容先用占位符。

### 4. 起草纪要

严格按范本的结构、页眉、决议措辞和讨论详略程度起草。

**讨论内容记多少**，按公司格式：

| 格式 | 记录方式 |
|---|---|
| 详细记录式 | 概括讨论实质：提出了什么问题、呈现了什么信息、董事会考虑了哪些因素。除非某项发言的归属在法律上有意义，不记录个人原话。 |
| 决议式 | 只记录汇报了什么、采取了什么行动；讨论只写“董事会就此进行了讨论”。 |
| 混合式 | 重大事项（收购、融资、重大批准）完整叙述，常规事项只记录行动。 |

- 有材料的，从演示文稿和管理层汇报中概括：董事会“听取并审阅了”某项汇报，就概括该汇报涵盖的内容。
- 没有材料的，插入【占位符——在此概括讨论内容】并清楚标记，**不得编造讨论内容**。
- **决议措辞**照抄范本（“决议如下”“决议”“兹决议”各家不同，属于内部风格，不能互换）。
- **附件**按出现顺序编号（附件一、二、三）。常见附件：管理层演示文稿、财务报表、估值报告、法律意见书、通知豁免书、同意书。

### 5. 审核与定稿

- 纪要本身是公司记录，不属于律师工作成果，分发的纪要上不加工作成果标识；起草说明、占位符标记和审查清单属于工作成果，应加标识，不随纪要分发。
- 标出所有占位符以及需要律师补充才能准确的章节。
- 草案上附注定稿前删除的说明：“本件为供律师审查的草案，非已批准的纪要。已批准的纪要是董事会行动的正式记录，具有法律后果，须由执业律师审查、修改并承担职业责任后方可批准。”
- **批准纪要前须经律师审核。** 经办人不是法务人员的，带以下要点去找律师：
  - 决定了什么（决议、表决、出席情况）；
  - 草案已记录的内容和仍为占位符的内容；
  - 未决问题（出席、法定人数或利益冲突方面的标记）；
  - 可能出错之处（决议表述错误、遗漏披露、法定人数缺陷、讨论摘要泄露受保护内容）；
  - 需请律师判断的问题（讨论详略是否符合该董事会惯例；闭门会议记录是否已适当隔离；是否有事项需要更多书面记录）。
  - 需要寻找律师的，可联系中华全国律师协会或所在地律师协会获取推荐。

## 检查清单

分发前逐项核实：

- □ 全体董事出席/缺席已对照实际出席情况确认
- □ 法定人数已确认无误
- □ 决议措辞与实际批准的内容一致（逐字核对）
- □ 表决记录正确，弃权票、反对票已记录
- □ 附件编号和引用正确
- □ 是否召开了闭门会议？如有，另行制作闭门会议记录
- □ 是否有利益冲突需披露？如有，记录董事回避情况
- □ 闭会时间已填写
- □ 按流程需要外部律师审查的，已审查

## 模板

**页眉：**

```
【公司名称】董事会
【会议类型】会议纪要
（或：【公司名称】董事会【委员会名称】会议纪要）

【日期】
【地点 / 电话会议 / 视频会议】
```

**开场：**

- 会议由【主持人姓名】于【时间】召集
- 通知：【已按规定发出通知 / 已豁免通知——豁免书作为附件】
- 法定人数：【N】名董事中【N】名出席
- 记录人：【姓名】

**出席情况：**

- 出席董事：【名单】
- 缺席董事：【名单，如有】
- 列席人员：【管理人员、外部律师等，注明身份】

**前次会议纪要：** 批准前次会议（【前次会议日期】）纪要。

**议程事项（每项一节）：**

```
【议程事项标题】

【汇报人姓名】就【议题】作了汇报。

【讨论摘要】

（如随后有决议：）
经动议并附议，下列决议【获一致通过 / 以【N】票赞成、【N】票反对、【N】票弃权表决通过】：

决议如下：【按公司惯用措辞写明决议内容】。
```

**闭会：** 无其他事项，会议于【时间】闭会。

**签署栏：** 记录人签署；部分公司格式另有董事长副签。

## 注意事项

- 纪要根据会议材料和律师提供的信息起草，不能代替出席会议的实时记录。
- 决议在法律上是否有效、是否充分，由律师判断。
- 草案须经律师审查后方可定稿和分发，由公司按自身流程分发。
