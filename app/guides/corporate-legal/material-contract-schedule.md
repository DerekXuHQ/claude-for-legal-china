股权收购协议中常有一项陈述与保证：「清单3.X列明了所有重大合同。」本指引用于从尽调发现中编制这份清单：哪些合同符合协议对重大合同的定义，并按协议要求的格式列出。

## 需要准备的材料

- 股权收购协议草案：「重大合同」的定义和清单格式。
- 公司内部的重要性阈值（可能与协议定义不同，以协议为准）。
- 尽调中提取的合同层面数据。
- 数据室目录。

## 办理步骤

### 第1步：取得定义

从股权收购协议中提取「重大合同」的定义，以协议定义为准。

- 交易结构不同（股权转让、资产转让、合并），各触发条件的解释也会不同。
- 受监管行业（医疗、国防、金融服务、电信、政府采购）可能在协议之外另有同意要求。涉及的，检索适用的反垄断、外商投资安全审查等规则，并引用相应规定。

协议定义中常见的触发条件（不能替代阅读协议本身，以协议所列为准）：

- 金额阈值（年度或累计）
- 合同期限
- 控制权变更或禁止转让条款
- 独家性或竞业禁止
- 前N大客户或供应商合同
- 不动产租赁
- 知识产权许可（许可进来和许可出去）
- 关联方协议
- 政府采购合同
- 非正常经营范围内的合同

机械适用：满足协议定义中任何一项条件的合同，均列入清单。

### 第2步：逐份适用定义

| 合同 | 满足条件 | 是否列入 |
|---|---|---|
| 【名称】 | 【年度金额≥X元；含控制权变更条款】 | 是 |
| 【名称】 | 【无】 | 否 |

以下边界情形标出来，交人工判断：
- 金额刚好低于阈值，但对企业经营重要；
- 满足某项条件但正在终止中；
- 口头协议或补充函，可能算也可能不算。

### 第3步：收集清单数据

| 字段 | 来源 |
|---|---|
| 对方当事人名称 | 合同 |
| 合同标题/类型 | 合同 |
| 日期 | 合同 |
| 期限/到期日 | 合同 |
| 年度/总金额 | 合同或管理层数据 |
| 满足哪项重大性条件 | 第2步分析 |
| 交易是否需要对方同意 | 尽调发现 |
| 数据室索引 | 尽调目录 |

字段缺失的，标出来，不推测。

### 第4步：按协议格式排版

披露清单通常为编号列表或表格，有时按合同类型分项。与协议草案中其他清单的格式保持一致（模板见下文）。

### 第5步：单独追踪同意事项

另列一张内部用的同意事项表（不放进清单本身），记录哪些已列入的合同需要取得对方同意，并纳入交割检查表。

| 清单编号 | 对方当事人 | 是否需要同意 | 状态 | 负责人 | 截止日期 |
|---|---|---|---|---|---|
| 3.X(a)(1) | 【名称】 | 是 — 控制权变更 §12.2 | 已请求 | 【姓名】 | 【日期】 |

**保密。** 同意事项表和交付前的工作草稿来源于受保密保护的尽调材料，沿用其保密等级，向保密范围外分发可能丧失保护。清单本身一旦作为已签署收购协议的附件交付，即为交易文件，不再受保护；交付前须删除所有内部注释。

## 检查清单

交付前确认：

- [ ] 满足任一条件的合同均已列入（完整性）
- [ ] 不满足任何条件的合同未列入（不过度披露——这是陈述与保证，不是数据倾倒）
- [ ] 清单与其他陈述与保证一致（例如清单3.X中创设担保物权的合同，也应列入担保物权清单）
- [ ] 每项条目均附数据室索引，便于买方律师找到原件

## 注意事项

- 重大性定义由股权收购协议决定，编制清单时不另行界定。
- 本工作只追踪哪些合同需要同意，不负责取得同意。
- 本工作填写陈述与保证所引用的清单，不起草陈述与保证本身。

## 模板

```markdown
## 清单 3.【X】 — 重大合同

截至签署日，重大合同如下：

### (a) 客户合同

1. 【协议标题】，签署日期【日期】，由【目标公司】与【对方当事人】之间订立。
   【如格式要求附简述，则添加。】
   【数据室：路径】

2. 【……】

### (b) 供应商合同

【……】

### (c) 不动产

【……】

【其余分项按协议的定义结构编排】
```
