大多数常规董事会批准不需要开会：高管任免、股权授予、银行授权、超出高管权限的合同审批、关联方安排，都可以通过一致书面决议完成。本指引用于以公司内部格式、基于最接近的先前决议快速起草，并对签署前应由外部律师审查的行动作出标记。

## 适用范围

本方法适合在决议存档或范本中有直接先例的日常决议：高管任免、股权授予、年度授权、标准合同审批等。

**重大单项行动**，无论草案质量如何，都应经外部律师审查：并购交易（资产收购、股权收购、合并、投资）、融资轮、向新投资者发行股权、控制权变更条款、解散或清算、重大不动产交易，以及任何会在日后尽调中被审视的行动。识别为重大行动的，作出标记；标记不阻止起草，而是提示考虑改编先例的草案对此行动是否足够。

## 两种必须先停下来的情形

**一、重大行动 + 当天签署。** 同时满足以下两项的，不把草案作为「可签署」版本交付：

1. 行动属于下文「审查标记」类别（并购、融资、清算、资本结构变更、控制权变更条款、与融资或并购挂钩的董事选举、重大不动产交易，以及会出现在日后融资或并购数据室中的行动）；
2. 请求中有不可逆的时间信号：「今天下午发电子签」「今晚签署」「需要在开盘/交割/某时会议之前」等。

重大行动上的错误决议无法挽回，而时间压力正是出错的时候。此时只有两条路径：
- 先起草，经外部律师审查后再签署（常规路径）；
- 外部律师已介入本交易并认可了起草路径的，写明审查人和时间，在草案中注明外部律师已审查。

两条路径都未确认前，不开始起草。需要找律师的，可联系中华全国律师协会或当地律师协会获取推荐。没有重大行动的常规决议，或重大行动但没有当天签署要求的，按正常流程办理，审查标记照常适用。

**二、没有先例。** 既没有决议存档，也没有公司的范本决议的，先不起草。决议措辞、鉴于部分的详略、授权条款和签署栏惯例都是各公司特有的选择，用通用模板起草，审查者往往要从头重写，返工比节省的多。解决办法：
- 提供一份公司近期的任何书面决议（用于提取格式，不提取实质内容）；或
- 委托人明确表示「用通用模板起草，格式我自己调整」，并承诺分发前手工处理决议措辞、鉴于风格和授权条款。

## 需要准备的材料

- 决议存档位置或公司范本决议。
- 公司内部决议措辞惯例。
- 公司注册地（用于确认通知等要求）。
- 董事会组成（用于签署人名单）。
- 公司对书面决议适用范围和限制的内部规定。

## 办理步骤

### 第1步：明确行动

收集：
- **批准什么？**（一句话）
- **支持细节**：如被任免高管的姓名、股权授予的数额和价格、合同审批的对方当事人和合同金额。
- **生效日期**：当天还是特定日期。
- **签署人**：全体董事会还是特定委员会。内部规定某些行动须开会而不能书面决议的，此时标出。
- **董事冲突**：是否有董事在拟批准事项中有重大利益。有冲突的董事能否签署，取决于适用法律和冲突性质，但决议应作披露，并请委托人确认。

**行动分类：**

| 常规——通常有直接先例 | 审查标记——重大单项行动，建议外部律师审查 |
|---|---|
| 高管任免 | 并购交易（收购、合并、资产收购、投资） |
| 向既有股权激励计划参与者授予股权（期权、限制性股票、限制性股票单位） | 新融资轮或债务融资 |
| 银行账户授权或签署人更新 | 向新投资者发行股权 |
| 低于重大阈值的合同审批 | 控制权变更条款或触发 |
| 年度授权决议（税务事项、福利计划等） | 审批依公司章程或股东协议本身须经董事会批准的协议 |
| 按公允条件订立的关联方借款或服务协议 | 解散、清算或破产申请 |
| 注册地址或工商登记代理变更 | 重大不动产交易 |
| | 将在日后融资或并购数据室中作为董事会批准附件出现的任何行动 |

属于审查标记类别的，起草前提示：「这看起来像【行动类型】，属于重大公司行动，改编先例的草案可能不充分，建议分发前由外部律师审查。」并确认是否继续。

### 第2步：查找先例

**有决议存档的：**
1. 按行动类型关键词查找（如「高管任免」「股权授予」「银行授权」）。
2. 取最近的匹配决议；有多份接近的，列出标题和日期请委托人选择。
3. 阅读选定决议，提取决议措辞、鉴于部分结构、授权语言、特定条件或例外。
4. 记下先前行动与本次行动的差异，起草时逐项更新。

**只有范本的：** 从范本提取格式，并告知委托人：没有存档可查，草案沿用内部格式但没有实质先例匹配，本行动类型可能值得另找先前决议作实质起点。

### 第3步：起草决议

用内部格式；下文模板为标准结构，按先例或范本格式精确调整。起草要求：

- **精确。** 含糊的决议会在尽调中制造问题。「批准该交易」没有用；「批准【买方】与【公司】之间于【日期】签署的资产收购协议，基本形式见本决议附件一」才有用。
- **列明授权签署人。** 特定高管需要特定权限的，写出姓名，不笼统写「高级管理人员」。
- **引用附件。** 批准文件的，附上并在决议中引用。决议有多具体，就有多大用处。
- **严格沿用内部用语。** 「决议如下」「现决议」「兹决议」用哪个，以先例或范本为准；同一份决议内不混用。

### 第4步：确认注册地的书面决议规则

起草前查清注册地对书面决议的要求：

- 董事会书面决议是否须全体一致，还是允许较低门槛？
- 是否须通知未签署的董事？时间要求？
- 股东决议是否须通知未签署的股东？时间要求？
- 什么形式的签名有效（手签、电子签、分签副本）？
- 公司章程是否改变了默认规则，例如更高的签署门槛、不同的通知期限、限制哪些行动可以书面决议？

引用所依据的法条和章程条款，并核实时效（公司法规定会修订）。未经确认的规则，标出交律师核实。公司对这些问题有内部立场的，适用并说明法律依据。在成果中附一段「适用法律说明」，总结已确认和待确认的内容。

### 第5步：签署前把关

签署书面决议会约束公司并成为公司记录。使用者不是律师的，出定稿前须确认已经律师审查；未经审查的，整理一份简要说明带给律师：

- 行动是什么（决议内容）；
- 分析结果（适用法律说明、签署门槛、标出的冲突）；
- 未决问题（标出待律师核实的事项）；
- 可能出错的地方（决议无效、违反董事义务、签署瑕疵、冲突处理不当）；
- 要问律师的问题（这种方式是否合适、是否缺少鉴于内容、公司章程是否允许该行动以书面决议方式作出）。

需要找律师的，可联系中华全国律师协会或当地律师协会。

### 第6步：交付成果

1. **决议草案。** 签署后的书面决议是公司记录，不受保密保护，分发的决议不加工作成果页眉。草案前另附一段签署前说明（签署前删除）：「本件为供律师审查的草案，非已签署的决议。签署即约束公司并成为公司记录，须经执业律师审查、按需修改并承担职业责任后方可发出签署。」
2. **签署人检查表**（加工作成果页眉）。
3. **分发前检查清单**（加工作成果页眉）。

## 注意事项

- 某行动在法律上是否需要董事会批准，由律师判断。
- 董事义务和利益冲突如何解决，由律师处理；起草时只标出冲突。
- 重大交易的外部律师审查不可省略。
- 草案交律师审查后，按公司自身流程分发；签名回收按公司文件管理流程追踪，签署人检查表只是起点。

## 模板

### 一致书面决议

```
【公司名称】
【董事会 / 【委员会名称】】
一致书面决议

【日期】

以下签署人，构成【公司名称】（一家【注册地】【有限公司/股份公司】，以下简称"公司"）【董事会 / 【委员会】】的全体成员，依据【《公司法》第XX条/适用公司章程】通过书面决议替代会议，兹通过如下决议：

【议程项目 / 行动标题——如有多项决议】

鉴于，【背景叙述——一两句陈述相关事实和董事会为何被要求行动】；

鉴于，【如需要，附加叙述】；

现，因此，决议如下：【正在批准的具体行动，用精确语言——列名称、述金额、引用相关的具体协议或文件】；

进一步决议如下：【相关或执行决议——例如授权签署文件的具体高管、授予的权限】；

进一步决议如下，公司的高级管理人员各自且共同被授权和指示，以公司的名义并代表公司，采取一切行动，签署和交付该等高级管理人员认为必要或适当的所有文件、文书、证书和协议，以执行前述决议的意图和目的；

进一步决议如下，公司任何高级管理人员此前就前述事项采取的任何行动，特此予以追认、确认和批准。

【如为多项决议，为每个额外行动重复鉴于/决议块】

本书面决议可签署一份或多份副本，每份副本应被视为正本，全部副本共同构成同一文件。电子签名视为所有目的之原始签名。

【签署栏——每位必需签署人一份】

_______________________________
【董事姓名】
【职务，如适用】
日期：_______________

【每位董事/委员会成员重复】
```

### 签署人检查表

```
【工作成果页眉】

签署人检查表 — 【行动】 — 【日期】

所需签署人（需要一致同意）：
□ 【董事姓名 1】
□ 【董事姓名 2】
□ 【董事姓名 3】
【其余按董事会组成列出】

冲突披露：
【无 / 【董事姓名】具有已披露的利益——确认是否需回避或披露】

适用法律说明：【已确认规则——注册地 / 待确认】
```

### 分发前检查清单

```
【工作成果页眉】

分发前——检查：
□ 决议措辞精确描述了行动（无含糊批准）
□ 生效日期正确
□ 全部必需附件已附上并引用
□ 授权签署人正确列名
□ 董事冲突已披露或解决
□ 重大行动：外部律师已审查
```
