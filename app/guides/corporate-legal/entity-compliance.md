工商年报、企业所得税年度申报、信息公示、外商投资信息报告……每个主体在每个注册地都有自己的申报时间和逾期后果。本篇说明如何为集团各主体建立一份轻量的申报台账：知道什么到期、何时到期、针对哪个主体，并定期做主体健康审计。

## 适用情形

- 集团或公司名下有多个主体（子公司、分公司、代表处、合伙企业等），需要统一跟踪申报截止日；
- 需要了解未来30/60/90天内到期的申报事项；
- 并购、融资前需要确认各主体存续状态。

## 截止日的可靠性

- 台账中的截止日只是参考。各地申报要求和截止日可能调整，**依赖前须向工商登记代办机构或主管市场监督管理部门确认**。
- 使用代办机构的，代办机构针对具体主体的合规日历是权威依据，台账用于整理和呈现其数据，不替代它。
- 主体的实际经营范围与台账记录不一致的（未办理的异地经营备案、已注销主体、注册地迁移、由当地代理机构办理的跨省申报），台账结果可能不适用，应与代办机构或当地律师确认。

## 主体类型决定申报日历

申报日历取决于主体类型，不只是注册地。把同一注册地的所有主体当成一类，是常见且后果严重的错误。计算截止日前先确认每个主体的类型，不得把一种主体类型的截止日套到同一注册地的另一种主体类型上。

| 主体类型 | 要点 |
|---|---|
| 有限责任公司 / 股份有限公司 | 每年1月1日至6月30日通过国家企业信用信息公示系统报送并公示年度报告（国务院《企业信息公示暂行条例》第7、8条） |
| 外商投资企业 | 除年报外，还需按《外商投资法》及其实施细则完成外商投资信息报告（《外商投资法》第34条） |
| 合伙企业 | 每年1月1日至6月30日报送年度报告，内容与公司不同 |
| 代表处 / 分公司 | 各自有独立的年报义务 |
| 已进入注销程序或长期停业的主体 | 仍需报送年报；清算组成员、清算组负责人名单等需在清算组成立后60日内公示 |

台账中主体类型不明的，标为“类型未知”，确认后再计算截止日。

## 台账结构

每个主体记录：名称、类型（有限责任公司 / 股份有限公司 / 合伙企业 / 其他）、注册地、成立日期、状态（开业 / 休眠 / 注销中）、登记代办机构、备注。

每个主体在每个注册地或经营地，逐项记录申报事项：

| 字段 | 内容 |
|---|---|
| 地点及性质 | 注册地 / 经营地；备案日期 |
| 是否由当地代理办理 | 是 / 否；代理名称 |
| 申报类型 | 年度报告 / 企业所得税申报 / 外商投资信息报告 / 其他 |
| 截止日及依据 | 具体日期；固定日期 / 成立周年月 / 其他 |
| 最近申报日期、最近费用 | |
| 状态 | 正常（当期已申报，90天内无待办）/ 即将到期（90天内到期）/ 逾期（已过截止日且无申报记录）/ 未知（无信息，需确认） |
| 最近确认存续状态的日期 | |

台账头部记录公司名称、生成日期、最近更新日期、最近审计日期，并注明“截止日为参考信息，请与工商登记代办机构或市场监督管理部门确认”。

## 办理步骤

### 1. 建立台账

1. 取得主体清单（例如组织架构图）。
2. 对每个主体的每个注册地或经营地确认申报要求，不依赖过往缓存的时间表：
   - 先问有没有代办机构出具的最新合规报告，那是最权威的来源；
   - 没有的，记录经办人已知的信息：申报类型、截止日依据、最近申报日期、大致费用；
   - 仍不清楚的，标为“未知”，不凭参考表填日期，由经办人向代办机构或市场监管部门确认。
3. 遇到参考表中没有的注册地，逐项问清：需要哪些申报、何时到期（固定日期还是周年月）、大致费用、由谁代办；作为该地的自定义规则记录下来，以后同地主体直接沿用。
4. **跨省经营主体**：各省要求不同，一律先与当地申报代理或代办机构确认申报类型、频率和费用；还要问是否需要在当地报送集团层面的报告（如关联交易报告等）。有当地代理的，标为“代理办理”，报告时单列，提示向代理确认状态，不自行推算截止日。
5. 按周年月申报的，从成立日期推算；成立日期缺失的，状态标为“未知”。
6. 设定初始状态并汇总：主体数、注册地数、申报事项数，以及正常 / 即将到期 / 逾期 / 未知各多少项。

### 2. 定期报告

默认展示未来90天（也可选30、60、180天）：

```
主体合规报告 — 【日期】
【公司名称】

🔴 逾期（【N】）：
  【主体】 / 【省份】 / 【申报类型】 — 应于【日期】完成

⏰ 【N】天内到期（【N】）：
  【主体】 / 【省份】 / 【申报类型】 — 【日期】到期  【代办机构】

✅ 近90天已申报（【N】）：
  【主体】 / 【省份】 / 【申报类型】 — 已于【日期】申报

❓ 状态未知（【N】）：
  【主体】 / 【省份】 / 【申报类型】 — 无信息，请与代办机构确认

🌐 代理办理（【N】）：
  【主体】 / 【省份】 / 【申报类型】 — 由【当地代理】办理，请直接确认状态

存续状态：
  已确认存续状态的主体：【N】/【总数】
  近12个月未确认的主体：【列表】
```

主体超过约10个的，可以做成看板：按申报状态、存续状态计数，附可按注册地、申报类型、下一截止日排序的主体表。

### 3. 更新状态

- **逐项更新**：例如“【主体】已于【日期】申报年度报告，费用【金额】元”，更新最近申报日期、费用，状态改为正常。
- **按代办机构报告批量更新**：读取代办机构的合规报告，提取各主体的申报类型和截止日、最近申报日期、存续状态及确认日期、代理标注的警示。按名称匹配主体，名称相近的（同名不同注册的主体）先确认。完成后列出：已匹配数、报告中有但台账中没有的主体（可能需要补入主体清单）、台账中有但报告中没有的主体。
- **逐项排查**：对状态为“未知”或“逾期”的事项逐一确认是否已申报、何时、费用多少。

**记录申报前的律师审核**：向市场监管部门提交年度报告、所得税申报或信息公示，是主体的正式陈述，遗漏或错误可能导致处罚或丧失正常存续状态。经办人不是法务人员的，申报前请律师（或有资质的代办机构）审核，带上以下要点：

- 主体、注册地、申报类型和截止日；
- 台账中最近一次申报的信息（日期、费用、当时报告的董事高管信息）；
- 未决问题：董事高管信息是否仍准确，代办机构是否变更，主要经营场所是否变更；
- 可能出错之处：董事高管信息过时、错过截止日导致处罚或被注销、费用计算错误；
- 需请律师判断的问题：今年是否确实需要申报，是否有章程修订或高管变更需要反映，应由谁签署。
- 需要寻找律师的，可联系中华全国律师协会或所在地律师协会。

查看台账、报告到期事项不需要这一步。

### 4. 健康审计

| 审计项 | 看什么 |
|---|---|
| 申报合规 | 逾期事项、状态未知事项 |
| 休眠主体 | 维持休眠主体有年费、代办费和持续合规义务，审查是否应注销；成立超过5年且处于休眠的，列为注销候选 |
| 数据缺口 | 缺少成立日期的主体 |
| 存续状态 | 没有存续状态确认记录的主体（交易急需存续证明时有风险）；确认已超过12个月的主体（预期有并购、融资时尤应更新） |
| 经营备案 | 公司在某省有办事处、员工，但该省没有备案的主体。是否构成需要备案的经营存在，由律师根据业务事实确认 |
| 关联交易协议 | 关联交易协议签订不全的，列出可能需要协议的主体关系（母子公司服务、知识产权许可、借款） |

审计报告列明各项数量和清单，最后按优先级给出建议行动。

### 5. 导出

导出给财务、法务运营或外部代办机构时，每个主体 × 注册地 × 申报类型一行，列为：主体名称、主体类型、注册地、成立日期、状态、代办机构、管辖地、地点性质、申报类型、截止日、最近申报、最近费用、存续状态确认、备注。也可以导出只含未来90天申报的简表。

导出电子表格时注意：来自外部的文本（当事人名称、代办机构数据、系统导出内容）如以 `=`、`+`、`-`、`@` 或制表符、换行符开头，会被表格软件当作公式执行。应在这类单元格前加单引号使其显示为文本；CSV 文件中的逗号、双引号、换行符按规范转义。

## 注意事项

- 台账不提交任何申报，申报由律师、外部律师或代办机构完成。
- 台账不调取存续证明，只记录最近一次确认的时间。
- 在某省是否需要办理经营备案，取决于业务活动的事实，须由律师判断。
- 结构复杂的多主体集团，台账不能替代专业代办服务；它最适合没有代办支持的小型组织，或作为代办数据之上的一层整理。
- 截止日参考信息不是法律意见，依赖前逐项确认。

## 法律依据

- 《企业信息公示暂行条例》第7条、第8条
- 《外商投资法》第34条
