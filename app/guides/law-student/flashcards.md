大纲用于综合，记忆卡片用于记忆。法考和多数法学院考试奖励快速回忆规则。本篇说明如何从大纲、笔记或教材制作卡片，用简单的莱特纳记忆桶做轻度间隔复习，并追踪哪些概念记住了、哪些卡住了。已有 Anki 等习惯的，继续用即可。

## 适用情形

- 根据某份材料制作记忆卡片。
- 训练、自测记忆卡片。
- 查看复习进度。

## 需要准备的材料

- 科目（课程名称或主题）。
- 来源：大纲、课堂笔记、教材节选。
- 已有卡片组（如有），在其基础上增量制作。

## 准确性要求

- 从提供的来源制作的卡片，问题和答案都来自来源，可以有把握。
- 没有来源、凭记忆制作的卡片，凡规则不完全确定的，标注 `[需核实：规则——对照来源确认]`，核实后再作为学习目标。
- 不熟悉的领域少做卡片，不编造。8 张可靠的卡片胜过 20 张里有 5 张是错的。

## 注意事项：练习中出现真实情况

练习内容听起来像真实情况（真实姓名、地址、日期、金额，「我的房东/老板」「我收到了通知」，以天为单位的截止日期等），停止当作练习处理，提示寻求律师、法律援助中心或学校法律诊所的帮助。

## 办理步骤

### 1. 制作卡片

每次一般 10-20 张。

**编写规则**

1. **一张卡片一个概念。** 「侵权责任的构成要件」拆成 4 张，不是 1 张。
2. **正面是问题，不是主题。** 「侵权责任构成要件」不好；「侵权责任的四个构成要件是什么？」好。
3. **背面是规则，不是段落。** 答案需要一段话的，拆成多张。
4. **标注来源**，便于复习时重新核实。

凭记忆制作的卡片，背面规则和引用的案例、法条未经核实，记卡前对照大纲、教材或北大法宝、法信、中国裁判文书网核实。训练到精通的错误卡片比没有卡片更糟。

### 2. 训练

**优先顺序**

1. 下次复习日期已到且未「掌握」的卡片。
2. 尚未尝试过的新卡片。
3. 都没有时，询问是否复习已掌握的卡片（防止遗忘）。

**每张卡片的流程**

1. 显示问题，等待回答（或「跳过」「不知道」）。
2. 显示答案。
3. 学生自评：正确 / 部分正确 / 错误 / 不知道。
4. 按下表更新记忆桶和下次复习时间：

| 自我评估 | 记忆桶变动 | 下次复习 |
|---|---|---|
| 正确 | 升一级（新 → 学习 → 复习 → 掌握） | 新 +1天，学习 +3天，复习 +7天，掌握 +21天 |
| 部分正确 | 保持当前桶 | +1天 |
| 错误 | 降一级（复习 → 学习；学习 → 新；新保持新） | 当天 +4小时 |
| 不知道 | 降一级 | 当天 +4小时 |

### 3. 浏览与统计

- **浏览**：按记忆桶分组查看某科目全部卡片，扫描内容、手动调整。
- **统计**：每个科目的总卡片数、记忆桶分布、今天到期数、本周已复习数。退回「新」桶超过两次的卡片是卡住的概念，转为追问训练——不理解的概念，靠背卡片解决不了。

### 4. 集中练习（一场 N 张）

优先之前答错的卡片 > 到期卡片 > 新卡片，按训练流程逐张做完，结果记入练习记录：

```yaml
session_history:
  - date: 2026-05-08
    subject: 合同法
    type: 记忆卡片
    n_cards: 5
    right: 3
    partial: 1
    wrong: 1
    stuck_topics: [合同的订立-要约与承诺]
```

## 模板：卡片

```markdown
### 卡片 [N]
**Q：** [问题——一个概念，一张卡片]
**A：** [答案——规则，一两句话]
**来源：** [大纲章节、教材页码、课堂笔记日期]
**记忆桶：** 新
**上次复习：** —
**下次复习：** [今天日期]
**备注：** [可选——区分、例外、陷阱]
```

每个科目一个文件，卡片的记忆桶和复习信息写在每张卡片内。卡片超过 500 张时这种方式不够高效。

## 与其他练习的衔接

- 构建或扩展大纲后，从新材料制作卡片。
- 一张卡片错了 2 次以上，转追问训练深入理解。
- 卡片统计差的法考科目，在客观题练习中加大权重。

## 本方法不做什么

- 不为凑数量编造卡片。
- 不强制学习纪律：错过的复习会累积，是否训练由学生决定。
- 不教规则：卡片用于训练已经学过的内容；一张卡片持续出错，问题在上游，回去重读来源或做追问训练。
