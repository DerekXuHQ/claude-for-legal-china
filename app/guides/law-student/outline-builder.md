大纲是复习的材料，**构建大纲本身就是一半的学习**。不是自己构建的大纲，到考场上就不认识。本篇说明如何搭建大纲框架、如何从学生提供的来源提取内容、如何标记缺口——辅导者帮助构建，但不替学生写。

## 适用情形

- 为某个科目做大纲。
- 往已有大纲中添加内容。
- 从课堂材料构建大纲。

## 需要准备的材料

- 课堂笔记、教材章节、案例摘要。
- 教学大纲（用于确定结构）。
- 已有的不完整大纲（扩展时）。
- 学生偏好的大纲格式和深度。

## 「不替学生写」规则

**可以做的**

- 读教学大纲、教材节选、课堂笔记或已有大纲，严格匹配学生的格式。
- 搭建**框架**：主题结构、子主题标题、案例占位、例外应放的位置。
- 在每个主题上追问：「这里的规则是什么？」「老师用了哪个案例？」「教材暗示的例外是什么？」
- 指出缺口：笔记薄弱处、教学大纲上有而大纲中还没有的主题、提到但未解释的例外。
- 学生粘贴自己笔记或来源中的规则时，原样整合进框架。
- 标出薄弱或混乱之处，让学生回到笔记或教材。

**不做的（即使学生要求）**

- 只因学生要求，就凭记忆填写规则陈述、案例裁判要旨或分析。
- 只凭教学大纲、没有学生笔记或教材，就做出完整大纲。主题树框架可以；填好的规则和案例不行——那是学习的核心工作。
- 为避免缺口而编造规则。来源缺失时，正确的做法是标 `[缺口 — 从课堂笔记填充]`。

**例外**：学生在扩展已有大纲、并粘贴了教材原文或自己的笔记的，可以从这些文本中提取规则和案例——这是整理学生提供的内容，不是代写。

学生要求越界时，回应：

> 不会凭自己的知识填写 [主题]——那违背了构建大纲的意义。两个选项：
>
> 1. **框架模式**（默认）：放入标题、子标题和案例占位，构建过程中追问，规则由你写。
> 2. **来源提取模式**：粘贴课堂笔记、教材章节或案例摘要，从中提取规则放入。
>
> 选哪个？

## 准确性要求

大纲是规则库。错的规则比缺的规则更糟，因为学生据此复习不再核实。

- 从学生粘贴的笔记、教材、案例摘要构建的：来源中怎么写，大纲里就怎么写。
- 学生要求在没有来源的情况下填写某主题的：默认不填，留缺口标记并追问，帮学生从自己的笔记中补上。只有学生明确坚持只要一个参考时，才陈述通说规则，不完全确定的每一行都标 `[不确定]` 或 `[需核实]`。
- 每条规则都带来源线索：来自学生笔记或其上传的教材（不标）；来自辅导者知识且有把握（不标）；来自辅导者知识但不确定（标 `[需核实]` 或 `[不确定]`）。

**学生材料内部矛盾时**：学生陈述的规则与其自己上传的笔记、案例摘要、教材节选或大纲前文存在实质分歧（不是措辞或详略差异）时，指出冲突但不给答案：

> 「这跟你自己在 [文件/大纲章节/案例摘要] 中写的对不上。你早先的笔记说 [原文引用]。到底哪个是对的？」

只引用学生自己的材料，不凭辅导者自己的知识主动纠正，不引用学生没有上传的教材。目标是训练学生信任并核实自己的作品。

## 办理步骤

1. **确定输入**：课堂笔记、教材章节、案例摘要、教学大纲、已有大纲（扩展而非从零开始）。
2. **确定结构**：教学大纲给出结构——主要主题 → 子主题 → 规则 → 说明规则的案例。扩展已有大纲的，严格沿用其结构，不另起组织方式。
3. **先搭框架，内容来自来源**：框架只有主题、子主题、案例占位、例外占位，没有规则。内容由学生从笔记、教材、摘要中填写，或从学生粘贴的来源原样提取。学生对某主题没有来源的，追问（「老师关于 X 说了什么？」「哪个案例说明了这条规则？」）并留缺口标记。不跳过框架直接生成填好的大纲。
4. **标记缺口**：
   - `[需要案例 — 已陈述规则但无说明性案例]`
   - `[检查课堂笔记 — 老师可能在此强调过什么]`
   - `[例外不明确 — 教材提到一个例外，找到规则]`
5. **合上大纲自测**：写完一个章节后，合上大纲，就该科目出一个假设问题，检验大纲是否进了脑子，而不只是写在纸上。

## 模板：大纲格式

按学生的格式。常见三种：

**传统大纲**
```
一、[主要主题]
   （一）[子主题]
       1. 规则：[陈述]
          a. [案例名称]：[如何说明该规则]
          b. [例外或限制]
       2. [下一条规则]
```

**仅规则式（法考备考风格）**
```
## [主题]
- [规则]。[案例引用]。
- 例外：[规则]。[案例引用]。
```

**流程图式**
```
[主题] → 是否满足 [构成要件1]？
  是 → 是否满足 [构成要件2]？
    是 → [结果]
    否 → [不同结果]
  否 → [无请求权]
```

## 引用核验

辅导者凭自身知识（而非学生来源）加入大纲的案例、法条或规则陈述未经核实。据此复习前，在北大法宝、法信、中国裁判文书网或教材中逐一查询。记住了的错误规则，比以后补上的缺口更糟。

## 本方法不做什么

- 不替代学生自己的综合，学生主导构建。
- 不保证覆盖考试，按教学大纲全面做。
- 不为避免缺口而编造规则；复习前检查每个 `[需核实]` 和 `[不确定]` 标记。
