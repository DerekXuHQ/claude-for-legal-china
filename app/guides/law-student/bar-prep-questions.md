本篇用于法考备考练习：按考生的考试阶段（客观题/主观题）和薄弱科目出题、讲解、批改，追踪错题模式，并正确处理全国统一规定与省级司法口径的差异。本篇是培训课程的补充练习，不替代培训课程，也不预测真题。

## 适用情形

- 客观题练习、主观题练习。
- 按薄弱科目做集中练习（一场 N 题）。
- 自测与错题回归。

## 需要准备的材料

- 考试阶段：客观题 / 主观题 / 两者均需。
- 考试日期、薄弱科目、所报培训课程（瑞达/厚大/众合等或自学）。
- 所在省份（涉及省级口径时）。
- 学习计划（如有），用于确定当天安排的科目和仍薄弱的子主题。

## 注意事项：练习中出现真实情况

练习内容听起来像真实情况（自己的租房合同、停车罚单、家人的生意、朋友被逮捕，出现真实姓名、地址、日期、金额，「我的房东/老板/父母/朋友」「我收到了罚单/信函/通知」，以天为单位的截止日期），立即停止当作练习处理。法科生不是执业律师，不能提供法律意见；当事人应找法律援助中心、学校法律诊所、当地律师协会的律师推荐服务，或聘请律师。可以帮助理解相关法律概念，但那是学习，不是法律意见。

## 一、先确认考试阶段

法考每年更新考试大纲。国家统一法律职业资格考试分客观题和主观题两个阶段：

- **客观题**：试卷一（法治思想、法理学、宪法、中国法制史、国际法、司法制度与法律职业道德、刑法、刑事诉讼法、行政法与行政诉讼法）和试卷二（民法、知识产权法、商法、经济法、环境资源法、劳动与社会保障法、国际私法、国际经济法、民事诉讼法），全部为选择题。
- **主观题**：案例分析题、法律文书题、论述题。

出题前：

1. 确认考生参加的是客观题、主观题还是两者都要。没有确认的先问清楚，不能假设——两个阶段的考查范围和题型有实质差异，练错了题型是无法补救的错误。
2. 提示考生以司法部官网（https://www.moj.gov.cn/）当年度考试公告和大纲确认科目范围。培训机构课表与司法部大纲不一致的，以大纲为准。
3. 只在考生实际考查的科目范围内出题。考生列出的薄弱科目不在其考试范围内的，提示并让考生选择：（a）跳过；（b）练习其中可能与考试交叉的基础概念；（c）仍然练习，用于全面了解该领域。

## 二、省级口径处理

法考由国家统一命题，不存在省级独立命题；全国统一的法律规定是基础。但部分省份高级人民法院发布的指导意见或会议纪要在具体适用上存在差异，主观题案例分析可能涉及对地方司法口径的了解。

**常见差异领域**

- **合同法/民法**：最高人民法院合同纠纷司法解释全国适用，但各省高院可能对具体类型合同（如商品房买卖合同、建设工程合同）有指导意见。
- **劳动争议**：《劳动合同法》全国统一，但各省高院在具体赔偿标准、举证责任分配上可能有差异。
- **交通事故/侵权**：赔偿标准因省而异（如死亡赔偿金、误工费依据各省人均可支配收入计算）。
- **知识产权**：部分地方（如北京、上海、广州）设有知识产权法院，损害赔偿认定标准可能有区域差异。

**出题规则**

- 考生所在省份对某科目有地方口径、且与全国统一规定存在差异的，先问本次练习是否涉及省级口径，不混用。
- 每道题标注适用依据：`[全国统一规定]` 或 `[省级口径]`。全国统一规定的题目，答案以法律、行政法规、司法解释为准；涉及省级口径的，标注口径来源并写明这是地方性规则。
- **差异标注在规则层面，不在科目层面。** 每道合同法题都标「无实质差异」是噪音，考生会不再阅读。考查的具体规则无省级实质差异的，在题内写：`[浙江省关于民法典第XX条无实质差异——本答案适用于浙江。]`；存在实质差异的，用下面的「你所在省份存在差异」提示块；题目本身就基于某省口径构建的，不再加标签。不对整个科目统一标注「无实质差异」——同一科目里既有存在差异的规则，也有不存在差异的规则。

**规则存在差异时的答案写法**

```markdown
**正确答案：C**

**为什么选C（全国统一规定）：** [规则 + 适用]

**你所在省份（浙江）存在差异：** 根据《浙江省高级人民法院关于XXX问题的指导意见》第X条，该规则为[省级口径]。在此规则下，答案将是[A/B/C/D]。

**在法考中：** 在客观题和主观题中，除非题目明确指示适用地方性规则，否则默认以全国统一法律和司法解释为准。如果题目来自省级高院指导案例，则适用该省口径。

**需记忆的规则要点：** [一句话要点，标注差异]
```

不确定某省对该规则的现行立场时，标注：`[不确定：XX省对此规则的具体立场——请核实该省法考培训材料或该省高院最新指导意见]`，不得编造。错误而自信地陈述某省口径，比标注不确定危害更大。

## 三、准确性要求

每道题都陈述一条规则。自信地说出错误规则比没有题目更糟。

- **有把握**：公认要点，正常出题。
- **不确定**：因省份而异、属于少数观点，或对准确性没有把握的，行内标注 `[不确定：具体原因]`，提示考生先对照培训材料核实。
- **不掌握**：不出题，说明该领域没有可靠规则，建议跳过或使用培训课程。

答案解析中对规则没有把握的，标注 `[需核实：规则——对照瑞达/厚大/众合教材确认]`，宁可多标。

## 四、客观题

法考客观题分单选、多选、不定项选择三种题型；试卷一和试卷二各150分，满分300分。按真实题型出题。

**出题**：经典格式为案例事实 + 设问 + 四个选项。在考生实际考查范围内向薄弱科目倾斜（例如刑法和民法薄弱的，60%的题来自这两个科目）。难度为法考级别：核心是准确掌握法律规定要点并清晰适用，不是大学期末考试那种分析深度。

**每题讲解**

```markdown
**正确答案：C**

**为什么选C：** [规则 + 适用]

**为什么不选A：** [该选项考查的规则及为何在此处错误]
**为什么不选B：** [同上]
**为什么不选D：** [同上]

**需记忆的规则要点：** [一句话要点]

---

**引用核验。** 以上解释中引用的规则和案例未经独立核实。记入知识体系前，请对照法考培训教材（瑞达/厚大/众合）或权威法律法规数据库（北大法宝/国家法律法规数据库）核实。规则陈述有时会在构成要件上出错或混淆法条。
```

**追踪错题**：持续统计错在哪些科目、哪些子主题、哪些错误选项陷阱。例如：「5道证据法题错了3道，全部集中在非法证据排除——这已形成模式，专门训练非法证据排除。」

## 五、主观题

**出题**

- 案例分析题：给出案例材料，设若干问题。
- 法律文书题：给出案情，要求撰写起诉状、答辩状、判决书等。
- 论述题：给出主题，要求进行法律论述。

科目按薄弱领域或考生选择，限于实际考查范围。

**批改要点**

- 考点识别：找出了哪些考点，遗漏了哪些。
- 法条引用：是否准确、完整。
- 分析：是否把规则适用于具体事实，还是只罗列规则和事实。
- 结构：IRAC 或其他结构，可读性如何。

法考主观题评分看重完整性和逻辑性，不看文采。完整、结构清晰、法条准确的答卷可以通过；观点精彩但不完整的不能通过。

```markdown
## 主观题反馈

**考点识别：** [X] / [Y]
**遗漏考点：** [列表——这些是丢分项]

**法条引用：** [准确 / 基本准确 / 有误——逐考点说明]

**分析：** [是否真正进行了法律适用，还是仅罗列规则+事实？]

**结构：** [清晰 / 混乱]

**如果按法考标准评分：** [通过 / 边缘 / 尚未达到——附修改建议]
```

## 六、集中练习（一场 N 题）

1. 确认科目、题数 N、客观题还是主观题（或混合）。考生所在省份对该科目存在规则差异（劳动争议、侵权赔偿等）的，确认使用全国统一规则、省级口径还是混合。
2. 出 N 道题，按考生以往错过的子主题加权。
3. 逐题作答、讲解：给出正确答案并解释每个错误选项为何错，按第二部分处理省级差异。
4. 结束时出练习报告：

```markdown
## 练习：[科目]，[N] 题

**得分：** [X]/[N]（[百分比]）
**错题：** [列表——子主题 + 错在哪里]
**薄弱子主题：** [错题最集中的 2-3 个子主题]
**强项子主题：** [作答扎实的子主题]

**与既往练习的对比：** [例如："最近4次练习中有3次错在非法证据排除规则——这是停滞项，建议转为追问训练深入练习。" 或："刑法从40%提升到70%，但共同犯罪部分仍不稳固。"]

**学习计划更新：** 薄弱子主题已加入优先列表。下次安排 [科目] 练习：[日期]。
```

5. 把结果记入练习记录，供学习计划调整权重：

```yaml
session_history:
  - date: 2026-05-08
    subject: 刑法
    type: 法考-客观题
    n_questions: 10
    score: 6
    weak_subtopics: [共同犯罪, 刑罚裁量]
    jurisdiction_mode: national  # 或 provincial
```

## 七、与学习计划的衔接

有备考计划的，题目向本周计划中的科目倾斜，新学内容优先训练。

## 本练习不做什么

- 不替代法考培训课程，只作补充训练。
- 不预测真题，须全面复习。
- 不在省级口径不确定时不加标注就给答案；看到 `[不确定]` 或 `[需核实]` 的，先对照培训课程核实再依赖。
