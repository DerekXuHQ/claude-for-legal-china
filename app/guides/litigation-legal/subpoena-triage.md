---

调查令和协查通知都带着期限。常见的失误有四种：错过期限；提供过多（放弃了保密保护，或本可提出异议的负担照单全收）；提供不足（有拒不配合的风险）；错过申请撤销的窗口。本指引用于分类、分析，并形成合规方案和异议框架。

## 适用情形

- 公司收到法院调查令、律师调查令、行政机关协查通知或证人出庭通知。
- 监察委或刑事侦查类通知不在此流程内：**立即停止，按单位上报规则上报，并咨询刑事律师。**

## 需要准备的材料

- 调查令 / 协查通知原件及送达凭证。
- 案件台账（检索关联案件和证据保全状态）。
- 单位常打交道的监管机构、保密惯例、上报规则。

## 适用规则概览

| 类型 | 依据 |
|---|---|
| 法院调查令 | 《民事诉讼法》第67条及《民事诉讼法司法解释》第94—96条 |
| 律师调查令 | 各省、直辖市高级法院制定的律师调查令实施办法，各地规则不同 |
| 行政机关协查通知 | 各专门行政法规（如市场监管、税务、证券监管等） |
| 监察委 / 刑事侦查 | 《监察法》《刑事诉讼法》，应立即咨询刑事律师 |

以上规则引用只是起点，书面提出异议或配合前，须确认现行有效性和地方差异。

## 办理步骤

### 第〇步：研究适用规则

分析之前先查清适用的程序规则：法院调查令核对《民事诉讼法》第67条及司法解释第94—96条；律师调查令核对所在省、直辖市高级法院的实施办法；行政协查核对相关行政法规。要查清：地域管辖限制、异议期限（自收到起算）、保密审查要求、费用承担，并记下精确出处，核实现行有效。

法规数据库检索结果为零或很少的，如实说明已找到的内容，由律师决定是扩大检索、换用其他数据库、改用网络检索（结果须复核后才能依赖），还是暂停。每条规则、案例、法条的来源（数据库检索、网络检索、凭记忆、来文所载）都要注明；凭记忆的引用编造风险高，优先核验〔待核〕。

### 第一步：分类

- **法院调查令（民事诉讼）**：我方不是诉讼当事人，法院或对方律师申请调取我方文件。常见异议：关联性、负担、保密、地域管辖。
- **律师调查令**：对方律师持法院签发的调查令调取证据。审查签发是否合法、调查范围是否超出必要限度、商业秘密或个人隐私是否受到保护。
- **行政机关协查通知**：市监局、税务局、证监会、国家金融监督管理总局等。各机关规则不同；通常应更配合，但后果也更重。
- **证人出庭通知**：法院通知我方员工作为证人出庭，涉及证人准备、范围、关联性。
- **监察委 / 刑事侦查通知**：刑事程序，立即上报刑事律师，不做本流程的分流。

### 第二步：提取要点

- **签发机关**：具体法院名称或行政机关
- **申请方**（民事诉讼中）
- **案号 / 案件名称**
- **所需文件类别**：编号列表
- **出庭 / 询问主题**（涉及证人的）
- **答复 / 异议期限**：送达日期 + 按适用规则计算的答复窗口
- **提供日期**：文件须在何时前提供
- **地域范围**：涉及的文件保管人、地点、系统
- **联系人 / 回函对象**：公司内部的文件保管人或签收人

### 第三步：比对案件台账

- **当事人调查令**：核对案号是否与台账中的案件匹配；匹配的，转入该案件处理，本次分流仅作信息记录。
- **第三方调查令**（案号我方不认识）：记录当事人信息，作为单独来文归档。
- **同一案件多份调查令**：注明系协同签发，可考虑统一的回复策略。

### 第四步：分析范围、负担、保密

**范围 / 关联性**
- 所需文件类别是否对应我方实际可能持有的文件？
- 是否有类别过于宽泛、与争议焦点无关，属于「钓鱼式取证」？
- 地域管辖：按查明的规则判断，法院调查令与律师调查令的限制不同。

**负担**
- 涉及的文件保管人、需检索的系统、时间跨度
- 预估体量：小 / 中 / 大 / 极大
- 成本：第三方答复人可能有费用分担安排

**保密**
- 是否可能涉及律师与客户之间的保密内容？（涉及法务的事项几乎都会涉及，内部法务或外部律师的往来沟通尤其要注意。）
- 是否涉及商业秘密？（《反不正当竞争法》第10条）
- 是否涉及个人信息？（《个人信息保护法》，提供前需评估合法性基础）

**其他异议理由**
- 保密性：是否需要申请保护措施
- 重复：对方是否已从其他当事人处取得
- 不持有：我方没有对方要求的材料（具体说明）
- 送达不当：是否符合适用规则的送达要求

### 第五步：拟定异议框架

形成结构化的异议纲要（不是最终异议书），列明哪些异议适用及理由，由公司与外部律师最终确定。每项异议写明：

- 法律依据：第〇步查明规则的精确出处
- 具体适用对象：哪些文件类别、哪些保管人
- 强度：有力 / 合理 / 较弱

### 第六步：拟定合规方案

即使提出异议，通常仍会提供部分内容：

- **预计提供范围**：异议后仍将提供的内容
- **需检索的保管人**：姓名和系统
- **日期范围**
- **审查安排**：由谁负责保密审查（我方、外部律师、合同审查人员）
- **提供格式**：按调查令要求或协商确定
- **保密文件清单**：格式、字段

### 第七步：梳理期限

采用第〇步查明的期限。不同程序的异议期限算法不同，不要默认一个数字。

- 答复期限
- 异议期限（可能是收到后一定天数内）
- 提供日期（异议不成立时）
- 申请撤销的窗口期（走此路径的，时机至关重要）

全部排入日程，列为即时行动事项。

### 第八步：撰写分流意见（模板见下文）

### 第九步：答复前审查与转交

- **向签发机关作任何实质性答复前**（提出异议、提供文件、出庭作证或申请撤销），须经律师审查。错过期限有拒不配合风险，提供过多会放弃保密保护，提供不足有受处罚风险。由非律师人员处理的，可为律师准备一页摘要：通知类型、签发机关、期限、所需文件范围、异议框架及强度、保密和负担问题、拟采取的答复姿态、可能出错的地方、需要问律师的问题。需要找律师的，可联系当地律师协会或拨打 12348 法律援助热线。分流、范围判断和内部日程安排不受此限。
- 证据保全通知尚未发出的，按调查令范围发出。
- 行政机关协查通知：注意该监管机构的特定惯例，建议委托熟悉该领域的外部律师。
- 其他情况：一般建议立案登记（调查令往往重要到值得跟踪）；属于既有案件当事人调查令的，结合该案件简报处理。
- 最后列出下一步选项（如起草某文件、上报、补充事实、观察等待、其他），由律师选择。

## 边界

- 不起草最终异议书，只形成框架；异议书由公司与外部律师起草。
- 不代为申请撤销调查令，只列出选项；撤销申请需要针对管辖地的专门分析。
- 不自行确认各地规则的时效和地方差异，须经律师核实后方可行动。
- 不处理刑事程序调查，一律上报。

## 法律依据

- 《民事诉讼法》第67条
- 《民事诉讼法司法解释》第94—96条
- 各省、直辖市高级法院律师调查令实施办法
- 《反不正当竞争法》第10条（商业秘密）
- 《个人信息保护法》
- 律师法第38条（保密）
- 《监察法》《刑事诉讼法》（监察委 / 刑事侦查类通知）
