---

起草是下游工作，价值在动笔之前：把一封仓促的函件会跳过的问题逐一问清楚，包括筹码、最佳替代方案、不利后果承受度、保密过滤和实际读者。没想清楚就发出的律师函，比不发更糟。

## 适用情形

- 准备发付款催告、违约 / 催告整改、停止侵权、劳动合同相关、证据保全等律师函。
- 起草前需要先做委托登记。

## 办理步骤

1. 调出所内律师函惯例和风险校准标准。
2. 问核心 8 项（始终要问）。
3. 事项重大，或需要完整登记时，加问策略 5 项。
4. 按「标题 + 对方当事人 + 年月」给函件编代号。
5. 填写委托登记表（模板见下文）。
6. 登记完成后转入「律师函起草」。

## 核心问题（8 项，始终询问）

**1. 函件类型**
付款催告 / 违约·催告整改 / 停止侵权 / 劳动合同相关 / 证据保全 / 其他

**2. 当事人**
- 发函方：我方公司（多实体的指明具体实体）
- 收函方：对方名称、主体、地址
- 实际读者：谁会真正读这封函（法务？CEO？个人？）
- 关系：客户 / 供应商 / 前员工 / 竞争对手 / 第三方 / 其他

**3. 触发事件**
- 发生了什么、何时发生（日期关系到诉讼时效和通知期限）
- 现有证据（合同、邮件、记录、证人）

**4. 法律 / 合同依据**
- 具体合同条款
- 适用法律（管辖、法律选择条款）
- 所依据的法律法规（可先留占位，草案中标【引用：___】）

**5. 期望结果**
- 具体要求，而不是「解决问题」：在Y日前支付X元；停止某项具体活动；N日内整改；返还特定财产。
- 有多项要求的，排出主次（主要 / 备选）。

**6. 截止日**
- 推动此事的外部期限（诉讼时效、损害持续扩大、商业节点）
- 函中给对方的合规期限

**7. 先前沟通**
- 此前是否已非正式提出？何时、由谁、以什么形式？
- 对方至今的回应？
- 为什么现在升级为律师函？

**8. 发送安排**
- 送达方式
- 签署人
- 内部抄送人

## 策略问题（重大事项或完整登记时询问）

**9. 筹码和最佳替代方案**
- 我方的谈判筹码（合同权利、事实、声誉、商业）
- 对方拒绝怎么办，我方是否准备好起诉
- 对方可能的最佳替代方案

**10. 不利后果承受度**
- 事情公开后的声誉风险
- 先例风险：这封函是否会影响其他事项
- 监管或信息披露影响

**11. 语气姿态**
维护关系 / 克制 / 进取，取决于双方关系、金额和诉讼可能性。

**12. 保密过滤**
- 我方内部分析中哪些内容绝不能出现在函里
- 一句措辞不当就可能构成自认，要明确哪些内容留在函外

**13. 自认和权利放弃风险**
- 函中是否有内容可能被对方日后认定为对事实或责任的自认
- 是否有内容在没有保留条款的情况下放弃了某项权利
