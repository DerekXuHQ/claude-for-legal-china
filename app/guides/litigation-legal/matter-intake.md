每个新案件都按同一套问题登记，案件之间才有可比性。台账里的统一字段便于汇总，登记表的记述记下字段表达不了的内容，同时建立的历史记录成为后续的事件日志。

## 适用情形

- 新案件需要纳入案件台账（收到起诉状、律师函、协查通知、监管问询、内部报告等）。

## 需要准备的材料

- 单位的风险校准标准（严重性、可能性分级，重要性门槛，和解授权层级）。
- 利益冲突审查制度及检索结果。
- 外部律师库、内部相关人员名单。
- 起诉状、律师函等来源文件。

## 办理步骤

1. 逐项完成下文「登记内容」1—10。
2. 利益冲突检索未完成的，按下文「冲突门禁」处理，不得直接立案。
3. 生成案件代号：小写、连字符、末尾加年份（如 `acme-v-us-2026`、`employment-smith-2026`），并确认在台账中不重复。
4. 形成案件登记表、历史记录（以本次登记为第一条）和台账记录。
5. 写入前把台账记录和登记表交承办人核对，有错误或缺漏的先改。
6. 最后列出下一步选项（如起草某文件、上报、补充事实、观察等待、其他），由律师选择。

## 登记内容

### 1. 标识信息
- 案件名称（常用叫法，如「某某公司诉我方 2026 合同纠纷案」）
- 对方当事人
- 案件类别：合同纠纷 / 劳动争议 / 知识产权 / 行政监管 / 内部调查 / 产品责任 / 其他
- 案由（依据最高人民法院《民事案件案由规定》）
- 我方地位：原告 / 被告 / 申请人 / 被申请人 / 被调查人（单位有默认角色的预填后确认；「因案而异」的直接询问）
- 管辖：受理法院、仲裁机构或行政机关

### 2. 利益冲突检索
按单位利益冲突审查制度进行，并记录：
- **状态**：已通过 / 待定 / 未检索 / 已豁免
- **方式**：按单位制度规定的方式
- **审查人**：姓名 / 团队 / 律所
- **审查日期**
- **审查对象**：实际检索的名称和主体（对方、已知关联方、对方律师（如已知）、关键证人）。数量少可以，写「无」不行。
- **备注**：曾被标出但已通过的事项

### 3. 来源
律师函 / 起诉状送达 / 调查令·协查通知 / 行政监管问询 / 内部报告 / 诉前威胁

### 4. 风险分流（对照单位校准标准）
- 严重性：高 / 中 / 低
- 可能性：高 / 中 / 低
- 综合风险评级（矩阵结果）：高 / 中 / 低 / 危急
- 赔偿敞口范围（最佳估计）
- 非金钱敞口：禁令？行政处罚？声誉影响？先例效应？

### 5. 重要性
对照单位门槛：需计提 / 已披露 / 监控中 / 不适用

### 6. 外部律师
- 律所、主办合伙人
- 委托合同状态：已签署 / 待定 / 无
- 预算授权：金额和审批人

风险为中及以上但未指定外部律师的，须标出。

### 7. 内部负责人
- 业务负责人
- HR 负责人（劳动争议）
- 公关联系人（有声誉风险的）
- 信息安全负责人（涉及数据或网络安全的）
- 其他

### 8. 证据保全
- 是否已发出；已发出的，记录日期、范围、保管人名单。
- 下次更新日期（默认发出后六个月，按案件调整）。
- 未发出而案件已进入诉讼或可合理预见诉讼的，紧急标出。

### 9. 关键日期
- 答辩、异议、反诉等答复期限
- 下次开庭 / 庭前会议
- 诉讼时效截止日（如适用）
- 行政监管期限

### 10. 初始思路
一段话：我方的案件逻辑、对方的案件逻辑、关键事实。初始姿态：积极应对 / 寻求和解 / 调查中 / 观望。

## 冲突门禁

| 状态 | 处理 |
|---|---|
| 已通过 | 继续登记 |
| 待定 | 继续登记，但在登记表和台账中醒目标出冲突未解决；此后每次更新案件、每次汇总案件状态都再次提示，直至解决 |
| 已豁免 | 少见；须有豁免理由，记录豁免书的存在、签署人和存放位置（起草豁免书不在本流程内） |
| 未检索 | **停止，不建立登记表、历史记录和台账记录**，选择以下路径之一 |

未检索时的三条路径：

1. **现在检索。** 暂停登记，按冲突审查制度完成检索，带着「已通过」或「已豁免（附理由）」回来继续。
2. **标为待定，指定负责人和截止日期。** 仅限单位冲突审查制度允许平行登记的情形。记录谁在检索、预计何时有结果、检索哪些主体。登记继续，案件带「待定」状态，每次汇总和更新都提示，直至解决。
3. **书面说明理由后绕过。** 仅在承办人明确确认绕过时使用，记录如下：

```yaml
conflicts:
  status: 未检索
  override:
    by: 【姓名】
    date: 【日期】
    rationale: 【绕过冲突检索的理由——永久记录，不会自动失效】
```

此记录在每次案件汇总、简报和更新中都会显示，只有在冲突实际清除后由承办人手动删除。

## 边界

- **不代为进行利益冲突检索。** 只记录结果、状态、方式和审查对象；实际审查在单位规定的系统中完成。承办人说「已通过」的，照此记录。
- **不自行设定初始思路。** 记录承办人所说的内容。
- **不代发证据保全通知。** 缺失的标出，由承办人发出。

## 法律依据

- 最高人民法院《民事案件案由规定》
