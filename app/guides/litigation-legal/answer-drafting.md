被告（答辩人）收到民事起诉状后，针对原告的诉讼请求逐项答辩，形成结构规范、说理充分、攻防有据的民事答辩状。思路是：先看清对方主张什么、凭什么主张，再从事实和法律两条线逐项反驳，最后落到己方的明确请求。

答辩状立场服务于答辩人，但说理保持客观，不作"必胜""一定驳回"之类承诺。成稿为应诉文书草稿，不构成正式法律意见，以承办律师审定及法院裁判为准。

## 适用情形

- 民事案件被诉后应诉答辩、反驳起诉状。
- 不适用于刑事、行政答辩，起诉状撰写，合同起草。

## 基本原则

- **逐项对应**：原告有几项诉请，答辩就有几项回应，不遗漏、不含糊。
- **攻防分层**：把回应拆成"事实层"（经过是否如对方所述）和"法律层"（即便事实如此，法律上是否成立）两条线分别组织。
- **三视角校验**：分别从原告（其主张的薄弱点）、被告（己方最有利的抗辩）、法官（最可能采信哪条逻辑）三个角度审视答辩思路。

## 需要准备的材料

- 原告起诉状原文（扫描件、图片须先识别文字）。
- 原告的证据清单。
- 己方掌握的事实和证据：合同、付款凭证、往来记录、质检报告等。
- 材料不全（例如只有纠纷描述，没有起诉状原文）的，先向当事人补充对方的具体诉请和证据，不得凭空假设对方主张。

## 办理步骤

### 1. 拆解对方诉请与请求权基础

读透起诉状，逐条列清：

1. **诉讼请求清单**：逐项编号（如支付价款、赔偿损失、确认合同有效、返还财产），区分主请求与从请求（本金与利息、违约金）。
2. **事实主张**：原告据以起诉的事件经过、时间线、关键节点。
3. **请求权基础**：每项请求所依据的法律关系与法条（买卖合同、借贷合同、侵权、不当得利等）。起诉状未写明的，推断其最可能的请求权基础并标注"（推断）"。
4. **证据清单**：原告列举的证据及各自拟证明的内容。
5. **程序事项**：管辖法院、是否超过诉讼时效、原告主体是否适格等。

### 2. 确定抗辩思路

对每项诉请，从下列方向筛选可用的抗辩路径：

| 层面 | 抗辩方向 |
|---|---|
| 事实层 | 对方陈述的事实不真实或不完整；关键事实缺乏证据，证明责任在原告；存在对方未提及、对己方有利的事实 |
| 法律层 | 请求权基础不成立（不存在其主张的法律关系，或合同未成立/无效/已解除）；构成要件不齐备；存在抗辩权或免责事由（履行抗辩权、同时履行抗辩、不可抗力、免责约定等）；诉讼时效已过；数额抗辩（计算有误、违约金过高请求调减、损失未实际发生等） |
| 证据层 | 质疑对方证据的真实性、合法性、关联性；指出证据不能证明待证事实或因果关联；提出己方反证 |
| 程序层 | 管辖异议、主体不适格、重复起诉、应追加当事人等 |

选定路径后做三视角校验：哪项答辩最可能被对方进一步反驳；哪项抗辩证据最扎实、最适合作为主攻方向；哪条逻辑链最清晰、最可能被法官采信。据此排出答辩重点的先后。

**确认节点**：诉请清单和拟采用的抗辩提纲先交当事人或承办律师确认；补充了事实或调整了方向的，重新梳理后再继续。

### 3. 逐项答辩与己方主张

1. **总括意见**：一两句话表明总体立场，如"原告全部诉请均缺乏事实和法律依据，应予驳回"，或"请求依法驳回原告第 X 项诉请、对第 Y 项酌情认定"。
2. **逐项答辩**：每项诉请按"事实如何、法律如何、证据如何"逐条回应，一项诉请对应一段答辩，引用己方事实和证据支撑。
3. **己方主张**：如有独立主张（反请求线索、要求调减违约金、主张费用由原告承担等），单独列明。独立的反诉请求须另行提起反诉，答辩状只承担抗辩功能。
4. **证据组织**：列出支撑答辩的己方证据及收集方向（书证、转账记录、聊天记录、证人证言等），标注每份证据的证明目的；缺失的证据列明待补。

**法条引用**：只引用确有把握的条文，具体条文序号及现行有效性须核实后引用；不确定的，用"依据相关法律规定"概括，由承办人核实后落实。严禁编造法条、司法解释或案例。

**具体信息**：当事人姓名、住所、案号、法院全称、金额、日期等，未掌握的一律用占位符（如【答辩人姓名】），不得臆造。

### 4. 套用模板成文

填入下方模板。成文后须替换全部【】占位项、核实所引法条；需要反诉的另行起草反诉状。

## 模板

```
民事答辩状

答辩人：【答辩人姓名/名称】，【性别、出生日期/统一社会信用代码】，【住所/住所地】，
       【联系方式】。
      （如有法定代表人/负责人：法定代表人【姓名】，职务【职务】。）
      （如有委托诉讼代理人：委托诉讼代理人【姓名】，【单位及职务/律师事务所及执业证号】。）

被答辩人（原告）：【原告姓名/名称】，【基本身份信息】，【住所/住所地】。

  答辩人因【案由，如买卖合同纠纷】一案，针对被答辩人的起诉，现提出答辩意见如下：

一、答辩请求

  1. 请求人民法院依法驳回被答辩人的全部诉讼请求（或：驳回第【X】项诉讼请求，
     对第【Y】项诉讼请求依法予以调减/酌定）；
  2. 本案诉讼费用由被答辩人承担。

二、事实与理由

  （针对原告第一项诉请）
  对被答辩人主张的【该项诉请内容】，答辩人认为不能成立，理由如下：
  （一）事实方面：【陈述真实经过，指出对方事实主张失实或缺乏证据之处】。
  （二）法律方面：【说明请求权基础不成立／构成要件欠缺／存在抗辩事由／时效已过等，
       提示"依据相关法律规定，具体条文待核实"】。
  （三）证据方面：【质疑对方证据的真实性、合法性、关联性，或出示己方反证】。

  （针对原告第二项诉请）
  ……（同上结构逐项展开）……

  （如有己方独立主张）
  关于【违约金调减／费用负担／其他主张】，答辩人认为【理由及依据】。

  综上，被答辩人的诉讼请求【缺乏事实和法律依据／部分缺乏依据】，
  恳请人民法院查明事实，依法支持答辩人的答辩意见。

  此致

  【受理法院全称】人民法院

  答辩人（签名/盖章）：【答辩人姓名/名称】
                      【年 月 日】

  附：
  1. 本答辩状副本【份】；
  2. 证据材料【件】及证据清单一份。
```

## 检查清单

- [ ] 原告每一项诉请都有明确回应；无异议的也写明"对该项无异议"，不略过。
- [ ] 立场服务于答辩人，但说理基于事实与法律，不情绪化、不作胜负承诺。
- [ ] 未掌握的具体信息全部用占位符，没有臆造姓名、金额、案号、法院名称。
- [ ] 拿不准的法条已用概括表述代替并标注待核实；没有虚构条文、解释或判例。
- [ ] 材料不足以支撑某项答辩的，已向当事人补充材料，没有基于残缺信息下关键判断。
- [ ] 当事人有独立请求的，已说明反诉须另行提起。
- [ ] 交付时附提示：本文为应诉草稿，以律师审定及法院裁判为准。

## 办理示例：买卖合同纠纷应诉

原告起诉要求支付货款及违约金。

1. **拆解诉请**：买卖合同纠纷；诉请为①支付货款【金额】②支付违约金③承担诉讼费；请求权基础为买卖合同；证据为合同、送货单、对账单。
2. **抗辩思路**：货款部分核对是否已部分付款（事实＋数额抗辩）；货物存在质量问题可主张减价或拒付（法律抗辩＋证据反驳）；违约金过高主张调减（数额抗辩）；核查是否超过诉讼时效（程序抗辩）。三视角校验后，以"质量异议＋违约金调减"为主攻方向。
3. **逐项答辩**：每项诉请按事实、法律、证据三层回应，列出需补充的质检报告、付款凭证等。
4. **成文**：填入模板，信息用占位符，标注法条待核实，提示反诉另行提起。
