证据清单里的条目分三类：明显可采的、明显不可采的、需要判断的。首轮审查先把前两类筛出来，让律师把时间全部用在第三类上。

**这是首轮审查，每个标记都必须经律师审查，没有例外。**

## 适用情形

- 质证前需要审核证据清单。
- 对一批证据材料做真实性、合法性、关联性审查。

## 需要准备的材料

- 证据清单或证据材料集。
- 单位或律所的证据审查规程。

## 审查框架

中国民事诉讼中证据审查的核心是三性：

1. **真实性**：是否为原件、原物，或经核对无误的复制件、复制品。
2. **合法性**：来源和形式是否符合法律规定。
3. **关联性**：是否与待证事实相关。

**非法证据排除**（《民事诉讼法》司法解释第106条）：对以严重侵害他人合法权益、违反法律禁止性规定或者严重违背公序良俗的方法形成或者获取的证据，不得作为认定案件事实的根据。

## 判断标准

**三态规则：不确定的一律保留并标记，不自行认定为不符合标准。** 合法性存疑、关联性边界模糊的，保留在「待审查」状态并标出。错把证据当作不可采而排除，事后难以挽回；多标记一些，律师审查时可以纠正。宁可犯可以挽回的错。

### 明显可采（✅）：保留，不标记
- 原件，或经核对与原件一致的复制件
- 来源合法、形式合规
- 与待证事实直接相关
- 在举证期限内提交

### 不确定（✅ + ⚠️）：保留，标记交律师判断
- **复印件无法与原件核对**：真实性存疑。
- **未经对方同意制作的录音录像**：未严重侵害他人合法权益、未违反法律禁止性规定的，可能可采。
- **关联性边界模糊**：可能相关，也可能无关。
- **逾期提交的证据**：是否属于「因客观原因逾期」或「对方无异议」？（《民事诉讼法》第68条）
- **证人证言中的传闻**：属于证明力判断，而非可采性判断。

每个标记都写明具体的待决问题及正反两方面理由，让律师不必从头读起就能决定。

### 明显不可采（❌）：建议排除，写明理由
- 以严重侵害他人合法权益的方法获取
- 以违反法律禁止性规定的方法获取
- 与待证事实完全无关
- 经鉴定确认系伪造

处于临界状态的（例如录制行为是否构成严重侵害），归入「不确定」，不归入 ❌。

## 办理步骤

### 1. 格式检查

| 字段 | 有无 |
|---|---|
| 编号 | |
| 证据名称 | |
| 证据来源 | |
| 证明内容 | |
| 证据形式（书证 / 物证 / 电子数据 / 证人证言等） | |
| 是否原件 / 原物 | |

缺少字段的，先补全再做实质审查。

### 2. 逐项审查

```
条目【N】：【✅ 可采 | ✅ + ⚠️ 保留并标记 | ❌ 建议排除】
【✅：一行理由】
【✅ + ⚠️：保留；律师需要回答的具体问题；正反两方面理由】
【❌：一行理由——条目保留在清单上，直到律师决定移除】
```

### 3. 整体观察

- 同一问题是否反复出现？
- 是否有过度提交证据的情况？
- 证明内容的描述是否模糊？

## 审查结果模板

```markdown
【内部工作成果标头】

## 证据三性审查：【案件】——【日期】

**适用规则：**《民事诉讼法》第66条、第68条 + 司法解释第104—106条
**已审查条目：**【N】
**结果：**【N】✅ 可采 /【N】✅+⚠️ 保留并标记 /【N】❌ 建议排除

### ✅ + ⚠️ 已标记，待律师决定
| 条目 | 证据编号 | 问题 | 支持可采 | 反对可采 | 待判断 |
|---|---|---|---|---|---|

### ❌ 建议排除（律师确认后移除）
| 条目 | 证据编号 | 理由 |
|---|---|---|

### ✅ 可采（无需处理）
【数量；需要时附列表】

### 整体观察
【重复问题、过度提交、描述问题】

---

**采取任何行动前，律师须审查全部 ⚠️ 和 ❌ 项。**
```

## 边界

- 不作临界判断，⚠️ 就是「交人决定」。
- 不自行从清单中删除证据，❌ 只是给律师的建议。
- 不保证 ✅ 判断一定准确，证据清单由律师负责。

## 法律依据

- 《民事诉讼法》第66条（证据种类）
- 《民事诉讼法》第68条（逾期提交证据）
- 《民事诉讼法》司法解释第104—106条（证据审查与非法证据排除）
- 《最高人民法院关于民事诉讼证据的若干规定》
