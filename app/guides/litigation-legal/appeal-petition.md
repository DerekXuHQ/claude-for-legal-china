当事人不服原审裁判时，把笼统的"不服"转化为精准的法律异议，写成规范的民事上诉状或再审申请书。思路是：先从原审判决中结构化地挑出可攻击的错误，再判断走上诉还是再审，最后把错误组织成请求与理由，套用模板成文。

成稿为文书初稿和思路梳理，不构成正式法律意见；所引法律条文、期限和程序要求均以现行有效法律及司法解释为准，提交前须独立核实。

## 适用情形

- 不服一审判决、裁定，提起二审上诉。
- 不服已生效的判决、裁定、调解书，申请再审。
- 不适用于起诉状、答辩状。刑事上诉的上诉主体、期限、审理范围和法律依据与民事程序差异较大，应按刑事程序另行处理。

## 需要准备的材料

- 原审判决书、裁定书或调解书（含案号、送达日期）。
- 一审（及二审）诉辩材料、证据目录、质证意见、庭审笔录。
- 调查取证、鉴定、保全申请及法院的处理情况。
- 原审后新发现或新形成的证据（如有）。

## 办理步骤

流程：读原审判决并挑错 → 判定上诉/再审路径 → 组织请求与理由 → 套用模板成文 → 自查与定稿。

### 1. 读原审判决，系统挑错

带着"找突破点"的目标通读判决，不被卷宗信息淹没。按四个维度排查，每个疑点记录为"页码/段落＋原文表述＋问题类型＋反驳依据"，便于直接转写进文书。

**维度一：事实认定**
- 影响定性的核心事实是否明确认定，时间、地点、主体、行为、因果等要素是否完整。
- 认定的事实是否有证据支撑，有无以推测、习惯或常理替代证据。
- 是否遗漏对裁判有决定意义的事实，或对已查明事实片面取舍。
- 因果关系、责任比例的认定是否有据。

**维度二：证据采信**
- 己方关键证据未被采纳的，判决是否说明理由，理由是否站得住。
- 对方有瑕疵的证据被采纳的，判决是否给出合理说明。
- 申请调查取证、鉴定、保全被驳回的，是否有书面或可查的理由。
- 逐项审查证据的真实性、合法性、关联性与证明力，核对质证是否完整，评估是否有尚未提交、足以影响结果的材料。

**维度三：审判程序**
- 审判组织是否合法（应回避未回避、参与审理与署名是否一致等）。
- 是否遗漏必须参加诉讼的当事人或第三人。
- 是否剥夺当事人辩论权、质证权等程序权利。
- 送达、公告、开庭等程序是否合规。
- 法院依职权收集的证据是否经过质证。

**维度四：法律适用**
- 所引法律规范、司法解释是否准确、现行有效（逐条核实，不凭印象引用）。
- 构成要件与本案事实的归入是否准确完整。
- "本院认为"部分的推理链是否环环相扣，前提、过渡结论与最终结论之间有无断裂。
- 判项与诉讼请求是否对应，有无漏判、超判、计算错误或自相矛盾。

**挑错产出**：从全部疑点中筛出一到三个最有突破力的"硬伤"作为主攻方向，其余作辅助理由。硬伤的标准：错误明确、有据可证、足以影响裁判结果。

### 2. 判定救济路径

| | 上诉 | 再审 |
|---|---|---|
| 适用对象 | 尚未生效的一审判决、裁定 | 已经发生法律效力的判决、裁定、调解书 |
| 适用情形 | 认定事实错误、适用法律错误、程序违法、判项不当等 | 有足以推翻原裁判的新证据、原判决基本事实缺乏证据证明、适用法律确有错误、严重违反法定程序等法定事由 |
| 文书 | 民事上诉状 | 再审申请书 |
| 审理/受理法院 | 原审法院的上一级法院 | 原审法院的上一级法院或依法有管辖权的法院 |
| 期限 | 判决与裁定的上诉期不同，自送达次日起算；具体天数和起算方式以现行《中华人民共和国民事诉讼法》为准核实，不凭记忆填写 | 申请再审期限及其特殊起算情形以现行法为准核实 |

- 再审事由须逐项对照现行《中华人民共和国民事诉讼法》关于申请再审情形的规定核实，严禁捏造法条或条文序号。
- 裁判是否已生效、错误是否构成法定再审事由不清楚的，先向当事人说明两条路径的差异和各自门槛，确认后再成文，避免选错文书贻误期限。

### 3. 组织请求与理由

**请求的写法**
- 具体、可执行，与原判项一一对应（如请求撤销原判第几项、改判为何，或发回重审）。
- 一并主张诉讼费用承担。
- 不写"请求公正裁判"之类笼统表述，落到明确的处理结果。

**理由的组织**
- 攻原审之错，而不是复述一审主张：每条理由指向第 1 步挑出的具体错误，引用原判页码或原文，再给出反驳。
- 按"事实—证据—程序—法律"分块，或按错误严重程度排序，先打硬伤。
- 每条理由形成闭环："原判如何认定 → 错在何处 → 正确结论应为何 → 依据是什么"。
- 只引现行有效条文，核对条号与内容一致。

### 4. 套用模板成文

按第 2 步选定的路径使用对应模板。【】为待填项，斜杠表示择一。

### 5. 自查与定稿

见下方检查清单。定稿前再次提示：上诉期限、再审期限及具体程序要求以现行有效法律为准，须独立核实后再提交。

## 模板

### 模板 A：民事上诉状

```
民事上诉状

上诉人（原审【原告/被告/第三人】）：【姓名/名称】，【自然人填性别、出生日期、民族、住所；法人或组织填统一社会信用代码、住所、法定代表人姓名及职务】。
【如有委托诉讼代理人，列代理人姓名、单位及联系方式】

被上诉人（原审【原告/被告/第三人】）：【姓名/名称及基本信息，格式同上】

上诉人因【案由】一案，不服【原审法院名称】【案号】民事判决，现提起上诉。

上诉请求：
1. 撤销【原审法院名称】【案号】民事判决第【 】项，依法改判【具体请求】；（或：撤销原判，发回重审）
2. 本案一、二审诉讼费用由被上诉人承担。

上诉理由：
一、【第一项错误，如认定事实错误】
【引用原判表述及页码，说明错在何处，给出反驳与正确结论及依据】

二、【第二项错误，如适用法律错误/程序违法】
【同上结构】

【按需续列】

综上，原审判决【认定事实/适用法律/审判程序】存在错误，请求二审法院依法支持上诉人的上诉请求。

此致
【二审法院名称】

上诉人：【签名/盖章】
【年 月 日】

附：本上诉状副本【 】份；证据材料【 】份。
```

### 模板 B：再审申请书

```
再审申请书

再审申请人（原审【 】、【原】审【 】）：【姓名/名称及基本信息】
【如有委托诉讼代理人，一并列明】

被申请人（原审【 】、【原】审【 】）：【姓名/名称及基本信息】

再审申请人因【案由】一案，不服【作出生效裁判的法院名称】【案号】已发生法律效力的民事【判决/裁定/调解书】，现申请再审。

再审请求：
1. 撤销【法院名称】【案号】民事【判决/裁定】；
2. 依法【改判【具体内容】/发回重审/再审】；
3. 本案诉讼费用由被申请人承担。

事实与理由：
本案符合现行《中华人民共和国民事诉讼法》规定的申请再审情形，具体为：

一、【对照现行法核实后填写的具体再审事由，如：有新的证据足以推翻原裁判】
【展开论证：该事由对应的事实、证据及其对裁判结果的颠覆性影响】

二、【第二项再审事由，如：原判决认定基本事实缺乏证据证明 / 适用法律确有错误 / 严重违反法定程序】
【展开论证】

【按需续列】

综上，原【判决/裁定】确有错误，符合法定再审条件，特申请再审，请依法支持申请人的再审请求。

此致
【受理再审申请的法院名称】

再审申请人：【签名/盖章】
【年 月 日】

附：原审法律文书复印件；新证据及相关材料【 】份；本申请书副本【 】份。
```

模板中涉及再审事由的表述，须与现行法逐项比对后再定稿，不得直接照搬模板文字作为法定事由。

## 检查清单

- [ ] 上诉请求/再审请求具体、可执行，与原判项对应。
- [ ] 每条理由都指向具体错误并附依据，没有泛泛重复一审主张。
- [ ] 所引法条、案号、当事人信息、金额准确一致。
- [ ] 再审事由已对照现行法核实，没有臆造条文。
- [ ] 文书类型与救济路径匹配，期限已提示核实。
