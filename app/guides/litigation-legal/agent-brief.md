为开庭审理准备代理词（也称代理意见、辩论意见、法庭辩论提纲），以民商事案件为主，也适用于一般诉讼。核心是站在己方当事人立场，围绕争议焦点把事实、证据、法律编成一条自洽的论证链，逐点回应并反驳对方观点，最后落到明确的代理意见结论。

## 适用情形

- 庭审中宣读或庭后提交的代理词、辩论意见、法庭辩论提纲。
- 不适用于起诉状、答辩状、上诉状等启动或推进程序的诉状类文书，也不适用于合同起草和审查。只写文书中某一节的，见「诉讼文书章节起草」。

## 需要准备的材料

- 当事人及诉讼地位（原告/被告/第三人，己方代理谁）、案由。
- 诉讼请求与答辩主张。
- 已固定的证据和待证事实。
- 案件所处审级、开庭安排；法庭已归纳的争议焦点（如有）。

## 办理步骤

四个阶段依次推进，前一阶段的产出是后一阶段的输入。

### 1. 梳理并锁定争议焦点

代理词的全部论证围绕争议焦点展开，焦点不清，论证必散。

- 收集案件底数（见上文材料）。
- 区分两类焦点：法庭已在庭审中归纳的，原样采用；法庭尚未归纳的，依诉辩主张的对立点自行提炼。
- 把焦点拆成可逐一攻防的小问题，例如"合同是否成立并生效""违约责任如何分担""损失数额如何认定""诉讼时效是否经过"，每个小问题单独成段论证。
- 每个焦点先写一句话的立场预判：己方主张什么结论，靠哪一两个支点站住。

### 2. 组织论证：事实＋证据＋法律

针对每个焦点，按"事实—证据—法律"的顺序拼齐论证，使每个法律结论都有事实支撑，每个事实主张都有证据落地。

- **理清事实**：按时间或逻辑顺序讲清与该焦点相关的关键事实，剔除枝节。陈述中性、克制，不夹带未经证明的结论。
- **绑定证据**：每项关键事实后点明由哪份证据支撑、证明了什么。己方证据简述证明力和指向；争议较大的事实，从真实性、合法性、关联性说明为何足以采信。证据以卷内已有或当事人确实持有的为准，不得虚构证据名称、内容或出处。
- **嵌入法律**：把事实涵摄到具体的请求权基础或抗辩规范之下，说明构成要件如何满足或欠缺，推出有利结论。引用法律、司法解释须核对现行有效版本和准确条号；不确定的，先写"相关规定"并标注待核实，不得臆造条文或编号。
- 三者要咬合：事实回答"发生了什么"，证据回答"凭什么相信"，法律回答"因此该如何评价"，连起来是一个完整推理。

### 3. 预判并反驳对方主张

代理词是攻防文书，须主动把对方可能的论点摆上台面再逐一击破。

- 站在对方立场，列出其最可能提出的核心主张、所依赖的事实版本和证据、援引的法律依据。
- 对每个对方论点选择反驳路径：
  - 事实主张缺乏证据支撑，或与在卷证据矛盾；
  - 证据的真实性、合法性、关联性存疑，或证明力不足；
  - 法律适用错误、援引条文不当、要件不成立；
  - 退一步，即便其主张部分成立，也不影响己方结论。
- 反驳穿插在相应焦点的论证中，"立中有破"，不另起炉灶单列；最关键的对立点可单独成段集中回应。
- 语气克制，针对主张和证据本身，不作人身攻击。

### 4. 套用模板成稿

把前三步成果填入下方模板。每个分点对应一个争议焦点，按"己方观点—事实与证据—法律依据—回应对方"展开，分点数量随焦点增减。

## 模板

```
代理词

审判长、审判员（人民陪审员）：

【律师姓名】律师接受本案【原告/被告/第三人】的委托，担任其诉讼代理人参加本案诉讼。庭审前，代理人查阅了案卷材料，参加了庭审调查，现根据本案查明的事实与相关法律规定，发表如下代理意见，供合议庭参考。

一、关于【争议焦点一，如：合同是否成立并生效】

代理人认为，【己方就本焦点的明确结论】。

1. 事实方面：【按时间或逻辑梳理与本焦点相关的关键事实】。

2. 证据方面：上述事实有【证据名称/编号】予以证明，该证据【说明证明事项与证明力；必要时从真实性、合法性、关联性角度说明可采性】。

3. 法律方面：依据【核实后的法律/司法解释条文，未核实处标注待核实】，【说明构成要件如何满足或欠缺，推出有利结论】。

4. 对方主张【对方主张】，不能成立，理由是：【针对性反驳：事实无据/证据存疑/法律适用错误/退一步亦不影响结论】。

二、关于【争议焦点二】

（依上述结构展开：己方观点—事实—证据—法律—回应对方。）

三、关于【争议焦点三，按需增减】

……

综上，代理人认为，【综合各焦点，归纳总体代理意见】。据此，恳请合议庭【如：依法支持/驳回相应诉讼请求，并对责任承担、费用负担等作出有利于己方当事人的认定】。

以上代理意见，请合议庭予以采纳。

代理人：【姓名】
【年】年【月】月【日】日
```

## 检查清单

- [ ] **紧扣焦点**：每一段都服务于某个争议焦点，无关内容删去。
- [ ] **三性意识**：评价每份证据都从真实性、合法性、关联性着眼，再落到证明力。
- [ ] **法条必核**：所有法律条文、司法解释及条号已核对现行有效版本；存疑处标"待核实"；没有编造法条、案例或证据。
- [ ] **事实有据**：没有把推测当作已证事实写入。
- [ ] **立场与分寸**：站在己方立场，语气就事论事，反驳针对主张而非人身。
- [ ] **与当事人确认**：涉及诉讼策略和关键事实陈述的重要表述，已与当事人沟通确认。
- [ ] 代理词为供律师审阅修改的草稿，不构成法律意见或对裁判结果的承诺，定稿须经承办律师审核并对内容负责。
