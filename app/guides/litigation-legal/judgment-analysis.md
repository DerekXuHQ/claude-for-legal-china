把一份已下达的判决书，从「说不清哪里不对、只觉得不服」，转化为「逐条指出错在哪、能不能救、怎么救」。围绕事实认定、法律适用、诉讼程序三类核心瑕疵逐层排查，再据此判断走上诉、再审还是检察监督，并给出可落地的下一步。

> 本分析为辅助意见，不构成正式法律意见，不替代承办律师的独立判断。任何救济决定均应由具备执业资格的人员结合案卷全貌与现行有效法律核实后作出。

## 适用情形

- 已生效或尚可上诉的裁判文书需要审查、寻找上诉或再审理由。
- 不适用于合同起草、非诉文书撰写、单纯法律咨询。

## 需要准备的材料

缺少某项不影响开始，但越齐全分析越准：

- 判决书原文（一审或二审）
- 当事人原诉讼请求或答辩意见
- 庭审笔录、举证质证记录（如有）
- 全案证据清单及关键证据
- 当事人对结果的初步异议点（哪怕只是模糊的「觉得不公平」）

## 办理步骤

### 第〇步：定位与读题

先确认三件事，划定分析边界：

1. **审级与效力**：一审可上诉判决，还是已生效判决？直接决定走上诉还是再审。
2. **案件类型与争点**：民事、行政还是刑事？核心争议是事实之争还是法律之争？
3. **委托人诉求落点**：最想推翻哪一项判项？带着这个目标读，避免陷入细节。

登记案件基本信息：案号、审理法院、审判组织、判决日期、生效情况、各方当事人及诉讼地位。

### 第一步：审查事实认定

逐项比对判决「经审理查明」部分与卷宗：

- 关键事实的时间、地点、主体、行为、因果等要素是否清晰、有无遗漏
- 每项认定背后是否有对应证据，还是以推测、常理代替证据
- 影响定性的争议事实是否被回避、含糊带过或与证据矛盾
- 因果关系、责任比例的认定逻辑是否成立

做法：建一份「事实异议对照表」，每行记录【判决原文表述 + 所在页 / 段 + 异议理由 + 支撑材料】，按是否影响判项排序，先抓对改判分量最重的。

### 第二步：审查证据采信

对每组关键证据问三个问题：

- 我方核心证据未被采纳的，判决是否给了理由，理由是否站得住？
- 对方有瑕疵的证据被采纳的，判决是否作了合理说明？
- 我方调查取证、鉴定、评估等申请被驳回的，是否有书面裁定或庭审释明？

审查维度：

- 逐证审查真实性、合法性、关联性「三性」及证明力强弱
- 质证环节是否完整，有无未经质证即作为定案依据的证据
- 是否还有尚未提交、足以动摇原认定的新证据

### 第三步：审查诉讼程序

程序瑕疵往往是最硬的突破口，重点核查：

- 审判组织是否合法（应回避未回避、署名法官未实际参与审理、合议庭组成不当）
- 是否遗漏必须参加诉讼的当事人或第三人
- 是否剥夺当事人的辩论、质证、举证等基本诉讼权利
- 送达、公告、期间等程序是否合规
- 法院依职权调取的证据是否经过质证
- 是否存在应当回避、管辖错误等情形

### 第四步：审查法律适用

- 所引法律、司法解释是否准确、现行有效，有无溯及力问题
- 法律要件与案件事实的归入是否完整对应，有无漏用、错用、张冠李戴
- 拆解「本院认为」的推理链：前提是否真实、中间结论是否由前提必然得出、判项是否随之成立
- 类案比对：同类争点下本判决的裁判尺度是否明显偏离

## 错误类型清单

**事实类**
- [ ] 关键事实认定缺乏证据，以臆断代替证明
- [ ] 主要事实与在案证据相互矛盾
- [ ] 影响定性的争议事实被遗漏或回避
- [ ] 因果关系 / 责任比例认定明显不当

**证据类**
- [ ] 选择性采信：采信一方有利证据，刻意回避另一方关键证据
- [ ] 采纳了未经质证或违法取得的证据
- [ ] 排除我方关键证据未说明理由或理由不成立
- [ ] 证明力判断显失公允
- [ ] 存在足以推翻原认定的新证据

**程序类**
- [ ] 审判组织不合法
- [ ] 遗漏必须参加诉讼的当事人
- [ ] 剥夺当事人辩论、质证等诉讼权利
- [ ] 送达或其他法定程序违法
- [ ] 管辖错误、应回避未回避

**法律适用类**
- [ ] 引用法条错误、失效或不适用本案
- [ ] 法律要件归入不完整或错误
- [ ] 裁判说理逻辑断裂、自相矛盾

**结构类**
- [ ] 超出诉讼请求判决（超判）
- [ ] 遗漏诉讼请求未作处理（漏判）
- [ ] 判项计算错误，或主文与说理不一致
- [ ] 说理部分未回应核心请求

## 找出致命伤

不平均罗列所有错误，而是找出**最能撬动改判的一两个点**：

- **可验证性**：程序违法、超判漏判、法条失效这类硬伤，无需重新评价证据即可成立，优先级最高。
- **因果性**：该错误是否直接导致判项不同？只影响说理、不改变结果的瑕疵，攻击价值有限。
- **逻辑断点**：把「本院认为」拆成若干推理步骤，定位哪一步出现跳跃或偷换。
- **回应缺口**：逐项核对诉讼请求是否都得到正面回应，未回应之处往往是结构性突破口。

## 上诉 / 再审 / 检察监督决策表

| 维度 | 上诉 | 再审 | 检察监督（抗诉 / 检察建议） |
|---|---|---|---|
| 适用前提 | 一审判决尚未生效 | 判决已生效 | 判决已生效且认为确有错误 |
| 典型事由 | 事实认定错误、法律适用错误、程序违法 | 有新证据足以推翻原判、原判基本事实缺乏证据、适用法律确有错误、严重违反法定程序等法定再审情形 | 符合法定监督情形、申请再审被驳回或逾期 |
| 时限 | 以判决书送达之日起的法定上诉期为准（逐案核对现行规定及个案送达日） | 法律规定的申请再审期间内（以现行规定为准） | 一般在再审途径受阻后提出 |
| 受理主体 | 上一级人民法院 | 原审或上级人民法院 | 人民检察院 |
| 策略要点 | 围绕致命伤精准攻击，不复述一审主张 | 紧扣某一项法定再审事由，论证其「足以推翻」原判 | 提供检察机关介入所需的事实与证据线索 |

再审事由必须逐条对照现行有效的《中华人民共和国民事诉讼法》及相关司法解释规定的法定情形核实，以个案适用的程序法为准。不凭印象引用条文序号、期间天数和法定情形；无法确认的，标注「待核实」，不给具体条号。刑事、行政案件适用相应程序法，须单独核对。

## 报告结构

各部分据实填写，证据与页码须可回溯：

1. **案件概览**：案号、审级、法院、判决日期、生效状态、当事人与诉讼地位、核心争点。
2. **事实认定分析**：逐项列出存疑认定、所在位置、异议理由及支撑材料。
3. **证据采信分析**：三性与证明力审查、异常采信 / 排除情形、新证据可能性。
4. **程序合规分析**：程序瑕疵点、对应法律依据（标注待核实项）、严重程度。
5. **法律适用分析**：法条准确性、要件归入、类案比对结论。
6. **致命伤定位**：最具改判价值的一至两个突破点及其对判项的影响。
7. **救济路径建议**：结合决策表，写明选择上诉 / 再审 / 检察监督的理由、拟主张的事由、需补强的证据，以及各项法定期限的「待核实」提示。
8. **风险与不确定性**：所依据材料的局限，以及尚需承办人核实的事项。

## 贯穿始终的原则

1. 上诉的本质是反驳原判之错，不是重复原审之诉。
2. 带着明确目标阅卷，把模糊的「不服」翻译成精确的法律异议点。
3. 优先攻击无需重新评价证据即可成立的硬伤。
4. 凡涉及法条序号、法定期限、法定事由，一律以现行有效文本为准，不确定即标注核实。
5. 所有结论以证据和卷宗为支撑，避免情绪化表达。

## 法律依据

- 《中华人民共和国民事诉讼法》及相关司法解释（上诉、再审、检察监督的法定情形和期间，以现行文本为准〔待核〕）
