案件台账只有保持更新才有用。本指引让每次更新成为两分钟的结构化记录：追加一条带日期的事件，同步刷新台账字段。

## 适用情形

- 案件有新进展：提交或收到文书、裁判下达、开庭、证据往来、和解要约、风险变化、人员变化等。
- 需要调整风险评级、阶段、下一期限、重要性等台账字段。

## 需要准备的材料

- 案件台账中该案的记录。
- 案件历史记录（追加对象）和登记表（只作参考，不改写）。
- 单位风险校准标准、重要性门槛、和解授权层级。

## 办理步骤

1. **确认案件已登记。** 台账中没有该案件的，不追加记录，先完成案件登记（含利益冲突检索）。
2. 确认案件代号；未提供的，从最近更新的案件中选定。
3. 选择事件类型（见下表），确定日期（默认当天，可补记以前的事件），写一段摘要：发生了什么、意味着什么、有何即时影响。
4. 按事件类型检查可能受影响的台账字段。
5. 属于接受和解的，先过「和解接受门槛」。
6. 属于下表所列类型的，必须进行重要性检查。
7. 有相关文件的，记下存放位置（非必填）。
8. 写入前把历史条目和台账变更交承办人确认，再写入；台账「最后更新」改为当天（补记的写事件日期）。

## 事件类型

| 类型 | 举例 | 通常影响的字段 |
|---|---|---|
| 程序性 | 起诉 / 答辩 / 申请已提交或收到，裁定 / 判决下达，开庭或庭前会议已进行，期限已确定 | 阶段、下一期限 |
| 证据 | 证据提交或收到，证人出庭或询问，调查令已送达 | 阶段、下一期限 |
| 实质性 | 新事实、关键文件出现、实体裁定 | 风险、重要性、敞口 |
| 策略 | 姿态转变、和解要约发出或收到、授权更新 | 重要性、敞口、状态 |
| 风险重评估 | 严重性或可能性变化 | 风险、重要性 |
| 相关方 | 新人员纳入、外部律师变更 | 外部律师、内部负责人 |
| 行政性 | 委托合同签署、预算调整、证据保全更新 | 证据保全、预算 |

都不匹配的，自由描述。可能受影响的字段包括：状态、阶段、风险、重要性、敞口范围、下一期限、外部律师、内部负责人、证据保全（已更新、扩大或解除）。

## 和解接受门槛

只适用于**接受**和解（接受要约、签署和解协议或原则同意接受），单纯记录要约或还价不适用。

接受和解会解决争议，通常要签署免责条款，还可能影响保险、税务和关联事项。由非律师人员处理的，须先经律师审查。可为律师准备一页摘要：案件、拟议和解条款（金额、结构、免责范围、保密、不得贬损条款）、涉及的敞口、和解授权层级的满足情况、可能出错的地方、接受前要问律师的问题。需要找律师的，可联系当地律师协会或拨打 12348 法律援助热线。

未经明确确认，不记录接受，也不调整重要性。

## 重要性检查

下列事件必须明确回答重要性是否变化，「不变」也要明说，不能默认跳过：

| 事件类型 | 检查要点 |
|---|---|
| 实质性 | 是否改变重要性？选项：需计提 / 已披露 / 监控中 / 不适用 |
| 策略 | 和解活动通常引起重要性重新分类；要约、还价或接受改变了敞口，或使争议从「有争议」变为「很可能且可估计」的，应重新分类 |
| 风险重评估 | 风险变了，重要性应跟进 |
| 行政监管 / 执法进展 | 协查通知、执法通知等通常需要做披露分析 |

在历史记录中写明：

```markdown
**重要性检查：**【未变更 / 由X变更为Y】
**理由：**【一句话】
```

重要性变为「需计提」或「已披露」、而该案此前未记录计提或披露的，按单位重要性门槛通知财务或审计委员会。

## 记录格式

历史记录中最新的在前，放在标题下方分隔线之后：

```markdown
## 【日期】——【事件类型】：【简短标题】

【一段摘要】

**字段变更：**
- 【字段】：【旧 → 新】
- 【字段】：【旧 → 新】

**关联文件：**【位置（如有）】
```

没有字段变更的，省略「字段变更」。

## 注意事项

- **不改写以前的记录。** 需要更正的，另加一条新记录，引用并更正原条目。
- **不悄悄修改台账。** 每处字段变更写入前都要给承办人看。
- **是否计提或披露由承办人决定。** 记录时只提出问题。
