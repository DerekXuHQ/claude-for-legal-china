在律师函委托登记完成后，据此起草可发送的律师函草案。这一步最重要的不是写，而是在动笔前把保密、权利放弃、自认和和解沟通姿态逐项想清楚。最常见的失误，是一封因为没人停下来检查而泄露内部分析或构成自认的函件。

## 适用情形

- 已完成律师函委托登记（见「律师函委托登记」），准备形成可发送的草案。
- 付款催告、违约 / 催告整改、停止侵权等类型的函件。

## 需要准备的材料

- 律师函委托登记表。
- 所内律师函惯例和内部文风要求。
- 所内模板（如有）；没有的按下文骨架起草。
- 基础合同、往来通信等事实材料。

## 律师函在中国法下的意义

- **意思表示**：律师函是委托人的意思表示，可能产生实体法上的效果（如催告、解除通知）。
- **诉讼时效中断**：发送律师函可以构成《民法典》第195条规定的诉讼时效中断事由。
- **证据价值**：律师函可作为后续诉讼的证据。
- **不当然受保护**：发给对方当事人的律师函不享有和解谈判方面的证据豁免，内容可能被对方作为证据使用。

## 办理步骤

1. 调出委托登记表和所内律师函惯例。
2. **运行起草前门禁**（见下方检查清单），逐项处理完再动笔。
3. 选模板：有所内模板用模板，没有的按函件类型用下文骨架。
4. 起草初稿，交承办律师审阅，反复修改至批准。
5. 定稿，同时形成发送前后检查清单。
6. 是否需要据此立案登记，由承办律师决定。

如因特殊原因跳过门禁，须在草案文件中注明跳过了门禁及原因。

## 起草前门禁

```
起草前检查清单 ——【函件代号】

1. 保密过滤
   委托登记中的保密过滤项：【列表】
   确认：以上内容都不会出现在草案中？【是 / 否】

2. 自认风险
   委托登记中的自认风险：【列表】
   每一项的措辞是否已受控或删除？【逐项 是 / 否】

3. 权利保留
   是否明确声明保留所有权利，且不构成对任何权利的放弃？

4. 和解谈判姿态
   委托登记的说明：【受保护 / 不受保护 / 个案判断】
   草案将【包含 / 不包含】和解谈判标记。

5. 保密弃权扫描
   草案中是否有句子会透露我方内部法律分析的实质内容？【是 / 否】
   如有，先改写再起草。

6. 语气姿态
   委托登记的说明：【维护关系 / 克制 / 进取】
   确认。

7. 事实准确性
   草案中每个事实都必须经过核实，不是「可能属实」，而是已核实。
```

## 模板

### 付款催告函
1. 当事人及关系背景（1段）
2. 事实：义务及其来源（合同条款 / 发票 / 订单）、日期
3. 违约：欠付什么、何时到期、发生了什么（或没发生什么）
4. 催告：具体金额、截止日、付款方式
5. 后果：移交律师、利息、费用、诉讼
6. 签名栏

### 违约 / 催告整改函
1. 当事人及协议（指明合同的生效日期、当事人）
2. 被违反的义务：合同条款，用通俗语言说明
3. 违约行为：具体事实、日期、现有证据
4. 整改：哪些具体措施可以整改；整改期限
5. 不整改的后果：解除、损害赔偿、合同约定的其他救济
6. 权利保留
7. 签名栏

### 停止侵权函
1. 当事人及己方权利（商标 / 著作权 / 合同等，指明权利）
2. 侵权 / 违规：具体行为、日期、证据
3. 要求：立即停止、删除、报告过往使用情况、书面确认合规
4. 合规期限
5. 不合规的后果：诉讼、禁令救济
6. 证据保全要求
7. 签名栏

## 起草规则

1. **具体胜过形容词。**「2026年3月14日，贵方发送了X」胜过「贵方反复且不当地发送了X」。
2. **每个事实都能追到来源**：对应一份文件、一个日期或一名证人。暂时无法核实的，标【需核实：具体主张】。
3. **引用先留占位符。** 需要法律依据的地方写【引用：法条 / 条款 / 案例】，不编造。
4. **后果措辞与语气一致。**
   - 维护关系：「我方希望在不采取进一步行动的情况下解决此事。」
   - 克制：「如贵方未在【N】日内整改，我方将考虑包括诉讼在内的各项措施。」
   - 进取：「如贵方未在【N】日内整改，我方将立即采取法律行动。」
5. **除非有意为之，不在函中讨论和解。**
6. **逐字引用必须逐字。** 没有确切原文的，不给对方、对方律师、证人或任何文件的话加引号。律师函里引错合同条款，是第一轮就失去对方律师信任的最快方式。

## 发送前后检查清单

外发的律师函本身**不加**「保密 · 律师工作成果」标头；下面这份清单和委托登记表属于内部工作成果，应加标头。

```markdown
【内部工作成果标头】

# 发送检查清单 ——【函件代号】

**发送版本：**【v1 / v2 …】
**发送日期：**【日期】
**签署人：**【姓名】

## 发送前
- [ ] 签署人最终通读
- [ ] 事实准确性：所有【需核实】标记已解决
- [ ] 引用：所有【引用】占位符已填写
- [ ] 保密标记已按内部规范处理（外发版本不含「律师工作成果」标头）
- [ ] 内部副本已清理
- [ ] 利益冲突已确认（如尚未完成）

## 发送后
- [ ] 合规截止日已排期：【日期】
- [ ] 对方无回应时的升级方案：【下一步 + 日期】
- [ ] 跟进检查已排期：【日期】
```

## 边界

- 只起草，不代为发送，发送由签署人负责。
- 不在起草环节检索引用，【引用】占位符留待律师填写核实。
- 不绕过起草前门禁。

## 法律依据

- 《民法典》第195条（诉讼时效中断）
