把零散的案件信息整理成一份结构规范、要素齐全、逻辑自洽的民事起诉状，符合《民事诉讼法》及相关规定对起诉状的要求。成稿为草稿，不构成法律意见，须由执业人员核校后使用；当事人主体信息、金额、管辖及法律条文均须独立核实后方可定稿。

## 适用情形

- 根据案件事实起草民事起诉状。
- 不适用于刑事自诉状、行政起诉状、答辩状或合同起草。

## 办理步骤

流程：要素采集 → 法律梳理 → 分段撰写 → 一致性自检 → 定稿输出。

### 1. 要素采集

当事人提供的材料可能是口头叙述、聊天记录、合同或票据。先提取结构化要素，再逐项核对是否齐全。

| 类别 | 需采集内容 | 是否必备 |
|------|------------|----------|
| 原告 | 自然人：姓名、性别、出生日期、民族、住所、身份证号；法人/组织：全称、住所、统一社会信用代码、法定代表人 | 必备 |
| 被告 | 同原告项；自然人另记联系方式与可送达地址 | 必备 |
| 第三人 | 同被告格式（若涉及） | 视情形 |
| 案件经过 | 事件起因、关键时间节点、双方行为 | 必备 |
| 争议行为 | 被告违反何种约定义务或实施何种侵权行为 | 必备 |
| 损害结果 | 原告由此产生的具体损失及计算方式 | 必备 |
| 证据线索 | 已掌握证据的名称与形式 | 尽量提供 |
| 拟诉法院 | 有管辖权的法院（如已知） | 尽量提供 |

**信息缺口的处理**
- 硬信息一律不臆造：当事人全称、统一社会信用代码、身份证号、争议金额、管辖法院等必须来自当事人提供或可核实的来源。缺失的用占位符标注，如【原告统一社会信用代码：待核实】，并请当事人补充。
- 事实表述含糊的，先就关键细节向当事人确认再落笔。
- 当事人未提及的要素逐项询问，不默认、不省略。

### 2. 法律梳理

事实基本清晰后做初步法律定位：

1. **确定案由**：依现行案由规定选取与事实最贴合的案由。案由牵动法律适用和请求方向，先定准。
2. **拟定诉讼请求**：逐项拆分，每项具体、可执行，避免"赔偿损失若干"之类模糊表述。
3. **匹配法律依据**：为每项请求找到支撑法条。法条不得凭记忆引用，引用前核实其存在且现行有效；无法确认的标注"法条待核实"。
4. **判断管辖**：依案件性质和当事人情况确定有管辖权的法院，并核对级别管辖与地域管辖（含约定管辖、专属管辖等特别规则）。

### 3. 分段撰写

按文末模板顺序逐部分生成。

**3.1 当事人信息**
- 自然人与法人/其他组织分别采用对应写法。
- 多名被告以"被告一、被告二……"编号，全文称谓统一。
- 主体硬信息缺失处保留占位符。

**3.2 诉讼请求**
- 排列顺序：确认之诉 → 给付之诉 → 程序性请求（如诉讼费负担）。
- 每项独立编号，前各项以分号收尾，末项用句号。
- 涉款项写明币种和确切数额，与"事实与理由"中的金额一致。

**3.3 事实与理由**（起诉状核心，分层展开）
1. 法律关系铺垫：交代原被告之间的基础关系（合同、侵权或其他）。
2. 事实叙述：按时间顺序客观陈述经过，关键事实括注对应证据。
3. 责任分析：逐项指出被告的违约或侵权行为，每项对应具体条款或法定义务。
4. 损害说明：阐明损失及计算口径，与诉讼请求金额对应。
5. 法律论证：援引相关法条论证诉求成立（法条须经核实）。
6. 收束：以"综上所述"概括，请求法院依法支持诉请。

要诀：请求与事实一一对应，保持客观，引用准确。

**3.4 此致法院与落款**
- 法院名称用规范全称。
- 具状人署名，起诉日期一般填提交之日。

**3.5 证据目录**
- 按证明对象分组，逐条列明证据名称与证明目的。
- 证明目的与对应诉讼请求呼应。

### 4. 一致性自检

见下方检查清单。发现问题直接修正，并说明改动之处。

### 5. 定稿输出

交付完整起诉状，附"待核实清单"：
- 仍为占位符、需补充的主体硬信息；
- 建议进一步核实的事项（法条时效、管辖法院、金额计算等）；
- 起诉状含当事人隐私信息，须妥善保管。

## 检查清单

| 检查项 | 核对内容 |
|--------|----------|
| 称谓统一 | 各部分当事人称谓前后一致 |
| 请求—事实 | 每项请求均有对应事实段落支撑 |
| 请求—依据 | 每项请求均有法律依据 |
| 金额吻合 | 事实理由与诉讼请求中的金额一致 |
| 证据覆盖 | 关键事实均有证据指向 |
| 格式规范 | 各部分符合模板要求 |
| 法条有效 | 援引法条存在且现行有效 |

## 办理示例

- **信息较完整**：借贷双方身份、借款与逾期事实齐备。提取要素 → 定案由（民间借贷纠纷）→ 拟请求（返还本金、利息、诉讼费）→ 套模板成文 → 自检输出；身份证号等未核实项保留占位符。
- **信息含糊**：当事人称"被公司辞退，想告公司违法解除"。识别缺口（公司全称、工作年限、工资标准、解除时间、有无书面通知等）→ 逐项追问 → 信息齐备后定案由（劳动争议）→ 确认是否已经劳动争议仲裁（劳动争议须先申请仲裁，对仲裁裁决不服的才可向法院起诉，《劳动争议调解仲裁法》第5条；未经仲裁的，应先拟劳动仲裁申请书）→ 撰写 → 自检输出。

## 模板

占位符【……】处填入经核实的信息；无法核实的保留占位并在交付时列入待核实清单。

住【住所地】，
身份证号/统一社会信用代码：【……：待核实】，
联系电话：【……】。
（法人或其他组织另列：法定代表人/负责人【姓名】，职务【……】。）

被告：【姓名/名称】，【性别】，【出生日期】，【民族】，
住【住所地】，
身份证号/统一社会信用代码：【……：待核实】，
联系电话：【……】。
（多被告时依"被告一、被告二……"分列。）

第三人：【……】（如涉及，格式同被告；无则删除本行）

诉讼请求

一、判令被告【具体给付/确认事项，写明币种与数额：……】；
二、判令被告【第二项请求：……】；
……
【末项】、本案诉讼费用由被告承担。

事实与理由

（一）基础法律关系
【交代原被告之间的合同/侵权或其他法律关系的形成。】

（二）案件事实
【按时间顺序客观陈述经过，关键事实括注证据，如（见证据X）。】

（三）被告的违约/侵权
【逐项指出被告行为及其所违反的约定条款或法定义务。】

请求依法支持原告的全部诉讼请求。
