差距被发现后往往就被遗忘了。本指引说明如何把政策差异分析发现的差距和待定的征求意见决策登记入台账，一直跟踪到关闭，并通知负责关闭它们的人。

## 适用情形

- 政策差异分析发现了部分或完全差距，需要登记跟踪。
- 需要查看开放差距、即将到期和逾期的事项。
- 需要关闭差距，或记录不整改的风险接受决定。
- 征求意见稿的提交决策待定（与《征求意见稿跟踪与提交决策记录》共用本台账规则）。

## 台账字段

| 字段 | 内容 |
|---|---|
| 编号 | 如 GAP-001 |
| 要求 | 法规要求的内容 |
| 法规 | 名称及条款 |
| 受影响政策 | 政策名称，或「需要制定新政策」 |
| 差距类型 | 无 / 部分 / 完全 / 新政策 / 观察 / 征求意见决策（见下表） |
| 负责人 | 政策索引中的负责人 |
| 负责人联系方式 | 已知的填写；不希望该负责人接收通知的留空 |
| 开立日期 | 【日期】 |
| 截止日期 | 法规生效日期、内部截止日期或征求意见截止日期 |
| 法规状态已核实 | 是 / 否。上游政策差异分析无法确认法规有效的，填「否」 |
| 状态 | 开放 / 处理中 / 已关闭 / 已接受风险 |
| 已通知 | 是 / 否。分配通知发出后填「是」 |
| 解决方案 | 关闭时填写 |

### 差距类型

| 类型 | 含义 | 提醒频率 |
|---|---|---|
| 无 | 政策已涵盖此要求，仅作审计留痕 | 不提醒 |
| 部分 | 政策涵盖该主题但未完全覆盖新要求，需要修订 | 到期前30天 |
| 完全 | 政策与新要求矛盾或未提及，需要重写或新增章节 | 到期前30天 |
| 新政策 | 现有政策中没有此项内容，需要起草政策 | 到期前30天 |
| 观察 | 前瞻性事项——预征求意见、调研通知、尚未定稿的征求意见稿。当前没有合规义务，政策工作等正式法规出台。截止日期是复查日期，不是合规截止日期 | 不自动提醒；征求意见稿发布时或到复查日期重新评估 |
| 征求意见决策 | 正在决定是否提交意见。截止日期是征求意见截止日期 | 截止日期前21天（比合规差距更紧） |

## 办理步骤

### 1. 从政策差异分析登记差距

政策差异分析中每一项部分或完全差距，都登记为附负责人和截止日期的跟踪事项。去重：相同要求 + 相同政策 = 同一差距，不重复登记。

### 2. 通知负责人

登记后向差距负责人发出分配通知。**每次发送前都要确认，没有例外**：

1. 先列明发给谁、发什么内容；
2. 取得明确同意；
3. 不因是定时任务、批量发送或昨天发过而跳过确认。

未经确认就自动发送，是这项工作中最不可逆的操作——把可能有误的内容发给了无法核对的人。发出后在台账中标记「已通知」。

企业通讯工具未配置的，不发送通知，改为在状态报告中标出。同一差距 7 天内最多提醒一次，不反复催促。

### 3. 出具状态报告

按逾期、30 天内到期、开放、观察事项、处理中、最近关闭分组（见下文「模板」）。

**法规状态未核实的，不得列为「逾期」。** 🔴 逾期意味着错过了有约束力的截止日期。法规状态未核实的（上游分析标记为未核实，或法规发布超过12个月、已过适用日期而未确认时效），截止日期可能并无约束力，应列为 🟡「需要审查」并注明原因。

「观察」和「征求意见决策」类事项不是合规差距，单独列示。

开放差距超过约 10 项的，可另行整理为按严重程度计数、按截止日期排列的时间线，以及附负责人、状态和最后更新日期的可排序清单。

### 4. 关闭差距

状态改为「已关闭」，填写解决方案和关闭日期。关闭须有解决方案说明，且说明中描述的人工操作已经完成，不能自行关闭。

### 5. 记录风险接受

有时结论是「不打算整改」。这是正当的决定，但必须留档：状态改为「已接受风险」，记录理由和接受人。该事项保留在台账中（不删除），但不再出现在开放差距报告里。

## 常见风险

- 差距登记后没有负责人或截止日期。
- 未经确认就发出通知。
- 法规状态未核实却列为逾期。
- 把观察事项和征求意见决策混入合规差距。
- 风险接受没有理由和接受人，或直接删除记录。

```markdown
### 🔴 逾期

| 编号 | 要求 | 政策 | 负责人 | 截止日期 | 逾期天数 |
|----|------|------|--------|----------|---------|
| | | | | | |

### 🟠 30天内到期

【同上】

### 🟡 开放

【同上】

### 👀 观察事项（前瞻性，法规尚未出台）

【观察类和征求意见决策类条目，不是合规差距，单独列示】

### 处理中

【同上】

### 最近关闭

【最近5项，附解决方案】

---

**最早开放的差距：** 【编号】，【N】天
**按负责人分布：** 【分布】
**已发送负责人通知：** 【N】 / 【差距总数】

---

**依赖前核实引注。** 台账中的法规引注来自上游的法规动态监测和政策差异分析，未经对照原始来源核实。关闭差距、接受风险或引用到任何合规声明、董事会报告或监管回复之前，须通过法律数据库或发布机关官网确认。
```

工作成果标头：律师出具的写「保密——律师工作成果——按照律师指示准备」；非律师出具的写「研究笔记——非法律意见——在行动前应由执业律师审阅」。完成后给出下一步选项：起草政策修订；升级报批；补充事实；暂缓观察；其他。
