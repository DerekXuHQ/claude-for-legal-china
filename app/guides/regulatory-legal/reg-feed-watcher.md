定期查看监管动态，按重要度过滤，只把值得关注的内容报出来。过滤才是价值所在——不经过滤的动态只是噪音。

## 适用情形

- 按日或按周定期检查法规动态。
- 指定某个日期以来的动态回顾。
- 收到一条法规文本或摘要，需要分类并判断是否要做政策差异分析。

本指引不包括：逐项通读每一条（只分类和补充要点，深度阅读留给筛选出来的事项）；调整重要度标准（标准不合适的，修改团队的重要度阈值）。不要求付费数据库，免费官方来源是基线，付费来源增加深度。

## 需要准备的材料

- **监测清单**：关注的监管机构、所属管辖、关注原因、信息来源。
- **重要度阈值**，分三档：
  - 始终重要（立即行动），如「有期限的新义务」「本行业的执法行动」；
  - 值得审阅（评估后决定），如「征求意见稿」「指引文件」「针对竞争对手的执法行动」；
  - 仅供参考（记录，不行动），如「监管官员讲话」「学术评论」。
- 信息来源配置和检查频率；上次检查时间。
- 简报的发送对象（如有）。

## 办理步骤

### 0. 检查覆盖范围

拉取前，把监测清单与已配置的信息来源对照，看哪类监管机构没有或几乎没有来源。例如监测清单有「金融监管」，来源中却只有中国人民银行，缺国家金融监督管理总局、中国证监会。发现明显缺口的，在简报顶部提示一次，建议补充对应机构的来源。

业务方已明确「暂不关注某监管机构」的，尊重并记录该决定，不反复提示。

### 1. 拉取动态

**第一层：免费官方来源（始终使用）**

- **中国政府网**（http://www.gov.cn/）：国务院公报、行政法规、部门规章等公告。
- **各部委官网**：公告、规章征求意见稿、政策解读等。

| 监管机构 | 监测内容 | 来源 |
|----------|----------|------|
| 国家互联网信息办公室（网信办） | 个人信息保护、数据安全、算法治理、内容管理 | cac.gov.cn |
| 国家市场监督管理总局 | 反垄断、反不正当竞争、广告、消费者保护 | samr.gov.cn |
| 工业和信息化部 | 电信、互联网信息服务、数据安全 | miit.gov.cn |
| 科学技术部 | 科技伦理、人工智能 | most.gov.cn |
| 国家数据局 | 数据要素、数据流通、数据基础设施 | 政府网站 |
| 最高人民法院 | 司法解释、指导性案例 | court.gov.cn |

另有最高人民检察院（https://www.spp.gov.cn/）及其他行业监管机构。

**第二层：付费法律数据库（如有）**

查询上次检查以来的更新，按监测清单中的监管机构过滤。跨来源去重——同一文件可能出现在多处，取信息最完整的来源。

**第三层：手动录入**

业务方粘贴的法规文本或摘要，作为单一事项直接进入第 2 步分类，来源记为「手动录入」。

**覆盖不足时如实报告。** 某监管机构返回很少或没有结果的，如实报告已发现的内容，由律师决定是扩大日期范围、换来源、改用网络检索（结果须向发布机关核实后才能依赖），还是到此为止。不凭记忆补齐。

**标明每一条的来源**：中国政府网、某监管机构官网、某法律数据库、网络检索（须复核）、业务方提供等。

**次级来源**（法律科技媒体、律所评论、行业协会简报、学术机构报告等）报道了监管行动但本身不是原始来源的：标注为次级来源及其名称，并注明「→ 追溯至原始来源：【监管机构链接，或「在该监管机构官网查找后再依赖」】」。找到原始来源之前，不得仅凭次级来源把事项列为「始终重要」，应降一档。

拉取后记录检查时间，下次从此时间点开始。

### 2. 分类

按团队重要度阈值为每一项定档：

| 事项类型 | 通常定档 |
|----------|-----------|
| 正式发布的行政法规 / 部门规章 | 始终重要 |
| 征求意见稿 | 值得审阅，并始终记录征求意见截止日期 |
| 预征求意见 / 调研通知 | 值得审阅——用于**策略**而非合规：尚未施加具体要求，但显示方向，且有实际的反馈截止日期。记录截止日期。转入政策差异分析时只做预案分析，不做差距分析 |
| 监管执法行动 / 行政处罚 | 行业匹配→重要；相关业务做法匹配→值得审阅；都不匹配→仅供参考或跳过 |
| 监管指引 / 指导意见 | 值得审阅 |
| 领导讲话 / 政策吹风 | 仅供参考，或按阈值跳过 |
| 和解 / 整改 | 视情况——新颖理论或案件量大→值得审阅；常规→跳过 |

### 3. 补充要点

「仅供参考」以上的每一项，写明：

- 一句话摘要（什么变了）；
- 为什么可能与本公司相关（「涉及公司正在做的【业务】」）；
- 来源链接；
- 生效日期或征求意见截止日期（如适用）。

「仅供参考」的事项不逐项摘要，只计数。

### 4. 出具简报并衔接

- 有「仅供参考」以上事项的，除即时报告外，另存一份可分享的简报文件。没有的，简报写「一切平静，【N】项仅供参考，无需关注」。
- 「始终重要」且可能影响政策的事项 → 建议对可能受影响的政策做政策差异分析。
- 差异分析发现差距 → 登记差距跟踪台账。
- 「跳过」以上的征求意见稿 → 记入征求意见台账，记录截止日期。

### 配置不全时

- 监测清单为空：无法开展，先补充至少一个监管机构。
- 重要度阈值为空：按上表默认分档，并在简报中注明。
- 信息来源配置为空：只查中国政府网公告，并在简报中注明。

## 常见风险

- 监测清单有某类监管机构，但没有配置对应来源，形成盲区。
- 凭次级来源把事项列为「始终重要」。
- 征求意见稿没有记录截止日期。
- 把预征求意见当作合规差距处理。
- 覆盖不足时用记忆或未核实的内容补齐。

## 模板

```markdown
【工作成果标头】

## 法规动态检查 — 【日期】

**期间：** 【上次检查】至【本次】
**已检查来源：** 【如「中国政府网、网信办官网、某法律数据库」】
**发现事项：** 共【N】项

### 要点

【N】项需在【日期】前采取行动——前3项：【X】、【Y】、【Z】

### 🔴 始终重要

**【监管机构】——【标题】**
【一句话摘要】。【与本公司的关联】。【日期】生效。
【链接】
→ 建议：对【可能受影响的政策】做政策差异分析

【每项重复】

### 🟡 值得审阅

**【监管机构】——【标题】**
【一句话】。【关联】。【截止日期，如有】。
【链接】

【征求意见稿：「💬 征求意见截止日期：【日期】——决策待定」】

【重复】

### 📝 仅供参考

【N】项——【标题 + 链接列表，不作摘要】

---

**本次检查更新至：** 【时间】
**征求意见中：** 【N】个征求意见稿待决定

---

**依赖前核实引注。** 以上法规引注未经对照原始来源核实。对任何法规、规章、指导意见或执法行动采取行动之前，通过法律数据库或发布机关官网确认其准确性、生效日期和当前状态。每项所标来源表明出处；网络检索所得和需复核的事项出错风险更高，应首先核查。
```

工作成果标头：律师出具的写「保密——律师工作成果——按照律师指示准备」；非律师出具的写「研究笔记——非法律意见——在行动前应由执业律师审阅」。
