指导老师按实践领域（劳动争议、婚姻家庭、消费者权益、行政纠纷等）各写一份指南，让学生在接待、起草、写信时按统一要求做事：问哪些问题、警惕哪些信号、哪些工作必须先经指导老师审查。每个领域大约 5—10 分钟可以写完，之后随时修改。

本指引的读者是指导老师，不是学生。指南是诊所的配置文件，不是学生的工作成果。

## 适用情形

- 诊所开设新的实践领域，或学期开始前修订某领域的工作要求。
- 指导老师希望调整学生在某领域的工作方式和审查流程。

## 指南应回答的问题

开始前先把这份清单过一遍，标出哪些已有明确想法、哪些需要思考；可以跳过的，在指南中注明「未指定，按默认做法」。

- 学生接触案件前需要知道什么？（职业道德规则、保密、权限范围）
- 学生在该领域最常犯的 3—5 个错误是什么？怎样及时发现？
- 学生何时必须停下来取得指导老师签字？（提交文书、发给当事人、对外陈述、就策略提出建议）
- 给当事人的书面沟通要达到什么阅读难度？（法律援助通常以初中水平为目标）
- 每个学生都应知道的本地规则、表格或期限有哪些？
- 哪些工作要教学生自己做，哪些可以直接给出成品？（可按文书类型分别设定）

## 办理步骤

### 1. 确定实践领域

劳动争议 / 婚姻家庭 / 消费者权益 / 行政纠纷 / 刑事辩护 / 其他（其他的给一个简短名称）。该领域尚未列入诊所实践领域的，可以先写指南，但应同步把它列入诊所画像，否则接待不会分到这个领域。该领域已有指南的，选择逐节修订、重写覆盖，或先看现有内容。

### 2. 接待问题

从该领域的通用接待问题出发，决定增、删、改：

| 领域 | 通用接待要点 |
|---|---|
| 劳动争议 | 用人单位、岗位、入职时间、合同签订、争议类型、仲裁情况、证据、时效 |
| 婚姻家庭 | 关系及争议焦点、子女、安全、现有裁定、时效 |
| 消费者权益 | 争议类型、金额、沟通记录、文件、已有投诉、时效 |
| 行政纠纷 | 行政机关、行为类型、复议情况、关键文件、时效 |

其他领域由指导老师从头描述。同时写明：红旗信号（出现时须在接待摘要中提出）、受理标准、转介标准。

### 3. 教学方式

决定辅助工具或模板替学生做多少、学生自己做多少：

| 方式 | 做法 | 适合 |
|---|---|---|
| 引导（默认） | 给出结构，学生填实质内容，再给反馈 | 大多数诊所的起点 |
| 协助 | 直接给出成品，学生审阅并在修改中学习 | 案件量大或期限紧 |
| 教学 | 不给成品，学生起草，以追问式反馈为主，两次尝试后才给示范 | 研讨式诊所，学习优先 |

可以设一个默认值，再按文书类型（当事人信函、备忘录、其他文书）单独设定，并写一两句理由，方便下学期的指导老师理解。

### 4. 审查门槛

默认：所有面向当事人的内容都要审查。逐项确定：

| 工作成果 | 门槛 |
|---|---|
| 接待摘要 | 【学生撰写，案件讨论会上审查 / 当事人看到前由指导老师审查 / 学生自留】 |
| 内部备忘录 | 【指导老师审查 / 学生自留】 |
| 当事人信函（预约 / 索取材料 / 简要进展） | 【指导老师审查 / 学生直接发送】 |
| 当事人信函（实质性建议 / 坏消息） | 始终由指导老师审查，不可更改 |
| 向法院 / 机关提交的文书草稿 | 始终由指导老师审查，不可更改 |
| 向法院报告的进展 | 始终由指导老师审查，不可更改 |
| 检索路线图 | 【学生直接使用】 |

实质性建议信函、法院提交文书和向法院的报告属于固定项，其余是可调整的常规项。

### 5. 其他领域工具的使用

学生需要借助其他业务领域的工作方法时（如合同审查、时间线整理、调查令应对、个人信息事项），写明：在什么情形下使用、结果是否必须经指导老师审查、是否只能在指导老师在场时使用。

### 6. 本地规则和管辖地

列出诊所在该领域常去的法院、学生需要使用的本地规则和表格，形成一份简短清单。

### 7. 写成指南并试用

按下方模板写成指南。只根据指导老师的回答填写，没说的留空，不编造。写完后可以拿一份示例当事人信函按设定的教学方式走一遍，看看学生会遇到什么。

## 注意事项

- 指南按实践领域分别编写；诊所整体的指导风格、管辖地、实践领域范围另行确定。
- 指南中的审查门槛是在诊所整体指导模式（正式审查队列 / 可配置标记 / 较轻度指导）基础上的细化，不替代它。
- 指南可以调整教学方式，但不能取消草稿标识、把握程度标注、核实提示等基本保障。
