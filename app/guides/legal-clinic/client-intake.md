接待是法律诊所最大的瓶颈之一：学生访谈 45 分钟，整理记录再花一小时，还要识别法律问题，候访名单却越来越长。结构化接待让学生把精力放在分析上，而不是誊写上。

接待不决定是否受理案件。是否受理由学生分析、指导老师判断。

## 适用情形

- 新当事人首次来访、进行接待访谈、记录新当事人情况。

## 需要准备的材料

- 诊所的实践领域、接待模板、指导风格、标记触发条件、管辖地信息。
- 指导老师为该领域编写的实践领域指南（有的话，用其中的接待问题、红旗信号和受理标准替代下面的通用问题；没有的，在摘要末尾注明「此为通用接待，指导老师可为本诊所定制问题」）。

## 办理步骤

### 1. 判断实践领域

当事人知道自己的问题，但不一定知道法律上属于哪类。先请当事人讲：「跟我说说发生了什么，今天是什么事让您来到诊所？」据此确定领域。问题跨领域的（如婚姻家庭当事人提到家庭暴力），所有相关领域都要记录。确定领域后，再检查有无该领域的指导老师指南。

### 2. 按领域提问（通用问题）

**劳动争议**
- 用人单位、岗位、入职时间、劳动合同签订情况
- 争议类型：工资拖欠、违法解除、工伤、社保
- 是否经过劳动仲裁（前置程序）
- 关键证据：劳动合同、工资单、解除通知、考勤记录
- 时效：仲裁申请期限一年，自知道权利被侵害之日起算

**婚姻家庭**
- 关系及争议焦点（离婚、子女抚养、财产分割、家庭暴力）
- 涉及子女的年龄、现抚养安排
- 安全：有无暴力、威胁、恐惧（谨慎处理，见跨领域问题）
- 现有法院裁定 / 判决
- 时效：是否已安排庭审

**消费者权益**
- 争议类型和涉及金额
- 与商家的沟通记录
- 文件：合同、付款凭证、沟通记录
- 是否已有相关投诉或诉讼
- 时效：诉讼时效三年，自知道权利受损之日起算（《民法典》第188条）

**行政纠纷**
- 行政机关名称、行政行为类型
- 是否经过行政复议
- 关键文件：行政决定书、告知书
- 时效：行政复议申请期限（60日）或行政诉讼起诉期限（6个月）

### 3. 留意跨领域问题

| 当事人说 | 同时涉及 |
|---|---|
| 「我担心我的身份问题」 | 行政法律问题——即使在劳动争议接待中 |
| 「我的配偶【威胁行为】」 | 家庭暴力 / 婚姻家庭 / 人身安全保护令——即使在消费者接待中 |
| 「我因为受伤不能工作」 | 可能的工伤 / 社保 / 侵权问题 |
| 「他们从我的工资里扣钱」 | 工资争议——劳动 / 行政交叉 |
| 「老板说会举报我」 | 劳动 + 可能的刑事 / 行政举报问题 |

每个跨领域问题都记入摘要。诊所是受理、转介还是一并处理，由指导老师决定，但学生必须看到。

### 4. 利益冲突标记

按诊所冲突检查流程，参照《律师法》第11条、第39条、第41条，《律师执业管理办法》第26—28条。至少检查：

- 对方当事人：诊所是否正在或曾经代理？
- 关联方：学生或诊所与其他人是否可能存在冲突？
- 立场冲突：本案是否损害诊所另一当事人的利益？

只标出，交指导老师审查，不自行解决。

### 5. 分流

不是受理决定，而是分流参考：

| 分类 | 含义 |
|---|---|
| 紧急 | 期限在数日内、有安全问题、不可逆损害即将发生 |
| 时间敏感 | 期限在数周内、损害持续但并非立即不可逆 |
| 标准 | 无紧迫期限，按正常排期处理 |
| 可能超出范围 | 超出诊所实践领域，需评估转介 |

### 6. 指导标记

按诊所指导风格和标记触发条件，出现触发情形（提到期限、家庭暴力迹象、身份问题等）的，在摘要中注明；实行正式审查队列的，注明「已排队等待【指导老师】审查」。

### 7. 期限移交（必做）

接待中出现任何期限（答辩期、庭审日、诉讼时效、行政复议申请期限等），每个期限单独形成一条记录，直接记入期限台账，不要让学生事后再誊写：

```
案件：【案件简称或当事人姓氏关键词】
类型：【答辩 | 庭审 | 诉讼时效 | 举证期限 | 行政复议 | 申请执行 | 其他】
内容：【一行描述应完成事项】
到期日：【需核实——学生与指导老师从触发事件起算】
依据：【触发事件 + 法条，如「起诉状送达日期2026-05-04，《民事诉讼法》第128条」】
负责人：【学生姓名】
提醒：提前 14、7、3、1 日
```

规则：
- 一个期限一条，不合并。
- 法定期限（答辩期、诉讼时效、法定申请期）的到期日一律写「需核实」，由学生和指导老师计算后更新。
- 触发文件上写明了日期的（传票上的庭审日期、复议告知书上的日期），直接填该日期；由触发事件推算的，写「需核实」。
- 接待中没有出现期限的，省略本项，不要编造。


## 注意事项

- 不决定是否受理：学生分析，指导老师决定。
- 不解决利益冲突：标出交指导老师审查。
- 接待中不提供法律建议：接待是收集信息，建议在分析和指导老师审查之后。
- 摘要只是起点：学生要通读、纠正表述错误的地方，再据此开展分析。
- 各领域的接待问题集可由指导老师另行提供；没有的使用上述通用问题。

## 法律依据

- 《民法典》第188条（诉讼时效）
- 《民事诉讼法》第128条（答辩期，示例）
- 《律师法》第11条、第39条、第41条
- 《律师执业管理办法》第26—28条
