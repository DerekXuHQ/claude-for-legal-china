诊所每周要发大量常规信函：「您的预约是周二下午2点」「请带上您的租赁合同」「我们已为您提交了答辩状」。用模板处理这些，学生就不必每周重复写同样的内容。

**只限常规信函。** 实质性建议、坏消息、案件策略，不用模板信函处理，应写正式的进展说明或先与指导老师商量。

## 适用情形

- 预约确认
- 向当事人索取文件
- 「已提交」「正在等待」之类的简要进展说明

## 需要准备的材料

- 诊所的通俗语言标准、指导风格、联系信息。
- 案件笔记（预约信息、所需文件、已办事项）。
- 该实践领域的指导老师指南（如有）。

## 办理步骤

1. 确定信函类型，选用下方模板。
2. **按教学方式起草**（以指导老师指南为准；未设定的按「引导」）：
   - **引导**：先给结构和清单（必要内容、通俗语言目标、签名要求），学生逐节自己起草，再就语体、阅读难度、必要内容、遗漏给出反馈；学生试过一次之后，才对某节给出示范。
   - **协助**：直接给出信函，标出需学生审查的地方，学生在修改中学习。
   - **教学**：不给成品，学生自己起草，以反馈和引导性问题为主；尝试两次仍有困难的，只就那一节给示范段落；记录学生做对和做错的地方，便于指导老师看到进步。
3. **通俗语言检查**：短句，不用法律术语，达到诊所规定的阅读难度。必须用术语的，第一次出现时解释，例如：「我们已提交了『答辩状』——这是向法院说明您对案件看法的文件。」
4. **签名与身份披露**：查阅所在地关于法学学生参与法律服务的规定，确认学生签署信函时须如何表明身份（通常须写明是法学学生并指明指导律师）。下方模板使用通用表述，发送前按规定调整。
5. **发送前审查**（见下文）。
6. 发出后，在当事人沟通日志中记一条「去」向沟通。

## 发送前审查

向当事人发信会对当事人产生法律后果，可能构成法律建议或代表当事人沟通。每封信函离开诊所前都要过审查：

1. 已按诊所指导规程审查（正式审查队列 / 可配置标记 / 较轻度指导）。正式审查队列模式下，常规信函也要排队；较轻度指导模式下，学生审查后可直接发送。
2. 所有内部标记（「草稿——需审查」「待核实」「需补充事实」等）已从当事人看到的版本中删除。审查标记只能放在信函正文之外，绝不能出现在当事人收到的版本里。
3. 签名符合所在地关于法学学生签署信函的规定。

学生草稿须经执业指导律师审查、修改并签字后方可发出，未经指导老师批准不得发送。

## 模板

### 预约确认

```markdown
【当事人姓名】：

本函确认您与【诊所名称】的预约：

**日期：**【日期】
**时间：**【时间】
**地点：**【地址 / 房间号，或「电话：【号码】」】
**接待人：**【学生姓名】

**请携带：**【所需文件——来自案件笔记，或留待学生填写】

如需改期，请至少提前24小时致电【诊所电话】。

【学生姓名】
法学专业学生（法律诊所学员）
在【指导律师姓名】指导下
【诊所名称】|【电话】|【工作时间】
```

### 文件索取

```markdown
【当事人姓名】：

为推进您的案件，我们需要您提供以下文件：

- 【文件1——例如「您的租赁合同」】
- 【文件2——例如「您收到的出租人的通知」】
- 【文件3】

**提交方式：**【送至诊所 / 发送邮件至【地址】/ 下次预约时携带】

**请于【日期】前提交**——【有期限的说明原因：「我们需要您在【日期】前提交这些文件，以便在法院答辩期限前为您提交答辩状。」】

如果您没有其中某些文件，或不明白我们的要求，请致电【诊所电话】，我们可以帮您。

【学生姓名】
法学专业学生（法律诊所学员）
在【指导律师姓名】指导下
【诊所名称】|【电话】|【工作时间】
```

### 简要进展说明

用于「已提交」「正在等待」这类常规说明；更全面的进展说明另行撰写。

```markdown
【当事人姓名】：

简要告知：【一行说明发生了什么——「我们已于【日期】向法院提交了您的答辩状」/「我们已于【日期】向出租人发出了律师函」】。

**下一步：**【一行——「我们正在等待对方回复」/「法院将安排庭审并通知日期」】。

您目前不需要做任何事，需要时我们会通知您。

【学生姓名】
法学专业学生（法律诊所学员）
在【指导律师姓名】指导下
【诊所名称】|【电话】|【工作时间】
```

## 不适用模板信函的情形

- **实质性建议**：信中要写「这是我对您案件的分析」「您应该这样做」的，不属于常规信函。
- **坏消息**：结案、不利裁决、无法提供帮助，需要斟酌，不用模板，交指导老师。
- **给对方律师或法院的任何文件**：受众不同，按文书起草或向法院报告的要求办理。
