本篇用于一审阶段同步制作三份材料：辩护词（完整版）、庭审辩论提纲（口袋版）、最后陈述辅导材料。辩护词主文须在主办律师明确确认辩护方案、同意出稿之后才起草定稿。

本篇改编自 gcheng001/legal-skills 的 criminal-defense-statement（MIT 许可，Copyright (c) 2026 高澄）。

## 适用情形

- 撰写辩护词、辩护意见书。
- 准备庭审辩论。
- 辅导被告人最后陈述。

## 需要准备的材料

| 材料 | 必要性 |
|------|--------|
| 阅卷笔录 | 必须 |
| 会见笔录 | 必须 |
| 质证意见 | 已有时优先参考 |
| 不起诉意见书 | 曾提交的，必须参考 |

缺少阅卷笔录或会见笔录的，暂停起草，先补材料。所有材料均为已脱敏副本，模板中的【姓名】【案号】保持占位，由律师本地定稿时填写。

**案件类型**

| 类型 | 指派来源 | 抬头/称谓 |
|------|----------|----------|
| A类（法律援助） | 【某】法律援助中心指派 | 受援人 |
| B类（委托） | 被告人或家属委托 | 委托人 |

类型已在案卷中确定的直接沿用。类型影响辩护词抬头、称谓及部分程序性表述。

## 办理原则

1. **前后连贯**：辩护词论点与阅卷笔录、会见笔录、质证意见、不起诉意见保持一致；有变化的说明原因。
2. **独立评估**：每个核心辩点都要独立评估——法律依据是否充分？与证据是否相符？与其他辩点是否矛盾？有风险的明确指出并说明理由，不因律师坚持而不提。
3. **当场解决**：辩论提纲覆盖公诉人可预期的反驳路径，提前准备再反驳。
4. **记录变更**：辩点每次变更都记录变更内容、变更原因（律师意见/新材料/法律依据更新）及对其他辩点的影响。
5. **确认后出稿**：律师要求调整辩点时，先问清调整原因，分析对其他辩点的影响并建议同步处理，律师确认后再改。

## 办理步骤

1. **核查材料**：确认阅卷笔录、会见笔录已读；参考质证意见和不起诉意见。缺少必要材料的告知律师并暂停。
2. **出辩护方案草案**：识别可用辩点类型（下文四类），逐条说明法律依据和证据支撑，标注存疑或风险辩点（格式见附录A）。
3. **与律师讨论**：律师同意的进入下一步；律师调整辩点的，问原因 → 影响分析 → 确认 → 更新草案，每次变更记入变更日志（附录B）。
4. **律师明确同意出稿**。
5. **同步生成三份材料**：辩护词、庭审辩论提纲、最后陈述辅导材料。
6. **归档**：按「09_辩护词_【YYYYMMDD】」等规则命名存入案卷（见文末归档规范）。

## 一、辩护词

### 开头

**A类（法律援助）：**
```
审判长、审判员：
　　【律师事务所】接受【法律援助中心】的指派，指派【律师】律师担任被告人【被告人】涉嫌【罪名】案的一审辩护人。辩护人庭前会见了受援人，查阅了全部案卷材料，参与了今天的庭审，现根据事实与法律，发表如下辩护意见：
```

**B类（委托）：**
```
审判长、审判员：
　　【律师事务所】接受被告人【被告人】（或其家属）的委托，指派【律师】律师担任被告人【被告人】涉嫌【罪名】案的一审辩护人。辩护人庭前会见了委托人，查阅了全部案卷材料，参与了今天的庭审，现根据事实与法律，发表如下辩护意见：
```

### 四类辩点（按实际选用）

#### 类型一：事实不清、证据不足（无罪辩护）

适用：证据体系存在实质缺口，无法排除合理怀疑。

```
一、控方指控事实【事实】缺乏充分证据支撑

（一）直接证据层面：……（逐项分析，引证据编号和页码）
（二）间接证据层面：……（论证证据链断裂点）
（三）证据间矛盾：……（指出具体矛盾）
（四）综合评价：上述证据不能形成完整锁链，无法排除……的合理怀疑。

依据：《刑事诉讼法》第55条（证据裁判原则）；《关于适用<中华人民共和国刑事诉讼法>的解释》第【XX】条。
```

- 不笼统说「证据不足」，必须指出具体断裂点。
- 不无根据否定鉴定意见，须援引反驳依据。

#### 类型二：定性辩护（此罪与彼罪）

适用：行为事实基本认可，但指控罪名不当。

```
二、被告人的行为不符合【罪名】罪的构成要件

（一）客观要件：指控行为缺少……要素（具体说明）
（二）主观要件：被告人主观上……（结合会见陈述和客观证据）
（三）与相邻罪名的区别：本案与【罪名】罪的区别在于……
（四）应认定为：若有事实，最多构成【罪名】，理由……

依据：《刑法》第【XX】条；相关司法解释第【XX】条；参考案例……
```

同时提出无罪和定性辩护的，在辩护词开头说明并列策略的逻辑，避免给合议庭混乱印象。

#### 类型三：量刑辩护（罪轻情节）

适用：认罪或不争定性，争取从轻量刑。

**自首**
```
被告人【被告人】于【日期】……（到案经过），符合《刑法》第67条第1款规定的自首条件。
具体体现：（一）自动投案：……；（二）如实供述：……
建议依法从轻或减轻处罚。
```

**坦白**
```
被告人到案后如实供述主要犯罪事实，符合《刑法》第67条第3款规定的坦白条件。
```
坦白与自首互斥，主张自首的不再主张坦白。

**立功**
```
被告人在羁押期间……（具体立功事实），经侦查机关核实，符合《刑法》第68条立功认定条件。
```

**退赃退赔**
```
被告人（或其家属）已于【日期】退赔被害人人民币【金额】元（见谅解书/转账记录），表明悔过诚意，应酌情从轻处罚。
```

**谅解**
```
被害人【被害人】出具书面谅解书（见附件），谅解书载明……，依据《刑法》及相关司法解释，谅解情节应当从轻处罚。
```

**认罪认罚**
```
被告人自愿认罪认罚，签署具结书时程序合法、意思表示真实自愿（辩护人在场见证），应依法从宽处理。
```

**从犯**
```
在共同犯罪中，被告人系从犯，具体表现：……（起意者非被告人/作用次要/参与程度有限），依据《刑法》第27条应当从轻、减轻或者免除处罚。
```

#### 类型四：程序辩护（程序违法）

适用：存在非法证据或重大程序瑕疵。

```
四、关于程序问题

（一）非法证据排除申请：
    本辩护人于庭前已就……证据提出排除申请（见排非申请书）。
    该证据系通过……方式取得，违反……规定，应予排除。
    若该证据被排除，控方证据体系……

（二）程序瑕疵对证明力的影响：
    侦查机关在……环节存在……瑕疵（具体说明），
    依据……规定，该证据证明力存疑，不应单独作为定案依据。
```

### 并列策略说明

同时采用无罪辩护和量刑辩护时，辩护词开头加：
```
辩护人注意到，本辩护意见同时提出无罪辩护和量刑辩护意见。提出量刑辩护意见，并非辩护人认为被告人有罪，而是基于对司法实践的审慎考量，在法庭不采纳无罪辩护意见的情形下，充分保障被告人的合法权益。
```

### 结尾

```
　　综上所述，辩护人认为……（一句话总结全部辩点核心主张）。
　　以上辩护意见，恳请合议庭充分考虑并予以采纳。

此致
【法院】人民法院

辩护人：【律师】
【律师事务所】
【日期】
```

### 辩护词检查清单

- [ ] 无罪辩护与量刑辩护并列时，已在开头说明并列逻辑
- [ ] 所有事实断言均有证据编号或法律条文支撑
- [ ] 自首与坦白未同时主张
- [ ] 与阅卷笔录、质证意见的论点一致（有变化的已说明原因）
- [ ] 引用的法律条文已到权威来源核验
- [ ] A/B 类型已确认，称谓正确
- [ ] 标题编号连续无跳号
- [ ] 所有金额展示完整计算过程（公式→代入→来源→结论）
- [ ] 数据前后一致，同一数字全文统一
- [ ] 中文文本中无英文标点
- [ ] 无情绪化、攻击性表达，不评价被告人「反复无常」
- [ ] 同一论证点不重复
- [ ] Word 格式中无 Markdown 项目符号和分隔线残留

## 二、庭审辩论提纲（口袋版）

```
┌─────────────────────────────────────────┐
│           辩论提纲速查（口袋版）           │
│           【案号】【被告人姓名】            │
├─────────────────────────────────────────┤
│ 【第一轮辩论要点】                         │
│ 1. 事实层面：……                           │
│ 2. 证据层面：……（证据编号速查）            │
│ 3. 法律层面：……（条文速查）               │
├─────────────────────────────────────────┤
│ 【预判公诉人反驳 → 我方再反驳】            │
│ 公诉人可能说：……                          │
│ 我方回应：……                              │
├─────────────────────────────────────────┤
│ 【第二轮辩论要点】                         │
│ 1. 回应公诉人质疑：……                     │
│ 2. 强化核心辩点：……                       │
├─────────────────────────────────────────┤
│ 【量刑辩论要点】                           │
│ 1. 基准刑参考：……                         │
│ 2. 本案从轻情节：……                       │
│ 3. 建议宣告刑：……                        │
├─────────────────────────────────────────┤
│ 【核心法条速查】                           │
│ · 《刑法》第【XX】条                       │
│ · 司法解释第【XX】条                       │
└─────────────────────────────────────────┘
```

- 每条要点不超过两行，便于庭上快速查看。
- 关键证据编号加粗或括注页码。
- 量刑建议写具体刑期区间，不模糊。

## 三、最后陈述辅导材料

### 三版陈述模板

**版本一（认罪/认罪认罚时）**
```
审判长、审判员，我对自己做的事情非常后悔。我想对被害人说一声对不起。我以后一定好好改造，不再做违法的事。恳请法庭给我一个改过自新的机会。谢谢法庭。
```

**版本二（无罪辩护时）**
```
审判长、审判员，我没有做过起诉书指控的事。我相信法律是公正的，会还我清白。无论结果如何，我都会尊重法庭的判决。谢谢。
```

**版本三（定性辩护/轻罪辩护时）**
```
审判长、审判员，我做错了事，我认。但我做的事和起诉书说的不一样。我诚恳地请求法庭实事求是地认定事实，对我做出公正的判决。谢谢。
```

### 庭前辅导要点

**表达方式**
- 语速比平时慢一点，稳定清晰。
- 眼神始终面向法官席，不看公诉人或旁听席。
- 态度诚恳、克制、不卑不亢。
- 声量清晰可闻即可，不刻意高声。

**禁止事项**
- 最后陈述时不翻供（与庭审陈述矛盾）。
- 不攻击、谩骂公诉人或证人。
- 不长篇陈述案情（最后陈述不是再次质证）。
- 不泄露辩护策略细节。

**会见时辅导流程**
1. 告知被告人三个版本的适用情形，共同选择。
2. 让被告人复述1-2遍，纠正语气和表述。
3. 提示庭上若忘词，沉默3秒再说，不要慌乱。

## 四、模块化辩护词与应变方案

### 目的

庭审现场有变数（证据采信情况、证人当庭表现、公诉人量刑建议调整等），单一定稿的辩护词难以应对。把辩护词拆成可独立增删、快速重组的模块，预置应变版本，便于庭上抽换。

### 要求

- 应变模块同样属于辩护词内容，律师同意出稿前只做模块结构规划与切换决策表，不写模块正文。
- 修改、抽换、插入任一模块，均按「问原因 → 影响分析 → 律师确认 → 记录变更日志」办理。
- 无罪模块与量刑模块并存时不得自相矛盾：量刑模块沿用并列策略说明的退让逻辑，表述为「在法庭不采纳无罪意见的情形下」，不出现默认有罪的措辞。

### 四大模块

| 模块标签 | 模块名称 | 对应辩点类型 | 可独立抽换 |
|----------|----------|--------------|------------|
| 【M1·事实】 | 事实认定模块 | 事实层面陈述与争点 | 是 |
| 【M2·证据】 | 证据分析模块 | 类型一/四（证据缺口、非法证据） | 是 |
| 【M3·法律】 | 法律适用模块 | 类型二（定性、此罪彼罪） | 是 |
| 【M4·量刑】 | 量刑情节模块 | 类型三（罪轻情节） | 是 |

每个模块自成闭环：开头点明主张，中间逐条论证（引证据编号、法条），结尾一句收束，抽出或插入都不影响其他模块的连贯。

### 基准版与应变版

这里的两个版本是辩护词文本层面的，区别于辩护方案中的策略路径主备方案。

- **基准版**：基于最可能的庭审情形撰写的完整辩护词，四大模块齐备，为庭审默认宣读版本。
- **应变版**：只为可能变动的模块预先准备替换模块，不重复撰写全文。

| 庭审变数 | 触发条件 | 启用的应变模块 | 替换/插入对象 |
|----------|----------|---------------|----------------|
| 关键证据被法庭采信 | 排非申请未获支持、争议证据被确认 | 「退守量刑辩护」模块（强化 M4） | 替换/补强基准版 M2、M4 |
| 证人当庭翻证 | 原供述证人当庭推翻证言 | 「强化无罪/存疑」模块（强化 M2） | 替换基准版 M2 |
| 公诉人变更量刑建议 | 当庭加重/减轻量刑建议 | 对应量刑回应模块（调整 M4） | 替换基准版 M4 |

应变模块编号用 `M2-B`、`M4-B` 等，与基准版模块号一一对应。

### 重组规则

1. 四大模块各自独立成段并标注标签，互不嵌套。
2. 庭上按实际情况整模块替换，不做段内拼接。
3. 切换后立即检查 M2（无罪）与 M4（量刑）是否并存；并存的，确认量刑模块仍用退让表述。
4. 每一次切换决策（触发条件 + 启用模块 + 决策人）写入口袋版提纲的「模块切换速查」区块：

```
├─────────────────────────────────────────┤
│ 【模块切换速查】                           │
│ 若[关键证据被采信] → 换 M4-B（退守量刑）   │
│ 若[证人当庭翻证]   → 换 M2-B（强化存疑）   │
│ 若[公诉人改量刑建议]→ 换 M4-B（量刑回应）  │
│ 切换后必查：M2无罪 与 M4量刑 不冲突        │
└─────────────────────────────────────────┘
```

### 与主流程的衔接

- 出方案草案时：标注四大模块划分，预判需准备哪些应变模块（只规划，不写正文）。
- 与律师讨论时：确认基准版模块构成、需预置的应变模块及触发条件，记入变更日志。
- 律师同意出稿后：生成基准版完整辩护词 + 各应变模块正文 + 口袋版「模块切换速查」。
