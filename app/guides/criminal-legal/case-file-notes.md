本篇用于在刑事案件中制作或修订阅卷笔录：先确定案件类型（法律援助类或委托类），再按对应结构逐部分撰写，并核对供述归属、讯问要素、原件与法律依据。只需对脱敏摘要做快速证据链梳理的，见《刑事笔录与证据链梳理》。

本篇改编自 gcheng001/legal-skills 的 criminal-case-review（MIT 许可，Copyright (c) 2026 高澄）。

## 适用情形

- 生成刑事阅卷笔录。
- 修订已有阅卷笔录。
- 依据阅卷笔录填写会见笔录。

## 需要准备的材料

- **已脱敏的卷宗副本**：诉讼文书卷、证据卷、补充侦查卷。发现未脱敏的真实姓名、身份证号、联系方式、案号、卷宗原文或照片，先脱敏再办理。文书模板中的【姓名】【案号】等占位符保持占位，由律师在本地定稿时填入真实信息。
- 指派通知书或委托手续（用于确定类型和阅卷时限）。
- 官方归档模板（法律援助类）。

## 一、确定案件类型

类型未明确时先确认；已明确的不再重复确认：

- **A. 法律援助类**：受援人，法律援助中心指派。
- **B. 委托类**：委托人，当事人或家属委托。

类型确定后的两个默认做法：

- **详略默认全量**：A类按12部分完整结构，B类按8部分完整报告。明确要求简版时才精简。
- **默认出两版**：提交版和自用版都出（见第四部分）。明确只要一版的，按要求办。

### 类型差异对照

未列出的部分两类完全一致。

| 项目 | A类：法律援助类 | B类：委托类 |
|------|------------------|--------------|
| 称谓 | 受援人 | 委托人 / 当事人 |
| 指派来源 | 法律援助中心指派 | 当事人或家属委托 |
| 文书抬头 | 受援人：【姓名】 | 委托人：【姓名】 |
| 会见笔录-身份告知 | 法律援助律师，由法律援助中心指派 | 委托辩护人，由当事人/家属委托 |
| 会见笔录-无偿告知 | 告知法律援助无偿性质 | 不适用，改为告知委托合同关系 |
| 会见笔录-费用说明 | 法律援助不收取费用 | 按已确认的委托合同或委托手续表述；未提供时标注待补充 |
| 归档要求 | 按《办理法律援助案件程序规定》（司法部令第148号，2023-09-01施行）第40-41条结案归档；地方细则须写明属地文件全称＋文号 | 按律所内部归档规范（可灵活调整） |
| 表头字段 | 阅卷时间、提请审查起诉时间、阅卷地点、涉嫌罪名 | 同左，可增加案号、委托人等字段 |
| 笔录标题 | 阅卷笔录（官方归档模板格式，不加空格） | 同左（报告式标题为「阅卷笔录（证据分析报告）」） |
| 阅卷笔录结构 | 12部分结构 | 证据分析报告式8部分 |
| 认罪认罚具结书审查、原件优先纠偏、续办与状态边界 | 适用 | 适用 |

**B类注意事项**

- 委托类不当然意味着阅卷时间更充分或举证更主动，以实际阶段、材料掌握程度和律师安排为准。
- 委托类不涉及法援中心审批流程；退赃、谅解、家属沟通等按已确认的委托权限处理。
- 「受援人」按语境替换为「委托人」或「当事人」；涉及「法律援助中心」的流程性字段删除或改为「委托来源/委托关系」，不得机械替换为「委托人」。
- 会见笔录不告知法律援助无偿性质；委托手续、费用和授权范围只按已确认材料表述，未提供时标注待补充。

## 二、笔录结构

### A类：12部分结构

按以下12部分组织正文，编号保持稳定，骨架和子项以官方归档模板为准：

1. 基本情况：身份信息、家庭与身体情况、前科、到案经过、强制措施、同案人员。
2. 起诉意见书指控事实：罪名与法律依据、事实摘录、案件来源、认罪认罚、量刑情节。
3. 受援人供述与辩解：逐次讯问摘录与评价、受援人辨认笔录。
4. 同案犯供述与辩解：与受援人定罪量刑相关的内容逐次摘录与评价。
5. 被害人情况及陈述：有则详细摘录，无则明确说明。
6. 证人证言：证人名单、辨认笔录（含他人对受援人的辨认）、与受援人相关内容及未涉及说明。
7. 客观性证据：物证、书证、鉴定意见、电子数据、视听资料、勘验检查辨认笔录清单。
8. 涉案财物扣押情况：扣押清单与缺失说明。
9. 辩方证据：已收集证据与待补充清单。
10. 证据分析：合法性、关联性、证明力、矛盾点、排除合理怀疑分析。
11. 相关法律规定：刑法、刑诉法、量刑规范性文件的相关条文。
12. 辩护思路：审查起诉阶段、审判阶段、待核实问题。

「基本信息」（阅卷时间、地点等）放在文档抬头，不作为第一章节；「相关法律规定」固定为第11项。

### B类：证据分析报告式8部分

封面/抬头 → 一、案件信息摘要 → 二、全案证据分类清单 → 三、逐证三性分析表（核心，用 ✅/⚠️/❌ 量化评分）→ 四、证据链整体评估 → 五、程序违法审查记录 → 六、辩护思路 → 落款。

形态变化不等于质量降级。下文的全部质量要求（原件优先、真实页码、讯问要素、供述归属、辨认笔录直接/间接指认区分、逐部分撰写确认、法条核验、Word格式、关联性筛选）对B类同样适用，只是落在报告式8部分的对应位置。12部分编号只适用A类。

## 三、通用质量要求（A、B类共用）

### 工作定位

- 以承办律师口吻起草或修订，直接陈述事实与分析结论，客观、专业、可核验。
- 每项事实尽量落到卷宗来源与页码。

### 保密与安全

- 只使用本案提供的信息，不跨案件复用，不外传、不推测敏感信息。
- 不覆盖原文；修订时出「修改建议」或「对照修订版（原文/修订后）」。
- 涉及证据归属、程序合法性、权限边界等高风险点，先标注风险再给处理意见。
- 通用方法和模板中不留存任何真实姓名、身份证号、地址、联系方式。

### 原件优先

- OCR、转写文本和摘要只用于检索和定位；签名、捺印、日期、印章、页码、在场人员等事实，以可核验的原件页面为准。
- OCR 未识别签名而原件可见签名的，记为「原件签名已确认」，不得写成「签名缺失」「值班律师是否在场不明」，也不得据此认定认罪认罚程序瑕疵或自愿性存疑。
- 认罪认罚具结书原件已确认值班律师签名后，只有当事人对实际在场过程或法律帮助实质提出具体异议时，才补查录像、听取意见记录等材料。
- 原件尚未回看时，自用版可记「原件待核」；提交版不得出现「待核对原件」等字样，改用中性事实表述，不得把 OCR 空白直接写成不利事实或程序风险。
- 修订历史稿时，保留其降级属性，修正可能把读者带回已撤回结论的判断，并记录修正依据与范围。

### 续办与补充阅卷

- 续办前先确认已完成步骤、待确认或阻断项、拟继续步骤及是否有新增材料，不重复通读未变化的全卷。
- 检察院补充起诉或退回补充侦查后有新增证据的，属补充阅卷：抬头补记补充阅卷时间，新增证据放入对应部分并标注「补充」。
- 试跑、待复核材料不得作为正式结论交付；法律依据须经权威来源复验，内容须人工核实。

### 讯问笔录必备字段（第 4、5 部分必检）

每次讯问至少包含：

- 第几次讯问
- 讯问起止时间（精确到分钟）
- 讯问地点
- 讯问人（姓名+单位）
- 记录人（姓名+单位）
- 卷宗页码
- 【摘录】与案件事实相关的完整问答/供述
- 【评价】与定罪量刑相关的分析

### 供述归属

- 每段供述必须对应正确陈述人，不得张冠李戴。
- 同案犯供述只保留与受援人定罪量刑有关的内容；无关联的写「未见直接关联内容」。
- 关键事实冲突列明「冲突点-对应页码-可能影响」。

### 供述变化追踪表（多次供述时必建）

| 次数 | 讯问时间 | 地点 | 供述核心内容 | 态度（有罪/无罪/辩解） | 与上一次差异 | 变化原因 |
|------|----------|------|--------------|------------------------|--------------|----------|
| 第1次 | | | | | | |
| 第2次 | | | | | | |

追踪重点：翻供时机（批捕后、律师介入后、见到同案供述后）、稳定供述的证明力、变化原因是否合理。

### 写作与格式

- 标题用「阅卷笔录」，不加空格。
- 官方模板中的括号备注分两类：**办案提示类**（如「注意时间：5个自然日内阅卷」「摘录+评价」）是给律师的说明，不写入正文，但「摘录+评价」作为内容要求须执行；**子项标题自带的范围注释**（如「身份情况（群众、党员、人大代表等）」「客观性证据（物证、书证及鉴定意见等）」）属官方标题格式，保持原样。模板空白下划线不保留，直接填实际内容。
- 避免绝对化措辞，程序事项优先用「资料显示」「卷内记载」。
- 所有摘录段落带页码。
- 删除模板提示语，不保留占位符。
- 文末保留落款（承办人签字、日期）。

**编号**

- 一级章节用中文数字（一、二、三、……十二、）。
- 章节内子标题统一用阿拉伯数字 1、2、3、，不用（一）（二）（三）；从第五部分起尤其注意全文一致。
- 法律原文引用中的编号（如司法解释条文中的（一）至（七））原样保留。

**精简**

- 「阅卷内容」后不写过渡语，直接进入正文。
- 不写「未见直接涉及相关内容，故不摘录」之类的模板化表述；无内容的部分直接省略或简要说明。
- 讯问人和记录人写在一行：「讯问人：某某、某某（单位）；记录人：某某」。
- 第11部分不写「相关法律文书」「本部分综合评价」，只保留法律条文。
- 第12部分只写辩护方向和具体辩护要点，不写「庭审策略」和「量刑建议」（属于辩护词内容）。

**Word 格式**（导出前逐项与律师确认）

1. 字体：全文仿宋_GB2312。
2. 字号：大标题（「阅卷笔录」及一、二、三章节标题）二号（22pt）加粗；子标题（1、2、3）小四号（12pt）加粗；正文四号（14pt）不加粗。
3. 行距：1.5 倍。
4. 首行缩进：正文段落首行缩进 2 字符。
5. 对齐：正文两端对齐，大标题居中。
6. 页边距：上下左右各 1.25 英寸。
7. 页码：底部居中。

不保留 Markdown 项目符号和分隔线，列表项转为普通段落；大标题和子标题字号必须区分。转 PDF 后检查嵌入字体，确认仿宋_GB2312 未被替换为黑体类字体。

**页码**

- 使用真实卷宗页码（通过卷内目录或页眉页脚确认）。
- 不得用 OCR 文本行号（如 63394 等五位数以上数字）作页码。
- 被辨认人身份情况说明的页码在卷内目录中查找，或根据卷宗实际页码范围（通常 200 页以内）标注。
- 无法确定准确页码的，标注「卷内目录第 X 页」；「需核对原件」属提交版禁词，不作为页码写法。

## 四、提交版与自用版

1. **默认两版**：提交版（可直接交法援中心归档）＋自用版（保留待核实要点、矛盾点清单、会见准备问题）。只要提交版的，被剥离的要点另行留存备查，不能凭空消失。
2. **提交版禁词**（出现即返工），共三类：
   - 未完成核查类：需核对／待核对／核对原件／纸质卷核对／经抽样辨识／辨识存疑／不可读／无法辨识／未能查看／待会见核实／向检察机关核实／向办案机关核实调取／待落实／待补充／待核（标题）／文号待核验／具结前应／庭前应完成／空白点／待终核；
   - 工作流程痕迹类：渲染／工作底稿／汇总稿／无文字层／文本层／OCR／分页／以超大文件方式；
   - 文件名式引用类：卷名不带文件日期后缀（补查卷20260731→补查卷一），不引用 PDF/txt/docx 文件名。
3. **改写四式**：中性事实陈述（「均为扫描图像」）→ 完成式（「已结合归案经过等在卷记载予以核对」）→ 辩护请求式（「辩护中将申请调取」「建议侦查机关出具补正或说明材料」）→ 中性对照（「以卷面记载为准」）。
4. **保留例外**（不得误删）：攻击侦查机关的实质瑕疵分析（「形成时间存疑」「是否同一存疑」）、证人原话、原卷真实印错的记载（如文号印「null」）、法定表述、法条原文。
5. **交付前自检**：全文复扫禁词清零 → 整段删除后小标题编号连续 → 修改页视觉检查。
6. 文号未经权威来源核验的不写；核不准时只写文件名称＋机关＋日期，不写「文号待核验」。

## 五、办理步骤

### 1. 阅卷顺序（材料齐备时）

1. **诉讼文书卷**：立案决定书、强制措施文书、起诉意见书/起诉书，了解指控全貌。
2. **供述与辩解卷**：全部讯问笔录、亲笔供词，掌握陈述变化。
3. **证人/被害人卷**：被害人陈述、证人证言，了解控方证据。
4. **书证物证卷**：合同、账册、凭证、物证照片，核实客观证据。
5. **鉴定与勘验卷**：鉴定意见、勘验/检查/辨认笔录，审查专业意见。
6. **程序卷**：搜查、扣押、冻结文书，审查取证合法性。

卷宗为一大本混编 PDF 的，可先按类目拆分并编制索引，索引分类须律师复核。

### 2. 三遍阅卷法

- **第一遍（通览）**：快速浏览全部材料，建立整体印象，标注疑点。
- **第二遍（细读）**：逐份精读，提取关键信息填入各部分。
- **第三遍（比对）**：横向比对证据间矛盾，纵向梳理时间线冲突。

### 3. 逐部分撰写、逐部分确认

一次写一部分，经承办律师审核确认后再写下一部分，不一次性生成全文。

### 4. 时限校验（A类）

- **5个自然日内阅卷**：比对指派通知书/指派日期与阅卷时间，超期的提醒律师附《情况说明》。此项只在办理中校验，不写入笔录正文。
- 补充阅卷按第三部分「续办与补充阅卷」处理。

### 5. 各部分写法

**表头**：只保留4项字段——阅卷时间、提请审查起诉/提起公诉时间、阅卷地点、涉嫌罪名（与官方归档模板一致）；补充阅卷的补记补充阅卷时间。除非明确要求，不加受援人姓名、案号等字段。「阅卷内容」后直接进入「一、被告人基本情况」。

**第一部分 基本情况**：严格按8项子标题填写——1、基本信息；2、身份情况；3、家庭情况；4、身体情况；5、前科情况；6、到案经过；7、强制措施；8、同案其他犯罪嫌疑人情况。不合并、拆分或增减子项。到案经过只写归案过程，不写扣押物品。本部分不标页码。

**第二部分 起诉意见书指控的事实**：按4项子标题——1、指控的罪名；2、指控的犯罪事实；3、是否认罪认罚；4、量刑情节和量刑建议。量刑情节项下的（1）至（4）是起诉书原文格式，保持原样。

**第三部分 受援人供述与辩解**：每次讯问单独列出，带完整元数据（时间、地点、讯问人、记录人）；摘录直接复制原文，不改写概括；每次讯问后必须有【评价】。公安阶段笔录详细摘录、保留关键问答；检察院阶段笔录只摘录与案件事实有关或有争议的部分。

**第四部分 同案犯供述与辩解**：只摘录与受援人定罪量刑有关的内容。

**第五部分 被害人情况及陈述**：有陈述的详细摘录；没有的简要说明。

**第六部分 证人证言**：只摘录与受援人有关的证言，包括他人对受援人的辨认笔录。

**第七部分 客观性证据**：只列实际存在的证据类型，不列空壳标题；扣押情况不在此写。

**第八部分 涉案财物扣押情况**：受援人涉案财物、涉案赃款追缴、同案犯涉案财物扣押统一在此写，不与第七部分重复。

**第九部分 辩方证据**：已收集证据与待补充清单。

**第十部分 证据分析**：按官方模板子项——1、指控证据是否合法，是否存在矛盾，是否排除合理怀疑；2、证人、鉴定人、勘验检查笔录制作人、翻译人员是否适格，是否符合法定程序；3、被害人陈述是否客观；4、可扩充关联性、证明力、证据链断裂点、矛盾点清单等。

**第十一部分 相关法律规定**：详细、全面，包括法律法规和司法解释；每条引用须到权威来源核验。不写「相关法律文书」「综合评价」「待核实问题」。

**第十二部分 辩护思路**：只写辩护方向和具体辩护要点，不写庭审策略（发问提纲、质证要点、辩论意见）和量刑建议（具体刑期）。

**落款**：文末必须有承办人签字和日期。

**通用写法**

- 有格式模板的，严格按模板结构填写，不改结构、字段名称或编号。
- 同案犯供述、证人证言只摘录与受援人定罪量刑有关的内容。
- 全文编号方式、页码标注、字体字号保持一致。
- 没有内容的证据类型直接跳过，不列空标题也不写「无」。
- 不同部分不重复同一内容（如扣押情况只在第八部分）。
- 交付时提供结构化正文 + 风险点清单 + 待补证据事项。

## 六、辨认笔录的抽取与评价

### 必须包含两类

1. **受援人辨认笔录**（第三部分）：受援人对同案人员等的辨认。
2. **他人对受援人的辨认**（第六部分）：同案人员、证人对受援人的辨认。

常见遗漏：只摘录受援人辨认他人，漏掉他人辨认受援人；漏标被辨认人身份情况说明的页码；未写明号位映射关系。

### 证据分层

- **直接指认**：辨认结果明确出现「某号即为某人（含被告姓名）」。
- **间接指认**：辨认结果只出现「某号=某角色」，须再用「被辨认人身份情况说明」完成号位映射。
- **背景性材料**：姓名只出现在名单或身份页，没有辨认结果，不得写成「已被指认」。

### 写入规则

- 每段摘录标注卷别与页码。
- 号位映射的结论用「间接指认」表述，不写成「直接辨认出某人」。
- OCR 缺字、断句、页码错位的，在自用版中加风险提示。
- 评价写清证明方向：证明角色分工、参与程度、与供述是否互证、是否存在混号风险。

```text
【某某辨认笔录】（诉讼证据卷第A页，身份说明见第B页）
【摘录】"……第N组第M号为外围望风人员……"
【对应关系】"第N组第M号=某某（身份说明页）"
【评价】该证据属于"号位指认+身份说明"的间接指认，可用于证明受援人角色；但需核验同批次照片编号一致性。
```

## 七、依据阅卷笔录填写会见笔录

适用于根据阅卷笔录填写会见笔录、且须保留模板内容的情形。

1. 先读会见笔录模板与阅卷笔录，列出争点清单（参与次数、角色分工、获利金额、时间区间、讯问合法性、认罪认罚过程、前科与累犯）。
2. 不删除模板原有条目，只填充律师端可预填内容；「被会见人回答（答：）」默认留空。
3. 在「律师根据案情，自行提问」中填入不少于 5 个针对性问题，直接对应争点清单。
4. 在「听取陈述后法律解答」处写个案化的法律解释，不一笔带过。
5. 在「本案风险及法律后果」中写明有利/不利量刑因素及程序风险，不用空泛表述。
6. 在「探讨辩护方案、征询辩护意见」中写明辩护路径并征询是否同意。

### 会见笔录检查清单

**内容**

- 表明身份并询问是否同意辩护。
- 告知法律援助无偿性质（A类）。
- 告知权利义务。
- 解释涉罪构成及量刑幅度，不空白、不模板化略写。
- 核实案件主要事实、情节、证据材料，问题具体可核验。
- 听取陈述、辩解后有针对性法律解答。
- 风险及法律后果与本案事实绑定。
- 沟通辩护方案并征询辩护意见。
- 认罪认罚案件告知相关程序权利与法律后果。
- 审判阶段补充诉讼程序、审判组织、回避权等说明。

**形式与现场**

- 不删除模板原条目，只填充和补充。
- 会见时间、地点、会见人、记录人等抬头信息完整。
- 空白项按本地办案规范划线或留白。
- 每页签名、捺印、日期按归档规范执行。
- 涂改处按规范捺印或签注。

## 八、交付前自检清单

**流程**
- [ ] 逐部分撰写、逐部分确认，没有一次性生成全文

**结构**
- [ ] 「基本信息」未与文档抬头重复，从「一、基本情况」开始
- [ ] 「相关法律规定」位于第11项
- [ ] 辨认笔录包含他人对受援人的辨认
- [ ] 按模板结构填写，未改字段名称、未合并或拆分子项
- [ ] 表头只有阅卷时间、提请审查起诉时间、阅卷地点、涉嫌罪名

**内容**
- [ ] 供述归属正确
- [ ] 讯问字段（时间/地点/人员/页码）齐全
- [ ] 关键摘录完整
- [ ] 每次讯问后有【评价】
- [ ] 检察院阶段笔录只摘录与案件事实有关或有争议的内容
- [ ] 同案犯、证人摘录经过关联性筛选
- [ ] 语体符合法律文书要求，建议性语言不过强
- [ ] 模板提示语已删除
- [ ] 出生信息、前科、强制措施时间等基础事实与卷宗一致
- [ ] 未把「身份说明名单出现姓名」写成「已被直接指认」
- [ ] 区分了直接指认与间接指认（号位映射）
- [ ] 会见笔录有个案针对性问题和法律解答
- [ ] 第一部分未标页码；到案经过未写扣押物品
- [ ] 第七、八部分不重复
- [ ] 无空壳标题
- [ ] 第11部分无「相关法律文书」「综合评价」「待核实问题」
- [ ] 第12部分无「庭审策略」「量刑建议」

**页码与格式**
- [ ] 页码为真实卷宗页码，不是 OCR 行号
- [ ] 被辨认人身份情况说明页码已正确标注
- [ ] Word 全文仿宋_GB2312；字号分二号/小四号/四号三级
- [ ] 落款有承办人签字和日期
- [ ] 子标题用 1、2、3，不用（一）（二）（三）
- [ ] 无 Markdown 项目符号和分隔线残留

**提交版**
- [ ] 无未完成核查类表述（「需核对原件」「待核对」「经抽样辨识」「辨识存疑照卷面抄录」「待会见核实」「需向检察机关核实」「具结前应」「待核（标题）」等）
- [ ] 无工作流程痕迹（「渲染」「工作底稿」「汇总稿」「无文字层」「文本层」「OCR」「以超大文件方式」）
- [ ] 无文件名式引用（如「补充侦查工作卷20260731第5页」应为「补查卷一第5页」；不引用 PDF/txt/docx 文件名）
- [ ] 提交版和自用版都已输出；只出提交版的，剥离要点已另行留存
- [ ] 整段删除后编号连续，无跳号、重号
- [ ] 未误删保留例外内容
- [ ] 未核验的文号未写入
