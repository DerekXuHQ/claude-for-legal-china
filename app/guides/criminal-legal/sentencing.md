对已认定构成犯罪的个案，按"量刑起点 → 基准刑 → 各情节按比例调节 → 拟宣告刑 → 缓刑判断"的顺序，给出可解释、可复核的刑期测算和量刑建议参考。量刑不是纯数学运算，而是在罪责刑相适应原则统摄下，把法定刑幅度、案件事实和各量刑情节折算为相对合理的刑罚区间。

## 适用情形

- 估算具体案件的刑期区间，评估自首、累犯、未遂、从犯、认罪认罚等情节的调节幅度。
- 为量刑建议、认罪认罚协商、量刑辩护意见提供测算底稿。
- 不适用于无罪辩护策略、证据审查、程序咨询、单纯法条检索。认罪认罚的协商策略另见「认罪认罚协商策略意见书」。

## 总则与高风险提示（先读）

- 测算结果只是**参考**，最终刑罚由法院在法定刑幅度内依法裁量；任何结论都不构成对裁判结果的承诺。
- 所有量刑幅度、起点刑取值、调节比例，**必须注明所依据的条文或量刑指导意见/实施细则**，并以现行有效规定及办案地最新细则核实；不同地区、不同时期的标准存在差异。
- 涉及具体百分比、起点取值的，**一律给区间而不给单一确定数**，并说明取值理由。
- **绝不臆造**任何条文、比例或数额标准。规则不明、案情要素缺失的，明确列为待补充或待核实，不得用假定数据掩盖空缺。
- 调节比例不能绝对化，须一案一议；同一情节在不同案件中的从宽/从严幅度可能不同。

## 需要准备的材料

- 罪名及对应法定刑幅度。
- 办案地是否有专门的量刑实施细则。
- 犯罪数额、次数、危害后果。
- 全部量刑情节：犯罪形态、共犯地位、主体责任能力、自首、坦白、立功、累犯、退赃退赔、和解谅解、认罪认罚等。

## 办理步骤

严格按五步顺序进行，不跳步。每一步先确认所需事实是否齐备，缺失的先补充。

### 第一步：确定量刑起点

量刑起点只依据该罪名**基本犯罪构成**对应的法定刑幅度确定，是"裸刑"，**不考虑**自首、立功、退赃、认罪认罚等任何具体情节。

1. **裸刑**：起点只反映基本构成，不掺入具体情节。
2. **取点**：在法定刑幅度内选定一个具体数值（而非区间），便于后续折算；通常落在幅度的**中段偏下**至接近下限处。
3. **依据**：有量刑指导意见或办案地实施细则规定的，按其规定；没有明确规定的，依基本构成事实在法定刑幅度内合理取点，并说明理由。
4. 先确认：罪名、对应法定刑幅度、是否有专门的量刑细则。

### 第二步：确定基准刑

基准刑 = 量刑起点 + 增加刑罚量。在起点基础上，根据本案**犯罪数额、犯罪次数、危害后果**等影响犯罪构成的事实增加相应刑罚量。

- 量刑起点只含基本构成；基准刑纳入本案具体的数额/次数/后果。
- 增加刑罚量的换算标准通常由办案地实施细则规定，须查阅**办案地最新细则**并注明出处；没有细则的，按比例合理估算、说明理由并给区间。

### 第三步：以各量刑情节按比例调节基准刑

核心环节，分两轮：先连乘类情节，后加减类情节。

**第一轮：连乘类情节**（多为影响罪责的修正情节）

- 犯罪形态：预备、未遂、中止；
- 共同犯罪地位：从犯、胁从犯、教唆犯；
- 主体/责任：未成年人、已满七十五周岁的人、限制责任能力人、又聋又哑或盲人；
- 正当化事由过当：防卫过当、避险过当。

公式（逐项相乘）：

```
B = 基准刑 × (1 − a₁%) × (1 − a₂%) × …
```

各 a 的取值须注明所依情节的法定从宽幅度（如未遂"可以从轻或减轻"、从犯"应当从轻、减轻或免除"等）及对应指导意见，给区间。

**第二轮：加减类情节**（一般从宽/从严情节）

自首、坦白、立功、累犯、当庭认罪、退赃退赔、刑事和解、赔偿谅解、**认罪认罚**等。

公式（同向相加、逆向相减后一次性作用于 B）：

```
C = B × (1 − 从宽合计% + 从严合计%)
  = B × (1 − m₁% − m₂% … + n₁% + n₂% …)
```

- 从宽情节（自首、坦白、立功、退赃、和解、谅解、认罪认罚等）→ 减少比例；
- 从严情节（累犯、累罚、对象特殊等）→ 增加比例；
- **认罪认罚是具有相对独立性的从宽情节，单独计列，不得与坦白等重复评价或遗漏。**
- 每个比例都标注依据条文/指导意见，并给区间。

### 第四步：综合校准，得出拟宣告刑

前三步得到一个"点"或窄区间，还要整体校准：

1. **全案审视**：结合主观恶性、人身危险性、社会危害性，衡量计算结果是否相称。
2. **类案平衡**：参照同类案件的通常处理结果，避免畸重畸轻。
3. **特殊情形处理**（拟宣告刑始终受罪责刑相适应原则制约）：

| 情形 | 处理 |
|------|------|
| 计算值趋近于零或为负 | 校准至合理低值；具备条件的，考虑不起诉/免予刑事处罚 |
| 拟宣告刑低于法定最低刑，且**无**法定减轻情节 | 以法定最低刑为准 |
| 拟宣告刑低于法定最低刑，且**有**法定减轻情节 | 可按拟宣告刑确定 |
| 拟宣告刑高于法定最高刑 | 以法定最高刑为准（除非依法加重） |
| 数罪 | 先分别测算各罪，再依并罚规则合并 |
| 结果明显失衡 | 依罪责刑相适应原则回调并说明 |

要给"幅度型"量刑建议的，也应先得出中心点再上下浮动，不要一开始就用宽区间掩盖测算。

### 第五步：缓刑（及非监禁措施）判断

拟宣告刑确定后，单独判断能否适用缓刑或其他非监禁处理：

- **门槛**：核对刑种与刑期是否落入可宣告缓刑的范围（如一般为拘役、三年以下有期徒刑），注明所依条文及现行标准。
- **实质条件**：综合犯罪情节、悔罪表现、有无再犯危险、对所居住社区有无重大不良影响等判断。
- **排除情形**：核对是否属于依法不适用缓刑的对象（如累犯、犯罪集团首要分子等）。
- 结论分三档——可能适用 / 不宜适用 / 需进一步评估，说明理由和待核实事项；最终是否适用由法院裁量。

## 文书结构

**一、案件基本信息**
- 罪名、法定刑幅度、是否有可适用的量刑细则、办案地。

**二、五步测算过程**

```
第一步 量刑起点：【取值/区间】  依据：【条文/细则；取点理由】
第二步 基准刑：【值/区间】 = 起点【值】 + 增加刑罚量【值】  依据：【数额/次数/后果换算出处】
第三步 调节基准刑：
  连乘类情节：【逐项列情节+比例区间+依据】
    B = 基准刑 × (1−a₁%) × (1−a₂%) … = 【B 区间】
  加减类情节：【逐项列情节+比例区间+依据，认罪认罚单列】
    C = B × (1 − Σ从宽% + Σ从严%) = 【C 区间】
第四步 综合校准：【全案/类案判断；特殊情形处理】
       拟宣告刑：【刑种 + 刑期区间】
第五步 缓刑判断：【可能/不宜/待评估】 + 理由 + 待核实项
```

**三、风险提示与待核实事项**
- 须确认或补充的事实、数额、情节。
- 各比例、起点取值所依规定可能因地区/时间不同而有差异，以现行有效规定核实。
- 本测算为参考，最终量刑由法院依法裁量。

## 测算示例

以下数值仅演示折算方法，**不是真实标准**；实际办案中所有比例和起点都须以现行规定及办案地细则核实。

**示例一：盗窃（仅加减类情节）**
- 案情：盗窃数额较大，有自首，认罪认罚，初犯。
- 第一步 起点：法定三年以下，中段偏下取约 9 个月（依细则核实）。
- 第二步 基准刑：按超出"数额较大"部分换算增加，约 18 个月（依办案地细则区间）。
- 第三步：无连乘类情节，B≈18 个月；自首（约减 20%–30%）＋认罪认罚（约减 10%–20%），C ≈ 18 ×(1−0.30…−0.15) ≈ 10–12 个月。
  - 注意：依《关于常见犯罪的量刑指导意见（试行）》（法发〔2021〕21号），认罪认罚与自首、坦白、退赃退赔、赔偿谅解等情节**不作重复评价**，兼具时整体一般可减少基准刑60%以下〔待核〕。这里分列相加只为演示公式，实际测算须按不重复评价规则合并评估。
- 第四步：参照类案，落在合理区间，拟宣告刑约有期徒刑 10–12 个月。
- 第五步：刑期在缓刑可考虑范围，结合悔罪与再犯危险，结论为"可能适用缓刑，待社区影响评估核实"。

**示例二：故意伤害（连乘＋加减情节）**
- 案情：致轻伤，系从犯，犯罪未遂，自首，已赔偿取得谅解。
- 第一步 起点：致轻伤、三年以下，取约 12 个月。
- 第二步 基准刑：按伤害后果增加，约 18 个月。
- 第三步：连乘类——从犯（约减 20%–40%）×未遂（约减 20%–40%），B ≈ 18×0.7×0.7 ≈ 8.8 个月（取中值演示）；加减类——自首（约减 20%–30%）＋赔偿谅解（约减 20%–30%），C ≈ 8.8×(1−0.4…) ≈ 5–6 个月。
- 第四步：拟宣告刑约 5–6 个月，未低于法定最低刑，无需特殊回调。
- 第五步：短期自由刑，结合谅解与再犯危险，结论为"可能适用缓刑，待评估"。

**示例三：测算值趋零**
- 案情：交通肇事致轻伤，自首、赔偿谅解、认罪认罚，从宽情节叠加致计算结果趋近于零。
- 第三步结果趋零；第四步校准时，具备条件的考虑相对不起诉（审查起诉阶段）或免予刑事处罚（审判阶段），并说明判断依据与待核实事项。

## 法律依据

- 最高人民法院、最高人民检察院《关于常见犯罪的量刑指导意见（试行）》（法发〔2021〕21号）〔待核〕
- 办案地高级人民法院量刑实施细则（按案件所在地适用）
