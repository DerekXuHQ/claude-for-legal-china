审查起诉阶段，辩护律师向检察院提交不起诉法律意见书。覆盖**法定不起诉**、**存疑不起诉**、**酌定不起诉**三类。涉案企业合规不起诉另行处理。

**脱敏前置（不可跳过）**：所用的案件材料、阅卷材料、卷宗一律为已脱敏副本。发现未脱敏的真实姓名、身份证号、联系方式、案号、卷宗原文或照片，立即停止，先脱敏。文书模板中的【姓名】【案号】等占位符保持占位，由律师在本地定稿时填入真实信息。

## 工作原则

1. **辩护立场贯穿全程**：始终从有利于犯罪嫌疑人的角度论证，不反向评价当事人行为。
2. **独立判断**：独立分析证据是否达到起诉标准，不盲目顺从指控逻辑，不迎合侦查结论。
3. **每轮有实质进展**：初步判断、要点草稿、正式文书，逐步推进，不兜圈子。
4. **记录讨论**：与律师确认的每一项要点记录在案，便于后续接手续办。
5. **确认后定稿**：论证要点草稿经律师明确确认后，才出具正式文书。

## 案件类型区分

首先确认 A/B 类型，它决定文书抬头和说明方式。

| 类型 | 委托关系 | 抬头写法 |
|------|----------|----------|
| **A 类（法律援助）** | 法律援助中心指派，受援人 | 法律援助辩护人：【姓名】，法律援助中心：【名称】 |
| **B 类（委托）** | 委托人/当事人直接委托 | 辩护人：【姓名】（执业律师），律师事务所：【名称】 |

## 需要准备的材料

- 阅卷笔录（优先）；没有的，至少要有证据目录或案件摘要。
- 核查：案由、指控事实、关键证据清单、当事人基本情况。

## 三类不起诉的依据与论证框架

### 法定不起诉（刑诉法第177条第1款）

**适用情形**（满足其一即可）：
- 情节显著轻微、危害不大，不认为是犯罪
- 犯罪已过追诉时效期限
- 经特赦令免除刑罚
- 告诉才处理的犯罪，没有告诉或撤回告诉
- 犯罪嫌疑人死亡
- 其他法律规定免予追究刑事责任

**论证重点**：直接论证行为本身不构成犯罪，或存在阻却追究的法定事由。无须进入证据分析层面，重点在法律适用。

**四层展开**：
- 事实层面：还原行为本质，指出与犯罪构成要件的偏差。
- 证据层面：指出现有证据支持"情节显著轻微"的证明方向。
- 法律适用层面：援引刑法相关条款（如第13条但书）、司法解释。
- 刑事政策层面：宽严相济，不宜动用刑罚手段。

### 存疑不起诉（刑诉法第175条第4款）

**适用情形**：退回补充侦查后，证据仍不足，不符合起诉条件。

这是技术性最强的类型，论证须精准到证据编号和页码。

1. **全面梳理证据体系**：列出指控所依赖的全部证据（按编号），标注每份证据的来源、形成时间、提取方式。
2. **逐一指出证据缺陷**：
   - 直接证据缺失（无书证/物证/视频）；
   - 言词证据不稳定（多次供述矛盾，指明具体页码）；
   - 鉴定意见程序违规或结论存疑；
   - 证人证言孤证且利益相关；
   - 电子数据取证程序瑕疵。
3. **定位证据链断点**：明确"指控事实→客观行为→主观故意"哪个环节缺证，用表格呈现：

| 待证事实 | 现有证据 | 缺陷描述 | 能否补正 |
|----------|----------|----------|----------|
| （填入） | （填入） | （填入） | 否 |

4. **排除合理怀疑论证**：提出有利于嫌疑人的另一种合理解释，论证现有证据无法排除该解释。
5. **论证补充侦查无法补正**：说明关键证据已客观灭失、从未存在或无法重建。

### 酌定不起诉（刑诉法第177条第2款）

**适用情形**：犯罪情节轻微，依照刑法规定不需要判处刑罚或者免除刑罚。

论证重在"人"的情况，结合当事人具体情形展开。

**犯罪情节轻微的认定**：
- 犯罪手段、危害后果、涉案金额均处于轻微范围；
- 与同类案件相比处于最低风险区间。

**有利量情情节**（逐项核查，符合的展开论证）：
- [ ] 初犯、偶犯（无前科劣迹）
- [ ] 如实供述、认罪认罚
- [ ] 积极退赃、赔偿损失
- [ ] 取得被害人谅解（附谅解书）
- [ ] 社区矫正条件成熟（有固定居所、家庭监督）
- [ ] 主观恶性小（被动参与、受人指使、认知偏差）
- [ ] 社会危险性低（无再犯可能性依据）

**刑事政策角度**：
- 宽严相济刑事政策的具体适用；
- 认罪认罚从宽制度（刑诉法第15条）；
- 社区矫正作为替代性措施的可行性；
- 起诉必要性缺失（社会效果、教育改造目标已实现）。

## 办理步骤

### 1. 读取案卷材料

优先使用阅卷笔录；没有的，取得证据目录或案件摘要。核查案由、指控事实、关键证据清单、当事人基本情况。

### 2. 判断不起诉类型

按以下格式给出初步判断，交律师确认：

```
【不起诉类型判断】
初步建议类型：【法定/存疑/酌定】
依据：【简述理由，2-3条】
如兼有多类型适用：【并列说明，建议主辅】
请律师确认类型后进入论证阶段。
```

### 3. 论证要点草稿

- 按所选类型展开四层论证。
- 存疑不起诉附证据缺陷分析表；酌定不起诉附量情情节核查表。
- 所有法条先标〔待核〕，经权威法规数据库核验后去除。
- 结尾附类案索引（如有支持性案例），见下文"类案检索"。

### 4. 律师确认后出具正式文书

- 律师明确确认后出具 Word 文件。
- 命名：`不起诉法律意见书_【案件代号】_【案由】_【日期】.docx`，保存在案件目录的输出文件夹。
- 需要时制定提交与跟进计划，见下文。

## 类案检索（按需）

在意见书中嵌入相似不起诉案例，以同类处理倾向增强说服力。在论证要点草稿与正式文书之间按需使用。

1. **检索**：在权威案例数据库检索与本案**罪名、情节、证据态势**相似的不起诉案例，优先匹配同罪名＋同不起诉类型。
2. **提炼**：每个类案提取四要素——案号/作出决定的检察院；与本案的关键相似点（罪名、情节、证据特征）；不起诉类型与核心理由；处理结果。
3. **嵌入**：以摘要表附在意见书末尾、结论之前。

**红线**：
- 类案必须真实，全部经检索获得并核验；核验前一律标〔待核〕。
- 严禁编造案例：没有检索结果的，如实写"暂未检索到高度相似类案"，不得虚构案号或裁判要旨。
- 注明检索日期和来源，并标明本索引仅供参考、不作为正式法律依据。

```
类案参考索引（检索日期：【YYYY-MM-DD】，来源：【数据库名称】）：
| 案例编号 | 相似点 | 不起诉类型 | 不起诉理由要旨 |
|---------|-------|-----------|--------------|
| 【X检不诉〔20XX〕X号】 | 同为【罪名】、初犯、已退赔 | 酌定不起诉 | 情节轻微+认罪悔罪+取得谅解 |
（本索引仅供参考，不作为正式法律依据）
```

## 提交与跟进计划（按需）

把"提交意见"从单点动作变成可执行、可追踪的流程：

1. **提交时机**：明确最佳提交节点并说明理由（如退回补充侦查重报后证据缺陷凸显时、审查起诉期限届满前为检察官预留决策空间时）。
2. **提交方式**：书面意见书正式提交＋申请当面沟通，双轨并行。
3. **跟进节点**：制定提交后的跟进时间表，每次与检察官沟通记录**时间/对象/核心观点/对方反馈**，形成沟通日志。
4. **口头沟通提纲**：从书面论证中提炼 3-5 个最有力的点，改写成口头表达版，供当面或电话沟通时直接陈述。

```
《不起诉意见提交与沟通计划》
- 提交对象：【检察院名称】人民检察院 公诉部门 【检察官】
- 最佳时机：【判断 + 理由】
- 提交方式：书面意见书 + 申请当面沟通
- 跟进节点：提交后3日电话确认收悉，【日期】预约面谈
```

## 质量红线

| 红线 | 处理方式 |
|------|----------|
| 存疑不起诉未引用具体证据编号/页码 | 不出稿，先补充阅卷笔录 |
| 法条未经核验即引用 | 统一标〔待核〕，核验完成前不出具正式文书 |
| 律师未确认即出具正式文书 | 禁止，只出草稿 |
| 意见书出现不利于当事人的表述 | 立即标出，请律师确认删改 |
| A类案件未注明法援机构信息 | 不出稿，先补充 |

## 法律依据

- 《中华人民共和国刑事诉讼法》第15条、第175条第4款、第177条第1款、第177条第2款
- 《中华人民共和国刑法》第13条
