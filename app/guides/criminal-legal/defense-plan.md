本篇是阅卷、证据分析与辩护词撰写之间的决策环节，只回答一个问题：**这个案子主攻哪个方向、为什么、备选是什么**。产出物是《辩护策略分析与路径选择报告》。对脱敏案情做罪与非罪、此罪与彼罪的法理分析，见《罪与非罪、此罪与彼罪辩护分析》。

本篇改编自 gcheng001/legal-skills 的 criminal-defense-strategy（MIT 许可，Copyright (c) 2026 高澄）。

## 适用情形

- 已有阅卷笔录，需要系统梳理辩点、评估强度、选择主攻路径。
- 制作辩点矩阵、比较策略方案。

## 需要准备的材料

- **阅卷笔录**（必备）：证据清单、证据编号、事实梳理、初步辩点线索。
- **会见笔录**（有则用）：当事人陈述、认罪态度、对指控的异议。没有的，在报告中注明「暂无会见笔录，部分辩点待会见核实」。
- 案件类型：A类（受援人 / 法律援助）或 B类（委托人 / 当事人）。报告中对当事人的称谓与类型一致。
- 所有材料均为已脱敏副本；模板中的【姓名】【案号】保持占位。

## 办理原则

1. **辩护贯穿全程**：策略须标注适用的诉讼阶段，并预判进入下一阶段后的变化。
2. **独立评估**：逐个独立评估辩点强度，不顺着预设结论走。律师认为是强辩点但证据或法律支撑不足的，直接写明「强度弱/不建议主攻」；辩点不成立、自相矛盾或会反噬其他辩点的，当场说明。独立不等于对抗：意见要真实，最终决策权归律师。
3. **当场解决问题**：证据编号对不上、法条不确定、辩点归类有歧义，当场查证或追问，不把模糊带进下游文书。
4. **完整记录讨论**：辩护方向是重大决策。讨论过程（争议点、评估意见、律师反馈、最终取舍理由）记入案件备忘录；讨论超过 3 轮即落盘记录。
5. **确认后定稿**：主攻路径经律师确认后报告才能定稿；确认前只出「讨论稿」，标注「待律师确认」。

## 分析工具

### 工具一：辩点矩阵

把阅卷中发现的**所有**辩点按三个维度归类，一个辩点一行，不遗漏、不合并稀释。

- 维度一（目的）：无罪辩点 / 罪轻辩点
- 维度二（性质）：实体辩点 / 程序辩点
- 维度三（层面）：事实层面 / 法律层面

| 辩点编号 | 辩点描述 | 类型(无罪/罪轻) | 性质(实体/程序) | 层面(事实/法律) | 支撑证据编号 | 强度评级 |
|---------|---------|----------------|----------------|----------------|------------|---------|
| D1 | （简明描述该辩点主张什么） | 无罪 | 实体 | 事实 | Z3、Z7、讯问笔录第2次 | 强 |
| D2 | … | 罪轻 | 程序 | 法律 | Z12 | 中 |
| … | … | … | … | … | … | … |

填表规则：

- **辩点编号**：D1、D2……全程稳定，下游文书以此引用。
- **支撑证据编号**：必须回填阅卷笔录中的证据编号（如 Z1、Z2……）或具体笔录名称。无证据支撑的辩点不进正表，放入「待核实线索」附表并注明。
- **层面**：事实层面（证据能否证明指控事实）/ 法律层面（即使事实成立，定性和法律适用是否正确）。跨层面的取主要层面，必要时拆成两行。
- 程序辩点（非法证据、管辖、超期羁押、未保障辩护权）即使不直接导致无罪也要入表，因其影响证据能力与量刑。

### 工具一补充：辩点发散（可选）

启用条件（满足其一）：①辩点矩阵不超过3条且定罪风险偏高；②律师对现有辩点不满意；③疑难新型案件。

按顺序做四步：

1. **静默复盘**：不查法条、不写文书，走读案情时间线，记下直觉疑点。
2. **种子回顾**：回顾以往归档的「难受点」规律。
3. **三行话原型**：每个候选辩点用三行写清——事实锚点、法律依据、攻击对象。
4. **跨界类比**：迁移其他部门法的裁判逻辑；类比所用案例须核验为真实案例。

约束：

- 发散产物不直接进正表：有证据支撑的按规则入表，其余入「待核实线索」附表，注明来源（静默复盘/种子/类比）。
- 三行话写不出的辩点不入任何表，说明还没想清楚。
- 对当事人利益没有增量的辩点不入清单；有反噬风险的当场写明劝阻。
- 发散结论交律师确认，不自动进入下游文书。

### 工具二：辩点强度评估

| 评级 | 标准 | 在策略中的角色 |
|------|------|--------------|
| **强** | 有明确法律依据，或证据存在硬伤（关键证据缺失/非法/矛盾），大概率被采纳 | 可作为主攻方向 |
| **中** | 存在合理争议，需充分论证，采纳与否取决于法庭裁量 | 主攻或重点配合 |
| **弱** | 仅属酌情情节，或证据/法律支撑薄弱，难以独立成立 | 仅作补充，不建议主攻 |

- 每个评级都要写依据，并关联具体证据编号或法律条文，不写「我认为比较强」之类的空话。
- 评为「弱」的，写明「强度弱/不建议主攻，理由：……」；律师主张但评估不成立的，写明「经独立评估，该辩点不成立/有反噬风险，理由：……」。
- 评级与类型、层面联动：无罪 + 法律层面 + 证据硬伤 = 最高价值组合；罪轻 + 事实层面 + 酌情 = 补充级。

### 工具三：定罪风险评估

在选择路径前，明确给出三档之一并说明依据：

- **大概率定罪**：依据……（证据扎实点）
- **有争议**：依据……（争议焦点）
- **有可能无罪**：依据……（致命缺陷）

判断须由「控方证据强度总评 + 强级辩点分布」共同推出。

### 工具四：辩护策略选择树

```
定罪风险评估
├─ 有可能无罪（控方证据链断裂 / 关键证据非法 / 核心构成要件缺失）
│   → 路径A：无罪辩护
│      · 触发条件：存在"强"级无罪辩点，且控方证据强度评为"弱"
│      · 核心动作：攻击证据链完整性、申请排除非法证据、否定构成要件
│      · 后续文书：不起诉意见书（审查起诉阶段）/ 一审无罪辩护词（审判阶段）
│
├─ 定性有争议（构成此罪而非彼罪 / 此情节而非彼情节）
│   → 路径B：定性辩护（轻罪辩护）
│      · 触发条件：事实基本成立，但罪名认定/数额认定/主从犯认定存在"强"或"中"级争议
│      · 核心动作：论证应适用更轻罪名或更轻情节，重构法律评价
│      · 后续文书：轻罪辩护词（必要时配合认罪认罚就轻罪协商）
│
└─ 大概率定罪（证据扎实、构成要件齐备、无重大程序瑕疵）
    → 路径C：量刑辩护
       · 触发条件：无"强"级无罪/定性辩点，控方证据强度评为"强"
       · 核心动作：最大化法定/酌定从轻减轻情节，争取认罪认罚从宽
       · 后续文书：认罪认罚从宽意见书 / 罪轻辩护词
```

每条路径都写明三要素：触发条件、核心动作、后续文书。

### 工具五：主方案与备选方案

此处「主方案/备选方案」与当事人「A类/B类」是两个概念，报告中用词区分。

- **主方案**：基于最可能的庭审情形，当前证据态势下的最优主攻路径 + 配合辩点组合。
- **备选方案**：预设庭审变数触发后的切换路径。典型变数：
  - 申请排除的关键非法证据未被排除、被采信；
  - 关键证人当庭翻证或新增不利证言；
  - 出现新证据、补充侦查改变证据态势；
  - 当事人当庭改变认罪态度。
  每个变数写成「若发生 → 则切换到路径X / 启用辩点Dn」。

### 工具六：量刑预估（参考算法）

结果须标注「参考算法，律师可调整」。

```
预估宣告刑 = 基准刑 ×（1 ± 从重/从轻调节比例）± 酌定调节
```

1. 定基准刑：按罪名、数额/情节对应的法定刑幅度，取中值或下限。
2. 列法定从重、从轻、减轻情节，分别标注调节比例。比例依据《关于常见犯罪的量刑指导意见（试行）》（法发〔2021〕21号）第三部分：自首可以减少基准刑40%以下、从犯应当减少20%–50%、未遂可以比照既遂减少50%以下、一般立功可以减少20%以下、重大立功可以减少20%–50%（以上比例已对照该意见全文核对，来源：最高人民法院网站发布稿、晋江市人民政府网站转载全文）。各地实施细则另有细化，具体测算以办案地细则为准。
3. 列酌定情节（退赃、赔偿、谅解、认罪态度、有无前科）。
4. 计算综合区间，给出预测刑期；低于法定最低刑的，以法定最低刑为底。

量刑预估写入报告第1部分或第7部分作为辅助，供判断路径C的预期收益。

## 办理步骤

1. **整理上游材料**：读阅卷笔录（证据清单、证据编号、事实梳理、辩点线索）和会见笔录（如有）；确认当事人类型与诉讼阶段。
2. **提取辩点并独立评估**：穷举所有辩点并编号 D1…Dn；填辩点矩阵并回填证据编号；满足条件的先做辩点发散；逐个评级并写依据；标注弱辩点、不成立辩点、有反噬风险的辩点；完成定罪风险评估和策略选择树草稿。
3. **与律师讨论**：展示矩阵、强度评估、定罪风险和选择树草稿，主动提出推荐的主攻路径及理由，指出不建议主攻的辩点。律师有不同意见时，再次依据证据和法律评估，能让步则让步，不能让步则坚持并说明。讨论超过 3 轮的，记入案件备忘录。
4. **确认后定稿**：律师明确确认主攻路径后，生成7部分完整报告；文件名不使用冒号等非法字符，时间用短横线；在案件备忘录追加「辩护方向决策」条目（决策结论 + 关键理由 + 确认时间）。

## 文书结构：《辩护策略分析与路径选择报告》

**报告头部**：案件名称、案号（如有）、当事人类型（A类/B类）、诉讼阶段、上游材料来源（阅卷笔录/会见笔录）、报告状态（讨论稿/已确认定稿）、日期。

正文7部分，顺序固定：

1. **案件证据态势总评**：控方证据强度评定为强/中/弱，给出整体判断（证据链是否完整、关键环节是否扎实）。
2. **辩点矩阵**：全部辩点归类表，附「待核实线索」附表（如有）。
3. **辩点强度评估**：逐辩点评级 + 依据 + 证据/法条支撑；弱辩点与不成立辩点显式标注。
4. **定罪风险评估**：三档判断之一 + 依据。
5. **辩护策略选择树**：主攻路径 + 选择理由（含三要素）。
6. **主方案与备选方案**：主方案 + 备选方案及变数应对。
7. **与后续文书的衔接**：下一步应制作哪份文书（不起诉意见书、辩护词、认罪认罚从宽意见），主打哪几个辩点编号，需要补强哪些证据和论证。

## 检查清单（定稿前）

- [ ] 每个辩点都关联了证据编号或法律条文
- [ ] 引用的法条全部经权威来源核验；未核验的标注〔待核〕，不以未核实法条支撑结论
- [ ] 无罪辩点与量刑辩点并存时，写明并列逻辑（如「主张无罪为第一顺位，量刑情节为退而求其次的备位辩护，二者不冲突」），不自相矛盾
- [ ] 站不住的辩点已标注「强度弱/不建议主攻」或「不成立」
- [ ] 定罪风险评估有明确三档判断和依据
- [ ] 选择树每条路径写齐触发条件、核心动作、后续文书
- [ ] 备选方案覆盖至少一种关键庭审变数
- [ ] 第7部分指明了后续文书及主打的辩点编号
- [ ] 报告状态正确（未确认 = 讨论稿，已确认 = 定稿）
- [ ] 重大讨论已记入案件备忘录

## 与后续文书的衔接

| 主攻路径 | 后续文书 |
|---|---|
| 路径A（无罪） | 不起诉意见书（审查起诉阶段）/ 无罪辩护词（审判阶段） |
| 路径B（定性/轻罪） | 轻罪辩护词 |
| 路径C（量刑） | 认罪认罚从宽意见 / 罪轻辩护词 |

本报告是后续文书的决策依据。起草后续文书时，先读本报告的主攻路径和辩点矩阵，按指定的辩点编号展开论证。
