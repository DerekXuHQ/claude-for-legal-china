就中国法争点形成可追溯的研究备忘录，包括相反观点和行动建议。只核对单个法条真伪的，见「法源与版本核验」。

## 需要准备的材料

- 代表谁、为谁决策、法律时点、备忘录用途。
- 已知事实和相关材料。

## 办理步骤

1. **拆解问题**：把开放问题拆成"法律关系—请求/抗辩—要件—待证事实—来源"的问题树，列出未经证实的假设。
2. **三轮检索**（逐个争点）：精确依据；同义词、上下位概念补漏；相反观点与冲突。每轮记录检索途径、日期、检索式和来源编号。
3. **核验**：关键规范按「法源与版本核验」的方法核验，类案按「类案检索与对比」的方法比较。官方原文与商业数据库摘要分层标注。
4. **成文**：先写条件化结论，再逐个争点展开（见下方结构）。
5. **控制结论**：关键依据缺失的，停止对应的确定性结论，不凭记忆填空。材料、事实、法律评价与程序状态四个层次分开写。

## 文书结构

1. 条件化结论。
2. 逐个争点：
   - 已知事实/待证事实；
   - 适用规则与效力；
   - 构成要件；
   - 证据与举证责任；
   - 对方最强论点；
   - 法律上成立与实际可执行的差别；
   - 程序与期限；
   - 风险和下一步。
3. 来源台账。
4. 未覆盖事项。
5. 核验日期。
6. 律师复核清单。
7. 十二模块状态表（见下）。

## 检查清单

用下列十二个模块的状态表逐项标为"适用""不适用"或"受阻"：适用的给出最低输出，不适用的给出具体理由，受阻的写明缺口与降级路径。

| 模块 | 关注内容 |
|---|---|
| 任务背景 | 任务目的、用途、委托人 |
| 法域与地域 | 适用法律、地区、法院层级 |
| 时间 | 事实发生日、分析截至日、规范版本时点 |
| 主体 | 当事人、角色、代表谁 |
| 事项 | 案件或事务本身 |
| 请求与要件 | 请求权/抗辩及其构成要件 |
| 法源与解释 | 规范、效力层级、解释与适用 |
| 证明 | 证据、待证事实、举证责任 |
| 程序 | 程序路径、期限 |
| 结果与执行 | 可能结果、可执行性 |
| 策略与不确定性 | 策略选择、风险、未决问题 |
| 治理 | 授权、保密、人工复核 |
