准备中国法律主题讲座、培训或公开分享时，建立来源包、案例清单和讲述提纲。只核对单个法条的，见「法源与版本核验」。

## 需要准备的材料

- 听众、时长、目的、地区、拟讲日期、是否公开传播。
- 已有的主题、议程和文案（予以保留）。
- 拟使用的个人实务案例：须先取得使用授权并脱敏，不得把案卷提交给商业数据库或在线服务。

## 办理步骤

1. **建立主张清单**：把主题拆为听众必须理解的法律问题、常见误区、示例与可执行动作。每项重要主张连接到原始法源或已核实的案例；记录规范版本、生效日与讲座日期的关系。
2. **核验**：法条按「法源与版本核验」的方法核验，案例按「类案检索与对比」的方法核验身份、状态与适用差异。政策解读与法律义务分开；未决草案、征求意见稿及商业数据库摘要显著标注，不写成现行法。
3. **成稿**：讲述提纲、来源台账、案例/示例使用状态、幻灯片建议、问答备选、讲前复核表。讲座日期前复查可能变化的法规和监管口径；无法核验的事实或数字从公开版删除，或保留但显著标注。
4. **授权**：公开发布、发送讲义、使用客户或第三方素材须另有授权。这里制作的只是供讲者审核的材料。

## 文书结构

- 讲述提纲
- 来源台账
- 案例/示例使用状态
- 幻灯片建议
- 问答备选
- 讲前复核表

## 检查清单

逐项检查下列十二个模块；与主题无关的模块说明理由；时效或案例授权受阻的，暂停对应内容。

| 模块 | 关注内容 |
|---|---|
| 任务背景 | 任务目的、用途、委托人 |
| 法域与地域 | 适用法律、地区、法院层级 |
| 时间 | 事实发生日、分析截至日、规范版本时点 |
| 主体 | 当事人、角色、代表谁 |
| 事项 | 案件或事务本身 |
| 请求与要件 | 请求权/抗辩及其构成要件 |
| 法源与解释 | 规范、效力层级、解释与适用 |
| 证明 | 证据、待证事实、举证责任 |
| 程序 | 程序路径、期限 |
| 结果与执行 | 可能结果、可执行性 |
| 策略与不确定性 | 策略选择、风险、未决问题 |
| 治理 | 授权、保密、人工复核 |
