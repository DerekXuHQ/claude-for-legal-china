最昂贵的认定决定，往往是没有人有意识地作出的：有人设想「找个劳务人员」，用工开始了，两年后事实看起来像劳动关系。本指引用于在安排开始前，对拟议用工安排适用劳动关系认定标准，区分劳动关系、劳务关系、承揽关系、派遣和外包，并指出所描述的事实与预定结构不符之处。各项认定标准、法律引用、门槛和例外，均以现行有效的研究结果为准。

## 适用情形

- 「想用一个人做承包商」「这是劳务关系还是劳动关系」「这个人的用工关系怎么认定」等，且用工**尚未开始**。

**先行门槛——用工是否已经开始？** 收集信息前先问：这项工作是否已经开始？该人员是否已在此安排下工作了任何时间（无论长短）？

如果已经开始，本指引不适用。分析既有关系不是规划工作，而是带补救性质的责任评估：补发工资（加班费、未休年休假工资）、未缴社会保险费、未付福利待遇、潜在行政罚款，以及继续用工的后续风险。该工作应由律师主导、与补救方案结合，建议同时咨询外部劳动法律师，并按公司上报规则上报（回顾性认定通常上报法务总监 + 外部劳动法律师）。

确需对既有安排做前瞻性分析用于规划（例如「如果今天重新设计这个安排，应如何考虑」）、且补救问题另有安排的，可以继续，但须明确：输出不是补救方案，不计算已发生期间的补发工资、罚款或社保风险，不替代重新认定风险评估，在被视为可靠之前须经律师确认。此时所有输出开头加注：

```
范围不匹配——本分析针对前瞻性用工安排，而此处的安排已经存在。本输出仅用于规划，
不是补救方案，不计算已有的补发工资/罚款/社保风险，不替代该事实情形所需的重新认定
风险评估。补救问题已按上报规则提交律师。
```

## 需要准备的材料

一次问齐，并说明每组问题要检验什么。答不上来的记为缺口，会影响分析：

**工作内容**

- 该人员实际每天做什么？
- 该工作是公司核心业务的组成部分，还是辅助性工作？（例如：软件公司的软件工程师 = 核心；律师事务所的IT服务人员 = 辅助性）
- 是有明确结束时间的限定项目，还是持续性无固定期限的工作？
- 技能的专门程度如何？是否具备公司团队不具备的专业能力？

**管理控制**

- 谁确定工作时间和安排——本人还是公司？
- 在哪里工作——公司办公场所、自行安排地点，还是均可？
- 公司是否指挥其如何完成工作（方法、流程、顺序），还是只要求最终成果？
- 是否管理公司的任何员工？

**经济从属性**

- 报酬如何计算——按小时、按天，还是按固定项目费？
- 公司是否提供设备、工具或软件，还是使用其自己的？
- 是否为其他公司工作，还是仅为此安排？
- 是否承担经营风险——能否获得超出约定费用的收益，或可能亏损？
- 是否已有自己的经营实体（有限责任公司、个体工商户等）？

**安排方式**

- 拟如何构建——直接劳务协议、劳务派遣，还是业务外包（公司对公司）？
- 如为劳务派遣：谁向劳动者支付报酬——派遣公司还是公司？谁负责日常管理？
- 是否有书面合同或模板？
- 大致持续多久——数周、数月、一年以上？
- 是否与公司员工一起从事类似工作？

**管辖地**

- 该人员实际在哪里提供劳动？

## 办理步骤

### 第1步：收集信息

按上列问题收集。已提供的信息不重复询问，只就缺口提问。

### 第2步：确定适用的认定标准

按管辖地和需要解决的问题，研究现行有效的劳动关系认定标准。核心依据：

**劳社部发〔2005〕12号《关于确立劳动关系有关事项的通知》**：

用人单位招用劳动者未订立书面劳动合同，但同时具备下列情形的，劳动关系成立：
（一）用人单位和劳动者符合法律、法规规定的主体资格；
（二）用人单位依法制定的各项劳动规章制度适用于劳动者，劳动者受用人单位的劳动管理，从事用人单位安排的有报酬的劳动；
（三）劳动者提供的劳动是用人单位业务的组成部分。

- **互联网平台用工**：参考《关于维护新就业形态劳动者劳动保障权益的指导意见》（人社部发〔2021〕56号），区分「劳动关系——不完全符合劳动关系情形——个人依托平台自主经营」三类。
- **劳动关系与劳务关系**：劳务关系适用《民法典》合同编，不受《劳动合同法》调整。
- **劳动关系与承揽关系**：承揽关系适用《民法典》第770条以下（承揽合同），定作人不承担劳动法下用人单位义务。

公司有内部用工认定政策的，先适用该政策，并标出与研究标准之间的冲突。

检索结果很少或没有结果的，如实报告已找到的内容，由律师决定是扩大检索、换用其他来源，还是标为未经核实；不得用未经核实的内容填补空白。每条引用注明来源，来自记忆或网络检索的引用须优先核验。

### 第3步：把标准逐项适用于事实

对每个适用标准逐项评分，不要概括——律师需要看到哪些要素没问题、哪些有问题。要素按研究确定的标准填写：

```
认定标准：【标准名称】
适用问题：【该标准判断什么——劳动关系/劳务关系/承揽关系】
来源：【法规/文件的具体位置】
时效：【核实日期】

| 要素/要件 | 收集的事实 | 倾向/通过-不通过 |
|---|---|---|
| 【要素1】 | 【事实】 | 【倾向或通过/不通过】 |
| 【要素2】 | 【事实】 | 【倾向或通过/不通过】 |

标准结构：
【该标准如何权衡各要素——例如三要素须同时满足才成立劳动关系，或某一要素权重较大】

该标准下的结论：
【支持劳动关系 / 不支持劳动关系 / 要素X不满足 / 不确定——存在争议的要素】
```

对每个适用标准重复。某些要素在司法实践中争议较大、高度依赖事实，须明确指出，不要掩盖；标准的存在不等于其在本案事实上的适用是确定的。

### 第4步：作出认定并找出差距

**认定结论**——拟议安排最准确的性质：

- **劳动关系（签劳动合同）**：事实支持在一个或多个适用标准下构成劳动关系。
- **劳务关系（签劳务协议）**：事实支持在所有适用标准下构成劳务关系。
- **派遣用工**：劳动者在派遣公司名下，实际用工单位是客户——实际用工单位实施日常管理的，存在混同用工/事实劳动关系风险。
- **业务外包（公司对公司）**：劳动者由外包公司雇佣——事实支持的，是最清晰的结构。
- **不确定/临界**：事实在一个或多个标准下正反皆有——说明是哪个标准、为什么。

不同问题上结论不同的（例如社保角度可辩解为劳务关系，但劳动报酬角度认定为劳动关系），明确说明，并指明起决定作用的问题和管辖地。

**差距分析**（最重要的输出）——把预定结构与事实实际支持的内容对比：

```
预定结构：【委托方想要的结构】
事实指向：【按研究标准，实际是什么】

差距：
【重大风险】【要素】：所描述的【内容】与【预定分类】冲突，因为【标准原文 + 引用】。
           按描述进行，存在重大认定风险。
【较弱点】【要素】：在【标准】下是较弱点。单独不构成否定，与其他因素结合则增加风险。
【无问题】【要素】：支持【预定分类】。
```

**上报触发**（出现任一情形，或公司规定的其他情形，按上报规则处理）：

- 拟议工作为公司核心业务且标准严格——未经律师审查不得继续；
- 公司有先前认定争议或行政处罚记录——提高审查标准；
- 劳动者将管理员工或具有重大预算权限；
- 安排预计超过12个月且无明确项目终止点；
- 存在结果会改变认定结论的争议要素。

## 常见风险

错误认定可能使企业面临补缴社会保险费、支付加班费和未休年休假工资、承担工伤保险责任以及行政处罚的风险。外包中由公司直接指挥、考勤、考核外包人员的，可能被认定为假外包、真派遣或直接劳动关系。

## 作出结论前的律师审核

经办人不是律师的，作出「可以按劳务关系/劳动关系/派遣/外包进行」的结论前，须经律师审查。提交律师时附上：

- 用工安排（工作、管理、经济从属性、结构）；
- 适用了哪些认定标准；
- 逐标准分析结果、条文引用和时效；
- 差距分析，突出问题要素；
- 未解决的问题和未确定事项；
- 可能的风险（此安排最可能在哪个认定理由上失败；是否叠加先前行政处罚/争议）；
- 需要问律师的问题（能否按劳务关系处理；改为派遣或外包能否消除风险；需要哪些合同条款支持认定）。

需要寻找律师的，可联系当地律师协会或拨打 12348 法律援助热线。

本分析适用收集信息时确定的管辖地。各省认定实践可能存在差异，认定逻辑也可能因问题类型（社会保险、劳动报酬、工伤保险）而不同；工作地变化或新增认定问题的，分析可能不适用。

## 不在本指引范围内

- 分析既有关系——仅限前瞻性分析。
- 起草劳务协议或外包服务合同。
- 就已发生的错误认定提供补救建议。
- 替代临界案件的外部律师意见——标准严格、要素争议大或先前有行政处罚的，用工开始前均应经人工审查。
