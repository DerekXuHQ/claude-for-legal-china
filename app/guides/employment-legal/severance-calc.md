根据工作年限、工资水平与离职情形，分步测算劳动者解除或终止劳动关系时可主张的各项款项：经济补偿金（N）、违法解除赔偿金（2N）、代通知金（N+1）、未签书面劳动合同二倍工资、加班费、未休年假工资折算。

测算结果是参考，用于估算区间、厘清计算逻辑，不是正式法律意见；各地裁判口径、基数认定与封顶标准存在差异，最终金额以仲裁裁决或法院判决为准。

## 适用情形

- 估算离职时的经济补偿、赔偿金或其他应付款项。

**不适用**：是否构成违法解除、工伤认定、竞业限制效力等定性判断；劳动合同条款审查；案例检索；仲裁起诉文书起草；社保、个税、公积金的代缴核算。本指引只做金额测算，不替代定性分析。

## 需要准备的材料

缺项的标注「待补」，结果给区间或留空，不臆造：

1. **入职日期 / 离职日期**——计算工作年限（精确到月）。
2. **离职情形**——决定适用哪一项（见下表）。
3. **月工资构成与金额**——计算基数的核心，区分「应得工资」口径。
4. **离职前 12 个月的工资明细**——有奖金、提成、津贴波动的逐月列出求平均。
5. **用工所在地**——决定社平工资 3 倍封顶数额与最低工资等地方标准。
6. **是否签订书面劳动合同、起止时间**——关系二倍工资。
7. **加班事实与举证情况**——加班费需有考勤、审批等证据支撑。
8. **应休未休年假天数**——年假折算项。

## 离职情形与可测算项目

本表只用于确定适用哪一项；是否真正满足某一情形属定性判断，须结合事实与专业意见确认。

| 离职情形 | 可测算项目 |
|---|---|
| 协商一致由用人单位提出解除 | 经济补偿金 N |
| 劳动合同期满终止（单位不续签或降低条件续签被拒） | 经济补偿金 N |
| 用人单位存在欠薪/未缴社保等，劳动者被迫解除 | 经济补偿金 N |
| 医疗期满不能工作 / 不能胜任 / 客观情况重大变化 | N + 代通知金（即 N+1） |
| 经济性裁员 | 经济补偿金 N |
| 用人单位违法解除/终止且劳动者不要求继续履行 | 赔偿金 2N（与 N 二选一，不并得） |
| 用工满一个月未签书面劳动合同 | 二倍工资差额 |
| 存在法定标准外加班 | 加班费 |
| 应休年假未休 | 未休年假工资折算 |

**互斥关系**：违法解除赔偿金 2N 与经济补偿金 N 不并列计算，主张 2N 时不再另算 N。代通知金（「+1」）仅在特定法定情形适用，不可随意叠加到任意解除上。

## 办理步骤

### 第1步：认定工作年限 N

以入职至离职的连续工作时间为准：

- 满 1 年记 1；
- 超过 6 个月不满 1 年的，按 1 年计；
- 不满 6 个月的，按 0.5 计。

示例：3 年 7 个月 → N = 4；3 年 5 个月 → N = 3.5；3 年整 → N = 3。

**年限封顶**：月工资高于用工地上年度职工月平均工资三倍的劳动者，经济补偿的计算年限最高不超过 12 年；月工资未达 3 倍线的，一般不设 12 年上限。是否触发封顶取决于基数与当地社平 3 倍数额的比较，须逐案判断。涉及跨制度年限分段（如分段计算历史工龄）的，分段口径〔待核〕。

### 第2步：确定月工资计算基数

这是最易出错、争议最大的环节，基数口径直接决定全部金额，计算前须先说清楚。

- **基本口径**：劳动合同解除或终止前 12 个月的平均应得工资。
- **应得工资**：通常指税前、代扣代缴个税及社保公积金个人部分之前的工资总额，一般包含计时/计件工资、奖金、津贴、补贴等货币性收入；是否包含某项（如年终奖、报销性补贴、加班费本身）各地认定不一〔待核〕。
- **不满 12 个月**的，按实际工作月数的平均工资计算。
- **上限**：月工资高于用工所在地上年度职工月平均工资三倍的，基数按「3 倍数额」封顶。该数额按地区、按年度发布，以用工地人社部门/统计部门最新公布为准〔待核〕。
- **下限**：基数原则上不低于当地最低工资标准〔待核〕。

```
月工资基数 = min( 离职前12个月平均应得工资 , 当地社平工资3倍〔待核〕 )
（若低于当地最低工资标准〔待核〕，则按最低工资）
```

### 第3步：逐项计算

**1. 经济补偿金 N**

```
经济补偿金 = 月工资基数 × N
```

- N 按第1步取值；基数按第2步口径（含 3 倍封顶）。
- 触发 3 倍封顶时，N 同时受 12 年上限约束：实际计算年限 = min(N, 12)。
- 分步：① 算工作年限 → N；② 算 12 个月平均应得工资；③ 与当地社平 3 倍比较定基数，判断是否封顶并据此决定 N 是否封 12 年；④ 相乘。

**2. 违法解除/终止赔偿金 2N**

```
赔偿金 = 经济补偿金标准 × 2 = 月工资基数 × N × 2
```

- 适用于用人单位违法解除/终止且劳动者不要求继续履行的情形；与 N 互斥。

**3. 代通知金（N+1 中的「+1」）**

```
代通知金 = 上一个月的工资 × 1
```

- 仅在法定「提前30日书面通知」情形下、用人单位未提前通知而以钱代通知时适用（医疗期满不能工作、不能胜任工作、客观情况重大变化三类）。
- 「+1」的基数通常为上月工资，与经济补偿金的「12 个月平均基数」口径可能不同，须分别计算〔待核〕。
- N+1 总额 = 经济补偿金 N + 代通知金。

**4. 未签书面劳动合同二倍工资差额**

```
二倍工资差额 = 应支付二倍工资期间的每月工资 × 1（即额外一倍）× 计算月数
```

- 适用：用工之日起满 1 个月不满 1 年未订立书面劳动合同。
- 起算：自用工满 1 个月的次日起；最长不超过 11 个月（即除正常发放的 1 倍外，额外再付不超过 11 个月的 1 倍）。
- 「额外一倍」的月基数按当月应得工资认定，口径争议处〔待核〕。
- 仲裁时效对可主张期间有影响，时效起算〔待核〕。

**5. 加班费**

加班费计算基数为劳动者正常工作时间月工资对应的小时/日工资（基数认定常有争议〔待核〕）：

```
日工资  = 月计薪基数 ÷ 21.75
小时工资 = 日工资 ÷ 8

工作日延时加班费 = 小时工资 × 加班小时数 × 150%
休息日加班费     = 日工资 × 加班天数 × 200%   （已安排同等补休的可不另付）
法定节假日加班费 = 日工资 × 加班天数 × 300%
```

- 21.75 为制度月计薪天数的通用折算值。
- 加班事实与时长需有考勤、审批等证据支撑；举证不足的只列公式、不推断金额。

**6. 未休年假工资折算**

```
应休未休年假工资 = 日工资 × 应休未休天数 × 300%
其中日工资 = 月工资基数 ÷ 21.75
```

- 300% 通常被理解为包含用人单位正常支付的当天 100% 工资在内，即「额外再补 200%」，但表述口径各地不一〔待核〕。
- 应休天数与工龄挂钩，须确认劳动者累计工龄对应的年假基准天数。

### 第4步：汇总

各适用项分行列出，写明公式与代入数值，再求合计。互斥项（N 与 2N）只取其一。

## 模板

```
【劳动补偿/赔偿测算】

一、基础信息
  · 工作年限：【X】年【X】个月 → N = 【N】
  · 离职前12个月平均应得工资：¥【金额】（口径：税前应得）
  · 当地社平工资3倍封顶：【金额】〔待核〕
  · 采用的月工资基数：¥【金额】（是否封顶：是/否）
  · 离职情形：【情形】

二、分项测算
  1. 经济补偿金 N：¥【金额】
     = 基数 ¥【金额】 × N 【N】
  2. （如适用，与1互斥）违法解除赔偿金 2N：¥【金额】
  3. （如适用）代通知金 +1：¥【金额】（基数：上月工资 ¥【金额】）
  4. （如适用）未签合同二倍工资差额：¥【金额】（【N】个月）
  5. （如适用）加班费：¥【金额】
  6. （如适用）未休年假折算：¥【金额】

三、合计（区间）：¥【金额】～ ¥【金额】
   注：含〔待核〕项时以区间或「待补」呈现，不得估死数。

四、依据与口径说明
  · 各项口径见上文；标注〔待核〕处以用工地最新规定为准。

本结果为测算参考，非正式法律意见；定性问题（是否构成违法解除、是否满足某情形等）
及最终金额需结合具体事实、当地裁判口径并经专业核实，以仲裁/判决为准。
```

## 检查清单：测算红线

1. **不捏造数额**：社平工资、社平 3 倍、最低工资、各地分年度标准一律标〔待核〕并提示核实，不凭记忆填具体数字。
2. **基数口径先讲清**：每次计算前说明「月工资基数」的含义、12 个月平均与 3 倍封顶规则，再代入。
3. **封顶双重检查**：触发社平 3 倍封顶时，同时检查 12 年年限上限。
4. **互斥不并得**：N 与 2N 二选一；「+1」仅限法定情形。
5. **低确定性给区间**：基数有争议、口径分地区、证据不足时，给区间或留「待补」，不输出唯一确定值。
6. **数字注明依据**：引用的标准、倍数、上限，均说明出自哪条规则或标〔待核〕。
7. **不越界做定性**：是否违法解除、是否工伤、竞业是否有效等，另行专业判断。
8. **时效提醒**：涉及二倍工资、加班费等可主张期间时，提示劳动仲裁时效的影响，时效起算〔待核〕。
