---

大多数解除没有问题，少数是等待发生的劳动争议。本指引用于在解除决定最终确定前逐项检查，把第二种情形找出来：高风险标记、工作地特定要求、经济补偿/赔偿金与协商解除协议、书面证据。工作地的具体规则和通知期限每次审查时现查现核，不凭记忆。

## 适用情形

- 审查拟进行的解除；判断「能不能解除这个人」。

## 需要准备的材料

- 员工姓名（或只写岗位）。
- 工作地（员工实际工作的省/直辖市）。
- 解除理由（绩效不达标、严重违纪、经济性裁员、岗位撤销）。
- 本单位工作年限。
- 年龄（涉及医疗期、距退休年限等保护）。
- 同一批次/同一决定中是否还有其他人被解除（涉及经济性裁员人数门槛）。
- 计划解除日期。
- 劳动合同、规章制度、录用通知，以及绩效记录、警告、绩效改进计划（PIP）等书面材料。

## 办理步骤

### 第1步：核实基本事实

按上列材料逐项核实。

### 第2步：高风险标记扫描

这是最重要的一步。默认检查以下标记（公司另有规定的一并检查）：

| 标记 | 为何高风险 | 检查 |
|---|---|---|
| **近期投诉/举报** | 报复性解除索赔 | 该员工近期是否提出过投诉（HR、监察、举报热线）？ |
| **受保护休假/医疗期** | 法定保护期解除 | 目前是否在医疗期、停工留薪期，或刚结束产假/哺乳期？ |
| **特殊保护群体 + 时机** | 违法解除——不得解除情形 | 是否属于《劳动合同法》第42条所列情形（三期女职工、工伤丧失劳动能力、医疗期、连续工作满15年距退休不足5年等）？ |
| **检举/控告** | 打击报复 | 该员工是否曾就违法、安全、欺诈等问题提出过检举或控告？ |
| **书面证据薄弱** | 「为什么现在解除？」 | 绩效解除：是否有绩效改进计划（PIP）、书面警告、有记录的反馈？还是毫无征兆？ |
| **差别对待** | 选择性解除 | 是否有其他人做同样的事且未被解除？ |
| **合同/规章制度承诺** | 违约 | 劳动合同、规章制度、录用通知或任何书面文件是否承诺了一个未被执行的程序？ |
| **工时制度分类错误** | 加班工资争议（150%/200%/300%） | 见下方分类检查 |

**工时制度分类错误标记**，同时满足以下全部条件时触发：

1. 员工所在省/直辖市对工时制度审批和执行有严格规定——北京、上海、广东、江苏、浙江（及公司认定的其他风险地区）；
2. 员工执行的是标准工时制外的特殊工时制（综合计算工时制或不定时工作制）；
3. 员工岗位名称包含「主管」「组长」「协调员」「分析师」「行政」「专员」（或公司认定的同类风险岗位）。

三项全部满足时标出：该岗位在该地执行特殊工时制，但岗位性质和实际工作内容可能不符合适用条件。解除前先做工时制度合规检查（见《工时与工资问题解答》）——被错误适用特殊工时制度的员工一旦解除，即存在成熟的加班工资争议（工作日150%、休息日200%、法定节假日300%），协商解除协议可能无法完全免除该等支付义务。不要因为岗位名称「看起来是管理岗」就忽略此标记——分类错误争议的核心正是岗位名称不等于实际工作性质。

**涉及补发工资计算的**（经济补偿建模、和解方案、风险敞口估计），按《工时与工资问题解答》中加班费计算基数和补发工资的框架计算：加班费计算基数、加班时长、150%/200%/300%倍数，以及劳动争议仲裁时效（《劳动争议调解仲裁法》第27条——一年）。所有补发工资数字标注「需核实——在主张或支付前咨询劳动法律师」〔待核〕。

**任何标记触发 → 在解除进行前按公司上报规则上报。** 在解除之前，不是事后。

### 第3步：工作地特定要求

最终确定方案前，研究员工所在地的适用规则，引用一手来源并核实现行有效：

- **最终工资支付时点**：解除和辞职可能不同。研究现行规则，包括拖延支付的罚则（如《工资支付暂行规定》第9条、各省/直辖市工资支付条例）。
- **未休年休假折算工资**：《职工带薪年休假条例》第5条，按日工资收入的300%支付。
- **经济补偿/赔偿金**：经济补偿按《劳动合同法》第47条（每满一年支付一个月工资）；违法解除按第87条（经济补偿标准的二倍）。
- **通知义务**：是否需要向人社部门报备（经济性裁员需提前30日向工会或全体职工说明情况，并向人社部门报告——《劳动合同法》第41条）；是否有省/直辖市特定的通知要求。
- **经济性裁员**：《劳动合同法》第41条适用条件（裁减20人以上或占职工总数10%以上）、优先留用规则（第41条第2款）、优先招用规则（第41条第3款）。

检索结果很少或没有结果的，如实报告已找到的内容，由律师决定是扩大检索、换用其他来源，还是停下标为待核实；不得用未经核实的内容填补空白。每条引用注明来源。最终工资支付时点、各省/直辖市工资支付条例、经济性裁员的法定程序和司法实践，是最容易引错的主题，优先核验。

### 第4步：经济补偿/赔偿金与协商解除协议

- 是否支付经济补偿？按法定公式还是双方协商？
- 是否需要签署协商解除协议？（支付额外补偿时通常需要——协商一致解除的法律依据为《劳动合同法》第36条）

**解除性质决定补偿标准：**

- **经济补偿（N）**：协商一致解除（第36条）、劳动者被迫解除（第38条）、无过失性解除（第40条）、经济性裁员（第41条）、劳动合同期满终止（第46条）。
- **赔偿金（2N）**：违法解除或终止（第87条），标准为经济补偿标准的二倍。
- **无需补偿**：劳动者主动辞职（第37条——提前30日书面通知）、过失性解除（第39条——严重违纪等）。

协商解除协议另需考虑：

- 各省/直辖市对劳动关系中可处分权利的特殊限制；
- 涉及性骚扰、歧视或其他受保护类别的保密或不得贬损条款的特殊限制；
- 协议不得限制劳动者向劳动监察部门投诉或申请劳动仲裁的法定权利。

### 第5步：书面证据检查

绩效解除尤其要查：

- 是否有书面轨迹？书面警告、绩效改进计划、反馈文件？
- 书面轨迹是否讲述一个一致的故事？
- 是否有书面文件与解除理由相矛盾（近期正面绩效评估、奖金、晋升）？

「为什么现在解除」：如果此人已绩效不达标一年，什么发生了变化？答案应有书面记录。

## 解除前的律师审核

经办人不是律师的，作出「可以解除」的结论或把解除当日清单标为就绪前，须经律师审查。违法解除、歧视、报复和工资争议都源于这一决定的做法。提交律师时附上：

- 员工、工作地、解除理由、计划日期；
- 审查发现的每个高风险标记及详情；
- 工作地特定发现（最终工资、未休年休假、通知义务、经济性裁员规则）及引用来源；
- 经济补偿/赔偿金分析，包括加班费、未休年休假等潜在争议；
- 未解决的问题和未确定事项；
- 可能的风险（该事实模式支持哪些主张）；
- 需要问律师的问题（这是否为干净的解除；解除前是否需要更多书面证据；协商解除协议是否需要特定条款；是否需要错开决定批次）。

需要寻找律师的，可联系当地律师协会或拨打 12348 法律援助热线。劳动法是解除面谈前短暂咨询的价值几乎总是高于事后应诉费用的领域之一。

本审查以第1步确定的工作地为前提。员工在其他省/直辖市或国家工作，或适用法律有争议的，结论可能不适用。

```markdown

**计划日期：** 【日期】
**来源：** 【引用来源及待核验事项】

---

### 底线

【可以进行 / 需先解决某问题 / 停止——一句话说明理由】

【第2步的每个标记：无问题 或 已触发及详情】

**上报：** 【无需 / 在进行前上报至【姓名】——【哪个标记】】

### 工作地要求（【省/直辖市】）

- 经济性裁员通知（如适用）：【规则及引用】

### 经济补偿/赔偿金与协商解除协议

- 补偿/赔偿金：【按公式计算的金额 / 协商金额 / 无】
- 协议：【需要 / 不需要——如需，适用现行法定要求并引用一手来源】
- 【适用的省/直辖市特定规则或协议限制】

### 书面证据

【对书面轨迹的评估，标出缺口】

### 进行 / 不进行

【可以继续 / 进行但需以下修改 / 暂停——等待上报审批】

### 解除当日检查清单

- [ ] 最终工资已准备，金额正确，按当地规则交付
- [ ] 解除证明（《劳动合同法》第50条）已准备
- [ ] 社会保险和公积金转移手续通知已准备
- [ ] 协商解除协议（如适用）已就绪
- [ ] 归还公司财产 / 注销访问权限已协调
- [ ] 【其他】
```

## 不在本指引范围内

- 作出解除决定——本指引审查决定。
- 进行解除面谈——由管理者执行。
- 保证不发生争议——只是通过捕获明显问题降低风险。

## 法律依据

- 《劳动合同法》第36、37、38、39、40、41、42、46、47、50、87条
- 《劳动争议调解仲裁法》第27条
- 《工资支付暂行规定》第9条
- 《职工带薪年休假条例》第5条
- 各省/直辖市工资支付条例
