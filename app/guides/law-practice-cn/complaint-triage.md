处理非政府采购领域的投诉、举报、申诉及其答复时，先把程序分清楚，再确定受理机关、证据和期限。

## 适用情形

- 代表投诉人提出投诉、举报或申诉。
- 代表被投诉人答复投诉。
- 作为处理机关一方，梳理受理和处理程序。

**政府采购质疑投诉不适用本指引**，另按政府采购质疑投诉的程序办理，不得把其前置程序套用到其他渠道。

## 需要准备的材料

- 事项发生日期和知悉日期。
- 相关文书及其版本。
- 送达凭证。
- 证据及其来源。
- 既有沟通记录和已经启动的程序。

## 办理步骤

### 1. 确定角色和程序性质

确认我方是投诉人、被投诉人还是处理机关。区分投诉、举报、申诉、行政复议、诉讼和民事协商，它们的受理机关、条件和期限各不相同。

### 2. 建材料台账

逐项登记上述材料。把四类内容分开记录：

- 当事人陈述；
- 可核实的事实；
- 有争议的事实；
- 法律评价。

### 3. 筛选候选渠道

按事项、地域、主管职责和服务角色筛选候选渠道，逐一核对：

- 受理条件；
- 前置步骤；
- 管辖；
- 是否存在重复处理；
- 保密及个人信息要求。

渠道无法确认的，先列为候选，不写确定的受理机关。

### 4. 计算期限

只有在起算事实、送达证据和适用时点的官方规则都已核实时，才计算期限。缺任何一项的，只给出候选期限窗口，并列明需要立即核对的材料，不断言已经逾期或可以受理。投诉渠道和期限须按具体事项核实现行规定。

### 5. 形成成果

- 程序分流表；
- 争点证据矩阵；
- 相反解释；
- 处理选项；
- 候选期限底稿；
- 文书草稿。

代表被投诉人的，逐项回应投诉内容，不只写一句否认。

提交、发送、公开或联系他人，须经委托人明确授权。

## 检查清单

逐项检查以下维度：适用的写出最低限度的结论；不适用的写明本案为何不适用；受阻的列出缺口和停止路径。受理机关、证据或时点无法确定的，停止相应的确定性程序判断。

| 维度 | 检查内容 |
|---|---|
| 任务背景 | 服务对象、我方角色、最终用途 |
| 管辖 | 地域和主管机关 |
| 时点 | 事实发生日、知悉日、送达日，以及应适用的规则版本 |
| 主体 | 投诉人、被投诉人、处理机关及其他相关方 |
| 事项 | 投诉、举报或申诉的具体内容 |
| 请求与构成要件 | 诉求及其成立条件 |
| 法律依据与解释 | 依据原文、版本、适用时点和相反解释 |
| 证据 | 已有证据、来源、待证事实 |
| 程序 | 渠道、受理条件、前置步骤、期限 |
| 结果与执行 | 可能的处理结果及其执行 |
| 策略与不确定性 | 处理选项、风险、尚未确定的事项 |
| 治理 | 授权、利益冲突、保密、个人信息和对外动作的边界 |

## 常见风险

- 把政府采购质疑投诉的程序套到其他渠道，或反之。
- 渠道未核实就写死受理机关。
- 缺少送达证据或起算事实就断言逾期或可受理。
- 把当事人陈述当作已查明的事实。
- 答复投诉只作概括否认。
- 未经授权提交、发送或公开材料。
