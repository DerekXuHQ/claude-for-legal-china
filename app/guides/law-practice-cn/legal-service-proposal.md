律师向客户提交法律服务方案时，用本指引拆分服务范围、选择收费结构、建立可复算的报价底稿，并分别形成客户版方案和内部审批清单。一般合同价款的审查不适用本指引。

## 适用情形

- 起草法律服务建议书、服务方案和报价。
- 核对已有方案的范围、费用和付款安排。

## 需要准备的材料

- 客户、服务角色、利益冲突审查结果。
- 事项性质、客户方决策人。
- 交付物、时限。
- 团队构成和内部审批要求。
- 客户预算、竞争报价和历史费率——只使用已授权的内部材料，不发送给外部检索或数据服务。

## 办理步骤

### 1. 拆分需求

把客户需求拆为：

- 核心服务；
- 可选服务；
- 明确排除的事项；
- 客户需配合的事项；
- 阶段性交付。

尚需尽调或法律研究才能确定的工作量，列为报价假设，不得暗示承诺结果。

### 2. 选择收费结构

按事项类型列出固定收费、计时收费、分阶段收费等候选结构。

- 风险代理只作为需另行核查的候选：先核对现行法律、地方规则、律所政策和该类事项的禁止或限制性规定，不凭参考表直接推荐。
- 市场价格须有本次可核验的来源，否则不填写区间，不编造价格。

### 3. 建立可复算的底稿

底稿列明：

- 任务；
- 人员；
- 工时或计价基础；
- 税费和第三方费用；
- 范围变更的触发条件；
- 确认程序。

检查小计与总价、付款节点、逾期和终止安排是否一致。

### 4. 形成两份成果

- **客户版方案草稿**：写清范围、团队、成果、时间、费用、排除事项和变更机制。
- **内部版清单**：报价假设、风险和审批事项。

获得授权前，不发送、不签署、不提交报价。

## 检查清单

逐项检查以下维度；与报价无关的维度写明理由。收费合规或事实存在缺口的，停止确定报价。

| 维度 | 检查内容 |
|---|---|
| 任务背景 | 客户需求、服务角色、用途 |
| 管辖 | 适用地区及地方收费规则 |
| 时点 | 方案时限和各阶段时间 |
| 主体 | 客户、决策人、团队成员 |
| 事项 | 事项性质和类型 |
| 请求与构成要件 | 客户目标与服务内容的对应 |
| 法律依据与解释 | 收费相关的法律、地方规则和律所政策 |
| 证据 | 报价依据和市场数据的来源 |
| 程序 | 确认程序、范围变更程序、审批程序 |
| 结果与执行 | 交付物和付款节点 |
| 策略与不确定性 | 报价假设和风险 |
| 治理 | 利益冲突、内部审批、授权和保密 |

## 常见风险

- 服务范围和排除事项写得模糊，后续争议。
- 报价暗示承诺结果。
- 未核实禁限规定就推荐风险代理。
- 填写没有来源的市场价格区间。
- 小计与总价、付款节点不一致。
- 把客户预算或竞争报价发给外部服务。
- 未经审批或授权就发出报价。
