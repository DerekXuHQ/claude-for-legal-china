用于审查中国境内的建设工程施工、总包、分包或代建合同，重点核对付款、工期、变更签证、验收结算和质保。普通 SaaS 合同、保密协议按对应的商事合同审查指引办理。

## 需要准备的材料

- 合同文件（原件只读，修订在工作副本上进行）。
- 我方角色：发包人、承包人、分包人或代建人。
- 项目地点、工程类别、招采背景、合同版本、图纸清单。
- 本次谈判目标。

任何默认立场只是起点，须按本次我方角色校准。

## 办理步骤

1. **核基础事项。** 主体、资质与授权、招投标和审批背景、合同成立与生效、合同与中标文件是否一致。相关规则按项目时点从官方来源核验。
2. **建交易闭环。** 依次检查：范围及界面、价款计量、预付款/进度款/结算、发票税费、变更签证、材料设备、工期顺延、停复工、质量、竣工验收、缺陷责任、保修、解除、索赔、争议解决。逐条核对定义、附件、金额与期限是否相互一致。
3. **逐项出具意见。** 每个重要问题按「条款定位—触发事实—法律风险—履约摩擦—建议改文—可谈判替代—证据/管理动作」写明，并分别说明对我方和相对方的利弊。未经核实，不填入固定的违约金比例或法定期限。
4. **抓审查重点。** 签证权限和时限、工程量确认、工期归因与关键路径、验收与结算的证据链、付款与质保金衔接、实际施工人和分包风险。项目已有专属审核要求的，优先适用。
5. **出具成果。** 风险总览、逐条意见及待核材料。需要批注版或修订版的，保留原件、在副本上作业，并分别核对结构与版式。正式交付前由律师复核。

## 检查清单

按以下十二个方面逐项检查。合同审查重点展开主体、效力、履约、证据和风险；其余方面写明与本任务无关的理由，或说明卡在哪里、缺什么材料。

| 方面 | 说明 |
|---|---|
| 任务背景 | 本次审查的目的和范围 |
| 法域 | 适用法律和地域规则 |
| 时间 | 项目时点及规则的时间效力 |
| 主体 | 各方身份、资质、授权 |
| 事项 | 工程内容与交易安排 |
| 请求与要件 | 可能主张的权利及构成要件 |
| 依据与解释 | 法律依据及条款解释 |
| 证明 | 证据及证据链 |
| 程序 | 争议解决程序 |
| 结果与执行 | 可能的结果及可执行性 |
| 策略与不确定性 | 谈判策略及不确定因素 |
| 治理 | 内部审批、复核和管理动作 |

合同文本的记载不能直接当作实际履行的事实。
