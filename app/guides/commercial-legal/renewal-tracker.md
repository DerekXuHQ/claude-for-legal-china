没有人会把合同读第二遍。续约日期在审查时提取一次，然后应当存放在一个地方，在取消截止日前 45 天提醒，而不是 45 天后才发现。本指引用于维护续约登记册、定期检查即将到来的取消截止日，以及处理已经错过的窗口。

## 适用情形

- 定期（例如每周）检查哪些合同即将续约、必须在何时之前取消。
- 合同审查（SaaS 订阅、供应商协议等）中发现续约条款，需要登记。
- 检查是否已错过取消窗口。

## 续约登记册

每份合同一条记录，建议字段如下：

| 字段 | 含义 |
|---|---|
| 对方当事人、协议名称 | 例如「某 SaaS 公司」「平台订阅协议」 |
| 签署日期 | |
| 初始期限届满日 | 仅作记录 |
| 当前期限届满日 | 计算取消截止日的依据 |
| 续约机制 | 例如「按年自动续约」 |
| 通知期（天） | 例如 60 天 |
| 通知方式 | 例如电子邮件、书面函件 |
| 送达缓冲（天） | 通知寄送在途所需时间 |
| 取消截止日（日历日） | 按通知期倒推的日期 |
| 取消截止日（有效日） | 回退到最后一个工作日后的日期 |
| 最晚发出日 | 有效截止日减去送达缓冲 |
| 截止日说明 | 滚动续约等特殊情况的说明 |
| 计算来源 | 例如「计算所得，须对照通知条款核实」 |
| 续约价格 | 例如「当时价目表（无上限）」 |
| 年度金额 | |
| 业务负责人 | 续约前需要联系的人 |
| 合同管理系统编号、状态、备注 | 例如「定价无上限，续约前重审；替代供应商：X、Y」 |

计算规则：

- **最晚发出日** = 取消截止日（有效日）− 送达缓冲天数，以最晚发出日触发提醒。
- **滚动续约**：保留初始期限届满日作记录，但取消截止日一律按当前期限届满日计算。
- **工作日回退**：每个取消截止日须回退至最后一个工作日。节假日范围按合同约定的管辖法域确定。同时记录日历日和有效日两个日期，以有效日触发提醒。

## 办理步骤

1. **登记。** 合同审查发现续约条款的，把上述字段录入登记册。登记册为空的，可从合同管理系统、电子签约平台批量导入当前协议。
2. **检查即将到来的事项。** 默认看未来 90 天，按紧急程度分组（半开区间）：
   - 🔴 取消截止日在 0-13 天内
   - 🟠 14-44 天
   - 🟡 45-89 天
   可根据需要调整窗口天数（例如 180 天）。
3. **列出建议动作。** 对每条到期事项写明联系谁（业务负责人）、是否仍需要该服务；定价无上限的，提示在失去谈判优势前获取替代报价。
4. **检查已错过的窗口。** 对取消截止日已过的合同，列出选项：
   - 协商逾期取消（很少成功，但值得一问）；
   - 接受续约，现在就标记下一年的取消截止日；
   - 检查协议中是否有其他终止权利。
5. **决定是否续约。** 发送不续约通知、让自动续约生效或签署续约，都会产生法律后果。使用者不是律师的，先与律师审阅。

## 注意事项

- 追踪只提示截止日和负责人；是否续约由业务负责人和律师决定。
- 续约日期应在合同审查时提取，追踪阶段不重新通读合同。
- 计算出的取消截止日须对照合同通知条款核实。

## 模板

### 即将到来的事项

```markdown
## 续约——未来90天

### 🔴 取消截止日在0-13天内

| 对方当事人 | 取消截止日 | 续约日 | 年度金额 | 负责人 | 备注 |
|---|---|---|---|---|---|

### 🟠 取消截止日在14-44天内

【同上表格】

### 🟡 取消截止日在45-89天内

【同上表格】

---

**建议动作：**
- [ ] 【对方当事人】 — 联系【业务负责人】：是否还需要？
- [ ] 【对方当事人】 — 定价无上限；在失去谈判优势前获取替代报价
```

### 已错过的取消窗口

```markdown
## 错过的取消窗口

| 对方当事人 | 原取消截止日 | 续约日 | 状态 |
|---|---|---|---|

**选项：**
- 协商逾期取消（很少成功但值得一问）
- 接受续约，现在标记下一年的取消截止日
- 检查协议中是否有其他终止权利
```
