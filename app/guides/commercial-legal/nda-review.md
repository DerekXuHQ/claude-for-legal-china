---

大多数接收的保密协议没有问题，少数藏有陷阱。本指引用于在几分钟内把保密协议分为绿、黄、红三档：绿色只需签字，黄色需要律师就一两项具体事项过目，红色在浪费任何人时间之前即行停止。销售、BD 人员可在联系法务前自助筛查。

## 需要准备的材料

- 保密协议文本。
- 团队审查指引中经律师确认的「保密协议分类标准」（区分销售方、采购方）。
- 对方当事人背景（大型企业或初创企业等）。

分类标准由各团队自行确定。法律、市场和团队风险容忍度差异太大，本指引不预设保密协议条款的默认立场，只列出需要检查的类别。审查指引没有覆盖的条款，向律师确认立场后补入审查指引，下次保持一致。

## 办理步骤

1. **确定方向。** 判断公司在这份保密协议中处于哪一方：对方在评估本公司产品的，本公司是销售方；本公司在评估对方产品的，是采购方。相互保密协议同样有方向（用谁的模板、谁在评估谁）。判断不了的，向业务人员确认。在结论中注明适用的是哪一方的审查指引。该方向尚无审查指引的，先与律师完成配置再分类。
2. **范围检查。** 先看文件是否超出「保密协议」的名义范围。相互商业保密协议里可能藏有：禁止交易条款、许可授权、排他性、禁止招揽、竞业限制、知识产权转让、优先购买权、最惠国条款，以及管辖范围远超保密争议的仲裁/管辖条款。中国法下，这些条款受《民法典》合同编（第463条及以下）调整，保密协议中植入超范围的实质性权利义务可能被法院认定为格式条款（《民法典》第496-498条）。
   - 含有超出保密范围义务的，**不论条款分析结果如何，一律标黄**，并写明：「本文件名为保密协议，但包含【禁止交易 / 许可授权 / 禁止招揽 / 排他性 / 知识产权转让 / 优先购买权 / 最惠国 / 宽泛仲裁条款】，不只是保密协议，转律师审查。」
   - 不要把实质是服务协议、条款清单或一揽子约定的文件按普通保密协议分类。
3. **逐项检查**（见下文检查清单），对照审查指引判定每项属于绿、黄还是红。
4. **出具分类结论**（格式见下文模板）。
5. **按结论流转。** 绿色进入标准签字流程；黄色交审批人就标注事项决定；红色不进入合同管理系统或审批流程，交法务负责人或指定的上报对象，也不要告知对方我方将签署。
6. **收尾。** 每份结论末尾附团队设定的收尾提示；未设定的，写「将最终保密协议通过标准审批流程处理。」

## 分类标准

| 档位 | 含义 | 处理 |
|---|---|---|
| 绿色——直接签字 | 满足审查指引每一项立场，无任何条款触发红色标志 | 按标准流程签字 |
| 黄色——律师过目 | 一项或多项条款偏离审查指引但不构成交易底线，或出现审查指引未涉及的条款 | 逐项列出，交审批人决定 |
| 红色——停止 | 命中审查指引「绝不接受」清单，或协议结构与团队标准立场不兼容 | 先与法务沟通 |

**绿色的前提。** 绿色是唯一无需律师审查即可签字的路径，只能建立在经律师审查的分类标准上。没有经律师审查的保密协议立场的，不能判绿色，应判黄色，把协议交给能做决定的人。在默认立场上判绿色，等于由非律师设定立场，再由下一个非律师依赖这个立场。

**非律师签字前的关口。** 签署保密协议会使公司受约束。使用者不是律师的，签字前须确认已与律师审阅；没有的，整理一页简报带给律师：对方当事人、保密协议方向（相互/单方）、已做的检查项、审查指引未涵盖的内容、按现状签字可能出现的问题，以及需要问律师的三件事。需要找律师的，可联系中华全国律师协会或当地律师协会获取律师推荐服务。

**对方背景校准。**
- 大型企业（世界500强级）通常不会就保密协议谈判。要判断红色标志是真正的交易底线，还是只是「和我方模板不同」，这个判断交上报对象做。
- 初创企业通常接受我方模板。对方保密协议有问题的，最快的路径往往是改用我方模板。

## 检查清单

各项归入哪一档，由团队审查指引决定。

| 检查项 | 看什么 |
|---|---|
| 相互性 | 相互还是单方。单方的，先做下面的单方问卷，不要直接标红 |
| 保密信息定义 | 范围（仅限标记信息还是一切披露信息）、标记要求、口头披露的确认窗口 |
| 例外排除 | 通常五项：①已为或成为公开信息（非因违约）；②接收方已经拥有的信息；③未参考保密信息独立开发的信息；④从无限制的第三方获得的信息；⑤法律或法院命令要求披露的信息（在法律允许的情况下通知披露方）。要求哪些、严格到什么程度，按审查指引 |
| 残留信息 | 是否允许接收方使用未经辅助记忆保留的信息；审查指引未涉及的，向律师确认 |
| 保密期限和存续期 | 初始保密期限、终止后保密义务的存续期 |
| 限制性约定 | 禁止招揽、竞业限制、排他性。中国法下，竞业限制主要适用于劳动合同关系（《劳动合同法》第23-24条） |
| 律师费 | 律师费转嫁条款。中国法下，律师费的承担一般遵循合同约定，诉讼中法院通常支持合同明确约定的合理律师费 |
| 备份和归档例外 | 销毁/返还条款是否对标准备份和归档保留系统设有例外 |
| 管辖法律 | 按审查指引的管辖法律和管辖地。《涉外民事关系法律适用法》第41条规定涉外合同当事人可以协议选择合同适用的法律，但中国法律有强制性规定的直接适用（第4条），外国法律的适用损害中国社会公共利益的适用中国法（第5条） |

**单方保密协议问卷。** 单方保密协议在某些情况下是合适的。标注前先问：

1. 在此关系中，我方是唯一披露保密信息的一方吗？
2. 是否为了有限、特定的披露目的，例如把我方技术分享给将为其工作的供应商？
3. 是否涉及并购、雇佣或投资？如果是，停止，本指引只适用于商业保密协议，转法务。

根据回答和审查指引立场决定绿、黄、红。

**法域。** 中国法下，商业合同中的竞业限制约定受《民法典》合同编约束，其可执行性需结合合理性和公共利益考量。保密协议涉及团队立场之外的法域的，在结论中注明本分类可能不能照搬。

## 修订要求

- **复杂度过滤。** 需要起草新语言、重构条款或插入实质性新规定的，不在分流阶段处理，写明「第【X】条——转法务审查」。执行摘要只写简单、机械的操作（删除、替换一个词或短语）。
- **清洁协议。** 通过全部检查、无标志问题的，执行摘要只写「未识别出红色标志。按标准流程签字。」不写长报告。
- **修订粒度尽量小。** 修订痕迹是谈判工具，不是重写。整条替换等于告诉对方「我们推翻了你的起草」，既有攻击性，又迫使对方重读整个条款。默认选能达到立场的最小改动：
  - 换一个词优先于换一个短语（「十二（12）」→「二十四（24）」）；
  - 换一个短语优先于换一句话（「由买方支付」→「由买方应付并支付」）；
  - 重构一个子条款优先于替换整句（加「（一）」「（二）」拆分复合条件）；
  - 替换一句话优先于替换整条；
  - 只有对方版本与我方立场相差太远、精准修改反而更难读时，才替换整条，并在转达函中说明：「我们替换了第8.2条而非标注修订，因为变更范围广泛。乐意与贵方逐一说明差异。」
  - 有疑问时，选更小的改动。

## 常见风险

- 名为保密协议，实含禁止交易、知识产权转让、排他等实质义务。
- 在缺少律师确认立场的情况下判绿色并直接签字。
- 结论发送对象超出保密范围：公共频道、全公司列表、对方当事人或其律师、供应商、客户都会使保密保护落空。发送范围在保密圈外的，准备仅限法务的保密版本和去标识化的通用版本，分别发送。

## 模板

结论前加工作成果页眉（律师使用：「保密 — 内部法律分析」；非法务人员使用：「研究笔记 — 非法律意见 — 须经执业律师审查后方可据以行事」）。

### 绿色

```markdown
## 保密协议分类：【对方当事人】

绿色——可签字（适用：【销售方/采购方】审查指引）

### 执行摘要

审查指引下未识别出红色标志。按标准流程签字。

| 检查项 | 状态 | 审查指引出处 |
|---|---|---|
| 【各检查项】 | 【通过/未通过】 | 【审查指引章节】 |

**下一步：** 【提交合同管理系统标准保密协议流程 | 发送给【审批人】签字】
```

### 黄色

```markdown
## 保密协议分类：【对方当事人】

黄色——标注事项待【审批人】审阅

### 执行摘要

- 【一条可操作的修改意见，如「删除禁止招揽条款（第6条）」】

### 标注事项

**1. 【问题】** — 第【X】条
   内容：【一行】
   标注理由：【命中哪项审查指引立场，或「审查指引对此无规定」】
   **法律风险：** 【🔴/🟠/🟡/🟢】 | **商业摩擦：** 【🔴阻碍交易 / 🟠减缓交易 / 🟡困扰客户 / 🟢不可见】
   可能解决方案：【接受 / 就【X】驳回 / 取决于交易背景】

### 其他事项

| 检查项 | 状态 | 审查指引出处 |
|---|---|---|
| 【通过的检查项】 | 通过 | 【审查指引章节】 |

**下一步：** 就标注事项询问【审批人】，可以接受的转入签字流程。
```

### 红色

```markdown
## 保密协议分类：【对方当事人】

红色——不要提交，先与法务沟通

### 执行摘要

- 【一条可操作的修改意见】

### 关键问题

**1. 【问题】** — 第【X】条
   > "【精确引用原文】"
   问题所在：【具体风险；所违反的审查指引立场】
   **法律风险：** 【🔴/🟠/🟡/🟢】 | **商业摩擦：** 【🔴阻碍交易 / 🟠减缓交易 / 🟡困扰客户 / 🟢不可见】
   建议回应：【使用我方模板 | 附具体条款驳回 | 终止】

**下一步：** 将此分类发送给【法务负责人或指定上报对象】。不要提交合同管理系统或审批流程。不要告知对方我方将签署。
```

## 法律依据

- 《民法典》第463条及以下（合同编）、第496-498条（格式条款）
- 《涉外民事关系法律适用法》第4条、第5条、第41条（法律适用选择）
- 《劳动合同法》第23-24条（竞业限制）
