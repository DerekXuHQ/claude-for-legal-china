市场部想说产品是最好的；法务要让它说真话，至少不说可以被证明为假的话。本流程找出会招来竞争对手律师函或监管机构调查的宣传主张，并在尽量保留宣传力度的前提下给出修改方案。

## 适用情形

- 审查落地页、邮件、广告、标语等营销文案。
- 「我们能这么说吗？」「这是夸张还是有问题？」

## 需要准备的材料

- 待审文案（全文）。
- 公司营销宣传标准：比较性宣传政策（允许但须附证实 / 不鼓励 / 绝不）、证实标准（发布前需要什么）、以往被驳回的宣传主张。
- 已有的证实材料（测试数据、调查报告、客户数据等）。
- PRD 或产品经理的确认：产品实际能做到什么。

## 办理步骤

### 1. 检索适用标准

检索适用法域和媒介的现行广告与证实标准，例如《广告法》、《反不正当竞争法》、地方消费者保护规定、行业监管规则和平台政策。

- 确定**具体宣传主张**需要什么证实：由谁测量、何时测量、样本量、比较基础。不只是看档案里有没有「某种」证实。
- 暗示性宣传和比较性宣传加强审查。
- 核实时效：广告执法指南和审查口径会更新。引用原始来源并精确定位。无法确认现行标准的，标出供律师核实，不陈述未经确认的规则。

**只引用与被审宣传有关的标准。** 把市场监管总局的每条指引、每个行业规则、每个执法案例都列一遍，真正起作用的标准反而看不见了。文案里没有推荐、证言或网红内容的，不引用推荐证言规则；没有触发披露规则的宣传，不引用披露规则；文案不针对某行业的，不引用该行业监管规定。一条标准能出现在报告里，是因为它对应一条具体宣传主张；否则删掉。

**引用和来源。**

- 检索结果很少或没有的（市场监管总局规则、广告违法案例、地方消费者保护规定、行业规则、平台政策），如实报告，由律师决定扩大检索、换数据库、联网检索（结果须比照发布机关复核），还是标为未核实。不得用记忆补全。
- 每条引用注明来源。未经检索核实的引用分三层：
  - **稳定的常见条文**（如《广告法》第9条禁用词、第28条虚假广告、《反不正当竞争法》第8条作为概念）：放行前仍需核实，优先级较低。
  - **需核实**：市场监管总局的具体执法行动、广告违法案例、地方消费者保护规定、行业规则、平台政策、判决、门槛、生效日期、近期更新（广告执法指南和推荐证言披露规则更新频繁）。
  - **需精确核实**：具体条款项、司法解释编号、案号，编造风险最高，一律对照原始来源。

### 2. 提取每一条宣传主张

逐句阅读，列出每一个陈述事实、作比较或作承诺的句子或短语。纯粹的主观夸张不列入。

### 3. 分类

以下是审查者应能识别的结构类型。某一措辞是否可能违法，取决于适用法域的现行规则、可用证实和受众，下结论前先检索核实。

**模糊 / 主观宣传**：没有可衡量内容的主观断言，如「管理项目的最佳方式」「您会爱上它」「革命性」。是否构成问题取决于法域、语境和受众，下结论前检索。

**具体事实性宣传**：可衡量、具体，理性的人可能据此作决定。

| 示例 | 需要找的证实 |
|---|---|
| 「比【竞争对手】快 50%」 | 基准测试数据、方法披露、日期 |
| 「10,000 家企业信赖」 | 实际数量（不是累计注册数，而是当前在用） |
| 「每周节省 5 小时」 | 研究或客户数据，披露样本 |
| 「企业级安全」 | 具体指什么？等保级别？说清楚，否则就是一项承诺 |
| 「个人信息保护合规」 | 已完成个人信息保护影响评估、实际配置到位；这是一项合同性承诺 |

**比较性宣传（加强审查）**：点名或暗指竞争对手。放行前检索适用法域和媒介对比较广告的规则。

| 示例 | 修改方向 |
|---|---|
| 「比钉钉快」 | 要么点名并附可辩护的直接对比数据，要么改为「比传统聊天工具更快」并附证实 |
| 「唯一能做 X 的平台」 | 只要有别人能做 X 就是虚假的；改为「第一个做 X 的平台」（如属实）或删去「唯一」 |
| 「【竞争对手】做不到这个」 | 展示己方功能，让受众自己比较 |

公司比较性宣传政策为「绝不」的，全部标出；为「允许但须附证实」的，检查证实。

**暗示性宣传**：没有明说、但理性读者会推断出来的意思。检索适用广告制度对暗示性宣传的处理；暗示性宣传通常与明示宣传承担同样的证实责任。

| 示例 | 暗示 | 修改 |
|---|---|---|
| 「终于，一个安全的替代方案」 | 竞争对手不安全 | 「终于，安全可验证」 |
| 无说明的客户 logo | 这些公司为产品背书 | 「客户包括……」可以；「受到……信赖」暗示更多 |
| 「面向医疗行业打造」 | 符合个人信息保护相关要求 | 澄清或加限定 |
| 「银行级安全」 | 获得金融监管机构认可 | 要么取得认证，要么删除 |

**绝对性宣传**：不容任何差错，一个反例就能证明为假。检索在适用法域下加限定能否解决问题。

| 示例 | 修改方向 |
|---|---|
| 「永不宕机」 | 「99.9% 正常运行时间」（附定义该指标的 SLA） |
| 「100% 准确」 | 一个具体、有证实、绑定基准的百分比 |
| 「保证」 | 只有确实提供附条款的保证时才可用；这会产生担保责任 |
| 「始终」「每个」 | 「通常」「大部分」 |

### 4. 逐条检查并给出判断

每条宣传按下列结构记录（见模板）：宣传原文、类型、档案中的证实、判断（✅ 没问题 / ⚠️ 需要证实 / ⚠️ 需要改写 / 🔴 删除）、建议修改、一句话理由。

### 5. 对照产品核实

产品真的能做到文案说的吗？这不是哲学问题，查 PRD 或问产品经理。常见偏差：文案按早期规格写的，产品后来改了，没人更新文案。

### 6. 披露要求检查

文案涉及下列情形的，适用额外的披露要求。检索适用法域（含平台政策和行业规则）的现行要求并核实时效，这些规则更新频繁。

- **推荐 / 评价**：发言者与广告主之间的利害关系通常需要披露，检索当前的形式和位置要求。
- **网红内容**：检索该渠道和受众当前的标识、清晰度和显著性要求。
- **「效果因人而异」/ 非典型效果**：展示的效果不具代表性时，检索是否需要披露、以何种形式披露。
- **免费试用 / 自动续费 / 默认勾选**：检索自动转付费条款的显著提示和同意要求，关注《消费者权益保护法》和《电子商务法》对自动续费的要求。

### 7. 「可发布」须经律师审核

批准宣传对外发布是一项法律行为：一旦发布，证实缺口和比较宣传的风险就会变成执法或竞争对手挑战的风险。经办人不是法务人员的，给出「可发布：是」之前须确认已经律师审核；未审核的，附一页给律师的简要材料（素材、拟批准的宣传、宣传类型、每条的证实情况、标出的暗示性宣传、文案上线前要问律师的三个问题）。可通过中华全国律师协会或当地律师协会的推荐服务查找律师。「经修改后可发布」「否——需重写」属于审查判断，不受此限。

## 修改稿的写法

- **短素材**（50 字以内，或一条短帖、标题、一句话、标语、短广告）：直接给出改好的文案，读者可以直接复制使用。不能只描述改了什么。
- **中等篇幅**（50-300 字）：给出改好的全文，修改直接写进去。
- **长素材**（300 字以上）：分项列出修改摘要（如「删除宣传 1；宣传 3 删去『任何』；宣传 4 因涉及受监管领域而弱化」），不贴全文。

## 本流程不做的事

- 不写营销文案，只修正文案中有问题的部分。修改建议尽量保留力度，语感由市场人员把握。
- 不证实宣传，只指出哪些需要证实、谁有数据。
- 不审查设计或图像，只审文字。图像暗示某一宣传的（如在竞争对手 logo 上打红叉），标出，视觉审查由人工判断。

## 模板

**单条宣传记录**

```markdown
**宣传：**「【原文】」
**类型：**【具体事实性 | 比较性 | 暗示性 | 绝对性】
**档案中的证实：**【有——链接 | 无 | 不明】
**判断：**【✅ 没问题 | ⚠️ 需要证实 | ⚠️ 需要改写 | 🔴 删除】
**建议修改：**「【保留力度的替代措辞】」
**理由：**【一句话】
```

**审查报告**

```markdown
【保密抬头】

# 营销审查：【活动 / 素材名称】

**审查日期：**【日期】
**素材：**【落地页 / 邮件 / 广告等】

---

## 摘要

共审查【N】条宣传：【N】✅ 【N】⚠️ 【N】🔴

**可发布：**【是 | 经以下修改后 | 否——需重写】

---

## 引用核实

本审查引用的市场监管总局规则、广告违法案例、地方消费者保护规定、行业法规或平台政策，据以放行或否决文案前，须在北大法宝、威科先行、法信等法律数据库或律所研究平台核实准确性和现行生效日期。广告执法指南、平台规则和地方消费者保护规定更新频繁。每条引用均注明来源，标〔待核〕的优先核查。
```

## 法律依据

- 《广告法》第9条、第28条
- 《反不正当竞争法》第8条
- 《消费者权益保护法》《电子商务法》（自动续费相关要求）
