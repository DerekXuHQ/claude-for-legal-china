本篇用于判断一个采购项目适用《政府采购法》、《招标投标法》还是其他采购制度，并识别采购程序和审查职责。制度已经确定、只是修改某一条合同条款的，不适用本篇。

## 需要准备的材料

建立输入卡，逐项填写：

| 字段 | 内容 |
|---|---|
| 采购人法律地位 | 国家机关、事业单位、团体组织、国有企业、其他 |
| 资金来源 | |
| 项目 / 标的 | 货物、工程、服务及具体内容 |
| 预算或估算金额 | |
| 实施地域 | |
| 采购方式 | |
| 公告时间 | |
| 当前阶段 | |
| 本方角色 | 采购人、代理机构、供应商/投标人、监管方等 |

缺少决定性字段的，列出候选制度及其差异，不强行选定。

## 办理步骤

1. **查询规范原文**：按项目适用的时点，查询法律、行政法规、部门规章、地方采购限额标准及项目公告原文。
2. **逐项核对**：按主管机关、规范层级、适用对象、新旧法衔接逐项比对。
3. **形成判断矩阵**：列为“候选制度 — 适用要件 — 已知事实 — 待证事实 — 原文定位 — 核验状态”。
4. **给出程序入口**：说明应走的程序和下一步需要补充的材料清单。法律关系、供应商资格、投诉路径、救济方式按不同制度分别展开。
5. **分层表述**：原始文件、已核实事实、制度评价、程序状态四层分开写，不混同。

## 检查清单

以下十二个方面逐项判断：适用的给出最低限度的输出；不适用的写明与本次制度判断相关的理由；受阻的写明缺口、补充路径，以及因此必须暂停的确定性结论。

- 任务背景
- 管辖
- 时间效力
- 相关主体
- 事项本身
- 请求与构成要件
- 法律依据与解释
- 证据
- 程序
- 结果与执行
- 策略与不确定性
- 内部治理与复核
