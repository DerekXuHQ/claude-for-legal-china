# Claude for Legal China

本地运行的中国大陆法律检索工具。资料全部下载到本机，按法律层级、地区、领域检索到条，带一个会多轮检索的 AI 问答，常用的条文、案例和回答可以收藏。

> 仅供参考，不构成法律意见。重要决定请咨询执业律师。本工具不是 Anthropic 官方产品；"Claude" 是 Anthropic, PBC 的商标，这里只用来说明它可以接 Claude 模型。

## 启动

```bash
./run.sh
```

第一次运行会做四件事，约 10 分钟：建 Python 虚拟环境、下载法规数据（约 210 MB）、抓取最高法指导性案例、建全文索引（约 1.1 GB）。之后再运行几秒就能打开，浏览器会自动打开 <http://127.0.0.1:8765>。

数据更新后重建索引：`./run.sh --rebuild`。只想更新指导性案例：`.venv/bin/python scripts/fetch_cases.py` 后再 `--rebuild`。

需要 Python 3.10 以上。

## 三个页面

- **检索**：按条文、法规名称、指导性案例、实务资料检索；条文和法规可以按层级（法律、司法解释、行政法规、监察法规、地方性法规）、地区、领域筛选，默认只看现行有效的版本。点结果在右侧看全文，可以跳到整部法规并定位到该条，旧版本和尚未生效的版本单独标出。
- **AI 问答**：直接描述情况提问，可以选地区。AI 会在本地资料里检索条文、看法规目录、读原文、查指导性案例和实务资料，然后按「结论摘要 / 适用的规定 / 不适用的规定 / 相关案例 / 处理流程 / 建议 / 可以向律师确认的问题」作答。回答里的引用可以点开看原文。同一对话里可以追问，点「新对话」重新开始。
- **收藏**：条文、法规、案例、实务资料和 AI 回答都能收藏并加备注，保存在本机。

## AI 设置

点右上角「设置」：

| 用法 | 接口类型 | 接口地址 | 模型 |
|---|---|---|---|
| 直连 Anthropic | Anthropic | 留空 | `claude-opus-5-5`（默认） |
| 经 Portkey 调 Claude | Anthropic | Portkey 网关地址 | 按 Portkey 配置填写；附加请求头填 `x-portkey-api-key` 等 |
| DeepSeek 等 OpenAI 兼容接口 | OpenAI 兼容 | 服务商地址 | 服务商的模型名 |

API key 只保存在本机 `data/settings.json`（文件权限 600），只会发给你填写的接口地址。直连 Anthropic 时默认开启服务端拒答回退（`fallbacks: "default"`），模型拒答时自动换模型重试。「分析深度」对应 Anthropic 的 effort，越高越深入、越慢、越贵。

## 数据来源和限制

| 内容 | 来源 | 说明 |
|---|---|---|
| 法律、行政法规、司法解释、监察法规、地方性法规（17,701 部，约 70 万条） | HuggingFace 数据集 [senry5433/china-effective-laws-regulations](https://huggingface.co/datasets/senry5433/china-effective-laws-regulations)，CC0-1.0，快照 2026-08-26 | 数据集作者称内容取自国家法律法规数据库的官方原文。它不是官方汇编，引用前以公报和官方数据库为准。快照之后修改的法律不在里面 |
| 商标法（2026 年修订） | 国家知识产权局公布全文 | 数据集快照之后通过，2027-01-01 施行，单独补入，见 `extras/` |
| 最高人民法院指导性案例 | court.gov.cn「指导性案例」栏目 | 官方公开文件，`scripts/fetch_cases.py` 每秒最多一个请求 |
| 实务要点和处理流程 | 本仓库各插件的 `references/` 和 `skills/` | 仓库内容，随仓库更新 |

没有收录、也不会去抓取的：

- **国家法律法规数据库**：robots.txt 禁止自动采集。所以只用现成的数据集快照，不直接抓取。
- **人民法院案例库**：用户协议禁止汇编和镜像。
- **中国裁判文书网**：禁止商业镜像，文书还涉及个人信息。
- **国家标准全文**：有版权。

数据集的几处处理：

- 同一法规有多个版本都标为"有效"时，按日期最新的一份作为现行版本，其余标"旧版本"。
- 地级市法规按"经××省人大常委会批准"解析所属省份，解析不出的归入"其他"。
- 领域标签按法规标题的关键词粗分，只覆盖约一半法规，不作为法律分类。

## 文件

```
run.sh                  一键启动
server.py               本地服务（只监听 127.0.0.1）
agent.py                AI 检索代理与工具
search.py               检索层（网页和 AI 共用）
static/                 页面
scripts/download_data.py  下载法规数据集
scripts/fetch_cases.py    抓取指导性案例
scripts/build_index.py    建索引
extras/                 数据集之外补充的法规
data/                   下载的数据、索引、设置和收藏（不进 git）
```
