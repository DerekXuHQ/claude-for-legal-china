# AI for Legal China

中国大陆法律法规的桌面检索工具：法律、司法解释、行政法规、地方性法规和最高法指导性案例都装在本机，按层级、地区、领域检索到条，带一个会多轮检索的 AI 问答（接 Portkey 或其他 OpenAI 兼容接口），常用的条文、案例和回答可以收藏。app 会定期到官方网站检查法规更新。

> 仅供参考，不构成法律意见。

## 安装

| 系统 | 安装包 |
|---|---|
| Mac（Apple 芯片：M1 到 M5） | `AIForLegalChina-<版本>-mac-arm64.dmg` |
| Mac（Intel 芯片） | `AIForLegalChina-<版本>-mac-x64.dmg` |
| Windows（x64） | `AIForLegalChina-<版本>-win-x64-setup.exe` |
| Windows（ARM） | `AIForLegalChina-<版本>-win-arm64-setup.exe` |

Mac：打开 DMG，把 app 拖进「应用程序」。安装包没有经过 Apple 公证时，第一次双击会提示「无法验证开发者」：点「完成」，然后到「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」，输入开机密码确认。只需要这一次，之后正常双击即可。

Windows：双击安装程序。没有代码签名时会出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

第一次打开时 app 会解压法规数据、建立全文索引，大约一两分钟，有进度条。之后打开是即时的。数据放在：

- Mac：`~/Library/Application Support/AI for Legal China/data/`
- Windows：`%APPDATA%\AI for Legal China\data\`

## 四个页面

- **检索**：按条文、法规名称、指导性案例、实务资料检索；条文和法规可以按层级、地区（31 个省级行政区）、领域筛选，默认只看现行有效的版本。点结果在右侧看全文，可以跳到整部法规并定位到该条。同一法规有多个版本时，可以逐条对比。
- **AI 问答**：直接描述情况提问，可以选地区。AI 会在本地资料里检索条文、看法规目录、读原文、对比新旧版本、查指导性案例和实务资料，然后按「结论摘要 / 适用的规定 / 不适用的规定 / 相关案例 / 处理流程 / 建议 / 可以向律师确认的问题」作答。回答里的引用可以点开看原文。
- **收藏**：条文、法规、案例、实务资料和 AI 回答都能收藏并加备注。
- **法规更新**：官方网站上新公布的法律、新版本、文本更正和新的指导性案例都记在这里，点开可以看逐条对比。

## 官方文本与更新检查

能取到官方全文的，一律用官方全文，界面上标「官方全文」：

| 内容 | 官方来源 |
|---|---|
| 法律 | 中国人大网「法律文件」栏目 |
| 行政法规 | 国家行政法规库（司法部） |
| 司法解释、指导性案例 | 最高人民法院网站 |

其余文本（主要是地方性法规和较早的法律）来自国家法律法规数据库，经 CC0 数据集 [senry5433/china-effective-laws-regulations](https://huggingface.co/datasets/senry5433/china-effective-laws-regulations)（快照 2026-08-26）获取，界面上注明「尚未与官方网站逐条核对」。

更新检查怎么做：

- **检查新发布**：只看三个网站最近发布的内容，找有没有新法规、新版本、新案例，几分钟。默认每周自动做一次（「设置」里可以改成每天、每 3 天、每月或关闭），也可以在「法规更新」页手动点。
- **全面核对**：把三个网站上的全部法规逐部重新读一遍，和本地现有文本逐条比对，找出入并改正，约 30 分钟。
- 官方版本和本地版本日期相同：用官方全文替换本地文本，有出入的记为「文本更正」。
- 官方版本更新：作为新版本加入。已经施行的直接成为现行版本，旧版本保留可对照；还没施行的标「尚未生效」，现行版本上加注，到了施行日期自动切换。
- 全国人大常委会的修改决定：在被修改的法律上加注，提醒结合决定理解。

访问规则：同一网站两次请求至少间隔 2 秒；网站返回反自动访问的验证页时，立即停止访问该网站，下次再试，不尝试绕过。国家法律法规数据库的 robots.txt 禁止自动采集，app 不访问；人民法院案例库、中国裁判文书网禁止汇编和镜像，不收录。

## AI 设置

点右上角「设置」，填两项就能用：

- **接口地址**：默认 `https://api.portkey.bond/v1`（Portkey）。也可以改成 OpenAI、DeepSeek 等任何 OpenAI 兼容服务的地址。
- **API key**：你自己的 key。

点「连接并读取模型清单」，app 会列出这个 key 能用的全部模型。用哪个模型、分析多深（快速 / 标准 / 深入），在 AI 问答的输入框下方选，app 会记住上次的选择。

API key 只保存在本机 app 数据文件夹的 `settings.json`（仅本人可读），只会发给你填写的接口地址。

## 开发与打包

需要 Node 22 以上；构建数据包另需 Python 3.10 以上。

```bash
npm install
npm run data        # 构建数据包：下载数据集、抓指导性案例、建 base.db、官方全面核对、压缩，约半小时
npm start           # 开发模式运行
npm test            # 单元测试
npm run dist:mac    # Mac Apple 芯片安装包 → dist/
npm run dist:mac:intel
npm run dist:win    # Windows x64 和 arm64 安装包（可以在 Mac 上打）
```

钥匙串里有 Apple「Developer ID Application」证书时，`dist:mac` 会正式签名并公证；没有时用临时签名，别人第一次打开要右键 →「打开」。Windows 没有代码签名证书时，安装会提示「未知发布者」。

```
main.mjs                    Electron 主进程：窗口、菜单、首次准备、定时检查更新
server/api.mjs              本地服务（127.0.0.1 随机端口，带启动令牌）
server/search.mjs           检索
server/agent.mjs            AI 检索代理和工具
server/diff.mjs             版本逐条对比
server/official/            官方网站：访问、解析、并入本地库、更新检查
server/workers/             后台线程：首次准备资料库、检查更新
renderer/                   界面
scripts/                    数据包构建、打包脚本
extras/                     数据集之外补充的法规
```
