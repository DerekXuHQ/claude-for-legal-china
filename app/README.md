# 中国法律检索

中国大陆法律法规的桌面检索工具：法律、司法解释、行政法规、地方性法规和最高法指导性案例都装在本机，按层级、地区、领域检索到条，带一个能办事的法律助理：看合同、出方案审查意见、评估被诉和起诉、起草文书，每件事单独保存（接 Portkey 或其他 OpenAI 兼容接口）。常用的条文、案例和产出可以收藏。app 会定期到官方网站检查法规更新。

> 仅供参考，不构成法律意见。

## 安装

| 系统 | 安装包 |
|---|---|
| Mac（Apple 芯片：M1 到 M5） | `ChinaLawSearch-<版本>-mac-arm64.dmg` |
| Mac（Intel 芯片） | `ChinaLawSearch-<版本>-mac-x64.dmg` |
| Windows（x64） | `ChinaLawSearch-<版本>-win-x64-setup.exe` |
| Windows（ARM） | `ChinaLawSearch-<版本>-win-arm64-setup.exe` |

Mac：打开 DMG，把 app 拖进「应用程序」。安装包没有经过 Apple 公证时，第一次双击会提示「无法验证开发者」：点「完成」，然后到「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」，输入开机密码确认。只需要这一次，之后正常双击即可。

Windows：双击安装程序。没有代码签名时会出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

第一次打开时 app 会解压法规数据、建立全文索引，大约一两分钟，有进度条。之后打开是即时的。数据放在：

- Mac：`~/Library/Application Support/中国法律检索/data/`
- Windows：`%APPDATA%\中国法律检索\data\`

## 页面

- **浏览**：按目录翻看全部内容，不用先搜索。法律法规可以按层级、地区（31 个省级行政区）、领域筛选，按名称拼音或日期排序；指导性案例按编号排列；办案指引按领域分组。点开就能从头读到尾：法规正文带章节目录，按条排版；用「上一部 / 下一部」可以顺着目录一部一部往下翻。
- **检索**：输入法规名称或关键词。名称匹配的法规排在前面，其后是内容匹配的条文；也可以单独检索指导性案例和办案指引。只显示现行有效和尚未施行的版本；旧版本在法规正文页的「其他版本」里，可以打开或逐条对比。
- **法律助理**：把一件事交给助理办。每件事是一个「事项」，左边列表里保存全部历史，随时回来接着办。
  - 可以上传 PDF、Word、图片（截图、照片会自动识别文字）、录音和视频（需要配置语音转文字模型）。
  - 助理先判断这是哪类事（劳动用工、合同审查、方案合规、被诉应对、能不能起诉、期限、主体调查、公司股权、文书起草等 18 类），缺关键事实时先问你；然后按这类事的专业做法检索法条、案例和办案指引，给出结论、依据、金额和期限的计算、下一步和可以直接用的文书。
  - 合同和方案审查分几轮：先查出审查要用的法条，再逐条审查，然后用另一家的模型复核挑错、补漏，最后写成审查意见（含修改后的条款文字和谈判要点）。
  - 回答里提到的每个法条都会回资料库核对，对上的可以点开看原文，对不上的会标出来。
  - 每份产出都可以导出 Word。
- **收藏**：条文、法规、案例、办案指引和助理的产出都能收藏并加备注。
- **法规更新**：官方网站上新公布的法律、新版本、文本更正和新的指导性案例都记在这里，点开可以看逐条对比。

右上角的 ◐ 按钮切换浅色、深色和跟随系统。

**办案指引**是本项目各插件里的实务要点（审查清单、规则要点）和工作流程（某类事务的处理步骤），只读，随 app 更新。

## 官方文本与更新检查

能取到官方全文的，一律用官方全文，界面上标「官方全文」：

| 内容 | 官方来源 |
|---|---|
| 法律 | 中国人大网「法律文件」栏目 |
| 行政法规 | 国家行政法规库（司法部） |
| 司法解释、指导性案例 | 最高人民法院网站 |

其余文本（主要是地方性法规和较早的法律）来自国家法律法规数据库，经 CC0 数据集 [senry5433/china-effective-laws-regulations](https://huggingface.co/datasets/senry5433/china-effective-laws-regulations)（快照 2026-08-26）获取，界面上注明「尚未与官方网站逐条核对」。

更新检查怎么做：

- **检查新发布**：只看三个网站最近发布的内容，找有没有新法规、新版本、新案例，几分钟。默认每周自动做一次（「设置」里可以改成每天、每 3 天、每月或关闭），也可以在「法规更新」页手动点。
- **全面核对**：把三个网站上的全部法规逐部重新读一遍，和本地现有文本逐条比对，找出入并改正，约 30 分钟。
- 官方版本和本地版本日期相同：用官方全文替换本地文本，有出入的记为「文本更正」。
- 官方版本更新：作为新版本加入。已经施行的直接成为现行版本，旧版本保留可对照；还没施行的标「尚未生效」，现行版本上加注，到了施行日期自动切换。
- 全国人大常委会的修改决定：在被修改的法律上加注，提醒结合决定理解。

访问规则：同一网站两次请求至少间隔 2 秒；网站返回反自动访问的验证页时，立即停止访问该网站，下次再试，不尝试绕过。国家法律法规数据库的 robots.txt 禁止自动采集，app 不访问；人民法院案例库、中国裁判文书网禁止汇编和镜像，不收录。

## AI 设置

点右上角「设置」：

- **接口地址**：默认 `https://api.portkey.bond/v1`（Portkey）。也可以改成 OpenAI、DeepSeek 等任何 OpenAI 兼容服务的地址。
- **API key**：你自己的 key。点「连接并读取模型清单」会列出这个 key 能用的全部模型。
- **复核模型**：合同、方案审查时用来交叉复核的模型，默认自动选另一家族的强模型。
- **语音转文字模型**：上传录音、视频和语音输入用；不配置时，可以用系统听写（Mac 连按两下 Fn，Windows 按 Win+H）。

主力模型和分析深度（快速 / 标准 / 深入）在法律助理的输入框下方选，app 会记住上次的选择。API key 只保存在本机 app 数据文件夹的 `settings.json`（仅本人可读），只会发给你填写的接口地址。

助理的设计和评测方法见 `docs/AI-DESIGN.md`、`eval/README.md`。

## 开发与打包

需要 Node 22 以上；构建数据包另需 Python 3.10 以上。

```bash
npm install
npm run data        # 构建数据包：下载数据集、抓指导性案例、建 base.db、官方全面核对、压缩，约半小时
npm start           # 开发模式运行
npm test            # 单元测试
npm run dist:mac    # Mac Apple 芯片安装包 → dist/
npm run dist:mac:intel
npm run dist:win    # Windows x64 和 arm64 安装包（可以在 Mac 上打）
```

钥匙串里有 Apple「Developer ID Application」证书时，`dist:mac` 会正式签名并公证；没有时用临时签名，别人第一次打开要右键 →「打开」。Windows 没有代码签名证书时，安装会提示「未知发布者」。

```
main.mjs                    Electron 主进程：窗口、菜单、首次准备、定时检查更新
server/api.mjs              本地服务（127.0.0.1 随机端口，带启动令牌）
server/search.mjs           检索
server/agent.mjs            AI 检索代理和工具
server/diff.mjs             版本逐条对比
server/official/            官方网站：访问、解析、并入本地库、更新检查
server/workers/             后台线程：首次准备资料库、检查更新
renderer/                   界面
scripts/                    数据包构建、打包脚本
extras/                     数据集之外补充的法规
```
