## 名称与副标题

- 副标题（30 字以内）：法规检索 · 法律助理 · 150 个专项 Agent

## 描述

中国法律检索把现行法律、行政法规、司法解释、地方性法规和指导性案例装进手机，离线也能检索；配上 AI 法律助理和 150 个按完整工作流程办事的专项 Agent，把常见的法律事务做成可以直接用的成品。

**法规检索**
- 全文检索条文、案例和办案指引，标注现行有效、已废止、尚未生效
- 法规原文优先取自中国人大网、国家行政法规库、最高人民法院；定期从官方网站检查新发布的法规
- 收藏条文和案例，随时翻看

**法律助理**
- 用平常的话描述遇到的事，助理先问清关键事实，再给判断、依据和下一步
- 引用的条文逐条对照原文核对，读过原文的条文可以点开查看
- 区分事实、假设和判断，没核实的内容会标出来

**专项 Agent**
- 保密协议三色分流、供应商合同审查、合同修订追踪、起诉状、答辩状、辩护词、量刑测算、经济补偿测算、隐私政策、商标申请……每个 Agent 按完整技能办事，交付指定格式的成品
- 定时 Agent 盯着合同续约、诉讼期限、假期、知识产权续展和法规变化，到期前提醒
- 台账和实务画像：按你们团队的立场、红线和审批人办事

**文件随手读**
- 拍照、截图、扫描件、PDF、Word、录音都能读，中文识别包括生僻字和繁体字
- 导出 Word，用系统分享发给同事

**说明**
- AI 功能需要在「设置」里填写你自己的模型服务 API key；问题和文件只发给你填写的服务商
- 法规库、事项、台账都保存在手机本机
- 内容仅供参考，不构成法律意见

## 隐私政策（放在网页上，网址填进 App Store Connect）

**中国法律检索 隐私政策**

更新日期：2026 年 11 月

1. 我们不收集你的个人信息。本 App 没有账号系统，不使用任何统计、广告或追踪服务。
2. 法规资料库、你建立的事项、上传的文件、台账、实务画像和设置都只保存在你的设备上。
3. 你使用 AI 功能时，你的问题和你选择上传的文件内容，会直接从你的设备发送给你在「设置」里填写的模型服务商（接口地址由你填写）。这些数据如何处理，适用该服务商的隐私政策。我们无法看到这些内容。
4. API key 只保存在你的设备上，只会发送给你填写的接口地址。
5. 首次打开时，App 会从 GitHub 下载法规数据包；你开启「法规更新」时，App 会访问中国人大网、国家行政法规库、最高人民法院网站的公开栏目。这些请求不包含你的个人信息。
6. 麦克风、语音识别、相机、相册权限只在你使用语音输入、拍照识别、选择图片时使用，录音和图片不会被保存或上传到我们这里。
7. 联系方式：通过 GitHub 项目页面（https://github.com/DerekXuHQ/claude-for-legal-china）提交问题。
