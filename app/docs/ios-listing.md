# App Store 上架文字（草稿）

## 名称与副标题

- 名称：中国法律检索
- 副标题（30 字以内）：法规检索 · 法律助理 · 150 个专项 Agent

## 描述

中国法律检索把现行法律、行政法规、司法解释、地方性法规和指导性案例装进手机，离线也能检索；配上 AI 法律助理和 150 个按完整工作流程办事的专项 Agent，把常见的法律事务做成可以直接用的成品。

**法规检索**
- 全文检索条文、案例和办案指引，标注现行有效、已废止、尚未生效
- 法规原文优先取自中国人大网、国家行政法规库、最高人民法院；定期从官方网站检查新发布的法规
- 收藏条文和案例，随时翻看

**法律助理**
- 用平常的话描述遇到的事，助理先问清关键事实，再给判断、依据和下一步
- 引用的条文逐条对照原文核对，读过原文的条文可以点开查看
- 区分事实、假设和判断，没核实的内容会标出来

**专项 Agent**
- 保密协议三色分流、供应商合同审查、合同修订追踪、起诉状、答辩状、辩护词、量刑测算、经济补偿测算、隐私政策、商标申请……每个 Agent 按完整技能办事，交付指定格式的成品
- 定时 Agent 盯着合同续约、诉讼期限、假期、知识产权续展和法规变化，到期前提醒
- 台账和实务画像：按你们团队的立场、红线和审批人办事

**文件随手读**
- 拍照、截图、扫描件、PDF、Word、录音都能读，中文识别包括生僻字和繁体字
- 导出 Word，用系统分享发给同事

**说明**
- 不注册也能检索法规、离线问答（本机小模型）；注册账号并开通后可用在线模型
- 法规库、事项、台账都保存在手机本机
- 内容仅供参考，不构成法律意见

## 隐私政策（放在网页上，网址填进 App Store Connect）

正文见 `app/account-server/privacy.html`（随账号服务部署在 `/privacy`）。要点：

- 不登录也能用；法规库、事项、文件、台账、设置只在设备上。
- 注册账号只保存邮箱、密码摘要、自愿填写的称呼/单位/用途，以及注册和登录时间、设备类型。
- 本机小模型在设备上运行，不上传；在线模型的问题和文件从设备直接发给开通的接口，账号服务不经手。
- 不用任何统计、广告、追踪服务。
- App 内可随时删除账号，服务端立即删除并作废 key。

## App 审核备注（提交时填写）

- 检索、浏览、收藏、台账和「本机小模型」不需要登录。本机小模型在「设置 → AI 设置」下载（约 350 MB），之后离线可用。
- 在线模型（法律助理的完整问答、Agent）需要账号开通。审核用测试账号：〔提交前填写邮箱和密码〕，在「设置 → 账号 → 登录」输入即可。
- 删除账号：「设置 → 账号 → 删除账号」。
- 第一次打开会下载约 110 MB 的法规数据并在本机建立索引，需要 2–5 分钟。
