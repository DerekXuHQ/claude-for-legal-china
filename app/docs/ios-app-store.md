# iOS 版上架 App Store：要做的事

标注说明：没有标注的是已经做好或确定的；〔待核实〕是写这份文档时没有逐条核对官方最新要求的；〔判断〕是建议。

## 一、只有你能做的（需要账号、付款或身份）

1. **加入 Apple Developer Program**（developer.apple.com/programs）。个人或公司都可以；用公司名义上架要先有 D-U-N-S 编码，审批通常要几天。年费在中国大陆是 688 元〔待核实〕。
2. **在 App Store Connect 新建 App**：套装 ID 用 `com.derekxuhq.chinalawsearch`（想换就告诉我，工程里一处改动）。
3. **建一个 App Store Connect API 密钥**（用户和访问 → 集成 → App Store Connect API，角色选 App 管理），把 Issuer ID、Key ID 和下载的 .p8 文件交给 GitHub Secrets；之后 GitHub 每次构建可以自动签名并上传到 TestFlight，你在手机上用 TestFlight 装。
4. **隐私政策网址**：上架必填。内容要点：App 不收集数据；用户的问题和上传的文件只发给用户自己在「设置」里填写的模型服务商；法规库和事项都存在手机本机。可以放在 GitHub Pages 上，我可以起草。

## 二、中国大陆区上架的额外要求

- **App 备案（ICP）**：自 2024 年起，在中国大陆区上架的新 App 需要在 App Store Connect 填写工信部 App 备案号〔待核实最新口径〕。备案要通过有资质的接入服务商办理，以个人或公司主体提交。
- **生成式 AI**：面向中国大陆公众提供生成式人工智能服务，适用《生成式人工智能服务管理暂行办法》（2023 年 8 月 15 日起施行），通常需要完成算法备案和生成式人工智能服务备案（登记）〔待核实对「用户自带 API key、调用第三方模型」这种形态是否同样要求〕。App Store 中国区下架过未完成备案的 AI 应用〔待核实〕。
- 〔判断〕先在中国大陆以外的地区上架（香港、台湾、新加坡、美国等），中国大陆区等备案办完再开。界面里的法律内容只针对中国大陆法，这一点对海外地区的上架没有影响。

## 三、审核时容易被问到的（已经按要求做了的打 ✓）

- ✓ 不下载可执行代码：iOS 版不做「在线更新程序代码」，代码随 App 版本走审核；在线下载的只有法规数据包。
- ✓ 能重新下载的大文件（法规数据库约 1 GB）不进 iCloud 备份。
- ✓ 隐私清单（PrivacyInfo.xcprivacy）：不追踪、不收集；声明了读取启动参数（UserDefaults）和文件修改时间两个理由。
- ✓ 加密出口合规：只用系统 HTTPS，`ITSAppUsesNonExemptEncryption = NO`。
- ✓ 麦克风、语音识别、相机、相册都写了用途说明。
- ✓ 「仅供参考，不构成法律意见」的提示在法律助理输入框下方和每份导出文件里。
- 需要你提供 API key 才能用 AI 功能：审核员没有 key 会卡住。提交时在「App 审核信息」里附一个测试用 key（额度设小一点），并说明检索、浏览、台账等不需要 key 也能用。
- 〔判断〕法律类 App 一般不属于必须以公司名义提交的高度监管类别，但以律所或公司名义提交更稳妥。
