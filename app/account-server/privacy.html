一、不登录也能用

法规检索、浏览、收藏、事项、台账和本机小模型都不需要账号。这些数据只保存在你的设备上，我们看不到。

二、账号收集的信息

只有你注册账号时，我们才保存：邮箱、密码（只存不可逆的加密摘要）、你自愿填写的称呼、单位和申请说明，以及注册时间、最近登录时间和设备类型（iOS 或电脑）。这些信息只用于登录和开通在线模型，不用于广告，不提供给第三方。

账号开通在线模型后，服务端保存为你分配的接口地址和 API key（加密保存），并在你登录后发到你的设备。

三、AI 功能的数据去向

  • 本机小模型：问题和资料只在设备上处理，不上传。模型文件从我们的服务器下载一次。
  • 在线模型：你的问题和你选择上传的文件内容，会从你的设备直接发给为你开通的模型接口（或你在「设置」里自己填写的接口）。我们的账号服务不经手这些内容。

四、其他网络访问

首次打开时，App 会下载法规数据包；开启「法规更新」时，App 会访问官方网站的公开栏目。这些请求不包含你的个人信息。本 App 不使用任何统计、广告或追踪服务。

五、权限

麦克风、语音识别、相机、相册权限只在你使用语音输入、拍照识别、选择图片时使用，录音和图片不会上传到我们这里。

六、删除账号

在 App 的「设置 → 账号」里可以随时删除账号。删除后，服务端会立即删除你的邮箱、密码摘要、申请信息和分配的 API key，并作废该 key。设备上的资料由你自己保留或删除。
