# 中国律师业务

| 技能 | 用途 |
|---|---|
| `cold-start-interview` | 建立服务角色、保密与审批画像 |
| `consultation-analysis` | 可追溯咨询分析和客户答复草稿 |
| `legal-service-proposal` | 法律服务范围、报价底稿与方案草稿 |
| `complaint-triage` | 一般投诉、举报和申诉程序分流 |
| `legal-terminology` | 法律文书用语规范化（改编自 HoriZon，署名见根目录 `NOTICE`） |

具体项目的目录、利益冲突、交付与审批规则以目标工作区为准。政府采购质疑投诉使用 `procurement-legal`。领域 MCP 只声明元典官方入口；真实授权和调用须在宿主核验。
